Q516

シンジケートローンと証書貸付に、純資産維持・経常利益維持・レバレッジ比率の財務制限条項（コベナンツ）が付いている。取締役会への報告の仕組みをどう作ればよいか。これまで取締役会に一度も報告していなかったが問題か。

基本取締役会設置会社監査役設置会社金融機関取引#
A
財務制限条項の一覧と、決算・四半期ごとの判定結果（余裕の幅を含む）を、定期的に取締役会に報告する仕組みを作るべきです。財務制限条項に抵触すると、銀行の請求で借入金全額の期限の利益を失うおそれがあり、会社に著しい損害を及ぼし得る事項だからです。
会社法上、財務制限条項の報告を直接義務づける条文はありませんが、取締役会は代表取締役等の職務執行を監督し（362条2項2号）、業務執行取締役は3か月に1回以上職務執行の状況を報告しなければなりません（363条2項）。大会社などでは損失の危険の管理体制（内部統制）を決める義務もあります（362条4項6号）。財務制限条項の管理はその典型的な対象です。
これまで報告していなかったことが直ちに違法になるわけではありませんが、抵触が近づいていたのに取締役会が知らなかったとなると、取締役の監督義務が問われ得ます。次の取締役会から報告を始めてください。

根拠が明らかでない点（推測を含みます）

  • 財務制限条項の遵守状況を取締役会に報告しなかったことが、それだけで取締役の責任につながるとした判例は確認できていません。本文は、監督義務・リスク管理体制の一般論からの整理です。
  • 「余裕が10％を下回ったら臨時報告」は実務上の目安の例で、法令・判例の根拠はありません。

実務のポイント

  • コベナンツ一覧を作る：契約ごとに、指標の定義（単体か連結か、どの数値を使うか）、基準値、判定時期、抵触した場合の効果（請求喪失・当然喪失・金利上乗せ等）、銀行への報告期限。
  • 判定結果は「適合／不適合」だけでなく、基準値までの余裕（例：純資産が基準の何％上か）と、次回判定の見込みも報告する。
  • 指標の定義は契約ごとに違う（例：「経常損益が2期連続で損失とならないこと」「純資産を前期末の75％以上に維持」）。財務部門が定義に沿って計算し、経理・監査役が確認する。
  • 業績予想の修正、減損、特別損失の計上を検討する段階で、コベナンツへの影響を同時に計算させる。
  • 銀行への遵守状況の報告書（コンプライアンス・サーティフィケート）の提出期限も一覧で管理する。

進め方

  1. 財務部門が全借入契約の財務制限条項を洗い出し、一覧表を作る。
  2. 取締役会規程又は報告事項の一覧に「財務制限条項の遵守状況（四半期ごと）」を加える。
  3. 決算・四半期決算の確定後、財務部門が判定し、経理部門と監査役に共有する。
  4. 取締役会で、判定結果・余裕の幅・見通しを報告する（363条2項の職務執行状況の報告とあわせてよい）。
  5. 余裕が一定の幅（例：10％）を下回ったら、臨時に報告し、対応策の検討を始める。
  6. 銀行への遵守状況の報告書を期限内に提出し、控えを保管する。

すでに手続を欠いてしまった場合（事後の是正）

財務制限条項の遵守状況を取締役会・監査役に報告しないまま運用していた場合（抵触はまだ生じていない）

  1. 財務部門に全契約の財務制限条項の一覧と、直近の判定結果・余裕の幅をまとめさせる。
  2. 次の取締役会で、これまで報告していなかった事実と現状を報告し、監査役にも共有する。
  3. 取締役会規程・報告事項一覧を改め、四半期ごとの報告と臨時報告の基準を定める。
  4. 内部統制の基本方針（損失の危険の管理）に財務制限条項の管理を加えるかを検討する。
  5. 銀行への遵守状況報告書の提出漏れがないかも確認し、漏れていれば直ちに提出する。

注1取締役会は代表取締役の業務を監督する 重要
  1. 条文
    会社法 362条2項 二号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 二　取締役の職務の執行の監督
  2. 条文
    会社法 363条2項 （取締役会設置会社の取締役の権限）

    第2項　前項各号に掲げる取締役は、三箇月に一回以上、自己の職務の執行の状況を取締役会に報告しなければならない。

  3. やさしく言うと

    取締役会の仕事の一つは、社長などが仕事をきちんとしているか監督することです。そのため、業務を執行する取締役は、3か月に1回以上、取締役会に仕事の状況を報告しなければなりません。

  4. この事例では

    財務制限条項を守れているかは、会社の資金繰りの根幹に関わる情報です。四半期ごとの職務執行状況の報告の中に、財務担当取締役から遵守状況を報告させる項目を設けるのが効率的です。

  5. 実務のコツ

    報告は数字の羅列にせず、「あと何円の損失で抵触するか」を示すと、取締役が危険の大きさを判断しやすくなります。

注2財務制限条項の管理は「損失の危険の管理体制」の一部
  1. 条文
    会社法施行規則 100条1項 二号 （業務の適正を確保するための体制）

    第1項　法第三百六十二条第四項第六号に規定する法務省令で定める体制は、当該株式会社における次に掲げる体制とする。

    • 二　当該株式会社の損失の危険の管理に関する規程その他の体制
  2. やさしく言うと

    取締役会は、会社が損をする危険を管理する仕組み（リスク管理体制）を決めます。大会社などでは、この体制の決定が義務になっています。

  3. 判例
    リスク管理体制構築義務（日本システム技術事件）
    最高裁判所第一小法廷 平成21年7月9日 判決（集民231号241頁）

    従業員の架空売上げ計上により有価証券報告書に虚偽記載がされ株主が損害を被った事案で、会社が営業部と財務部の分離や売掛金残高の確認など通常想定される不正を防止しうる体制を整えており、不正行為が通常容易に想定し難い巧妙な方法によるものであったことなどから、代表取締役にリスク管理体制構築義務違反の過失はないとした判決。

    代表取締役のリスク管理体制の構築義務が問題になった判例です。通常想定される不正を防止できる程度の体制を整えていたかを基準にしています。財務制限条項の管理も、通常想定される危険（業績悪化による抵触）に備える体制として考えることができます。

  4. この事例では

    内部統制の基本方針の「損失の危険の管理」の項目に、資金調達契約の財務制限条項の管理と取締役会への報告を明記しておくと、体制として位置づけが明確になります。

  5. 落とし穴

    財務部門だけが把握していて、取締役会も監査役も知らないまま抵触した場合、取締役の監督が不十分だったと評価されるおそれがあります。

注3著しい損害のおそれがあれば、監査役への報告も必要
  1. 条文
    会社法 357条1項 （取締役の報告義務）

    第1項　取締役は、株式会社に著しい損害を及ぼすおそれのある事実があることを発見したときは、直ちに、当該事実を株主（監査役設置会社にあっては、監査役）に報告しなければならない。

  2. やさしく言うと

    取締役は、会社に大きな損害が出るおそれのある事実を見つけたら、すぐに監査役（監査役会設置会社では監査役会）に報告しなければなりません。

  3. この事例では

    財務制限条項への抵触が確実になり、借入金の一括返済を求められるおそれが生じた場合は、この報告の対象になり得ます。取締役会への報告とは別に、監査役にも直ちに報告してください。

  4. 落とし穴

    「まだ判定日前だから」と報告を遅らせないでください。この報告は「おそれ」の段階で必要です。

実務取締役会決議あり取締役会設置会社金融機関取引#
A
抵触が見込まれた段階で、取締役会に報告し、銀行（シンジケートローンではエージェントを通じて貸付人）に事前に説明して、権利放棄（ウェイバー）又は条項の変更を申し入れるのが基本です。抵触してからの交渉より、抵触前の方が銀行の理解を得やすく、条件も有利になりやすいからです。
ウェイバーの申請そのものは、法律上必ず取締役会決議が要る行為ではありません。しかし、①銀行が条件として金利の引上げ、担保の提供、配当の制限などを求めることが多く、それらは多額の借財の条件変更や重要な財産の処分に当たり得ること、②申請の方針は会社の資金繰り全体に関わる重要な判断であること、から、取締役会で方針と交渉の範囲を決議しておくべきです。
交渉の結果、契約の変更契約（アメンドメント）を結ぶ場合は、その条件で改めて取締役会の決議（又は事前に決めた範囲内であることの確認）を経てください。

根拠が明らかでない点（推測を含みます）

  • ウェイバーの申請自体に取締役会決議が必要とする法令・判例はありません。本文の「決議しておくべき」は、条件変更が多額の借財・重要な財産の処分に関わることからの実務上の推奨です。
  • ウェイバー（一回限りの権利不行使）が開示府令19条2項12号の5の「財務上の特約の内容の変更」に当たるかは、確認できた解釈資料がありません。
  • シンジケートローンでウェイバーに必要な同意の範囲（多数貸付人か全貸付人か）は契約ごとに異なります。

実務のポイント

  • 抵触の見込み額・時期・原因と、改善策（資産売却、コスト削減、増資等）を数字で示せる資料を作ってから銀行に行く。
  • シンジケートローンでは、ウェイバーや条項変更に「多数貸付人」又は「全貸付人」の同意が必要とされることが多い。どちらが必要か契約で確認する。
  • ウェイバーの範囲（今回の判定期だけか、次期以降も緩和するか）と、手数料・金利上乗せ・追加担保などの条件を事前に想定し、取締役会で許容範囲を決めておく。
  • 他の借入契約にも同じ指標の条項やクロスデフォルト条項がないか確認し、全行に同時に対応する。
  • 上場会社では、財務上の特約の内容の変更や特約に定める事由の発生が臨時報告書の対象になる場合がある。

財務制限条項への抵触は、通常、銀行の請求によって期限の利益を失う事由です。銀行が請求すれば、借入金の全額を直ちに返す義務が生じ、他行の契約のクロスデフォルト条項にも波及し得ます。こうした事態は会社に著しい損害を及ぼすおそれがあるので、取締役は監査役に報告する義務を負います（会社法357条1項）。

法律上の注意点 注釈3件・クリックで開く

注1著しい損害のおそれは、直ちに監査役に報告する 重要
  1. 条文
    会社法 357条1項 （取締役の報告義務）

    第1項　取締役は、株式会社に著しい損害を及ぼすおそれのある事実があることを発見したときは、直ちに、当該事実を株主（監査役設置会社にあっては、監査役）に報告しなければならない。

  2. やさしく言うと

    取締役は、会社に大きな損害が出るおそれがあることに気づいたら、すぐに監査役に報告しなければなりません。

  3. この事例では

    抵触により借入金全額の一括返済を求められるおそれがあり、他行の借入れにも波及し得るので、典型的な「著しい損害のおそれ」です。財務担当取締役は、取締役会の開催を待たずに監査役に報告してください。

  4. 落とし穴

    財務部長（使用人）が気づいて取締役に上げなかった場合でも、その後に知った取締役は直ちに報告する義務を負います。報告の遅れが重なると、取締役の責任の問題になり得ます。

注2抵触すると期限の利益を失うことがある
  1. 条文
    民法 137条 （期限の利益の喪失）

    次に掲げる場合には、債務者は、期限の利益を主張することができない。

    • 一　債務者が破産手続開始の決定を受けたとき。
    • 二　債務者が担保を滅失させ、損傷させ、又は減少させたとき。
    • 三　債務者が担保を供する義務を負う場合において、これを供しないとき。
  2. やさしく言うと

    民法では、破産などごく限られた場合にだけ、借り手は期限の利益（期限まで返さなくてよい利益）を失います。

  3. 用語

    請求喪失事由：その事実が起きただけでは期限の利益を失わず、銀行が請求（通知）したときに初めて失う事由。財務制限条項への抵触は、多くの契約でこの扱いです。

  4. この事例では

    財務制限条項への抵触は、契約で定めた期限の利益喪失事由です。銀行が請求するまでは期限の利益を失わないのが通常なので、請求される前にウェイバーを得ることが目標になります。

  5. 実務のコツ

    銀行がすぐに請求しない場合でも、「権利を放棄した」ことにはなりません。書面でウェイバーを受け取るまで、問題は解決していないと考えてください。

注3継続企業の前提に関する注記の要否を検討する
  1. 条文
    会社計算規則 100条1項 （継続企業の前提に関する注記）

    継続企業の前提に関する注記は、事業年度の末日において、当該株式会社が将来にわたって事業を継続するとの前提（以下この条において「継続企業の前提」という。）に重要な疑義を生じさせるような事象又は状況が存在する場合であって、当該事象又は状況を解消し、又は改善するための対応をしてもなお継続企業の前提に関する重要な不確実性が認められるとき（当該事業年度の末日後に当該重要な不確実性が認められなくなった場合を除く。）における次に掲げる事項とする。

    • 一　当該事象又は状況が存在する旨及びその内容
    • 二　当該事象又は状況を解消し、又は改善するための対応策
    • 三　当該重要な不確実性が認められる旨及びその理由
    • 四　当該重要な不確実性の影響を計算書類（連結注記表にあっては、連結計算書類）に反映しているか否かの別
  2. やさしく言うと

    会社が今後も事業を続けられるかに大きな疑いが生じる状況があり、対策をとってもなお重要な不確実性が残る場合は、計算書類にその旨を注記します。

  3. この事例では

    財務制限条項への抵触は、そうした状況の一つとして検討の対象になり得ます。ただし、銀行からウェイバーを得られた、資金繰りに問題がない、など対応策で不確実性が解消すれば、注記は不要になることがあります。銀行との交渉の状況を会計監査人と共有し、判断してください。

  4. 落とし穴

    注記の要否は計算書類の承認（取締役会・株主総会）の前に固める必要があります。交渉が決算発表の日程に間に合うよう、早く動いてください。

注1子会社への支援も、親会社にとっての重要な業務執行 重要
  1. 条文
    会社法 362条4項 一・二号 （取締役会の権限等）

    第4項　取締役会は、次に掲げる事項その他の重要な業務執行の決定を取締役に委任することができない。

    • 一　重要な財産の処分及び譲受け
    • 二　多額の借財
  2. やさしく言うと

    大切な財産の処分（大きな貸付けを含むと解されている）や大きな借入れ・保証は、取締役会で決めます。

  3. この事例では

    子会社への多額の貸付けは「重要な財産の処分」として、子会社の借入れの保証は「多額の借財」として、親会社の取締役会決議が必要になり得ます。付議基準に照らして判断してください。

  4. 落とし穴

    子会社を支援することが親会社の利益になるか（回収の見込み、支援しない場合の損失との比較）を審議しないまま支援すると、親会社の取締役の善管注意義務が問われ得ます。比較の資料を上程書に付けてください。

注3子会社の取締役と親会社の取締役を兼ねる場合

    会社法 356条1項 二号 （競業及び利益相反取引の制限）

    第1項　取締役は、次に掲げる場合には、株主総会において、当該取引につき重要な事実を開示し、その承認を受けなければならない。

    • 二　取締役が自己又は第三者のために株式会社と取引をしようとするとき。
  2. やさしく言うと

    取締役が他の会社のために会社と取引をするときは、取締役会の承認が必要です。

  3. この事例では

    親会社の取締役が子会社の代表取締役として親会社と貸付契約を結ぶ場合、完全子会社（100％子会社）との取引は、会社同士の利益が実質的に対立しないため利益相反取引の承認は不要と一般に解されています。完全子会社でない場合は、他の株主がいるので、承認を得る方が安全です。

    利益相反取引に当たるときは、兼任する取締役が特別利害関係人として議決に加われない場合があります。人数の計算に注意してください。

  • 臨時報告書の対象かは、①特約が「財務指標の基準を維持できないと期限の利益を失う」ものか、②元本が純資産額の10％以上か、③連結子会社との契約でないか、の3点で判定する。

  • 記載事項（契約の締結日・相手方の属性・元本・弁済期限・担保・特約の内容、事由の内容と発生日、対応策）を準備する。対応策はウェイバーの申請状況など具体的に書く。

    会社の大切な財産を処分すること（担保に入れることを含む）は、取締役会で決めなければなりません。

    取締役会決議を要する重要な財産の処分
    最高裁判所第一小法廷 平成6年1月20日 判決（民集48巻1号1頁）

    重要な財産の処分に当たるかは、財産の価額、総資産に占める割合、保有目的、処分行為の態様、従来の取扱い等を総合考慮して判断するとし、総資産の約1.6％に当たる株式の譲渡について、重要な財産の処分に当たらないとはいえないとした判決。

    「重要な財産の処分」に当たるかは、財産の価額、総資産に占める割合、保有目的、処分の態様、従来の取扱いなどを総合して判断するとした判例です。本社不動産は事業の基盤なので、担保設定は重要な財産の処分に当たる可能性が高いと考えられます。

  4. この事例では

    根抵当権の設定は、取締役会で、対象不動産、極度額、被担保債権の範囲を特定して決議します。銀行は登記の際に議事録の写しを確認することが多いので、議事録にこれらを省略せずに書いてください。

  5. 落とし穴

    被担保債権の範囲を「銀行取引による一切の債権」とすると、今後の借入れ全てが担保されます。ウェイバーの条件なら、範囲を限定するよう交渉してください。

注1期限の利益を失うと、銀行は預金と相殺できる 重要
  1. 条文
    民法 505条1項 （相殺の要件等）

    第1項　二人が互いに同種の目的を有する債務を負担する場合において、双方の債務が弁済期にあるときは、各債務者は、その対当額について相殺によってその債務を免れることができる。ただし、債務の性質がこれを許さないときは、この限りでない。

  2. やさしく言うと

    お互いに同じ種類の債務（お金の支払義務）を負っていて、両方の支払期限が来ていれば、差し引きで消すこと（相殺）ができます。

  3. この事例では

    会社が期限の利益を失うと借入金の返済期限が来るので、銀行は会社の預金（銀行から見れば預金の払戻し義務）と相殺できます。預金の拘束は相殺の準備です。相殺されれば預金は戻らないので、給与などの支払は他行の口座から行う前提で資金繰りを組み直してください。

  4. 落とし穴

    拘束された口座に入金があると、その分も相殺の対象になり得ます。入金口座の変更を検討する場合は、他の銀行との契約や取引先への影響も含めて判断してください。

注2緊急時は招集手続を省略して取締役会を開ける
  1. 条文
    会社法 368条2項 （招集手続）

    第2項　前項の規定にかかわらず、取締役会は、取締役（監査役設置会社にあっては、取締役及び監査役）の全員の同意があるときは、招集の手続を経ることなく開催することができる。

  2. やさしく言うと

    取締役（監査役設置会社では監査役も）の全員が同意すれば、1週間前の招集通知なしで取締役会を開けます。

  3. この事例では

    当日中に取締役会を開き、資金繰りと対応方針を決めます。WEB会議での出席も活用し、全員の同意を得た事実を議事録に書いてください。全員の同意が得られなければ、定款で短縮した招集期間で開きます。

  4. 実務のコツ

    同意はメールで取り付け、記録を保存しておくと、後で手続が争われたときの証拠になります。

注3見通しが立たなければ、早めに法的整理を検討する
  1. 条文
    民事再生法 21条1項 （再生手続開始の申立て）

    第1項　債務者に破産手続開始の原因となる事実の生ずるおそれがあるときは、債務者は、裁判所に対し、再生手続開始の申立てをすることができる。債務者が事業の継続に著しい支障を来すことなく弁済期にある債務を弁済することができないときも、同様とする。

  2. やさしく言うと

    会社が破産しそうな「おそれ」の段階で、民事再生の申立てができます。支払期限の来た債務を、事業に大きな支障を出さずには払えない場合も同様です。

  3. なぜこのルールか

    完全に資金が尽きてからでは、事業を続けながら再建することができません。早い段階で申し立てられるようにして、事業の価値を守るための制度です。

  4. この事例では

    資金繰り表で「給与や税金が払えなくなる日」が見えたら、その前に申立てを判断できるよう、弁護士と書類の準備を始めてください。申立ての決定は取締役会で行うのが通常です（再生の節を参照）。

  5. 落とし穴

    返済の見込みがないのに仕入れを続けたり、一部の債権者だけに返済したりすると、取締役の第三者に対する責任や、後の手続での否認の問題につながるおそれがあります。弁護士の助言を受けて行動してください。
