Q163

役員改選と定款変更を行った定時株主総会の議事録を作りたい。登記にもそのまま使える議事録には、何を書けばよいか。

基本取締役会設置会社監査役設置会社非公開会社公開会社#
A
株主総会議事録には、会社法施行規則72条3項の事項を記載します。具体的には、①開催の日時・場所（その場にいない役員・株主がオンライン等で出席した場合はその方法）、②議事の経過の要領とその結果、③監査役等が法律に基づいて述べた意見・発言の概要、④出席した取締役・監査役・会計監査人等の氏名、⑤議長の氏名、⑥議事録の作成に係る職務を行った取締役の氏名です。
登記に使う場合は、これに加えて、法務局が決議要件の充足を確認できるよう、議決権を行使できる株主の議決権の数と出席株主の議決権の数、各議案の賛成の程度（過半数・3分の2以上など）、選任された役員の氏名と就任承諾の有無を明確に書くのが実務です。
議事録は総会の日から10年間本店に、写しを5年間支店に備え置きます（会社法318条2項・3項）。

根拠が明らかでない点（推測を含みます）

  • 議決権の総数・出席議決権数・賛成の程度を書くのは、登記で決議要件の充足を確認してもらうための実務上の工夫で、会社法施行規則72条3項が直接求める記載事項ではありません。
  • 「被選任者は席上就任を承諾した」と記載した議事録を就任承諾書として援用できる扱いは登記実務の運用とされていますが、本サイトでは法務局の先例の原文を確認していません。新任の取締役で印鑑証明書や本人確認証明書が必要な場合の扱いも含め、司法書士に確認してください。

実務のポイント

  • 法定の記載事項（施行規則72条3項1号〜6号）を漏れなく書く。特に「作成に係る職務を行った取締役」の記載漏れが多い。
  • 定足数・決議要件の判断材料（議決権の総数、出席議決権数）を書く。特別決議の議案は「3分の2以上の賛成」と書く。
  • 選任議案は、被選任者の氏名を書き、「被選任者は席上就任を承諾した」と書けば、議事録を就任承諾書として援用できる（出席している場合）。
  • 報告事項も「議事の経過の要領」として報告した旨を書く。
  • 定款で議事録への署名・記名押印を定めていれば、それに従う。

進め方

  1. 総会当日の記録（出席株主数・議決権数の集計、シナリオ、質疑メモ）を集める。
  2. 施行規則72条3項の事項に沿って議事録案を作成する。
  3. 議長・担当取締役・監査役に内容を確認してもらう。
  4. 定款の定めや登記の必要に応じて、記名押印（又は電子署名）をする。
  5. 本店に原本を、支店に写しを備え置く。
  6. 登記事項があれば、総会の日（効力発生日）から2週間以内に登記を申請する。

すでに手続を欠いてしまった場合（事後の是正）

株主総会議事録を作成していなかった、又は法定の記載事項（議長の氏名、作成に係る職務を行った取締役の氏名など）が欠けた議事録を備え置いていた場合

  1. 当日の資料（シナリオ、出席・議決権の集計表、録音）を集め、実際に行われた議事と決議を確認する。
  2. 欠けている記載事項を補った議事録を作成する（作成日は実際の作成日とし、総会の日付をさかのぼって偽らない）。
  3. 登記に使った議事録に誤りがあった場合は、登記の内容に影響するかを司法書士に確認し、必要なら更正登記をする（商業登記法132条）。
  4. 本店に議事録を備え置き（会社法318条2項）、支店にも写しを備える（同条3項）。
  5. 議事録の不作成・記載漏れ・備置きの懈怠は過料の対象になり得る（会社法976条7号・8号）ことを踏まえ、次回から作成者・作成期限・チェック担当を決めておく。

注1議事録は必ず作成し、10年間備え置く 重要
  1. 条文
    会社法 318条1項 （議事録）

    第1項　株主総会の議事については、法務省令で定めるところにより、議事録を作成しなければならない。

  2. 条文
    会社法 318条2項 （議事録）

    第2項　株式会社は、株主総会の日から十年間、前項の議事録をその本店に備え置かなければならない。

  3. やさしく言うと

    株主総会を開いたら、省令に従って議事録を作り、総会の日から10年間本店に置いておかなければなりません。支店にも写しを5年間置きます（電子データで支店から閲覧できる措置をとれば不要）。

  4. なぜこのルールか

    総会で何が決まったかは、株主・債権者・登記所が後から確認する必要があり、決議の効力が争われたときの重要な証拠にもなります。

  5. この事例では

    議事録の作成を怠ったり、書くべき事項を書かなかったり、虚偽の記載をしたりすると、取締役が過料の対象になります（会社法976条7号）。登記に使わない総会でも、必ず作成してください。

注2議事録の法定記載事項 重要
  1. 条文
    会社法施行規則 72条3項 一・二・四・五・六号 （議事録）

    第3項　株主総会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 一　株主総会が開催された日時及び場所（当該場所に存しない取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役。第四号において同じ。）、執行役、会計参与、監査役、会計監査人又は株主が株主総会に出席をした場合における当該出席の方法を含む。）
    • 二　株主総会の議事の経過の要領及びその結果
    • 四　株主総会に出席した取締役、執行役、会計参与、監査役又は会計監査人の氏名又は名称
    • 五　株主総会の議長が存するときは、議長の氏名
    • 六　議事録の作成に係る職務を行った取締役の氏名
  2. やさしく言うと

    議事録には、開催日時と場所、議事の流れの要点と結果、出席した役員の名前、議長の名前、議事録を作った取締役の名前を書きます。オンラインで出席した役員や株主がいれば、その出席方法も書きます。

  3. この事例では

    見本の議事録は、1号＝１・２、2号＝６、4号＝３、5号＝４、6号＝７に対応させています。自社の様式を作るときは、各号との対応表を作って漏れがないか確認すると確実です。

  4. 実務のコツ

    「議事の経過の要領」は、発言を逐語で書く必要はなく、議案の説明・主な質疑・採決の方法と結果が分かれば足ります。

注1会社法上、総会議事録に署名義務はない
  1. 条文
    会社法 318条1項 （議事録）

    第1項　株主総会の議事については、法務省令で定めるところにより、議事録を作成しなければならない。

  2. 条文
    会社法 369条3項 （取締役会の決議）

    第3項　取締役会の議事については、法務省令で定めるところにより、議事録を作成し、議事録が書面をもって作成されているときは、出席した取締役及び監査役は、これに署名し、又は記名押印しなければならない。

  3. やさしく言うと

    株主総会の議事録については、法律は「作成しなければならない」とだけ定め、署名や押印を義務づけていません。これに対し、取締役会の議事録は、出席した取締役・監査役が署名か記名押印をしなければなりません。

  4. なぜこのルールか

    総会の議事録は、作成を担当した取締役（施行規則72条3項6号）を記載させることで責任の所在を明らかにしています。取締役会議事録は、決議に賛成した取締役の責任（会社法369条5項）と結びつくため、署名を求めています。

  5. この事例では

    押印の要否は、まず定款の定めで決まり、次に登記で印鑑証明書が必要かで決まります。どちらにも当たらなければ、押印がなくても議事録として有効です。社内の慣行で押印する場合も、押印者の範囲を決めておくと迷いません。

注2総会で代表取締役を定めた場合の印鑑証明書 重要

    商業登記規則 61条6項 一号 （添付書面）

    第6項　代表取締役又は代表執行役の就任による変更の登記の申請書には、次の各号に掲げる場合の区分に応じ、それぞれ当該各号に定める印鑑につき市町村長の作成した証明書を添付しなければならない。ただし、当該印鑑と変更前の代表取締役又は代表執行役（取締役を兼ねる者に限る。）が登記所に提出している印鑑とが同一であるときは、この限りでない。

  2. やさしく言うと

    代表取締役が新しく就任する登記で、その代表取締役を株主総会で選んだ場合は、議長と出席した取締役が議事録に押した印鑑について、市区町村の印鑑証明書を付けなければなりません。

    代表取締役は会社の代表者として登記所に印鑑を届け出る人です。誰かが勝手に議事録を作って代表者を変更する事態を防ぐため、議事録の真正を実印で担保しています。

株主総会（書面決議を含む）の決議が必要な登記には、議決権の割合が多い順に上位の株主を載せた証明書（株主リスト）を添付します（商業登記規則61条3項）。

基準となる議決権は、その決議で議決権を行使できるものに限られます。株主全員の同意が必要な登記の場合は、全株主を載せたリストが必要です（同条2項）。

  • 同じ総会の複数議案で議決権を行使できる株主が同じ場合に1通にまとめられる扱い、基準日の株主名簿を基に作成する扱いは、法務省の案内に基づく実務とされていますが、本サイトでは通達の原文を確認していません。司法書士に確認してください。

実務のポイント

  • 議案ごと（決議ごと）に作成が必要。同じ総会の複数議案で議決権を行使できる株主が同じなら、1通にまとめて「対象議案」を列挙できる。
  • 議決権の割合の分母は「総株主の議決権の数」（その決議で行使できるもの）。自己株式・相互保有株式は含まない。
  • 株主名簿上の基準日の株主を基に作成する。基準日後の異動は原則として反映しない。
  • 上場会社でも必要。株主名簿管理人から上位株主のデータを取り寄せて作成する。
  • 種類株主総会の決議が必要な登記では、その種類の株主のリストが必要。

進め方

  1. 登記に使う決議（議案）を特定する。
  2. その決議で議決権を行使できる株主と、総株主の議決権の数を株主名簿から確認する。
  3. 議決権の多い順に並べ、上位10名と3分の2に達する人数を比べ、少ない方の人数を記載する。
  4. 各株主の氏名・住所・株式数・議決権数・割合を記載し、代表取締役が証明する。
  5. 議事録とともに登記申請書に添付する。

  1. 審査中なら、法務局の補正の指示に従い、正しい株主リストを提出する（商業登記法24条ただし書）。
  2. 株主名簿（基準日の名簿）と議決権の数を見直し、上位10名と3分の2の基準のどちらで人数を決めたかを再確認する。
  3. 登記完了後に誤りが分かった場合は、登記された事項そのものに誤りがあるかを確認する。株主リストの誤りだけで登記事項に誤りがなければ、更正登記の対象にはならないと考えられるため、司法書士に扱いを相談する。
  4. 誤りの原因（自己株式を分母に含めた、議決権のない株式を数えた等）を記録し、作成手順を見直す。

注1審査中なら補正で直せる 重要
  1. 条文
    商業登記法 24条 八号 （申請の却下）

    登記官は、次の各号のいずれかに掲げる事由がある場合には、理由を付した決定で、登記の申請を却下しなければならない。ただし、当該申請の不備が補正することができるものである場合において、登記官が定めた相当の期間内に、申請人がこれを補正したときは、この限りでない。

    • 八　申請書又はその添付書面（第十九条の二に規定する電磁的記録を含む。以下同じ。）の記載又は記録が申請書の添付書面又は登記簿の記載又は記録と合致しないとき。
  2. やさしく言うと

    申請書や添付書面の記載が他の書面や登記簿と合わないときは、申請は却下されます。ただし、直せる不備なら、登記官が決めた期間内に直せば（補正）、却下されません。

  3. この事例では

    議事録の氏名が就任承諾書・住民票と一致しないのは、典型的な補正の対象です。法務局から連絡があったら、期限と補正の方法（差替えか、訂正印か）を確認し、訂正した議事録を提出します。

  4. 実務のコツ

    補正期限までに対応できないと却下され、登記期間（2週間）の徒過につながります。法務局からの連絡を受ける担当者を決めておきましょう。

注2添付書面の訂正の方法
  1. 条文
    商業登記規則 48条2項 （記載の文字）

    第2項　前項の書面につき文字の訂正、加入又は削除をしたときは、その旨及びその字数を欄外に記載し、又は訂正、加入若しくは削除をした文字に括弧その他の記号を付して、その範囲を明らかにし、かつ、当該字数を記載した部分又は当該記号を付した部分に押印しなければならない。この場合において、訂正又は削除をした文字は、なお読むことができるようにしておかなければならない。

  2. やさしく言うと

    登記に関する書面の文字を直すときは、直した字数を欄外に書くか、直した部分を括弧などで示し、そこに印を押します。消した文字は読めるように残しておきます。

  3. この事例では

    議事録の訂正印は、議事録に押印した全員が押すのが通例です。印鑑証明書を添付する押印者は、同じ実印で訂正印を押します。修正液で消すのは避けてください。

  4. 落とし穴

    総会で決議されていない内容に書き換えることは「訂正」ではなく、虚偽記載になります（会社法976条7号の過料のおそれ）。訂正は、実際の決議内容に合わせる範囲に限ってください。

A
株主総会議事録は電磁的記録で作成することができます（会社法施行規則72条2項）。会社法上、総会議事録には署名・押印の義務がないため、電子データで作成すること自体に特別な措置はいりません。
登記のオンライン申請で議事録を添付書面情報として送信するときは、作成者が、法務大臣の定める方式に従った電子署名をし、その電子証明書をあわせて送信する必要があります（商業登記規則102条2項・5項）。使える電子証明書は、商業登記電子証明書、マイナンバーカードの署名用電子証明書、法務大臣が指定する民間の電子証明書などに限られます。
代表取締役の就任の登記などで、書面なら押印と印鑑証明書が必要な者（商業登記規則61条6項）がいる場合は、その者全員の電子署名が必要になると考えられています。使えるサービスや署名者の範囲は法務省の案内で確認してください。

根拠が明らかでない点（推測を含みます）

  • 書面なら押印・印鑑証明書が必要な者全員の電子署名が要る、という点は、商業登記規則102条と法務省の案内から考えられている扱いで、署名者の範囲の細部は本サイトでは確認できていません。
  • 立会人型（クラウド型）電子署名サービスのうち登記に使えるものは法務省が公表する一覧によりますが、一覧は随時変わるため、申請の前に最新の案内を確認してください。

  • 電子議事録の作成自体は自由。登記に使うかどうかで必要な電子署名が変わる。
  • 登記に使うなら、法務省が認める電子証明書（指定されたクラウド型電子署名サービスを含む）で署名する。一般の電子契約サービスがすべて使えるわけではない。
  • 書面で押印・印鑑証明書が必要な者は、電子の場合もその者の電子署名が必要になると考えておく。
  • 書面申請で電子議事録を添付する場合は、電磁的記録媒体（CD-R等）に記録して提出する（商業登記法19条の2、商業登記規則36条）。

実務のポイント

  • 動議は「誰が・何を・議長がどう扱ったか・結果」を書く。議長不信任動議は議長交代の可否として採決した事実を書く。

  • 録音・速記録は、決議取消しの出訴期間（3か月）を過ぎるまで少なくとも保存する。

  1. 総会当日、速記者・録音で議事を記録し、事務局が動議・質疑・退場の時刻と内容をメモする。

注1議事の経過の要領とは 重要
  1. 条文
    会社法施行規則 72条3項 二号 （議事録）

    第3項　株主総会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 二　株主総会の議事の経過の要領及びその結果
  2. やさしく言うと

    議事録には、総会の流れの要点（開会、報告、議案の説明、質疑、動議、採決など）と、その結果を書きます。全ての発言を書く必要はありません。

  3. なぜこのルールか

    議事録は、総会が法令・定款に従って運営されたかを後から確認するための記録です。要点が分かれば足りますが、争いになりやすい場面は具体的に記録しておく必要があります。

  4. この事例では

    紛糾した総会では、動議の処理・質疑の打切り・退場・採決の方法の4点を、時刻と回数を含めて書きます。「質疑の後、可決された」とだけ書くと、手続の公正さを議事録で示せません。

まず「作成したが紛失した」のか「そもそも作成していない」のかを確かめます。登記を申請している以上、そのとき法務局に議事録（書面決議ならみなし決議の議事録）を添付しているはずなので、法務局の附属書類（受付の日から10年間保存。商業登記規則34条4項4号）の閲覧、司法書士・親会社の保管書類から写しを回収できることが多いです。
写しが見つかれば、それを本店に備え置き、原本を紛失した経緯を記録します。見つからず、作成されていなかったと分かった場合は、当日の資料などの記録に基づいて、実際に行われた決議の内容どおりに今から議事録を作成します。作成日は実際の作成日とし、総会の日にさかのぼって作成したように装ってはいけません。
議事録の作成（会社法318条1項）・備置き（同条2項）を怠ったことは過料の対象になり得ます（会社法976条7号・8号）が、議事録がないことだけで、実際に行われた決議が無効になるわけではないと一般に解されています。

根拠が明らかでない点（推測を含みます）

  • 議事録がないことだけでは実際に行われた決議は無効にならない、という点は一般的な理解で、これを直接判断した判例は本サイトの登録簿にありません。
  • 会社が法務局の附属書類の閲覧について「利害関係を有する者」に当たるのは通常と考えられますが、法務局の運用（撮影の可否等）は確認していません。
  • 事後作成の議事録の記載方法（注記の書き方、作成者を誰にするか）に法令の定めはなく、本文の文例は実務上の工夫です。

実務のポイント

  • 登記をしているかどうかは、議事録が「一度は作られていた」かを判断する手がかりになる。登記の申請書類一式の控えを探す。
  • 法務局の附属書類の閲覧は「利害関係を有する者」が請求できる（商業登記法11条の2）。会社自身は通常これに当たる。
  • 親会社側に、同意書・提案書・議事録の写しが残っていることが多い（完全子会社は書面決議で済ませていることが多い）。
  • 事後に作成する議事録は、記録で確認できる事実だけを書く。不明な点（開催時刻など）を推測で埋めない。
  • 書面決議だった場合は、同意書の備置き（会社法319条2項の10年間）も欠けていないかを同時に確認する。

注1議事録の作成・備置きは会社の義務 重要
  1. 条文
    会社法 318条1項 （議事録）

    第1項　株主総会の議事については、法務省令で定めるところにより、議事録を作成しなければならない。

  2. 条文
    会社法 318条2項 （議事録）

    第2項　株式会社は、株主総会の日から十年間、前項の議事録をその本店に備え置かなければならない。

  3. やさしく言うと

    株主総会を開いたら（書面決議のときも）、議事録を作り、総会の日から10年間、本店に置いておかなければなりません。

  4. なぜこのルールか

    株主や債権者が、どのような決議がされたかを後から確認できるようにするためです（会社法318条4項の閲覧・謄写の請求）。

  5. この事例では

    過去3期分はいずれも10年の備置き期間の中にあります。写しを回収して備え置くか、作成されていなかった分は今から作成する必要があります。

  6. 落とし穴

    議事録の作成や備置きを怠ったときは、取締役等が過料の対象になり得ます（会社法976条7号・8号）。発見した後に放置しないことが大切です。

注2法務局に出した議事録は閲覧できる
  1. 条文
    商業登記法 11条の2 （附属書類の閲覧）

    登記簿の附属書類の閲覧について利害関係を有する者は、手数料を納付して、その閲覧を請求することができる。この場合において、第十七条第三項に規定する電磁的記録又は第十九条の二に規定する電磁的記録に記録された情報の閲覧は、その情報の内容を法務省令で定める方法により表示したものを閲覧する方法により行う。

  2. 条文
    商業登記規則 34条4項 四号 （帳簿等）

    第4項　次の各号に掲げる帳簿等の保存期間は、当該各号に定めるとおりとする。

    • 四　申請書その他の附属書類（次号、第十号及び第二十二号の二の書類を除く。）　受付の日から十年間
  3. やさしく言うと

    登記の申請に添付した書類（附属書類）は、法務局で受付の日から10年間保存され、利害関係のある人は手数料を払って閲覧できます。

  4. この事例では

    役員変更の登記をしているなら、そのときの議事録が法務局に残っています。閲覧して内容を書き写す（又は撮影が認められる範囲で記録する）ことで、紛失した議事録の内容を復元できます。

  5. 実務のコツ

    閲覧の方法（撮影の可否、予約の要否）は法務局ごとに案内が異なることがあるため、事前に管轄法務局に問い合わせてください。

注3後から作る議事録の書き方
  1. 条文
    会社法施行規則 72条4項 一号 （議事録）

    第4項　次の各号に掲げる場合には、株主総会の議事録は、当該各号に定める事項を内容とするものとする。

    • 一　法第三百十九条第一項の規定により株主総会の決議があったものとみなされた場合　次に掲げる事項
      イ　株主総会の決議があったものとみなされた事項の内容
      ロ　イの事項の提案をした者の氏名又は名称
      ハ　株主総会の決議があったものとみなされた日
      ニ　議事録の作成に係る職務を行った取締役の氏名
  2. やさしく言うと

    書面決議の議事録には、決議があったとみなされた事項、提案者、みなし決議の日、議事録の作成に係る職務を行った取締役を書きます。会議の場所や出席者は書きません。

  3. この事例では

    提案書・同意書から、提案の内容・提案者・同意の到達日を確認して記載します。作成者は、今作成する取締役（現在の代表取締役など）とし、注記で事後に作成したことと、根拠にした資料を明記します。

  4. 落とし穴

    総会の日付で作成したように見せかける（日付をさかのぼらせる）と、虚偽の記載（会社法976条7号）と評価されるおそれがあります。必ず実際の作成日を書いてください。

  5. 推測を含む点

    記録が乏しく決議の内容自体が確認できない場合は、議事録を作れないことがあります。その場合に、改めて同じ内容の決議（書面決議）をしておく方法が考えられますが、過去の決議の効力との関係は事案によるため、司法書士・弁護士に相談してください。
