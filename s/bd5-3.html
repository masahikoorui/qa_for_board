Q296

「3か月に1回以上の職務執行状況の報告」とは、誰が、いつ、何を報告すればよいのか。議事録にはどう書くか。

基本取締役会設置会社#
A
代表取締役と、取締役会で選定された業務執行取締役が、それぞれ3か月に1回以上、自分の職務の執行の状況を取締役会に報告します（会社法363条2項）。指名委員会等設置会社では、執行役が同じ報告をします（会社法417条4項）。
報告の内容や様式に法律の定めはありません。担当部門の業績と計画との差、重要な案件の進み具合、リスクやコンプライアンス上の問題など、取締役会が監督に使える情報を報告します。この報告は、メール等で全員に通知して省略することができないため、取締役会は少なくとも3か月に1回は実際に開催する必要があります。
議事録には、報告事項として、誰が何を報告し、どんな質疑があったかの概要を書きます（会社法施行規則101条3項4号の「議事の経過の要領」）。

根拠が明らかでない点（推測を含みます）

  • 「3か月に1回以上」の数え方（前回の報告日から3か月以内か、暦の四半期ごとに1回か）を明示した条文・判例は確認できていません。間隔が3か月を超えないように日程を組むのが安全です。
  • 報告の内容・様式（業績、重要案件、リスク等）は法令の定めがなく、実務上の例です。

実務のポイント

  • 報告義務者は「代表取締役」と「選定された業務執行取締役」。選定されていない取締役（社外取締役など）には義務はない。
  • 間隔が3か月を超えないように年間日程を組む（例：毎年3月・6月・9月・12月の定例取締役会）。「年4回開けばよい」と考えて間隔が空き過ぎないよう注意する。
  • 報告の様式を決めておく（業績・重要案件・リスク・次の3か月の予定）。担当取締役ごとに1〜2枚程度にまとめると、社外取締役も監督しやすい。
  • 報告は本人がするのが原則。執行役の報告は他の執行役を代理人としてできる旨の規定があるが（会社法417条4項）、取締役についてはそのような規定がないので、本人が出席して報告する運用にする。
  • 議事録には、報告者ごとに報告の要旨と主な質疑を書く。「各取締役から職務執行状況の報告があった」の一文だけでは、監督の実態が分からない。

進め方

  1. 年度初めに、報告の対象者（代表取締役・業務執行取締役）と報告月を年間計画に組み込む。
  2. 開催の2〜3週間前に、事務局が各報告者に報告資料の作成を依頼する（様式を配る）。
  3. 資料を取りまとめ、招集通知とともに取締役・監査役に事前に送る。
  4. 取締役会で各報告者が報告し、社外取締役・監査役から質疑を受ける。
  5. 議事録に報告の要旨と質疑の概要を記載する。
  6. 報告の実施日を管理表に記録し、次の報告期限（3か月後）を確認する。

注1誰が、どのくらいの頻度で報告するのか 重要
  1. 条文
    会社法 363条2項 （取締役会設置会社の取締役の権限）

    第2項　前項各号に掲げる取締役は、三箇月に一回以上、自己の職務の執行の状況を取締役会に報告しなければならない。

  2. 条文
    会社法 363条1項 （取締役会設置会社の取締役の権限）

    第1項　次に掲げる取締役は、取締役会設置会社の業務を執行する。

    • 一　代表取締役
    • 二　代表取締役以外の取締役であって、取締役会の決議によって取締役会設置会社の業務を執行する取締役として選定されたもの
  3. やさしく言うと

    代表取締役と、取締役会で業務執行の担当に選ばれた取締役は、少なくとも3か月に1回、自分がどのように仕事をしているかを取締役会に報告しなければなりません。

  4. この事例では

    報告義務者の一覧を作り、担当ごとに報告月を決めます。業務執行取締役を新たに選定したり、退任したりしたら、一覧を更新します。

  5. 用語

    職務の執行の状況：担当する業務がどう進んでいるか、問題が起きていないかといった、業務執行の中身。業績の数字だけでなく、重要な案件やリスクも含めて考えます。

注2なぜ報告が必要なのか（取締役会の監督）
  1. 条文
    会社法 362条2項 二号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 二　取締役の職務の執行の監督
  2. やさしく言うと

    取締役会の仕事の一つは、取締役の仕事ぶりを監督することです。

  3. なぜこのルールか

    監督するには、まず業務執行の状況を知る必要があります。定期的な報告を義務付けることで、取締役会が業務執行者を監督できる情報を、少なくとも3か月ごとに得られるようにしています。

  4. この事例では

    報告は「数字を読み上げる場」ではなく、社外取締役や監査役が質問し、問題を早く見つけるための場です。資料を事前に送り、質疑の時間を確保した議事進行にしてください。

  5. 実務のコツ

    監査役は取締役会に出席し、必要があれば意見を述べる義務があります（会社法383条1項）。報告の資料は監査役にも同時に送りましょう。

注3報告は議事録にどう残すか
  1. 条文
    会社法施行規則 101条3項 四号 （取締役会の議事録）

    第3項　取締役会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 四　取締役会の議事の経過の要領及びその結果
  2. やさしく言うと

    取締役会の議事録には、会議でどのような話がされたか（議事の経過の要領）と、その結果を書かなければなりません。報告事項もこれに含まれます。

  3. この事例では

    報告者ごとに、報告の要旨と主な質疑を書きます。「3か月に1回以上報告していた」ことを後で証明するのは議事録なので、報告者の氏名と、会社法363条2項に基づく報告であることを明記しておくと確認しやすくなります。

  4. 落とし穴

    報告資料を議事録に添付する場合でも、口頭でのやり取り（質問と回答）は資料には残りません。重要な質疑は議事録本文に書いてください。

注4指名委員会等設置会社の執行役の場合
  1. 条文
    会社法 417条4項 （指名委員会等設置会社の取締役会の運営）

    第4項　執行役は、三箇月に一回以上、自己の職務の執行の状況を取締役会に報告しなければならない。この場合において、執行役は、代理人（他の執行役に限る。）により当該報告をすることができる。

  2. やさしく言うと

    指名委員会等設置会社では、業務を執行するのは執行役なので、執行役が3か月に1回以上、取締役会に報告します。執行役は、他の執行役に代わりに報告してもらうこともできます。

  3. この事例では

    監査役設置会社や監査等委員会設置会社の取締役には、このような代理の規定はありません。報告予定の取締役が欠席しそうなときは、取締役会の日程を調整するか、次の取締役会で期限内に報告できるように計画します。

実務取締役会設置会社非公開会社#
A
できません。取締役会への報告は、取締役・監査役の全員に報告事項を通知すれば省略できるのが原則ですが（会社法372条1項）、代表取締役・業務執行取締役の3か月に1回以上の職務執行状況の報告だけは、この省略が認められていません（同条2項）。

開催の負担を減らすには、ウェブ会議・電話会議による出席を活用する、取締役・監査役全員の同意で招集手続を省略する（会社法368条2項）、報告と同時に決議事項もまとめて審議する、といった方法があります。

根拠が明らかでない点（推測を含みます）

  • ウェブ会議・電話会議による取締役会の開催が認められる要件（音声が即時に伝わり、互いに意見を交わせること）は、会社法施行規則101条3項1号が出席の方法の記載を求めていることなどを踏まえた一般的な解釈で、要件を直接定めた条文はありません。

実務のポイント

  • 書面決議（370条）は「決議」を省略する制度、報告の省略（372条1項）は「報告」を省略する制度。いずれも、363条2項の職務執行状況の報告には使えない。
  • ウェブ会議・電話会議による開催は、出席者の音声が即時に伝わり、互いに意見を交わせる状態であれば、取締役会の開催として扱えると一般に解されている。議事録には出席の方法を書く。
  • 3か月に1回の定例取締役会の日程を年度初めに決めてしまうと、開催漏れを防げる。
  • 書面決議・報告の省略をしたときも、議事録（会社法施行規則101条4項）を作成し、本店に備え置く。
  • 監査役設置会社で書面決議をするには、監査役が異議を述べないことも必要。監査役にも提案書を送る。

進め方

  1. 現在の取締役会の開催状況（実開催日、書面決議の日）を一覧にし、職務執行状況の報告が3か月以内ごとにされているか確認する。
  2. 年4回以上の定例取締役会（実開催）の日程を決め、取締役・監査役の予定を押さえる。
  3. 遠方の取締役のためにウェブ会議の環境を整え、接続確認の手順を決める。
  4. 各定例取締役会で、代表取締役・業務執行取締役が職務執行状況を報告する。

注1報告の省略ができる場合とできない場合 重要
  1. 条文
    会社法 372条1項 （取締役会への報告の省略）

    第1項　取締役、会計参与、監査役又は会計監査人が取締役（監査役設置会社にあっては、取締役及び監査役）の全員に対して取締役会に報告すべき事項を通知したときは、当該事項を取締役会へ報告することを要しない。

  2. 条文
    会社法 372条2項 （取締役会への報告の省略）

    第2項　前項の規定は、第三百六十三条第二項の規定による報告については、適用しない。

  3. やさしく言うと

    取締役会に報告すべきことは、取締役（監査役設置会社では監査役も）の全員に知らせれば、取締役会で報告しなくてもよいのが原則です。しかし、代表取締役などの3か月に1回の職務執行状況の報告だけは、この方法で省略できません。

  4. なぜこのルールか

    職務執行状況の報告は、取締役会が業務執行者を監督するための基本的な仕組みです。資料を配るだけでは、質問したり議論したりする機会がなくなります。そこで、少なくとも3か月に1回は、取締役が実際に集まって報告を聞く機会を確保させています。

  5. この事例では

    メールで資料を送っても、363条2項の報告をしたことにはなりません。3か月以内ごとに取締役会を実際に開催し、そこで報告してください。

注2書面決議はどこまで使えるか
  1. 条文
    会社法 370条 （取締役会の決議の省略）

    取締役会設置会社は、取締役が取締役会の決議の目的である事項について提案をした場合において、当該提案につき取締役（当該事項について議決に加わることができるものに限る。）の全員が書面又は電磁的記録により同意の意思表示をしたとき（監査役設置会社にあっては、監査役が当該提案について異議を述べたときを除く。）は、当該提案を可決する旨の取締役会の決議があったものとみなす旨を定款で定めることができる。

  2. やさしく言うと

    定款に定めがあれば、議決に加われる取締役全員が書面やメールで提案に同意したとき、取締役会で可決したものとみなすことができます。監査役設置会社では、監査役が異議を述べると使えません。

  3. この事例では

    書面決議は「決議」を省略するための制度で、「報告」には使えません。今回の会社は、決議は書面決議を続けてもよいものの、3か月に1回の報告のためには取締役会の開催が別に必要です。

  4. 落とし穴

    定款に書面決議の定めがないのに書面決議をしていた場合は、その決議自体に問題が生じます。まず定款を確認してください。

    第2項　前項の規定にかかわらず、取締役会は、取締役（監査役設置会社にあっては、取締役及び監査役）の全員の同意があるときは、招集の手続を経ることなく開催することができる。

A
まず、できるだけ早く取締役会を開催して、代表取締役・業務執行取締役に職務執行状況を報告させ、違反の状態を解消します。そのうえで、同じ取締役会で、今後の定例開催の日程と再発防止策を決議しておきます。
報告がなかったことで、その間に書面決議で適法に成立した決議が当然に無効になるわけではないと考えられます。しかし、報告をしなかったことは法令違反であり、取締役会による監督が機能していなかったことになります。その間に会社に損害を与える事態が起きていれば、報告を怠った代表取締役だけでなく、監督を怠った他の取締役の責任が問題になり得ます。
監査役は、法令違反の事実を取締役会に報告する義務を負い、監査報告でも指摘することがあります。事実を隠さず、監査役と相談しながら是正してください。

根拠が明らかでない点（推測を含みます）

  • 報告を欠いていた期間の書面決議が当然には無効にならないという点は、書面決議（会社法370条）と職務執行状況の報告（363条2項）が別の制度であることからの解釈で、これを直接判断した判例は確認できていません。
  • 空白期間の報告を後でまとめて行うことで違反の状態が解消されるかについて定めた条文はなく、是正の方法として一般に考えられているものです。過去の違反の事実が消えるわけではありません。

実務のポイント

  • 空白期間を特定する：最後に実開催した日、その間の書面決議の一覧、書面決議の定款の根拠と同意書の有無。
  • 空白期間の書面決議に別の不備（定款の定めがない、全員の同意がない、監査役の異議）がないかも、あわせて点検する。
  • 是正の取締役会では、空白期間の業務執行の状況をまとめて報告させ、重要な事項を洗い出す（未報告の利益相反取引、重要な契約など）。
  • 取締役会の招集権者が動かないときは、他の取締役も招集を請求できる（会社法366条2項）。社外取締役・監査役から開催を求めることもできる。
  • 再発防止として、定例取締役会の年間日程、事務局の管理表、報告期限の事前アラートを決める。

進め方

  1. 最後の実開催日と、その後の書面決議・報告の一覧を作り、空白期間を確定する。
  2. 監査役に事実を報告し、是正の方針を相談する。
  3. 取締役会を招集し（全員の同意があれば招集手続を省略してよい）、代表取締役・業務執行取締役に空白期間を含めた職務執行状況を報告させる。
  4. 同じ取締役会で、定例開催の年間日程と再発防止策を決議する。
  5. 空白期間中に取締役会の承認・報告が必要だった事項（利益相反取引、重要な業務執行など）がないかを確認し、あれば追認・報告の手続をとる。
  6. 次回以降、報告が3か月以内ごとにされているかを事務局が管理し、監査役にも共有する。

すでに手続を欠いてしまった場合（事後の是正）

本問そのものが、3か月に1回の職務執行状況の報告を欠いた後の是正です。是正の基本の順序は次のとおりです。

  1. 最後に実際に開催した取締役会の日と、その後の書面決議・報告の省略の一覧を作り、空白期間を特定する。
  2. 監査役に事実を報告し、是正の方針を相談する。
  3. 速やかに取締役会を開催し（招集権者が動かなければ会社法366条2項の招集請求を使う）、代表取締役・業務執行取締役に空白期間の職務執行状況をまとめて報告させる。
  4. 空白期間の書面決議に別の不備がないか、未報告の重要事項（利益相反取引、重要な契約）がないかを点検し、必要なものは同じ取締役会で追認・報告を受ける。
  5. 同じ取締役会で、定例開催の年間日程と再発防止策（事務局の管理表・期限の事前通知）を決議する。
  6. 議事録に、報告が欠けていた期間と経緯、是正の内容を記載する。

注1報告をしなかったことは法令違反 重要
  1. 条文
    会社法 363条2項 （取締役会設置会社の取締役の権限）

    第2項　前項各号に掲げる取締役は、三箇月に一回以上、自己の職務の執行の状況を取締役会に報告しなければならない。

  2. 条文
    会社法 372条2項 （取締役会への報告の省略）

    第2項　前項の規定は、第三百六十三条第二項の規定による報告については、適用しない。

  3. やさしく言うと

    代表取締役などは3か月に1回以上、取締役会で職務執行状況を報告しなければならず、この報告は省略できません。取締役会を開かずに半年以上過ごせば、この義務に違反した状態になります。

  4. この事例では

    違反の状態を解消するには、取締役会を実際に開いて報告させるしかありません。空白期間を含めた報告をできるだけ早く行い、議事録に「空白があったこと」と「是正の報告をしたこと」を記録します。

  5. 実務のコツ

    過去にさかのぼって「報告があったこと」にすることはできません。議事録を後から作って取り繕うことは、絶対にしないでください。

注2監督を怠った取締役の責任
  1. 条文
    会社法 362条2項 二号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 二　取締役の職務の執行の監督
  2. 条文
    会社法 423条1項 （役員等の株式会社に対する損害賠償責任）

    第1項　取締役、会計参与、監査役、執行役又は会計監査人（以下この章において「役員等」という。）は、その任務を怠ったときは、株式会社に対し、これによって生じた損害を賠償する責任を負う。

  3. やさしく言うと

    取締役会は取締役の職務を監督する役割を持ち、取締役一人ひとりもその一員として監督の責任を負います。任務を怠って会社に損害を与えた取締役は、会社に損害を賠償する責任を負います。

  4. なぜこのルールか

    取締役会が開かれず報告もないと、代表取締役の業務執行を誰もチェックできません。その間に不正や大きな損失が起きれば、「監督していなかった」ことが責任の根拠になり得ます。

  5. この事例では

    報告がなかったこと自体からすぐに損害賠償責任が生じるわけではありませんが、空白期間中に問題が起きていれば、他の取締役（社外取締役を含む）の監督の責任が問われる可能性があります。是正の取締役会では、空白期間の業務執行の状況をまとめて確認してください。

注3取締役会を開いてもらえないとき
  1. 条文
    会社法 366条2項 （招集権者）

    第2項　前項ただし書に規定する場合には、同項ただし書の規定により定められた取締役（以下この章において「招集権者」という。）以外の取締役は、招集権者に対し、取締役会の目的である事項を示して、取締役会の招集を請求することができる。

  2. やさしく言うと

    取締役会を招集する取締役（通常は代表取締役）が決められている会社でも、他の取締役は、議題を示して取締役会の招集を求めることができます。

  3. 判例
    取締役の監視義務（取締役会に上程されない事項）
    最高裁判所第三小法廷 昭和48年5月22日 判決（民集27巻5号655頁）

    取締役は、会社に対し、代表取締役の業務執行を監視し、必要があれば取締役会を自ら招集し又は招集を求め、取締役会を通じて業務執行が適正に行われるようにする職責があるとした判決。

    取締役は代表取締役の業務執行を監視し、必要があれば自ら取締役会を招集し又は招集を求める職責があるとした判例です。取締役会が開かれない状態を放置した取締役の責任を考える出発点になります。

  4. この事例では

    代表取締役が開催に消極的なときは、社外取締役などが招集を請求できます。請求したのに一定期間内に招集されないときは、請求した取締役が自ら招集することもできる仕組みになっています（会社法366条3項）。

  5. 実務のコツ

    監査役も、取締役の不正行為や法令違反などがあると認める場合で必要があるときは、取締役会の招集を請求できます（会社法383条2項）。事務局は、こうした手段があることを役員に周知しておくとよいでしょう。

注4監査役の対応
  1. 条文
    会社法 382条 （取締役への報告義務）

    監査役は、取締役が不正の行為をし、若しくは当該行為をするおそれがあると認めるとき、又は法令若しくは定款に違反する事実若しくは著しく不当な事実があると認めるときは、遅滞なく、その旨を取締役（取締役会設置会社にあっては、取締役会）に報告しなければならない。

  2. やさしく言うと

    監査役は、取締役の法令違反などを見つけたときは、遅れずに取締役会に報告しなければなりません。

  3. この事例では

    報告の空白は法令違反なので、監査役が把握していれば取締役会で指摘することになります。是正の取締役会では、監査役の意見を聞き、議事録にその概要を記載します（監査役の報告の内容の概要は議事録の記載事項です）。

  4. 落とし穴

    監査役が知りながら放置すると、監査役自身の任務懈怠が問題になり得ます。事務局は、監査役への報告を後回しにしないでください。

A
まず取締役会で、代表取締役に正確な事実を改めて報告させ、報告されなかった経緯を調べる体制を決めます。職務執行状況の報告（会社法363条2項）は、取締役会が代表取締役を監督する（会社法362条2項2号）ための材料なので、重要な事実を伏せた報告は、報告義務を果たしたとは言いにくく、取締役としての任務を怠ったと評価されるおそれがあります。
また、取締役は、会社に著しい損害を及ぼすおそれのある事実を発見したら、直ちに監査役に報告しなければなりません（会社法357条1項）。この義務に反していた可能性もあります。
取締役会は、①事実の確認（損失の額、いつ誰が知っていたか）、②損失への対応（債権の保全・回収、会計処理）、③報告されなかった経緯の調査（社内調査か、外部の弁護士を入れた調査か）、④代表取締役の責任と再発防止、の順に進めます。他の取締役も、報告を鵜呑みにせず監視する職責があるとされているので、調査の結果を議事録に残し、取締役会として何をしたかを示すことが重要です。

実務のポイント

  • 最初の取締役会で、代表取締役本人から事実を報告させ、質疑の内容を詳しく議事録に残す。
  • 調査の主体を決める：社内の担当部門、監査役、外部の弁護士を入れた調査委員会。代表取締役自身が関わる問題なので、代表取締役の指揮下にない体制にする。
  • 損失への対応（債権の保全、担保の実行、貸倒引当金などの会計処理）は、調査と並行して急いで進める。会計監査人がいる会社では、会計監査人にも早めに伝える。
  • 上場会社では、損失の額によって適時開示が必要になることがある（取引所規則の制度）。開示の要否を早めに検討する。
  • 再発防止として、報告の様式に「重要な損失見込み・リスク」の欄を設け、担当部門のデータを添付させる。

調査の体制の比較

A案　社内の担当部門（法務・内部監査）で調査する

メリット
  • 早く、費用も小さい。
  • 社内の資料・人に通じている。
デメリット
  • 代表取締役の指揮下にある部門なので、調査の独立性・公正さが疑われやすい。

推奨B案　社外取締役・社外監査役と外部弁護士で調査委員会を設ける

メリット
  • 代表取締役から独立した調査になり、取締役会の監督の実効性を示しやすい。
  • 調査結果を株主・取引先・会計監査人に説明しやすい。
デメリット
  • 費用と時間がかかる。
  • 委員の選任と調査範囲の設定に手間がかかる。

C案　監査役（監査役会）の調査に委ねる

メリット
  • 監査役の法定の調査権限を使える。
デメリット
  • 取締役会としての監督の行動が見えにくく、他の取締役の監視の職責を果たしたことの説明が弱くなる。

推奨：代表取締役本人が報告を伏せていた事案なので、B案を推奨します。損失が小さく、報告の漏れが担当部門の連絡ミスにとどまることが明らかな場合は、A案で足りることもありますが、その場合も監査役の確認を受けてください。

進め方

  1. 事実を把握した取締役・監査役が、他の取締役・監査役に共有し、取締役会の開催を求める（招集権者が代表取締役本人で応じなければ招集請求をする）。
  2. 取締役会で、代表取締役から事実と経緯の報告を受け、損失の見込額と対応策を確認する。
  3. 同じ取締役会で、調査の体制（調査委員会の設置、委員、調査事項、報告期限）を決議する。
  4. 調査委員会が関係者の聴取・資料の確認を行い、取締役会に報告する。
  5. 取締役会で、調査結果を踏まえ、代表取締役の処遇（解職を含む）、責任追及の要否、再発防止策を審議・決議する。
  6. 監査役は監査の結果を取締役会に報告し、必要に応じて監査報告に記載する。

すでに手続を欠いてしまった場合（事後の是正）

不正確な報告が分かった後も、取締役会で取り上げず、調査や監査役への報告をしないまま放置していた場合

  1. 事実を知った取締役・監査役が、直ちに他の取締役・監査役に共有し、取締役会の開催を求める（招集権者が応じなければ会社法366条2項の招集請求）。
  2. 取締役会で代表取締役から改めて報告を受け、放置していた期間と理由も含めて議事録に残す。
  3. 調査委員会を設置し、報告の欠落の経緯に加え、放置していた間に損害が拡大していないか（債権の保全の遅れなど）も調査事項に入れる。
  4. 会計処理の修正が必要な場合は、会計監査人・監査役と相談し、計算書類への影響を確認する。
  5. 調査結果を踏まえ、取締役の責任と再発防止策を取締役会で決議する。

注1職務執行状況の報告は、監督の材料 重要
  1. 条文
    会社法 363条2項 （取締役会設置会社の取締役の権限）

    第2項　前項各号に掲げる取締役は、三箇月に一回以上、自己の職務の執行の状況を取締役会に報告しなければならない。

  2. 条文
    会社法 362条2項 二号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 二　取締役の職務の執行の監督
  3. やさしく言うと

    代表取締役は、3か月に1回以上、自分の仕事の状況を取締役会に報告します。取締役会はその報告をもとに、代表取締役の仕事ぶりをチェックします。

  4. なぜこのルールか

    報告が監督の材料である以上、良いことだけを報告し、悪い事実を伏せたのでは、取締役会は監督できません。報告は正確で、重要な事実を含んでいる必要があります。

  5. この事例では

    多額の貸倒れの見込みを知りながら「順調」と報告したことは、報告の義務を果たしたとは言いにくく、取締役の任務を怠ったものと評価されるおそれがあります。取締役会は、まず本人に正確な報告をやり直させ、その内容を議事録に残します。

注2著しい損害のおそれは、直ちに監査役へ
  1. 条文
    会社法 357条1項 （取締役の報告義務）

    第1項　取締役は、株式会社に著しい損害を及ぼすおそれのある事実があることを発見したときは、直ちに、当該事実を株主（監査役設置会社にあっては、監査役）に報告しなければならない。

  2. やさしく言うと

    取締役は、会社に大きな損害が出そうな事実を見つけたら、すぐに監査役に報告しなければなりません。

  3. この事例では

    大口取引先の破綻による多額の貸倒れの見込みは、会社の規模によっては「著しい損害を及ぼすおそれのある事実」に当たり得ます。監査役への報告がされていたかも調査事項に入れてください。

  4. 実務のコツ

    担当部門から代表取締役への報告が上がっていたかも確認します。代表取締役まで情報が届いていなかったのなら、問題は報告の仕組み（内部統制）の側にあります。

注3他の取締役にも、監視の職責がある
  1. 条文
    会社法 423条1項 （役員等の株式会社に対する損害賠償責任）

    第1項　取締役、会計参与、監査役、執行役又は会計監査人（以下この章において「役員等」という。）は、その任務を怠ったときは、株式会社に対し、これによって生じた損害を賠償する責任を負う。

  2. やさしく言うと

    取締役が任務を怠って会社に損害を与えると、会社に賠償する責任を負います。

  3. 判例
    取締役の監視義務（取締役会に上程されない事項）
    最高裁判所第三小法廷 昭和48年5月22日 判決（民集27巻5号655頁）

    取締役は、会社に対し、代表取締役の業務執行を監視し、必要があれば取締役会を自ら招集し又は招集を求め、取締役会を通じて業務執行が適正に行われるようにする職責があるとした判決。

    取締役は、代表取締役の業務執行を監視し、必要があれば取締役会を自ら招集し又は招集を求め、取締役会を通じて業務執行が適正に行われるようにする職責があるとした判例です。

  4. この事例では

    不正確な報告が判明した後に、他の取締役が何もしなければ、監視の職責を果たしていないと評価されるおそれがあります。調査委員会の設置、調査結果の審議、再発防止策の決定までを取締役会で行い、その経過を議事録に残してください。

注4監査役の役割
  1. 条文
    会社法 382条 （取締役への報告義務）

    監査役は、取締役が不正の行為をし、若しくは当該行為をするおそれがあると認めるとき、又は法令若しくは定款に違反する事実若しくは著しく不当な事実があると認めるときは、遅滞なく、その旨を取締役（取締役会設置会社にあっては、取締役会）に報告しなければならない。

  2. やさしく言うと

    監査役は、取締役の法令違反や著しく不当な事実を見つけたら、取締役会に報告しなければなりません。

  3. この事例では

    監査役は、報告の欠落と経緯について取締役会で意見を述べ、調査委員会に加わるか、独自に調査します。調査結果によっては、監査報告で指摘することになります。

  4. 落とし穴

    調査を代表取締役の指揮下にある部門だけに任せると、調査の公正さが疑われます。社外取締役・社外監査役・外部の弁護士を中心にした体制にしてください。
