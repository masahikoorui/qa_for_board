Q237

取締役会の定足数と可決の要件はどう数えるのか。審議の途中で取締役が退席し、出席者が過半数を割った場合はどうなるか。

基本取締役会設置会社#
A
取締役会の決議は、①議決に加わることができる取締役の過半数が出席し（定足数）、②出席した取締役の過半数が賛成することで成立します（会社法369条1項）。いずれも定款で引き上げることはできますが、引き下げることはできません。
「議決に加わることができる取締役」には、その議案に特別の利害関係を有する取締役は含みません（同条2項）。例えば取締役7名の会社で1名が特別利害関係人なら、6名を基準に、4名以上の出席と、出席者の過半数の賛成が必要です。
定足数は、開会時だけでなく、各議案を採決する時点で満たしている必要があると一般に解されています。途中退席で出席者が過半数を割ったら、その後の議案は決議できません。議長は、退席者が出るたびに出席者数を確認し、定足数を割るなら休憩して戻るのを待つか、残りの議案を延期します。

根拠が明らかでない点（推測を含みます）

  • 定足数が開会時だけでなく採決の時点ごとに必要という点は一般的な解釈で、明文はありません。
  • 欠員がある場合に現に在任する取締役（権利義務を有する者を含む）を基準に数えるという点は一般的な解釈で、直接判断した登録判例は確認できていません。

実務のポイント

  • 分母は「取締役の総数」ではなく「議決に加わることができる取締役」。特別利害関係人を除いて数える。
  • 欠員がある場合は、現に在任する取締役（任期満了・辞任後に権利義務を有する者を含む）を基準に数えるのが一般的。
  • 「過半数」は半数を超えること。6名なら4名、7名なら4名。半数ちょうどは過半数ではない。
  • 棄権・白票は賛成に数えない。出席者の過半数の賛成が必要なので、棄権は実質的に反対と同じ効果になる。
  • 議事録には、議案ごとの出席者数（途中退席・入室があればその時点）と賛成者を記載する。

進め方

  1. 開会前に、取締役の総数・出席予定者・特別利害関係人の有無を議案ごとに確認する。
  2. 開会時に、議長が出席者数と定足数を確認する。
  3. 退席・入室があれば、事務局がその時刻と氏名を記録する。
  4. 各議案の採決前に、議長が出席者数と定足数を確認する。
  5. 賛成者数が出席者の過半数かを確認し、結果を宣言する。
  6. 議事録に、議案ごとの出席状況と結果を記載する。

すでに手続を欠いてしまった場合（事後の是正）

途中退席で定足数を割ったまま議案を採決し、可決として扱ってしまった場合

  1. 議案ごとに、採決時点の出席者数と賛成者を記録・ログで確定する。
  2. 定足数を割っていた議案は決議が成立していないものとして扱い、決議に基づく実行がまだなら保留する。
  3. 適法に招集した取締役会（又は全員の同意による招集手続の省略）で改めて決議し、既に行った行為を追認する。
  4. 議事録の出席者数の記載が事実と違えば、出席者全員の確認を得て訂正する。
  5. 議長シナリオに、退席者が出るたびの定足数確認を組み込む。

注1定足数と多数決の数え方 重要
  1. 条文
    会社法 369条1項 （取締役会の決議）

    第1項　取締役会の決議は、議決に加わることができる取締役の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）が出席し、その過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行う。

  2. やさしく言うと

    決議には、議決に加われる取締役の半分を超える人数の出席が必要で、さらに、出席した人の半分を超える人数の賛成が必要です。定款で、この割合を高くすることはできます。

  3. なぜこのルールか

    一部の取締役だけで会社の重要事項を決めてしまうことを防ぐためです。株主総会と違い、定款で要件を緩めることは認められていません。

  4. この事例では

    取締役7名全員が議決に加われる議案なら、4名以上の出席が必要で、5名出席なら3名以上の賛成で可決です。賛成2名・反対2名・棄権1名なら、賛成が出席者の過半数に届かないので否決です。

  5. 用語

    定足数：会議で決議をするために必要な最低限の出席者数。

注2特別利害関係人は分母から外す
  1. 条文
    会社法 369条2項 （取締役会の決議）

    第2項　前項の決議について特別の利害関係を有する取締役は、議決に加わることができない。

  2. やさしく言うと

    議案に特別の利害関係がある取締役は採決に加われません。そのため、定足数の基準となる「議決に加わることができる取締役」の数にも入りません。

  3. この事例では

    7名中1名が特別利害関係人なら、6名を基準にして4名以上の出席が必要です。特別利害関係人が会議室に残っていても、その人を出席者として数えてはいけません。

注3欠員があるときの数え方
  1. 条文
    会社法 346条1項 （役員等に欠員を生じた場合の措置）

    第1項　役員（監査等委員会設置会社にあっては、監査等委員である取締役若しくはそれ以外の取締役又は会計参与。以下この条において同じ。）が欠けた場合又はこの法律若しくは定款で定めた役員の員数が欠けた場合には、任期の満了又は辞任により退任した役員は、新たに選任された役員（次項の一時役員の職務を行うべき者を含む。）が就任するまで、なお役員としての権利義務を有する。

  2. やさしく言うと

    任期満了や辞任で取締役が法律や定款で決めた人数を下回ったときは、辞めた取締役も、後任が就任するまで取締役としての権利と義務を持ち続けます。

  3. この事例では

    このような「権利義務取締役」も取締役会の構成員なので、招集通知の相手方になり、定足数の計算にも含めます。一方、死亡や解任で欠けた取締役は含まれません。現に在任する取締役の数を、登記と照らして確認してください。

  4. 落とし穴

    取締役会設置会社は取締役が3名以上必要です。欠員のまま放置すると、定足数の確保が難しくなるうえ、選任を怠った責任も問題になります。早めに株主総会で補充してください。

注4途中退席で定足数を割ったら
  1. 条文
    会社法施行規則 101条3項 四号 （取締役会の議事録）

    第3項　取締役会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 四　取締役会の議事の経過の要領及びその結果
  2. やさしく言うと

    議事録には、議事の進み方とその結果の要点を書きます。

  3. なぜこのルールか

    定足数は議案ごとに、採決の時点で満たす必要があると一般に解されています。そのため、誰がいつ退席・入室したかは、決議の有効性を判断するための重要な事実になります。

  4. この事例では

    途中退席で定足数を割ったら、議長は休憩を宣言して退席者の戻りを待つか、残りの議案を次回に延期します。定足数を割ったまま採決しても決議は成立しません。議事録には退席の時刻と、延期した事実を書きます。

  5. 実務のコツ

    退席予定がある取締役がいるときは、重要な議案をその人の在席中に審議できるよう、議案の順番を入れ替えます。

Q238

取締役会の採決で賛否が同数になった。議長が決めてよいか。否決された議案を修正して再上程するにはどうすればよいか。

実務取締役会決議あり取締役会設置会社#
A
議長が決めることはできず、議案は否決になります。決議には出席取締役の過半数の賛成が必要で（会社法369条1項）、同数は過半数に当たらないからです。定款で「可否同数のときは議長が決する」と定めても、議長は既に取締役として一票を投じているので、事実上二票を与えることになり、過半数で決めるという法律の要件に反するため無効と一般に解されています。登記実務でも、議長の決裁で可決とした決議は受け付けられないとされています。
否決後は、①反対の理由を確認し、②条件を修正した議案を作り、③次の取締役会（急ぐなら招集手続の省略を利用）に改めて上程します。同じ取締役会で修正案を出すこともできますが、修正の内容が大きいときは資料を整えてから再上程するのが適切です。
否決の事実と、賛成・反対した取締役は議事録に記載しておきます。反対した取締役の責任を後で問われないためにも、反対の記録は重要です。

根拠が明らかでない点（推測を含みます）

  • 可否同数の場合に議長に決裁権を与える定款の定めが無効という点は一般的な解釈で、直接判断した登録判例は確認できていません。
  • 登記実務で議長決裁による可決の議事録が受け付けられないという点は、このサイトでは先例の原文を確認できていません。

実務のポイント

  • 可否同数は否決。議長の決裁権を定める定款・規程があっても、それに頼って可決扱いにしない。
  • 議長も一人の取締役として議決権を行使する。議長だけ採決に加わらないという運用は、かえって賛否の数を不明確にする。
  • 否決の議事録には、賛成・反対の人数と、反対した取締役の氏名・理由の要旨を書く。
  • 再上程では、前回の否決理由にどう対応したかを上程書に書く。
  • 期限のある案件（契約の回答期限など）は、相手方への回答を延ばせるかを先に確認する。

  5. 次の取締役会（又は臨時取締役会）で再上程し、採決する。

可否同数なのに、定款・規程の議長決裁の定めに従って「可決」と扱い、議事録を作ってしまった場合

  1. その議案は否決されたものとして扱い、決議に基づく実行がまだなら止める。
  2. 既に実行していれば、取引の相手方との関係（相手方が議事録を見て事情を知っていたか）を確認する。
  3. 反対の理由に対応した修正案を作り、次回（又は臨時）の取締役会に上程して改めて決議する。可決されれば既に行った行為の追認もあわせて決議する。
  4. 登記に使っていた場合は、登記の扱いを司法書士に確認する。
  5. 議長決裁の定めを定款・取締役会規程から削除する（定款は株主総会の特別決議で変更する）。

A
特別の利害関係とは、その決議について、会社に対する忠実義務を誠実に果たすことが期待できないような、取締役個人の利害関係をいうと一般に解されています。典型例は次のとおりです。
当たるとされる例：①利益相反取引・競業取引の承認を受ける取締役（会社法356条1項、365条1項）、②代表取締役の解職決議の対象となる代表取締役（判例）、③取締役会決議による責任の一部免除の対象となる取締役（会社法426条1項は「当該責任を負う取締役を除く」と明記）、④自己が当事者となる譲渡制限株式の譲渡承認、⑤自分の取引について会社が訴訟を起こすかを決める場合の当該取締役。
当たらないとされる例：①代表取締役の選定決議の候補者（業務執行の地位に就くことは会社のための職務で、個人的な利益とはいえないと一般に解されている）、②株主総会で決めた報酬総額の範囲内で取締役会が個人別の配分を決める場合の各取締役（全員が関係するため、一般に特別利害関係とは扱われていない）。
判断に迷う場合は、利害関係があるものとして議決から外す方が、決議の効力を争われにくく安全です。

根拠が明らかでない点（推測を含みます）

  • 特別の利害関係の定義（忠実義務を誠実に果たすことが期待できない個人的な利害関係）は学説の一般的な説明で、明文はありません。
  • 譲渡制限株式の譲渡承認の当事者、自分の取引について会社が訴訟を起こすかを決める場合の当該取締役を特別利害関係人とする点は、一般的な解釈で、直接判断した登録判例は確認できていません。
  • 代表取締役の選定の候補者、報酬の個人別配分の各取締役が特別利害関係人に当たらないという点は一般的な解釈で、異なる見解もあります。

実務のポイント

  • 判断の基準は「その取締役個人に、会社の利益と離れた利害があるか」。会社のための職務上の利害は含まない。
  • 利益相反取引では、取締役本人のほか、取締役が代表する相手方会社との取引でも、その取締役は特別利害関係人になる。
  • 解職決議では対象の代表取締役は特別利害関係人（判例）。選定決議の候補者は一般に当たらない。
  • 迷うときは議決から外す。外しすぎても定足数を満たせば決議は有効だが、加えるべきでない者を加えると効力が争われる。
  • 議事録には特別利害関係取締役の氏名を記載する（会社法施行規則101条3項5号）。

  2. やさしく言うと

    議案について個人的な利害がある取締役は、その議案の採決に参加できません。

  3. なぜこのルールか

    取締役は会社のために忠実に職務を行う義務がありますが（会社法355条）、自分の個人的な利害がからむと、会社の利益より自分の利益を優先するおそれがあります。そこで、そのような取締役を採決から外して、決議の公正さを守っています。

    どの議案で誰が特別利害関係を有するかを、議案ごとに事前に確認します。上程書に「特別利害関係の有無」の欄を設けておくと、確認漏れを防げます。

    忠実義務：取締役が、法令・定款・株主総会決議を守り、会社のために忠実に職務を行う義務。

    全取締役の責任を一括で免除する議案にすると、議決に加われる取締役がいなくなります。議案の分け方を事前に検討してください。

    取締役会は、取締役が会議で議論し、他の人の意見を聞いて判断する場です。事前に賛否を決めてしまう書面投票や、他人に判断を任せる代理は、この会議の性質に合わないと考えられています。

  4. この事例では

    委任状や事前の賛成書面を出した取締役は欠席として扱います。その取締役を数えなくても定足数と過半数を満たすかを確認して決議します。

  2. 条文
    民法 644条 （受任者の注意義務）

    受任者は、委任の本旨に従い、善良な管理者の注意をもって、委任事務を処理する義務を負う。

  3. やさしく言うと

    会社と取締役の関係は委任の関係で、取締役は自ら注意を尽くして仕事をする義務を負います。

  4. なぜこのルールか

    株主は、その人の能力や人柄を信頼して取締役に選んでいます。取締役が議決を他人に任せることは、この信頼に反するため、認められないと一般に解されています。

注1議決に加われる取締役が1名でも決議できる 重要
  1. 条文
    会社法 369条1項 （取締役会の決議）

    第1項　取締役会の決議は、議決に加わることができる取締役の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）が出席し、その過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行う。

  2. やさしく言うと

    定足数も多数決も、議決に加われる取締役の人数を基準にします。議決に加われる取締役が1名なら、その1名が出席して賛成すれば、要件を満たします。

  3. なぜこのルールか

    特別利害関係人を除くのは決議の公正さを守るためで、その結果として人数が少なくなっても、残った取締役が会社のために判断すれば足りるという考え方です。

  4. この事例では

    今回の事例では、取締役Cが1名で決議します。ただし、1名の判断には偏りの危険があるので、第三者の評価や弁護士の意見、監査役の意見を判断材料として示し、それを検討したことを議事録に残します。

注2全員が特別利害関係人の場合
  1. 条文
    会社法 295条2項 （株主総会の権限）

    第2項　前項の規定にかかわらず、取締役会設置会社においては、株主総会は、この法律に規定する事項及び定款で定めた事項に限り、決議をすることができる。

  2. やさしく言うと

    取締役会のある会社では、株主総会が決められるのは、法律で定められた事項と定款で定めた事項に限られます。

  3. なぜこのルールか

    取締役会設置会社では、利益相反取引の承認は取締役会の権限とされています（会社法365条1項）。議決に加われる取締役がいなければ取締役会で承認できませんが、代わりに株主総会で承認できるかは、法律に明文がなく見解が分かれます。

  4. この事例では

    全員が特別利害関係人となる場合は、定款に「取締役会で承認できないときは株主総会で承認する」旨の定めを置いて株主総会で承認する方法や、株主全員の同意を得る方法を、弁護士と相談して選びます。取締役を増員して、利害関係のない取締役を確保する方法もあります。

  5. 判例
    株主全員の同意がある利益相反取引と取締役会の承認二次資料で確認
    最高裁判所 昭和49年9月26日 判決

    取締役と会社との利益相反取引が株主全員の同意（合意）によってされた場合には、取締役会（会社）の承認は不要であるとした判決として紹介されている。

    利益相反取引が株主全員の同意によってされた場合には、取締役会の承認は不要であるとした判決として紹介されているものです。株主が少数の会社では、株主全員の同意を得て記録を残す方法が検討されます。

注3議案を分けて議決できる取締役を確保する
  1. 条文
    会社法 369条2項 （取締役会の決議）

    第2項　前項の決議について特別の利害関係を有する取締役は、議決に加わることができない。

  2. やさしく言うと

    特別利害関係は、決議ごとに判断します。

  3. この事例では

    例えば、取締役A・Bの二人それぞれと会社が別々に取引する場合、一つの議案にまとめると二人とも外れますが、取引ごとに議案を分ければ、Aの議案ではBが、Bの議案ではAが議決に加われることがあります。ただし、二つの取引が実質的に一体なら、分けても利害関係は消えないので、無理に分けないでください。

  4. 落とし穴

    少人数の取締役会で利害関係者が多い状態が続くなら、社外取締役の選任など、機関設計そのものの見直しを検討してください。

Q244

当社の定款では、重要な議案について取締役会の決議要件を「出席取締役の3分の2以上の賛成」に加重している。ところが、過去の取締役会で、担当者が過半数の賛成で「可決」と扱っていた議案が見つかった。決議はどうなるか。どう処理すればよいか。

応用取締役会決議あり取締役会設置会社親子会社・グループ#
A
定款で決議要件を加重している場合は、その要件を満たさなければ決議は成立しません（会社法369条1項括弧書）。過半数の賛成しかなかった議案は、定款の要件に達していないので、決議は成立していないものとして扱うのが原則です。
決議に基づいて代表取締役が既に取引をしていた場合でも、相手方が決議の不備を知り又は知ることができたときでない限り、取引は有効とされる可能性があります（判例）。ただし、会社の内部では手続を欠いた状態なので、加重された要件で改めて決議し、既に行った行為を追認する必要があります。再決議で要件を満たせなければ、取引の扱い（解消、条件変更）を検討します。
なお、加重が定款ではなく取締役会規程や株主間契約（合弁契約）だけに定められている場合は、会社法369条1項の「定款で定めた場合」に当たらず、決議の効力には直接影響しないとの見方が一般的ですが、規程違反・契約違反の問題は残ります。

根拠が明らかでない点（推測を含みます）

  • 定款の加重要件を満たさない決議の効力（不成立か無効か）の呼び方や、その効果を直接判断した登録判例は確認できていません。
  • 取締役会規程や株主間契約だけで加重した場合に会社法上の決議の効力に影響しないという点は、会社法369条1項・29条の文言からの一般的な解釈（推測を含む）です。
  • 再決議による追認がさかのぼって効力を生じるかについては、明文・確立した判例は確認できていません。

実務のポイント

  • まず加重の根拠が定款か、取締役会規程か、株主間契約かを確認する。法律上決議の効力に関わるのは定款の定め。
  • 加重の対象となる議案の範囲（「重要な議案」の定義）を定款の文言で確認し、該当した議案を洗い出す。
  • 該当議案ごとに、採決時の出席者数・賛成数を議事録で確認し、要件の充足を判定する。
  • 要件を満たしていない議案は、加重要件で再決議・追認する。再決議が否決されたときの対応も事前に検討する。
  • 上程書・議事録のひな型に「決議要件（定款第○条）」欄を設け、議長シナリオで要件を読み上げる。

進め方

  1. 定款・取締役会規程・株主間契約の決議要件の定めを確認する。
  2. 過去の議事録を点検し、加重要件の対象なのに要件を満たしていない議案を一覧にする。
  3. 該当議案に基づく行為（契約の締結等）の実行状況を確認する。監査役に報告する。
  4. 合弁契約等がある場合は、相手方株主への説明を検討する。
  5. 次回（又は臨時）の取締役会で、加重要件に従って再決議・追認を行う。
  6. 議事録に決議要件と賛成数を明記する運用に改める。

すでに手続を欠いてしまった場合（事後の是正）

本問そのものが是正の手順です。定款の加重要件を満たさないまま可決として扱っていた場合の基本の順序は次のとおりです。

  1. 加重の根拠（定款・規程・契約）と対象議案の範囲を確認する。
  2. 過去の議事録から、要件を満たしていない議案を洗い出し、実行状況を確認する。監査役に報告する。
  3. 加重要件で再決議し、既に行った行為を追認する（文例の上程書・議事録）。
  4. 再決議で要件を満たせない場合は、取引の解消や条件変更を含めて対応を決める。
  5. 合弁の相手方など関係する株主に説明する。
  6. 上程書・議事録のひな型に決議要件欄を設ける。

法律上の注意点 注釈4件・クリックで開く

注1決議要件は定款で引き上げられる 重要
  1. 条文
    会社法 369条1項 （取締役会の決議）

    第1項　取締役会の決議は、議決に加わることができる取締役の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）が出席し、その過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行う。

  2. やさしく言うと

    取締役会の決議は出席者の過半数で決めるのが原則ですが、定款でそれより高い割合（例：3分の2以上）を定めることができます。定めた場合は、その割合を満たさないと決議は成立しません。

  3. なぜこのルールか

    合弁会社やオーナー一族の会社などで、重要な事項は少数派の取締役の賛成も得て決めたいというニーズに応えるためです。

  4. この事例では

    定款で3分の2以上と定めた議案を過半数で可決扱いにしたのは、要件を満たしていないので、決議は成立していないと考えるのが原則です。

注2規程や株主間契約だけで加重している場合
  1. 条文
    会社法 29条

    第二十七条各号及び前条各号に掲げる事項のほか、株式会社の定款には、この法律の規定により定款の定めがなければその効力を生じない事項及びその他の事項でこの法律の規定に違反しないものを記載し、又は記録することができる。

  2. やさしく言うと

    会社法が「定款で定めた場合」としている事項は、定款に書かなければ会社法上の効力を持ちません。

  3. 推測を含む点

    取締役会規程や合弁契約だけで決議要件を加重していた場合、会社法上の決議の効力には直接影響しないと考えるのが一般的ですが、規程違反として取締役の責任や、契約違反として相手方株主との紛争の問題が残ります。この点を直接判断した登録判例は確認できていません。

  4. この事例では

    どこに加重の定めがあるかで、処理が変わります。定款なら再決議が必須、規程・契約なら、その違反への対応（再決議や相手方への説明）を検討します。

注3既に行った取引の効力
  1. 条文
    会社法 349条4項 （株式会社の代表）

    第4項　代表取締役は、株式会社の業務に関する一切の裁判上又は裁判外の行為をする権限を有する。

  2. やさしく言うと

    代表取締役は会社を代表して一切の行為をする権限を持つので、取締役会の決議に不備があっても、結んだ契約が直ちに無効になるとは限りません。

  3. 判例
    取締役会決議を経ない代表取締役の取引の効力
    最高裁判所第三小法廷 昭和40年9月22日 判決（民集19巻6号1656頁）

    代表取締役が、取締役会の決議を経てすることを要する対外的な個々的取引行為を決議を経ないでした場合でも、相手方が決議を経ていないことを知り又は知ることができたときでない限り、その取引行為は有効であるとした判決。

    取締役会決議を要する取引を決議なしにした場合でも、相手方が決議のないことを知り又は知ることができたときでない限り有効とした判決です。

  4. この事例では

    相手方が議事録を確認していた場合や、合弁の相手方会社が取引の相手方である場合は、相手方が不備を知り得たと評価される可能性があります。早めに再決議・追認で手続を整えます。

注4再発防止：要件を議事録に明記する
  1. 条文
    会社法施行規則 101条3項 四号 （取締役会の議事録）

    第3項　取締役会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 四　取締役会の議事の経過の要領及びその結果
  2. やさしく言うと

    議事録には、議事の経過の要点とその結果を書きます。

  3. この事例では

    加重要件の議案では、議長が採決前に決議要件を告げ、議事録に「出席取締役○名中○名の賛成（3分の2以上）」と書くと、要件の充足を後から確認できます。

  4. 実務のコツ

    上程書の様式に「決議要件」欄を設け、事務局が定款の条項と照合してから上程します。
