Q152

定時株主総会で取締役を再任（重任）したが、変更登記をしないまま1か月が過ぎてしまった。どう対応すればよいか。

実務取締役会設置会社非公開会社公開会社#
A
気づいた時点で、直ちに重任による変更登記を申請してください。役員の氏名は登記事項なので、任期満了と同時に再任された場合でも「重任」の変更登記が必要で、期限は変更が生じた時から2週間以内です（会社法915条1項）。
期限を過ぎても登記の申請自体は受け付けられ、登記は通常どおりされます。ただし、登記を怠ったことについて、代表取締役などが100万円以下の過料に処せられることがあります（会社法976条1号）。過料は会社ではなく代表者個人に科される行政上の制裁で、遅れた期間などに応じて裁判所が決めます。
遅れを取り戻す方法はないので、「早く申請する」「同じ遅れを繰り返さない」の2つが対応の中心になります。

実務のポイント

  • 期限の起算点は「変更が生じた時」。重任なら任期満了の定時総会の終結時（その場で就任を承諾した場合）から2週間で、総会日の翌日から数えるのが一般的。
  • 再任でも登記は必要。「同じ人だから変更はない」という誤解が登記漏れの最大の原因。代表取締役の重任（取締役会での再選定）もあわせて登記する。
  • 登記の遅れは過料の対象になるが、それ以上に、登記が古いままだと金融機関取引や入札で登記事項証明書を出せず業務が止まる。
  • 任期満了時に後任を選んでいなかった（選任自体を忘れた）場合は、登記の問題ではなく選任懈怠の問題になる。速やかに株主総会を開いて選任する。
  • 長年登記をしていない会社は、最後の登記から12年で休眠会社として解散したものとみなされるおそれがある。非公開会社で任期を10年にしている会社は特に注意。

進め方

  1. 登記事項証明書を取り、登記されている役員と任期・選任日を確認する。
  2. 定時総会の議事録、就任承諾の有無、代表取締役を選定した取締役会議事録を揃える。
  3. 登記申請書と添付書類（株主総会議事録、株主リスト、取締役会議事録など）を作成し、本店所在地の登記所に申請する（オンライン申請も可）。
  4. 司法書士に依頼する場合は、遅れている事実を最初に伝え、最短の申請日を決める。
  5. 後日、裁判所から過料の通知が届いたら、代表者個人として対応する（会社の経費処理の可否は税理士に確認）。
  6. 役員の任期一覧（選任日・満了予定の定時総会・登記日）を作り、総会準備のスケジュールに「登記申請」を組み込む。

注1変更登記はいつまでにしなければならないか 重要
  1. 条文
    会社法 915条1項 （変更の登記）

    第1項　会社において第九百十一条第三項各号又は前三条各号に掲げる事項に変更が生じたときは、二週間以内に、その本店の所在地において、変更の登記をしなければならない。

  2. 条文
    会社法 911条3項 十三・十四号 （株式会社の設立の登記）

    第3項　第一項の登記においては、次に掲げる事項を登記しなければならない。

    • 十三　取締役（監査等委員会設置会社の取締役を除く。）の氏名
    • 十四　代表取締役の氏名及び住所（第二十三号に規定する場合を除く。）
  3. やさしく言うと

    取締役の氏名や代表取締役の氏名・住所は、登記簿に載せる事項です。これらに変更があったときは、2週間以内に本店の所在地で変更の登記をしなければなりません。

  4. なぜこのルールか

    登記は、取引の相手方が「この会社の代表者は誰か」を確認するための公の記録です。現実と登記がずれていると、相手方が誤った人と取引してしまうおそれがあるので、短い期限が定められています。

  5. 用語

    重任：任期が満了した役員が、同じ総会で再び選任され、間を置かずに引き続き就任すること。登記簿には「重任」と記録されます。

  6. この事例では

    再任でも、登記簿には任期ごとの就任の記録が必要なので、重任の登記をします。今回は既に期限を過ぎているので、書類を揃えて一日でも早く申請してください。

  2. やさしく言うと

    登記を怠った取締役や代表取締役などは、100万円以下の過料に処せられることがあります。過料は刑罰ではなく、行政上の秩序を守るための金銭的な制裁です。

    過料の対象は、登記を申請すべき立場の代表取締役などの個人です。期限を過ぎた登記も受け付けられるので、まず申請を済ませます。遅れた理由を記録した社内報告書を残しておくと、再発防止策の説明に役立ちます。

注4長期間登記をしないと解散したものとみなされることがある
  1. 条文
    会社法 472条1項 （休眠会社のみなし解散）

    第1項　休眠会社（株式会社であって、当該株式会社に関する登記が最後にあった日から十二年を経過したものをいう。以下この条において同じ。）は、法務大臣が休眠会社に対し二箇月以内に法務省令で定めるところによりその本店の所在地を管轄する登記所に事業を廃止していない旨の届出をすべき旨を官報に公告した場合において、その届出をしないときは、その二箇月の期間の満了の時に、解散したものとみなす。ただし、当該期間内に当該休眠会社に関する登記がされたときは、この限りでない。

  2. やさしく言うと

    最後の登記から12年たった株式会社は「休眠会社」とされ、法務大臣の公告後2か月以内に「事業を廃止していない」旨の届出をしないと、解散したものとみなされます。

  3. この事例では

    役員の重任登記を何年も忘れている会社は、この対象になるおそれがあります。登記事項証明書で最後の登記の日を確認し、登記漏れがあれば、まとめて申請してください。

  4. 実務のコツ

    任期を長くした会社でも、少なくとも任期ごとに重任登記が入るので、任期管理と登記管理を一体にしておけば休眠会社扱いを防げます。

Q153

株主総会で取締役・監査役を選任した。役員変更登記の申請にはどの書類を添付すればよいか。

基本取締役会設置会社監査役設置会社#
A
基本は、①株主総会議事録、②株主リスト、③就任承諾書（又はそれに代わる議事録の記載）の3点で、代表取締役を選定した場合は④取締役会議事録が加わります（商業登記法46条2項、54条1項、商業登記規則61条3項）。
さらに、新任（再任でない）の取締役・監査役については本人確認証明書（住民票の写しなど）が、新たに代表取締役になる者については就任承諾書の印鑑の印鑑証明書が必要です（商業登記規則61条4項・5項・7項）。代表取締役を選定した取締役会議事録には、原則として出席取締役・監査役の印鑑証明書が必要ですが、前の代表取締役が登記所届出の印鑑を押していれば不要です（同条6項）。
誰が新任で誰が再任か、代表取締役が変わるかどうかで必要書類が変わるので、総会前に一覧表で整理してください。

実務のポイント

  • 株主リストは総会ごと・議案ごとに作るのが原則。議決権数上位10名か、上位から加算して3分の2に達するまでの株主のうち、少ない方の人数を記載し、代表取締役が証明する。
  • 就任承諾は、総会の席上で承諾し議事録にその旨を記載すれば、議事録を就任承諾書として援用する取扱いが登記実務で広く行われている。欠席者からは就任承諾書を取る。
  • 取締役会設置会社では、取締役（代表取締役以外）の印鑑証明書は不要だが、新任の取締役・監査役には本人確認証明書が必要になる。
  • 代表取締役が交代する場合は、新代表者の印鑑の届出（印鑑届書）もあわせて行う。
  • 添付書類を電子データで作成しオンライン申請する場合は、電子署名の要件が書面とは異なるので、法務省の案内で確認する。

進め方

  1. 総会の議案確定時に、役員ごとに「新任・再任・退任」「代表取締役の交代の有無」を一覧にする。
  2. 新任者から本人確認証明書（又は印鑑証明書）、欠席予定者から就任承諾書を事前に取得する。
  3. 総会議事録に、選任の結果と、出席候補者が席上で就任を承諾した旨を記載する。
  4. 総会の基準日の株主名簿をもとに、株主リストを作成する（株主名簿管理人に依頼すると早い）。
  5. 取締役会で代表取締役を選定した場合は、取締役会議事録を作り、押印する印鑑を確認する。
  6. 申請書を作成し、総会日から2週間以内に申請する。

注1株主総会議事録を添付する根拠
  1. 条文
    商業登記法 46条2項 （添付書面の通則）

    第2項　登記すべき事項につき株主総会若しくは種類株主総会、取締役会又は清算人会の決議を要するときは、申請書にその議事録を添付しなければならない。

  2. やさしく言うと

    登記する内容が株主総会や取締役会の決議で決まるものなら、その決議があったことを示すために議事録を添付します。

  3. この事例では

    取締役・監査役の選任は総会の決議で、代表取締役の選定は取締役会の決議で決まるので、それぞれの議事録を添付します。書面決議（みなし決議）の場合は、議事録に代えて決議があったとみなされることを証する書面を添付します（同条3項）。

  4. 実務のコツ

    登記官は議事録の記載だけで判断するので、選任された人の氏名、決議の結果、就任承諾の有無を正確に書いてください。氏名の漢字の誤りは、登記の補正や却下の原因になります。

実務上場会社#
A
総会で決議事項が決議されたときは、金融商品取引法に基づき、「遅滞なく」臨時報告書をEDINETで提出します（金融商品取引法24条の5第4項）。提出が必要な場合と記載事項は内閣府令（企業内容等の開示に関する内閣府令）で定められており、総会の開催日、決議事項の内容、決議事項ごとの賛成・反対・棄権の議決権の数、可決の要件、決議の結果などを記載します。
実務では、総会の当日から数日以内に提出する会社が多く、事前行使分に当日出席株主の分をどこまで加えたか（全部を集計しなかった場合はその理由）も書きます。これは会社法ではなく金融商品取引法上の開示なので、会社法上の議事録や決議通知とは別に準備が必要です。
また、総会での決議内容によっては、取引所の規則による適時開示や書類の提出が求められるので、取引所のガイドブックで確認してください。

実務のポイント

  • 賛否の数は、事前行使（書面・電子）分と、当日出席の大株主など賛否を確認できた分の合計で記載するのが一般的。当日分の一部を集計しなかった場合は、その理由を書く。
  • 可決要件（普通決議・特別決議など）と、決議の結果（賛成比率を含む）を議案ごとに書く。役員選任議案は候補者ごとに書く。
  • 株主名簿管理人（信託銀行）の集計データと議事録の結果が一致しているか、提出前に必ず照合する。
  • 提出後に数字の誤りが判明したら、訂正報告書を提出する。誤りの原因（集計の範囲・転記ミス）を記録しておく。
  • 総会で定款変更や配当などを決議した場合の取引所への開示・書類提出は、取引所規則の制度なので、適時開示ガイドブックで要否と期限を確認する。

  1. 総会前に、株主名簿管理人と、当日出席株主の賛否を集計する範囲（大株主・機関投資家など）と方法を決めておく。

  4. 経理・IR部門と法務部門で内容を確認し、代表者の確認を得る。
  5. EDINETで提出する（総会日から数日以内を目安に、遅滞なく）。
  6. 提出後に誤りが判明したら、速やかに訂正報告書を提出し、必要に応じて社内記録を残す。

    有価証券報告書を出している会社（上場会社など）は、投資者のために必要なものとして内閣府令が定める出来事が起きたときに、その内容を書いた臨時報告書を遅滞なく提出しなければなりません。株主総会で決議事項が決議されたことは、内閣府令で定められた提出事由の一つです。

  3. なぜこのルールか

    どの議案にどれだけの反対があったかは、投資者が会社の経営や議案への支持の度合いを判断する重要な情報です。株主総会の結果を速やかに公表させるために設けられています。

  4. この事例では

    提出期限は日数で決められていませんが、「遅滞なく」なので、総会後数日以内に出すのが実務の通例です。総会の準備スケジュールに、集計の確定日と提出予定日を入れておいてください。

  5. 落とし穴

    提出の要否・記載事項の細目は内閣府令や開示ガイドラインで定められ、改正もあります。前年の書類をそのまま使わず、最新の様式を確認してください。

注2当日出席分をどこまで集計するか
  1. 条文
    会社法 311条2項 （書面による議決権の行使）

    第2項　前項の規定により書面によって行使した議決権の数は、出席した株主の議決権の数に算入する。

  2. やさしく言うと

    書面で議決権を行使した株主は、総会に出席したものとして数えます。事前行使の分は賛否がはっきりしているので、そのまま集計できます。

  3. この事例では

    会社法上は、賛成が可決要件を満たしたことが明らかになれば決議は成立するので、当日出席株主の全員の賛否を数える必要はありません。そのため臨時報告書では、事前行使分に、当日出席した大株主など賛否を確認できた分を加え、残りを加算しなかった理由を記載する扱いが広く行われています。

  4. 実務のコツ

    当日の集計範囲（どの株主の分を加算するか）は、総会前に株主名簿管理人と決めておきます。賛否が拮抗しそうな議案は、当日分も含めて集計できる体制を用意してください。

  1. 条文

    臨時報告書にも、有価証券届出書の訂正の規定が準用されており、内容に誤りなどがあれば訂正報告書を提出します。重要な事項に虚偽の記載や記載漏れがあった場合の責任の規定も準用されています。

    賛否の数の転記ミスや議案番号の誤りに気づいたら、速やかに訂正報告書を提出します。可決・否決の結論自体が変わるような誤りなら、決議の効力の問題（集計の誤り）として、法務部門・弁護士とあわせて検討してください。

    臨時報告書の数字と、会社のウェブサイトに掲載した決議通知・議事録の数字が食い違わないよう、訂正するときは全部を一緒に直します。

Q155 株主総会の後、株主に決議通知を送る必要はあるか。決算公告との関係や、決議通知に誤りがあった場合はどうするか。
Q155

株主総会の後、株主に決議通知を送る必要はあるか。決算公告との関係や、決議通知に誤りがあった場合はどうするか。

基本取締役会設置会社公開会社非公開会社#
A
決議通知（総会の結果を知らせる書面）の送付は、会社法上の義務ではありません。総会に出席しなかった株主に結果を知らせるため、多くの上場会社などが慣行として送付したり、ウェブサイトに掲載したりしています。
これとは別に、定時総会の後には、貸借対照表（大会社は損益計算書も）の公告（決算公告）が会社法上の義務です（会社法440条1項）。ただし、有価証券報告書を提出している会社は不要です（同条4項）。決議通知に貸借対照表を載せても、決算公告をしたことにはならない点に注意してください。
決議通知に誤りがあっても、総会で成立した決議の効力には影響しません。誤りの内容を確認し、訂正のお知らせを送付又は掲載するのが通常の対応です。

実務のポイント

  • 決議通知は任意なので、送るか、ウェブ掲載にとどめるかは会社が決めてよい。配当金の支払通知と同封する例が多い。
  • 決算公告は、定款で定めた公告方法で行う。官報・新聞なら貸借対照表の要旨で足り、電子公告やウェブでの掲載（5年間）を選ぶこともできる。
  • 有価証券報告書の提出会社は決算公告が不要。上場会社は代わりに臨時報告書（議決権行使結果）を提出する。
  • 決議通知の誤りは決議の効力に影響しないが、決議の内容（配当額・選任された者）を誤って伝えると株主が混乱するので、すぐ訂正する。
  • 決議通知と議事録・臨時報告書・登記の内容が一致しているか、総会後に一度照合する。

進め方

  1. 総会前に、決議通知の形式（郵送／ウェブ掲載）と発送日を決め、原案を作っておく。
  2. 総会当日、結果に応じて決議通知の原案を確定する（修正動議・否決があれば反映）。
  3. 議事録・集計結果と照合したうえで発送・掲載する。
  4. 決算公告が必要な会社は、公告方法に従い、定時総会の終結後遅滞なく公告する。
  5. 誤りが見つかったら、正誤表を作り、訂正のお知らせを送付・掲載する。

注1決算公告は会社法上の義務 重要
  1. 条文
    会社法 440条1項 （計算書類の公告）

    第1項　株式会社は、法務省令で定めるところにより、定時株主総会の終結後遅滞なく、貸借対照表（大会社にあっては、貸借対照表及び損益計算書）を公告しなければならない。

  2. 条文
    会社法 440条4項 （計算書類の公告）

    第4項　金融商品取引法第二十四条第一項の規定により有価証券報告書を内閣総理大臣に提出しなければならない株式会社については、前三項の規定は、適用しない。

  3. やさしく言うと

    株式会社は、定時総会が終わったら遅滞なく、貸借対照表（大会社は損益計算書も）を公告しなければなりません。ただし、有価証券報告書を提出する会社は、その中で財務情報を開示しているので不要です。

  4. なぜこのルールか

    会社の取引先（債権者）などが、会社の財産の状態を知ることができるようにするための仕組みです。

  5. この事例では

    非上場の会社は、決議通知を送るかどうかとは関係なく、決算公告をしなければなりません。決議通知に貸借対照表を載せて株主に送っても、公告にはなりません。公告をしないことは過料の対象にもなります。

注2決算公告の方法
  1. 条文
    会社法 939条1項 一・二・三号 （会社の公告方法）

    第1項　会社は、公告方法として、次に掲げる方法のいずれかを定款で定めることができる。

    • 一　官報に掲載する方法
    • 二　時事に関する事項を掲載する日刊新聞紙に掲載する方法
    • 三　電子公告
  2. 条文
    会社法 440条3項 （計算書類の公告）

    第3項　前項の株式会社は、法務省令で定めるところにより、定時株主総会の終結後遅滞なく、第一項に規定する貸借対照表の内容である情報を、定時株主総会の終結の日後五年を経過する日までの間、継続して電磁的方法により不特定多数の者が提供を受けることができる状態に置く措置をとることができる。この場合においては、前二項の規定は、適用しない。

  3. やさしく言うと

    公告の方法は、定款で官報・日刊新聞・電子公告のいずれかに決めます。官報や新聞で公告する会社は、貸借対照表の要旨で足ります。また、貸借対照表の内容を自社のウェブサイトなどに5年間掲載する方法をとれば、官報などでの決算公告に代えることができます。

  4. この事例では

    官報公告の会社は、掲載の申込みから掲載まで日数がかかるので、総会の準備と並行して手配します。ウェブ掲載で代える場合は、そのURLを登記する必要があります（会社法911条3項26号）。

  5. 実務のコツ

    定款の公告方法と、実際に行っている公告方法が一致しているか、登記事項証明書で確認してください。

注3決議通知の誤りは決議の効力に影響しない
  1. 条文
    会社法 318条1項 （議事録）

    第1項　株主総会の議事については、法務省令で定めるところにより、議事録を作成しなければならない。

  2. やさしく言うと

    株主総会の議事は議事録に残すことが義務づけられています。決議の内容を示す正式な記録は議事録であって、決議通知は株主へのお知らせにすぎません。

  3. この事例では

    決議通知の数字や氏名を誤っても、総会での決議は議事録どおりに成立しています。訂正のお知らせでは「決議の内容に変更はない」ことを明記して、株主の不安を防ぎます。逆に、議事録自体に誤りがあるときは、議事録の訂正として別に検討が必要です。

  4. 落とし穴

    配当金の額や支払開始日を誤って通知すると、問い合わせが殺到します。配当関係の数字は、取締役会の決議・総会の決議・株主名簿管理人の支払データの3つと照合してから発送してください。
