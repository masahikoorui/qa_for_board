Q197

取締役会をWEB会議（Zoom・Teams等）で開催できるか。どんな条件を満たせば「出席」として扱えるか。

基本取締役会設置会社#
A
できます。会社法施行規則は、取締役会の開催場所にいない取締役が出席した場合の「出席の方法」を議事録に書くよう定めており（会社法施行規則101条3項1号）、WEB会議や電話会議による出席を前提にしています。
WEB会議で出席したと認められるには、出席者の音声（と映像）が即時に他の出席者に伝わり、出席者が一堂に会するのと同じように、適時・的確に意見を述べ合える状態であることが必要と一般に解されています。登記実務でも、このような状態が確保されていたことが議事録に記載されていれば、WEB会議・電話会議による取締役会の議事録を登記の添付書面として扱っています。
実務では、①参加者全員の音声が相互に聞こえることを開会時に確認する、②本人であることを確認する、③資料を全員が見られるようにする、④議事録に出席の方法と上記の状態を記載する、の4点を押さえてください。

実務のポイント

  • 開会時に、議長がオンライン出席者の名前を呼んで音声・映像の接続を確認し、「一堂に会するのと同等に意見交換ができる」ことを確認する。
  • 議事録の冒頭（日時・場所の欄）に、誰がどの方法で出席したかを記載する（会社法施行規則101条3項1号）。
  • 資料は事前に送付するか、画面共有する。機密資料はダウンロード不可の共有方法を使う。
  • オンライン出席者のいる場所で第三者が聞いていないか（秘密保持）を確認する。
  • 取締役会規程にWEB会議による出席を認める条項を置き、運用ルール（本人確認、通信障害時の扱い）を定めておく。

進め方

  1. 招集通知に、WEB会議による出席が可能なこと、接続方法を記載する。
  2. 事前に接続テストを行い、資料を送付する。
  3. 開会時に、議長が出席者全員の接続と音声の相互確認を行い、定足数を確認する。
  4. 議事中、オンライン出席者にも発言の機会を与え、採決では一人ずつ賛否を確認する。
  5. 議事録に、出席の方法と通信状態の確認結果を記載する。
  6. 議事録に署名（又は電子署名）をもらう。

注1WEB会議での出席は法令が予定している 重要
  1. 条文
    会社法施行規則 101条3項 一号 （取締役会の議事録）

    第3項　取締役会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 一　取締役会が開催された日時及び場所（当該場所に存しない取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役）、執行役、会計参与、監査役、会計監査人又は株主が取締役会に出席をした場合における当該出席の方法を含む。）
  2. やさしく言うと

    取締役会の議事録には、開催した日時と場所を書きます。その場所にいない取締役などが出席したときは、どのような方法で出席したかも書きます。

  3. なぜこのルールか

    この規定は、会議室にいなくても電話やWEB会議で出席できることを前提にしています。取締役が遠隔地にいても議論に加われるようにし、取締役会を開きやすくするためです。

  4. この事例では

    WEB会議で出席した取締役については、議事録の「場所」の欄に「取締役○○はWEB会議システムにより出席した」と書きます。誰がどの方法で出席したかを一人ずつ特定してください。

注2「出席」と言えるための条件
  1. 条文
    会社法 369条1項 （取締役会の決議）

    第1項　取締役会の決議は、議決に加わることができる取締役の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）が出席し、その過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行う。

  2. やさしく言うと

    取締役会の決議には、議決に加われる取締役の過半数の「出席」が必要です。

  3. なぜこのルールか

    取締役会は、取締役が互いに意見を述べ合い、議論を通じてよりよい結論を出す場です。そのため、遠隔地からの参加が「出席」と言えるには、会議室にいるのと同じように、その場で発言し、他の人の発言を聞いて応じられる状態が必要だと考えられています。

  4. この事例では

    WEB会議では、映像がなくても音声が双方向で即時に伝わっていれば足りると一般に解されています。逆に、音声が聞こえない、一方的に視聴しているだけ、という状態は出席に当たりません。議長は開会時と採決時に、全員の音声を確認してください。

  5. 実務のコツ

    議事録に「出席者の音声と映像が即時に他の出席者に伝わり、適時的確な意見表明が互いにできる状態であることを確認した」と書く記載例が、登記実務でも広く使われています。

注3WEB会議の議事録への署名
  1. 条文
    会社法 369条3項 （取締役会の決議）

    第3項　取締役会の議事については、法務省令で定めるところにより、議事録を作成し、議事録が書面をもって作成されているときは、出席した取締役及び監査役は、これに署名し、又は記名押印しなければならない。

  2. 条文
    会社法 369条4項 （取締役会の決議）

    第4項　前項の議事録が電磁的記録をもって作成されている場合における当該電磁的記録に記録された事項については、法務省令で定める署名又は記名押印に代わる措置をとらなければならない。

  3. 条文
    会社法施行規則 225条1項 六号 （電子署名）

    第1項　次に掲げる規定に規定する法務省令で定める署名又は記名押印に代わる措置は、電子署名とする。

    • 六　法第三百六十九条第四項（法第四百九十条第五項において準用する場合を含む。）
  4. やさしく言うと

    書面の議事録には、出席した取締役・監査役が署名か記名押印をします。議事録を電子データ（電磁的記録）で作る場合は、署名の代わりに電子署名をします。

  5. この事例では

    WEB会議で出席した取締役も「出席した取締役」なので、署名（記名押印）が必要です。遠隔地の出席者が多い場合は、議事録を電子データで作成し、電子署名サービスで署名を集めると効率的です。書面で作る場合は、議事録を郵送で回付します。

  6. 落とし穴

    登記に使う議事録で、代表取締役の選定など印鑑証明書が必要な場合は、電子署名の種類に制限があるなど、登記所の扱いが細かく決まっています。登記に使う議事録の作り方は事前に司法書士・法務局に確認してください。

Q198

海外出張中の取締役が、現地から電話で取締役会に参加したいと言っている。出席として扱えるか。注意点は何か。

実務取締役会決議あり取締役会設置会社#
A
扱えます。電話会議でも、その取締役の音声が即時に他の出席者に伝わり、他の出席者の発言も即時に聞けて、一堂に会するのと同じように適時・的確に意見を述べ合える状態であれば、取締役会に出席したものと扱われます。海外からの参加であっても、この点は変わりません。
注意点は、①本人確認（声だけでは分かりにくいので、事前に登録した番号からの接続や、合言葉の確認をする）、②資料の共有（電話では画面を見られないので、事前に資料を送り、議長が「資料○ページの」と特定しながら進める）、③時差・通信状況（現地時間の深夜を避ける、通話が途切れた場合の連絡方法を決める）、④秘密保持（ホテルのロビーや空港など第三者がいる場所で参加させない）、⑤議事録への記載と署名（出席の方法を書き、署名は帰国後又は電子署名で）です。

実務のポイント

  • 電話番号・接続方法を事前に決め、開会時に議長が本人の声と在席を確認する。
  • 資料は事前にメールで送り、電話出席者が手元で見られることを確認する。
  • 採決では、電話出席者に個別に賛否を聞き、「賛成」と明確に発言してもらう。
  • 電話出席者がいる場所の周囲に第三者がいないことを確認する（インサイダー情報を含む議案では特に重要）。
  • 通話が切れたときに備え、事務局の携帯番号を伝え、切断中に採決しない運用にする。

進め方

  1. 出張予定の取締役と、参加方法（電話番号、現地時間、場所）を事前に調整する。
  2. 議案資料を事前に送付し、受信を確認する。
  3. 開会時に、議長が電話出席者の声と在席を確認し、音声が相互に聞こえることを確認する。
  4. 審議では、電話出席者に発言の機会を個別に与える。
  5. 採決では、電話出席者の賛否を個別に確認する。
  6. 議事録に「取締役○○は電話会議の方法により出席した」と記載し、帰国後に署名をもらう（又は電子署名）。

WEB会議で開いた取締役会の途中で、ある取締役の通信が途切れて戻らないまま採決になった。決議は有効か。どう処理すればよいか。

実務取締役会決議あり取締役会設置会社#
A
通信が途切れている間、その取締役は取締役会に出席していないものとして扱うのが一般的な考え方です。そのため、①その取締役を除いても、議決に加わることができる取締役の過半数が出席しており（定足数）、②出席者の過半数が賛成している（会社法369条1項）なら、決議は成立していると考えられます。
ただし、通信の途絶を議長が把握しないまま採決し、その取締役を「出席・賛成」として数えていた場合は問題です。定足数・賛成数の計算をやり直し、要件を満たしていなければ決議は成立していません。また、途絶した取締役が反対意見を述べるつもりだったなど、その取締役の参加が議論に影響し得た事情があるときは、決議の効力が争われるおそれがあります。
実務では、通信が切れたら、①議長は直ちに審議・採決を中断し、②一定時間（例：10分）再接続や電話での参加を試み、③戻らなければ、その取締役を欠席として定足数を再確認したうえで続行するか、重要な議案は次回に延期します。議事録には、途絶した時刻・復帰の有無・その間の議事を記載します。

実務のポイント

  • 通信が途絶えた取締役は、その間「出席していない」扱い。途絶中の採決では、その取締役を定足数・賛成数に数えない。
  • 議長は採決の直前に、オンライン出席者の接続を確認する（名前を呼んで返事をもらう）。
  • 通信が途切れたときの手順（中断、再接続の試み、電話への切替え、延期の判断）を取締役会規程や議長シナリオに定めておく。
  • 途絶した取締役が反対の可能性がある議案や、賛否が拮抗する議案は、無理に採決せず延期を検討する。
  • 議事録に、途絶・復帰の時刻と、その間に審議・採決した議案を正確に記載する。

進め方

  1. 通信の途絶に気付いたら、議長が審議を一時中断し、事務局が電話等で本人に連絡する。
  2. 一定時間内に再接続できれば、途絶中の議論の要点を説明してから再開する。
  3. 再接続できなければ、その取締役を欠席として、定足数を満たしているかを確認する。
  4. 議案の重要性・賛否の状況を考え、続行して採決するか、延期するかを判断する。
  5. 採決した場合は、途絶した取締役に結果を連絡し、意見があれば次回の取締役会で報告させる。
  6. 議事録に、途絶・復帰の時刻、定足数の確認、採決の結果を記載する。

実務取締役会設置会社#
A
会社法には取締役会の議長についての規定がなく、定款又は取締役会規程で定めるのが通例です。多くの会社は「取締役会は取締役社長が議長となる。社長に事故があるときは、あらかじめ定めた順序により他の取締役が議長となる」と定めています。定めがない場合は、出席取締役の互選（多数決）で議長を選びます。
社長が欠席した場合は、定款の順位に従って他の取締役が議長を務めます。社長自身が特別利害関係を有する議案（社長の会社との取引の承認、社長の解職など）では、社長はその議案の議決に加われないため（会社法369条2項）、その議案の間は議長を交代するのが適切と一般に解されています。議長は議事を整理し、採決を行う立場なので、利害関係のある人が務めると公正さが疑われるからです。
議事録には議長の氏名を書きます（会社法施行規則101条3項8号）。議長が交代した場合は、交代した議案と交代後の議長の氏名を記載します。

実務のポイント

  • 定款・取締役会規程で、議長と代行順位を定める。「事故があるとき」に、特別利害関係を有する場合を含めておくと運用しやすい。
  • 社外取締役を議長とする会社も増えている（監督と執行の分離）。その場合も代行順位を定める。
  • 議長も取締役として議決権を行使できる。可否同数のときに議長が決める（決裁権）とする定めは、一般に無効と解されている。
  • 特別利害関係のある議案では、議長を交代したうえで、その取締役を退席させるのが通例。
  • 議事録には、議長の氏名、交代した場合はその議案と交代後の議長を記載する。

進め方

  1. 開催前に、議長予定者の出欠と、議長が特別利害関係を有する議案がないかを確認する。
  2. 議長が欠席・特別利害関係を有する場合は、定款・規程の順位で代行議長を決め、議長シナリオを用意する。
  3. 当日、議長が交代するときは、交代の理由を述べてから交代する。
  4. 交代後の議長が当該議案を審議・採決し、終了後に元の議長に戻す。
  5. 議事録に、議長の氏名と交代の経緯を記載する。

実務のポイント

  • 陪席させる者の範囲と、陪席の可否を誰が決めるか（議長）を取締役会規程に定める。
  • 陪席者には秘密保持の義務を確認する（社員は就業規則、顧問弁護士は守秘義務、外部の者には秘密保持契約）。
  • 説明が終わった陪席者は、審議・採決の前に退席させる運用にすると、取締役どうしの率直な議論がしやすい。
  • 陪席者本人の人事・報酬の議案、本人の所属部門の不正調査の議案では、必ず退席させる。
  • 議事録には、陪席者の発言を「○○部長から説明があった」のように記載し、出席者（取締役・監査役）と区別する。

進め方

  1. 議案ごとに、説明のために必要な陪席者を決め、議長の了承を得る。
  2. 陪席者に、出席の時間帯（当該議案の説明時のみ等）と秘密保持を伝える。
  3. 当日、議長が陪席者の入室・退席を指示する。
  4. 人事・不正調査などの議案の前に、関係する陪席者を退席させたことを確認する。
  5. 議事録に、説明者として陪席者の氏名・役職と説明の要旨を記載する。

応用取締役会設置会社#
A
録画を後で見て賛成を伝えてきた取締役は、出席としても賛成としても扱えません。取締役会の出席には、その場で他の出席者と即時に意見を交換できることが必要で、後からの賛成表明は、会議への参加とはいえないからです。このような事後の賛成は、定款に定めがある場合の書面決議（会社法370条）とも違います。書面決議は、会議を開かずに全員が提案に同意する別の制度だからです。
チャットだけで参加した場合は、見解が分かれ得る難しい場面です。他の出席者の発言を即時に聞けて、自分の意見もチャットで即時に伝わり、議長がそれを読み上げるなどして議論に反映できる状態なら、出席と扱える余地があるという考え方もあります。しかし、音声による「即時・双方向」のやりとりが確保されていたかは後で争われやすく、慎重に扱うのが安全です。
実務では、音声が使えない取締役には電話での参加に切り替えてもらい、それもできなければ欠席として扱い、定足数を確認したうえで決議します。重要な議案で、その取締役の参加が欠かせない場合は延期を検討します。

実務のポイント

  • 後から録画を見ての賛成は、出席にも賛成にもならない。その取締役は欠席として記録する。
  • チャットのみの参加は、出席の扱いに疑義が残る。電話への切替えを優先し、切り替えられなければ欠席として扱うのが無難。
  • 欠席者の賛否を決議に数えたい場合は、会議ではなく書面決議（定款の定め、全員の同意、監査役の異議なし）を使うしかない。
  • 定足数がその取締役の出席に依存している場合は、特に慎重に扱う（欠席扱いで定足数割れなら決議できない）。
  • 議事録には、その取締役の参加状況（音声不調、電話への切替え、欠席扱いの時刻）を事実どおり書く。

進め方

  1. 音声の不調が分かったら、議長が審議を一時中断し、事務局が電話での参加への切替えを依頼する。
  2. 電話で参加できれば、音声の相互確認をしてから再開する。
  3. 電話でも参加できなければ、その取締役を欠席として扱い、定足数を確認する。
  4. 定足数を満たしていれば採決する。満たさない、又は重要な議案なら延期する。
  5. 後から賛成を伝えてきた欠席取締役には、決議には数えられないことを説明し、意見は次回の取締役会で述べてもらう。
  6. 議事録に事実経過を記載する。

注1「出席」には即時の意見交換が必要 重要
  1. 条文
    会社法 369条1項 （取締役会の決議）

    第1項　取締役会の決議は、議決に加わることができる取締役の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）が出席し、その過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行う。

  2. やさしく言うと

    取締役会の決議は、出席した取締役の過半数の賛成で決まります。会議に出席していない取締役の意見は、賛否の数に入りません。

  3. なぜこのルールか

    取締役会は、取締役が互いに議論し、他の人の意見を聞いて考えを改めることもある場です。会議の後に録画を見て賛成するのでは、この議論に参加したことになりません。

  4. この事例では

    録画を見て後から賛成を伝えてきた取締役は、欠席として扱います。その取締役を数えなくても定足数と過半数の賛成を満たしていれば、決議は有効です。満たしていなければ、決議は成立していないので、改めて取締役会を開く必要があります。

  5. 落とし穴

    後からの賛成を議事録上「出席・賛成」と記載すると、事実と異なる議事録になります。議事録の虚偽記載は過料の対象にもなり得ます（会社法976条7号）。

注2チャットだけの参加をどう考えるか
  1. 条文
    会社法施行規則 101条3項 一号 （取締役会の議事録）

    第3項　取締役会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 一　取締役会が開催された日時及び場所（当該場所に存しない取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役）、執行役、会計参与、監査役、会計監査人又は株主が取締役会に出席をした場合における当該出席の方法を含む。）
  2. やさしく言うと

    議事録には、会議の場所にいない取締役の出席の方法を書きます。法令は、どの方法なら出席になるかまでは定めていません。

  3. なぜこのルールか

    出席と言えるかどうかは、その方法で即時に双方向の意見交換ができるかで判断されると一般に解されています。チャットは文字の入力に時間がかかり、他の人が読み落とすこともあるため、音声と同じように即時の意見交換ができるかは状況によります。

  4. この事例では

    チャットだけで参加した取締役を出席として扱うことには、後で争われる余地が残ります。音声が使えない場合は、まず電話への切替えを試み、それができなければ欠席として扱うのが安全です。チャットで寄せられた意見は、議長が読み上げて議論の参考にし、議事録には「欠席取締役から意見が寄せられた」と記録します。

注3会議に出られない取締役の賛成を生かすには
  1. 条文
    会社法 370条 （取締役会の決議の省略）

    取締役会設置会社は、取締役が取締役会の決議の目的である事項について提案をした場合において、当該提案につき取締役（当該事項について議決に加わることができるものに限る。）の全員が書面又は電磁的記録により同意の意思表示をしたとき（監査役設置会社にあっては、監査役が当該提案について異議を述べたときを除く。）は、当該提案を可決する旨の取締役会の決議があったものとみなす旨を定款で定めることができる。

  2. やさしく言うと

    定款に定めがあれば、会議を開かずに、議決に加われる取締役全員が提案に書面やメールで同意することで、決議があったものとみなすことができます（書面決議）。

  3. なぜこのルールか

    書面決議は、会議での議論を省く代わりに、全員の同意という高いハードルを課しています。会議に出なかった一人の賛成を、会議の決議に足すための制度ではありません。

  4. この事例では

    会議を開いた以上、その決議は出席者の多数決で決まります。欠席者の賛否を反映させたいなら、最初から書面決議を使うか、欠席者も出席できる日に会議を開くことになります。

  5. 判例
    表見代表取締役（代表取締役代行者）と持ち回り決議
    最高裁判所第一小法廷 昭和44年11月27日 判決（民集23巻11号2301頁）

    「代表取締役代行者」という名称は、旧商法262条にいう会社を代表する権限を有するものと認むべき名称に当たるとした。また、持ち回りの方式によった決議は有効な取締役会の決議とは認められないとされた事例であり、代表者選任が無効な場合に旧商法262条の類推適用により会社が善意の第三者に責任を負うとされた事例でもある。

    持ち回りの方式（取締役を個別に回って賛成を集める方式）による決議は、有効な取締役会の決議とは認められないとされた事例です。会議に出ない取締役の賛成を個別に集めても、会議の決議にはならないことを示しています。
