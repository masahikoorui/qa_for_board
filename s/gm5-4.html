Q126

会計監査人設置会社では、計算書類を定時株主総会で「承認」ではなく「報告」で済ませられると聞いた。どのような条件で、どのように手続を進めればよいか。

基本取締役会決議あり取締役会設置会社監査役設置会社上場会社#
A
会計監査人設置会社で、取締役会の承認を受けた計算書類について、会計監査人の無限定適正意見があり、監査役（監査役会等）の監査報告に会計監査人の監査を相当でないとする意見がないなどの要件を満たせば、定時株主総会の承認は不要となり、取締役が内容を報告すれば足ります（会社法439条、会社計算規則135条）。
この場合、計算書類は取締役会の承認の時点で確定します。そのため、取締役会での計算書類の承認決議が実質的な「確定」の手続になります。
要件を一つでも欠くと、原則どおり総会の承認決議（会社法438条2項）が必要です。監査報告を受け取った段階で要件を点検し、承認議案にするか報告事項にするかを招集の決定までに確定させてください。

実務のポイント

  • 会計監査報告が「無限定適正意見」か（限定付適正意見・不適正意見・意見不表明なら報告では済まない）。
  • 監査役会（監査等委員会・監査委員会）の監査報告に、会計監査人の監査の方法又は結果を「相当でない」とする意見がないか。監査役会設置会社では、各監査役の付記意見にも注意する。
  • 監査報告の通知期限を過ぎて「監査を受けたものとみなされた」計算書類でないか（会社計算規則135条4号）。
  • 事業報告は、会計監査人設置会社でも常に「報告事項」。承認議案にはならない。
  • 取締役会の承認決議の日が計算書類の確定日になる。その後の修正は原則としてできない前提で、取締役会の前に最終版を固める。

進め方

  1. 決算期末後、計算書類・事業報告・附属明細書を作成し、会計監査人と監査役（監査役会）に提出する。
  2. 会計監査報告と監査役会の監査報告を受領し、会社計算規則135条の要件を満たすか確認する。
  3. 取締役会で、監査を受けた計算書類・事業報告・附属明細書（連結計算書類があればそれも）を承認する。
  4. 同じ取締役会（又は別の回）で定時株主総会の招集を決定し、計算書類を報告事項とする旨を目的事項に定める。
  5. 招集通知に計算書類・事業報告・監査報告を添付（電子提供措置をとる会社はその措置）して発送する。
  6. 総会当日、議長（又は担当取締役）が計算書類の内容を報告する。決議はとらない。
  7. 総会議事録には、報告事項として計算書類の内容を報告した旨を記載する。

法律上の注意点 注釈4件・クリックで開く

注1原則：計算書類は定時株主総会の承認が必要 重要
  1. 条文
    会社法 438条2項 （計算書類等の定時株主総会への提出等）

    第2項　前項の規定により提出され、又は提供された計算書類は、定時株主総会の承認を受けなければならない。

  2. 条文
    会社法 438条3項 （計算書類等の定時株主総会への提出等）

    第3項　取締役は、第一項の規定により提出され、又は提供された事業報告の内容を定時株主総会に報告しなければならない。

  3. やさしく言うと

    計算書類（貸借対照表や損益計算書など）は、株主が総会で「承認」して初めて確定するのが原則です。一方、事業報告は、内容を総会で「報告」すればよく、承認の決議はいりません。

  4. なぜこのルールか

    計算書類の数字は、配当できる金額（分配可能額）の計算の基礎になります。会社の持ち主である株主に、その数字を確定させる権限を持たせているのです。

  5. この事例では

    会計監査人を置いていない会社や、置いていても次の注釈の要件を満たさない会社では、招集通知の目的事項に「決議事項　第【○】期計算書類承認の件」を立て、議案として決議をとります。

注2例外：会計監査人設置会社の特則（報告で足りる場合） 重要
  1. 条文
    会社法 439条 （会計監査人設置会社の特則）

    会計監査人設置会社については、第四百三十六条第三項の承認を受けた計算書類が法令及び定款に従い株式会社の財産及び損益の状況を正しく表示しているものとして法務省令で定める要件に該当する場合には、前条第二項の規定は、適用しない。この場合においては、取締役は、当該計算書類の内容を定時株主総会に報告しなければならない。

  2. 条文
    会社計算規則 135条1項 一・二・四・五号

    法第四百三十九条及び第四百四十一条第四項（以下この条において「承認特則規定」という。）に規定する法務省令で定める要件は、次の各号（監査役設置会社であって監査役会設置会社でない株式会社にあっては、第三号を除く。）のいずれにも該当することとする。

    • 一　承認特則規定に規定する計算関係書類についての会計監査報告の内容に第百二十六条第一項第二号イに定める事項（当該計算関係書類が臨時計算書類である場合にあっては、当該事項に相当する事項を含む。）が含まれていること。
    • 二　前号の会計監査報告に係る監査役、監査役会、監査等委員会又は監査委員会の監査報告（監査役会設置会社にあっては、第百二十八条第一項の規定により作成した監査役会の監査報告に限る。）の内容として会計監査人の監査の方法又は結果を相当でないと認める意見がないこと。
    • 四　承認特則規定に規定する計算関係書類が第百三十二条第三項の規定により監査を受けたものとみなされたものでないこと。
    • 五　取締役会を設置していること。
  3. やさしく言うと

    会計監査人（公認会計士・監査法人）が「この計算書類は正しい」と意見を出し、監査役側もその監査を「相当でない」と言っておらず、取締役会で承認していれば、総会の承認はいらず、報告だけでよくなります。

  4. なぜこのルールか

    会計の専門家と監査役の二重のチェックを通っているなら、株主総会で改めて承認するまでもない、という考え方です。上場会社など大きな会社では、総会の負担を減らす意味もあります。

  5. 用語

    無限定適正意見：会計監査人が、計算書類が会社の財産・損益の状況をすべての重要な点で正しく表示していると認めるときに出す意見。会社計算規則126条1項2号イの意見がこれに当たる。

  6. この事例では

    監査報告を受け取ったら、①会計監査報告が無限定適正意見か、②監査役会の監査報告に「相当でない」意見がないか、③付記意見がその意見になっていないか、④監査報告が期限内に出ているか、を確認します。全部満たせば報告事項、一つでも欠ければ承認議案です。

  7. 落とし穴

    招集通知の発送後に監査報告の内容が要件を満たさないと分かった場合、報告事項のまま総会を開くと計算書類が確定しません。招集の決定前に監査報告を受領して確認するスケジュールを組んでください。

注3取締役会の承認が「確定」の時点になる
  1. 条文
    会社法 436条3項 （計算書類等の監査等）

    第3項　取締役会設置会社においては、前条第二項の計算書類及び事業報告並びにこれらの附属明細書（第一項又は前項の規定の適用がある場合にあっては、第一項又は前項の監査を受けたもの）は、取締役会の承認を受けなければならない。

  2. やさしく言うと

    取締役会がある会社では、監査を受けた計算書類や事業報告を、取締役会で承認しなければなりません。

  3. なぜこのルールか

    会社法439条の特則が使える場合、総会の承認がないので、この取締役会の承認が計算書類を確定させる最後の手続になります。

  4. この事例では

    上程書に監査結果と「439条の要件を満たす」旨を書き、議事録にも監査役の報告と議長の説明を残します。後日、配当の分配可能額や役員の責任（会社法465条など）を判断するとき、確定日がいつかが問題になるため、記録として重要です。

  5. 実務のコツ

    連結計算書類は、承認議案になることはなく、内容と監査の結果を総会に報告します（会社法444条7項）。報告事項の件名にまとめて記載するのが一般的です。

注4招集通知に何を付けるか
  1. 条文
    会社法 437条 （計算書類等の株主への提供）

    取締役会設置会社においては、取締役は、定時株主総会の招集の通知に際して、法務省令で定めるところにより、株主に対し、前条第三項の承認を受けた計算書類及び事業報告（同条第一項又は第二項の規定の適用がある場合にあっては、監査報告又は会計監査報告を含む。）を提供しなければならない。

  2. やさしく言うと

    取締役会がある会社では、定時総会の招集通知と一緒に、取締役会で承認された計算書類・事業報告と、監査報告・会計監査報告を株主に提供しなければなりません。

  3. この事例では

    報告事項扱いでも、計算書類と監査報告の提供は省略できません。電子提供措置をとる上場会社では、電子提供措置事項として掲載します。

  4. 実務のコツ

    本店での備置き（会社法442条1項）は、取締役会設置会社では総会の2週間前の日から始まります。招集通知の発送日と同じ日から備え置く運用にしておくと漏れません。

注1配当決議で定める3つの事項 重要
  1. 条文
    会社法 454条1項 （剰余金の配当に関する事項の決定）

    第1項　株式会社は、前条の規定による剰余金の配当をしようとするときは、その都度、株主総会の決議によって、次に掲げる事項を定めなければならない。

    • 一　配当財産の種類（当該株式会社の株式等を除く。）及び帳簿価額の総額
    • 二　株主に対する配当財産の割当てに関する事項
    • 三　当該剰余金の配当がその効力を生ずる日
  2. やさしく言うと

    配当をするたびに、株主総会で「何を配るか（通常は金銭）と総額」「株主にどう割り当てるか（1株いくら）」「いつ効力が生じるか」を決めます。決議要件は、特別な定めがない限り普通決議です。

  3. なぜこのルールか

    配当は会社の財産が株主に出ていく行為なので、その都度、株主自身が中身を確認して決める仕組みにしています。

  4. この事例では

    参考書類と議事録に、この3つを漏れなく書きます。「1株につき○円」だけで総額が書いていない、効力発生日が書いていない、という不備がよく見られます。

  5. 落とし穴

    1株当たりの金額は、株式の数に応じて平等でなければなりません（会社法454条3項）。特定の株主だけ多く配ることはできません（種類株式で内容を定めている場合を除く）。

注2分配可能額の範囲内か（効力発生日で判定） 重要
  1. 条文
    会社法 461条1項 八号 （配当等の制限）

    第1項　次に掲げる行為により株主に対して交付する金銭等（当該株式会社の株式を除く。以下この節において同じ。）の帳簿価額の総額は、当該行為がその効力を生ずる日における分配可能額を超えてはならない。

    • 八　剰余金の配当
  2. やさしく言うと

    配当で株主に渡す金銭の総額は、配当の効力が生じる日の「分配可能額」を超えてはいけません。分配可能額は、ざっくり言えば、期末の剰余金から自己株式の帳簿価額などを差し引いた、株主に配ってよい上限額です。

  3. なぜこのルールか

    会社の財産を株主に配りすぎると、会社に貸している債権者が返済を受けられなくなります。債権者を守るための上限です。

  4. この事例では

    取締役会の時点では、期末の数字に、期末後の自己株式の取得・処分などを反映させて、効力発生日の分配可能額を見込みます。上程書に計算表を付け、議事録に「分配可能額の範囲内であることを確認した」旨を残します。

  5. 実務のコツ

    期末後に自己株式を取得した、資本金を減少したなどの事情があると、分配可能額が期末時点と変わります。経理部に「期末後の変動」を一覧にしてもらうと確認しやすくなります（本節「分配可能額の計算」の問を参照）。

注3準備金の積立て
  1. 条文
    会社法 445条4項 （資本金の額及び準備金の額）

    第4項　剰余金の配当をする場合には、株式会社は、法務省令で定めるところにより、当該剰余金の配当により減少する剰余金の額に十分の一を乗じて得た額を資本準備金又は利益準備金（以下「準備金」と総称する。）として計上しなければならない。

    第2項　株式会社が剰余金の配当をする場合には、剰余金の配当後の利益準備金の額は、当該剰余金の配当の直前の利益準備金の額に、次の各号に掲げる場合の区分に応じ、当該各号に定める額を加えて得た額とする。

    配当をすると、配当で減る剰余金の10分の1を準備金として積み立てなければなりません。ただし、準備金の合計が資本金の4分の1（基準資本金額）に達していれば、積み立てる必要はありません。

  4. なぜこのルールか

    準備金は、会社の財産の「クッション」です。配当のたびに少しずつ積み立てさせることで、債権者のための財産を確保します。

  5. この事例では

    上程書の判断材料に、準備金の現在額と、積立てが必要かどうか・必要ならその額を書きます。積立ては法律上当然に行うもので、総会の議案にする必要はありませんが、株主資本等変動計算書には反映させます。

    第2項　基準日を定める場合には、株式会社は、基準日株主が行使することができる権利（基準日から三箇月以内に行使するものに限る。）の内容を定めなければならない。

  2. やさしく言うと

    基準日を決めて「この日の株主に権利を与える」とする場合、その権利は基準日から3か月以内に行使されるものに限られます。

  3. この事例では

    定時総会を期末から3か月を超えた時期に開く会社は、定款の基準日の定めとの関係を事前に整理しておく必要があります。

期中の利益を分配可能額に含めたい場合は、臨時計算書類を作成して承認を受ける必要があります（会社法441条、461条2項2号）。

  • 「期末時点」ではなく「効力発生日時点」で判定する。期末後の自己株式取得・消却・配当・資本金等の減少を全部洗い出す。
  • 自己株式の帳簿価額は、期末に保有していた分も期末後に取得した分も、効力発生日に保有していれば差し引かれる。
  • 期中の利益は、臨時計算書類を作らない限り分配可能額に入らない。業績が良くても期末後の利益は使えない。
  • のれん・繰延資産が大きい会社、その他有価証券評価差額金がマイナスの会社は、会社計算規則158条の控除で分配可能額が大きく減ることがある。
  • 取締役会や総会の決議日と効力発生日の間にさらに自己株式を取得する予定があれば、その分も見込んでおく。

進め方

  1. 期末の貸借対照表から、その他資本剰余金とその他利益剰余金の合計（期末の剰余金の額）を確認する。
  2. 期末後から効力発生日までの株主資本の変動（自己株式の取得・処分・消却、資本金・準備金の減少、配当）を一覧にする。
  3. 会社法446条に従い、効力発生日の剰余金の額を計算する。
  4. 会社法461条2項・会社計算規則158条の控除項目（自己株式の帳簿価額、のれん等調整額、評価差額金など）を差し引き、分配可能額を出す。
  5. 配当総額（及び同時期の自己株式取得枠）と比べ、余裕があるかを確認する。
  6. 計算表を取締役会の上程書に添付し、監査役にも共有する。

      イ　資産の額
      ロ　自己株式の帳簿価額の合計額
      ハ　負債の額
      ニ　資本金及び準備金の額の合計額

    • 五　最終事業年度の末日後に第百七十八条第一項の規定により自己株式の消却をした場合における当該自己株式の帳簿価額
    • 六　最終事業年度の末日後に剰余金の配当をした場合における次に掲げる額の合計額

  2. やさしく言うと

    剰余金の額は、期末の貸借対照表から計算した額をスタートにして、期末後に自己株式を消却した、配当をした、資本金を減らした、といった変動を足し引きして求めます。

  3. なぜこのルールか

    期末後にも会社の財産は動きます。配当する時点での実際の状態に近づけるため、期末後の変動を反映させる仕組みになっています。

  4. この事例では

    期末後に自己株式を「取得」しただけでは、剰余金の額は変わりません（消却すれば会社法446条5号で減ります）。取得した自己株式は、次の注釈の分配可能額の計算で差し引かれます。どちらの段階で影響するかを区別すると計算を間違えません。

注2分配可能額は「剰余金の額」から自己株式等を差し引く 重要
  1. 条文
    会社法 461条2項 一・三・四・六号 （配当等の制限）

    第2項　前項に規定する「分配可能額」とは、第一号及び第二号に掲げる額の合計額から第三号から第六号までに掲げる額の合計額を減じて得た額をいう（以下この節において同じ。）。

    • 一　剰余金の額
    • 三　自己株式の帳簿価額
    • 四　最終事業年度の末日後に自己株式を処分した場合における当該自己株式の対価の額
    • 六　前三号に掲げるもののほか、法務省令で定める各勘定科目に計上した額の合計額
  2. やさしく言うと

    分配可能額は、剰余金の額から、会社が持っている自己株式の帳簿価額、期末後に自己株式を売った代金、法務省令で定める項目などを差し引いた額です。

  3. なぜこのルールか

    自己株式の取得も、株主にお金を払う点では配当と同じです。すでに自己株式取得で払った分は、配当の上限からも差し引くことで、二重に払い出すことを防いでいます。

  4. この事例では

    期末後に取得した自己株式の帳簿価額は、効力発生日に保有していれば丸ごと差し引かれます。今回の事例では、取得額の分だけ分配可能額が減るので、配当総額が収まるかを計算し直してください。

  5. 落とし穴

    自己株式の取得自体も分配可能額の規制を受けます（会社法461条1項2号・3号）。配当と自己株式取得の両方を予定しているときは、合計額で分配可能額に収まるかを確認する必要があります。

配当の支払後に、計算の誤りで分配可能額を超える配当をしていたことが判明した。会社としてどう対応すればよいか。

応用取締役会決議あり取締役会設置会社監査役設置会社#
A
分配可能額を超えた配当については、配当を受けた株主と、配当に関する職務を行った業務執行者・総会に議案を提案した取締役などが、会社に対し連帯して、交付された金銭の帳簿価額に相当する額を支払う義務を負います（会社法462条1項）。会社は、まず事実と超過額を確定し、誰にどう支払を求めるかを取締役会で決める必要があります。
取締役等は、注意を怠らなかったことを証明すれば責任を負いません（同条2項）。また、この義務は原則として免除できず、行為時の分配可能額を限度とする免除に総株主の同意が必要です（同条3項）。
違法配当であることを知らなかった株主は、支払をした取締役等からの求償には応じなくてよいとされています（会社法463条1項）。そのため実務では、多数の株主から回収するのではなく、取締役等の責任の追及や、再度の適法な配当決議による是正など、事案に応じた対応を弁護士と検討します。違法配当の効力（無効か有効か）については見解が分かれています。

実務のポイント

  • まず超過の有無と額を確定する：効力発生日の分配可能額を再計算し、会計監査人の確認を得る。
  • 責任を負う者を特定する：配当の職務を行った業務執行取締役、総会議案提案取締役（会社法462条1項6号イ）、取締役会議案提案取締役など。
  • 監査役に直ちに報告し、取締役の責任追及の訴えについては監査役が会社を代表する点に注意する（会社法386条）。
  • 上場会社では、決算訂正や適時開示（取引所規則）の要否を並行して検討する。
  • 再発防止として、配当決議前の分配可能額の計算を複数部署でチェックする手順を定める。

進め方

  1. 経理部・会計監査人とともに、効力発生日の分配可能額と配当総額を再計算し、超過額を確定する。
  2. 監査役（監査役会）に報告し、外部の弁護士に責任関係と効力について意見を求める。
  3. 取締役会で、事実関係の報告を受け、対応方針（取締役等への請求、株主への請求の要否、是正措置）を決議する。
  4. 責任を負う取締役等に対し、支払を求める通知をする（取締役に対する訴えの提起は監査役が会社を代表する）。
  5. 上場会社は、開示の要否を検討し、必要なら適時開示を行う。
  6. 次回の定時総会で、事実と対応を株主に報告する（事業報告への記載を含めて検討）。

    第2項　前項の規定にかかわらず、業務執行者及び同項各号に定める者は、その職務を行うについて注意を怠らなかったことを証明したときは、同項の義務を負わない。

  2. 条文
    会社法 462条3項 （剰余金の配当等に関する責任）

    第3項　第一項の規定により業務執行者及び同項各号に定める者の負う義務は、免除することができない。ただし、前条第一項各号に掲げる行為の時における分配可能額を限度として当該義務を免除することについて総株主の同意がある場合は、この限りでない。

  3. やさしく言うと

    取締役が「注意を尽くしていた」と証明できれば、支払義務を負いません。また、この義務は原則として免除できず、例外として、配当時の分配可能額の範囲までなら、株主全員の同意で免除できます。

  4. なぜこのルールか

    分配可能額までの部分は本来配ってよかった額なので、株主全員が同意すれば免除してよいが、それを超える部分は債権者のための財産なので、株主の同意だけでは免除できない、という考え方です。

  5. この事例では

    取締役会では、計算の誤りがどの段階でなぜ起きたかを調べ、各取締役が注意を尽くしていたかを判断する材料を残します。上場会社など株主が多数の会社では、総株主の同意による免除は事実上困難です。

    会社法424条以下の一般の責任免除・責任限定の手続は、この義務には使えません。会社法462条3項の特別な規定が優先します。

Q130

子会社株式を株主に配当（現物配当）したい。金銭以外の財産を配当する場合、決議要件や手続はどう変わるか。

応用取締役会決議あり取締役会設置会社非公開会社公開会社#
A
金銭以外の財産を配当すること（現物配当）もできますが、当社の株式・社債・新株予約権は配当財産にできません（会社法454条1項1号）。
株主に金銭分配請求権（現物の代わりに金銭を請求できる権利）を与えるなら普通決議で足りますが、与えない場合は特別決議が必要です（会社法309条2項10号）。
また、会計監査人設置会社が定款で配当を取締役会で決められるとしていても、金銭分配請求権を与えない現物配当は取締役会では決められず、株主総会の決議が必要です（会社法459条1項4号ただし書）。
一定数未満の株式しか持たない株主には現物を割り当てず、金銭を支払う扱い（基準株式数）を定めることもできます（会社法454条4項2号、456条）。子会社株式の配当は税務上の扱い（スピンオフ税制等）も大きく影響するため、税理士等の確認が欠かせません。

実務のポイント

  • 配当財産の「帳簿価額の総額」で分配可能額を判定する（時価ではない）。
  • 金銭分配請求権を与えるか、与えないかで決議要件が変わる（与えない＝特別決議）。
  • 子会社株式を配ると子会社の株主が多数になるため、子会社側の株主名簿・譲渡制限（承認手続）・株主数の増加への対応を準備する。
  • 端数（基準株式数未満）の株主への金銭の支払額の算定方法を決めておく。
  • 税務（法人税・源泉所得税）の取扱いは制度が複雑なため、専門家の確認を必須とする。

進め方

  1. 配当財産（子会社株式の数・帳簿価額）を確定し、分配可能額の範囲内か確認する。
  2. 金銭分配請求権を与えるか、基準株式数を設けるかを決め、税務上の取扱いを専門家と確認する。
  3. 取締役会で、株主総会の招集と現物配当議案の内容を決定する。
  4. 招集通知・参考書類に、配当財産の種類・帳簿価額の総額・割当て・効力発生日、金銭分配請求権の有無等を記載する。
  5. 金銭分配請求権を与える場合は、行使期間の末日の20日前までに株主に通知する（会社法455条1項）。
  6. 総会で決議する（金銭分配請求権を与えないなら特別決議）。
  7. 効力発生日に株式を交付し、子会社の株主名簿の名義書換えを行う。

注1現物配当で定める事項 重要
  1. 条文
    会社法 454条4項 一・二号 （剰余金の配当に関する事項の決定）

    第4項　配当財産が金銭以外の財産であるときは、株式会社は、株主総会の決議によって、次に掲げる事項を定めることができる。ただし、第一号の期間の末日は、第一項第三号の日以前の日でなければならない。

    • 一　株主に対して金銭分配請求権（当該配当財産に代えて金銭を交付することを株式会社に対して請求する権利をいう。以下この章において同じ。）を与えるときは、その旨及び金銭分配請求権を行使することができる期間
    • 二　一定の数未満の数の株式を有する株主に対して配当財産の割当てをしないこととするときは、その旨及びその数
  2. やさしく言うと

    金銭以外の財産を配るときは、通常の3事項に加えて、①株主に「現物の代わりに金銭をください」と言える権利（金銭分配請求権）を与えるか、②少ししか株式を持たない株主には現物を配らずに金銭を払うか、を総会で決められます。

  3. なぜこのルールか

    現物は分けにくく、株主によっては受け取っても困る財産もあります。金銭で受け取る道を用意したり、端数の処理をしたりできるようにしています。

  4. この事例では

    子会社株式の配当では、株主に金銭分配請求権を与えると会社が多額の現金を用意しなければならないため、与えない設計が一般的です。その場合は次の注釈のとおり特別決議になります。

注2金銭分配請求権を与えないなら特別決議 重要
  1. 条文
    会社法 309条2項 十号 （株主総会の決議）

    第2項　前項の規定にかかわらず、次に掲げる株主総会の決議は、当該株主総会において議決権を行使することができる株主の議決権の過半数（三分の一以上の割合を定款で定めた場合にあっては、その割合以上）を有する株主が出席し、出席した当該株主の議決権の三分の二（これを上回る割合を定款で定めた場合にあっては、その割合）以上に当たる多数をもって行わなければならない。この場合においては、当該決議の要件に加えて、一定の数以上の株主の賛成を要する旨その他の要件を定款で定めることを妨げない。

    • 十　第四百五十四条第四項の株主総会（配当財産が金銭以外の財産であり、かつ、株主に対して同項第一号に規定する金銭分配請求権を与えないこととする場合に限る。）
  2. やさしく言うと

    金銭以外の財産を配り、しかも金銭で受け取る選択肢を株主に与えない場合は、出席株主の議決権の3分の2以上の賛成が必要な特別決議になります。

  3. なぜこのルールか

    株主は、受け取りたくない財産を一方的に押しつけられることになるため、普通決議より慎重な要件にしています。

  4. この事例では

    招集通知の参考書類に、特別決議である理由を書いておくと、株主にも決議要件が分かります。議事録にも「出席株主の議決権の3分の2以上の賛成」と書きます。

Q131

会計監査が総会日までに終わらない見込みになった。定時株主総会はどうすればよいか（継続会で計算書類を扱う方法）。

実務取締役会設置会社監査役設置会社上場会社#
A
予定どおり定時株主総会を開催し、計算書類の承認（又は報告）などを後日の「継続会」で行う旨を総会で決議する方法が一般的です。継続会は同じ総会の続きなので、改めて招集の決定や招集通知をする必要はありません（会社法317条）。
当日の総会では、継続会の日時・場所を決めるか、議長に一任する決議をします。監査が終わったら、計算書類と監査報告を株主に提供し、継続会で承認（又は報告）します。
継続会は相当の期間内に開く必要があると一般に解されています。また、配当の基準日から3か月以内に配当決議をする必要がある点や、役員の任期が「定時総会の終結の時」まで続く点に注意してください。

実務のポイント

  • 継続会の決議は、総会の普通決議で行う。日時・場所を当日決めるか、議長（取締役会）に一任するかを決める。
  • 継続会で扱う事項（計算書類の承認・報告、事業報告）と、当日決議する事項（役員選任など）を分ける。
  • 取締役の任期は「定時総会の終結の時」まで。継続会が終わるまで総会は終結しないため、退任予定の役員の任期も継続会まで延びると考えられている。登記の日付に注意する。
  • 監査完了後、継続会の前に、計算書類・監査報告を株主に提供し、本店に備え置く。
  • 上場会社では、決算発表の延期・有価証券報告書の提出期限延長など、取引所規則・金商法上の対応も並行して行う。

進め方

  1. 監査の遅れが判明した時点で、監査役・会計監査人と完了見込み日を確認し、取締役会で継続会方式で進める方針を決める。
  2. 招集通知（既に発送済みなら追加の通知・ウェブ掲載）で、計算書類を継続会で扱う予定であることを株主に知らせる。
  3. 総会当日、役員選任など他の議案を決議し、計算書類の承認等を継続会で行う旨の決議をとる。
  4. 監査完了後、取締役会で計算書類を承認し、株主に計算書類・監査報告を提供する。
  5. 継続会を開催し、計算書類の承認（又は報告）を行う。
  6. 当日分と継続会分の総会議事録をそれぞれ作成する。

注1継続会なら改めて招集手続はいらない 重要
  1. 条文
    会社法 317条 （延期又は続行の決議）

    株主総会においてその延期又は続行について決議があった場合には、第二百九十八条及び第二百九十九条の規定は、適用しない。

  2. やさしく言うと

    総会で「この続きは後日やります」（続行＝継続会）と決めたときは、続きの会のために、改めて取締役会で招集を決めたり、招集通知を送ったりする必要はありません。

  3. なぜこのルールか

    継続会は、元の総会と同じ一つの総会の続きと扱われるからです。株主はその総会で日程を知ることができます。

  4. この事例では

    当日の総会で継続会の決議をとり、日時・場所を当日決めるか議長一任とします。一任した場合は、決まった日時・場所を株主に知らせる運用（書面・ウェブサイト）をとるのが実務です。法律上の招集通知ではないので、2週間前の期間制限はかかりませんが、株主が出席できるよう余裕をもって知らせてください。

  5. 落とし穴

    継続会があまりに先の日になると、実質的には新しい総会と同じで、別途の招集手続が必要ではないかと問題になり得ます。相当の期間内（実務上は数週間程度が目安とされることが多い）に開くようにしてください。

注2継続会の前に計算書類を株主に提供する
  1. 条文
    会社法 437条 （計算書類等の株主への提供）

    取締役会設置会社においては、取締役は、定時株主総会の招集の通知に際して、法務省令で定めるところにより、株主に対し、前条第三項の承認を受けた計算書類及び事業報告（同条第一項又は第二項の規定の適用がある場合にあっては、監査報告又は会計監査報告を含む。）を提供しなければならない。

  2. 条文
    会社法 442条1項 一号 （計算書類等の備置き及び閲覧等）

    第1項　株式会社は、次の各号に掲げるもの（以下この条において「計算書類等」という。）を、当該各号に定める期間、その本店に備え置かなければならない。

    • 一　各事業年度に係る計算書類及び事業報告並びにこれらの附属明細書（第四百三十六条第一項又は第二項の規定の適用がある場合にあっては、監査報告又は会計監査報告を含む。）　定時株主総会の日の一週間（取締役会設置会社にあっては、二週間）前の日（第三百十九条第一項の場合にあっては、同項の提案があった日）から五年間
  3. やさしく言うと

    本来、計算書類と監査報告は招集通知と一緒に株主に渡し、総会の2週間前から本店に置いておくべきものです。

  4. この事例では

    監査が遅れると、招集通知の時点では計算書類を提供できません。継続会方式では、監査完了後、継続会より相当前に、計算書類と監査報告を株主に提供し、本店に備え置く扱いが一般的です。条文が直接予定していない状況なので、提供の時期・方法は弁護士とも相談して決めてください。

  5. 実務のコツ

    上場会社では、電子提供措置の追加掲載や取引所への開示を合わせて行います。

注3役員の任期と継続会
  1. 条文
    会社法 332条1項 （取締役の任期）

    第1項　取締役の任期は、選任後二年以内に終了する事業年度のうち最終のものに関する定時株主総会の終結の時までとする。ただし、定款又は株主総会の決議によって、その任期を短縮することを妨げない。

  2. やさしく言うと

    取締役の任期は、選任後2年以内に終わる最後の事業年度の定時株主総会が「終わった時」までです。

  3. この事例では

    継続会を決めた場合、定時総会は継続会が終わるまで終結しないと考えられています。そのため、任期満了で退任する予定の取締役は、継続会の終結の時まで在任し、退任の登記の退任日も継続会の日になると解されています。当日の総会で後任を選ぶ場合は、就任の時期（当日か、継続会の終結の時か）を議案で明確にしておきましょう。

  4. 落とし穴

    当日の総会終了後に任期満了の登記を申請してしまうと、退任日が誤りになります。登記は継続会の後に申請してください。

注4配当がある場合の基準日の問題
  1. 条文
    会社法 124条2項 （基準日）

    第2項　基準日を定める場合には、株式会社は、基準日株主が行使することができる権利（基準日から三箇月以内に行使するものに限る。）の内容を定めなければならない。

  2. やさしく言うと

    基準日の株主が行使できる権利は、基準日から3か月以内に行使するものに限られます。

  3. この事例では

    期末を配当の基準日としている会社で、配当議案を継続会に回すと、決議が基準日から3か月を超えるおそれがあります。その場合は、配当議案だけは当日の総会で決議する（分配可能額の確認ができる場合）か、別の基準日を設けるなどの対応を検討します。

  4. 実務のコツ

    議決権の基準日についても同じ問題があるため、継続会の日程は基準日から3か月以内に収めるのが安全です。
