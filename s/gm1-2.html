Q009

3月決算の会社の定時総会が6月に集中するのはなぜか。「基準日」とは何か。

基本取締役会設置会社公開会社上場会社#
A
基準日とは、「この日に株主名簿に載っている株主に、権利を行使させる」と会社が定める日のことです。株式は日々売買されるので、議決権を持つ株主を特定の日で確定させるために使います。
基準日の株主が行使できる権利は、基準日から3か月以内に行使するものに限られます（会社法124条2項）。多くの会社は定款で事業年度末日（3月31日）を定時総会の基準日と定めているので、定時総会は3か月以内の6月末までに開く必要があり、6月下旬に集中します。
定款に基準日を定めておけば、毎年の公告は不要です。定款にない基準日を定めるときは、基準日の2週間前までに公告します。

実務のポイント

  • 定款の「定時株主総会の議決権の基準日」の条項と、事業年度末日を確認する。
  • 基準日から3か月以内に総会を開けない場合は、別の基準日を定め直す必要がある（開催延期の問いを参照）。
  • 基準日は義務ではない。株主が少なく株式の移動がない非公開会社では、総会当日の株主名簿上の株主に議決権を行使させる方法もある。
  • 上場会社では、振替制度により、基準日の株主は総株主通知によって会社に通知される（株主名簿管理人との日程調整が必要）。
  • 剰余金の配当の基準日（期末配当・中間配当）も、通常は定款で定めている。総会の基準日と同じ日にするのが一般的。

注1基準日とは 重要
  1. 条文
    会社法 124条1項 （基準日）

    第1項　株式会社は、一定の日（以下この章において「基準日」という。）を定めて、基準日において株主名簿に記載され、又は記録されている株主（以下この条において「基準日株主」という。）をその権利を行使することができる者と定めることができる。

  2. 条文
    会社法 124条2項 （基準日）

    第2項　基準日を定める場合には、株式会社は、基準日株主が行使することができる権利（基準日から三箇月以内に行使するものに限る。）の内容を定めなければならない。

  3. やさしく言うと

    会社は、ある日（基準日）を決めて、その日に株主名簿に載っている人を「権利を使える株主」とすることができます。ただし、基準日の株主が使える権利は、基準日から3か月以内に使うものに限られます。

  4. なぜこのルールか

    上場株式のように毎日持ち主が変わる場合、総会当日の株主を確定してから招集通知を送ることはできません。そこで、ある日で区切って株主を確定させます。一方、あまりに古い日の株主に権利を使わせると、既に株を手放した人が議決権を持つことになるので、3か月の上限があります。

  5. この事例では

    3月31日が基準日なら、6月30日までに総会を開く必要があります。会場の確保、監査の日程、招集通知の発送期限を考えると、多くの会社が6月下旬に開くことになります。

  6. 用語

    株主名簿：株主の氏名・住所・持株数などを記載した会社の帳簿。上場会社では、株主名簿管理人（信託銀行等）が管理している。

注2定款に定めれば公告は不要
  1. 条文
    会社法 124条3項 （基準日）

    第3項　株式会社は、基準日を定めたときは、当該基準日の二週間前までに、当該基準日及び前項の規定により定めた事項を公告しなければならない。ただし、定款に当該基準日及び当該事項について定めがあるときは、この限りでない。

  2. やさしく言うと

    基準日を定めたら、その2週間前までに、基準日と行使できる権利の内容を公告します。ただし、定款に基準日と権利の内容が書いてあれば、公告は要りません。

  3. この事例では

    定時総会の基準日は定款に定めておくのが通例なので、毎年の公告は不要です。臨時総会など定款にない基準日を使う場合は、取締役会で基準日を決め、2週間前までに定款所定の方法（官報、日刊新聞、電子公告）で公告します。

  4. 落とし穴

    公告の方法は定款で決まっています（会社法939条）。電子公告の会社は、調査機関による調査の手配も必要なので、日程に余裕を持たせてください。

注3定時総会の時期
  1. 条文
    会社法 296条1項 （株主総会の招集）

    第1項　定時株主総会は、毎事業年度の終了後一定の時期に招集しなければならない。

  2. やさしく言うと

    定時総会は、決算期の後の「一定の時期」に開きます。会社法は何か月以内とは定めていませんが、基準日を事業年度末日にしていると、3か月以内に開く必要が出てきます。

  3. この事例では

    6月に開くのは法律の直接の要求ではなく、「基準日を3月31日とする定款」と「基準日から3か月以内」というルールの組合せの結果です。基準日を変えれば、7月以降に定時総会を開くことも可能です（定款変更が必要になることが多い）。

  4. 実務のコツ

    上場会社では、有価証券報告書の提出期限（事業年度経過後3か月以内）との関係もあるため、6月の開催が定着しています。

実務取締役会設置会社監査役設置会社公開会社#
A
総会日を仮に決め、①招集通知の発送期限、②計算書類等の備置き開始日、③決算取締役会（計算書類の承認・招集決定）、④監査役・会計監査人の監査報告の受領日、⑤計算書類の監査役等への提供日、の順に逆算します。
発送は総会の2週間前まで（会社法299条1項）、備置きも総会の2週間前の日から（会社法442条1項）です。会計監査報告は原則として計算書類の受領から4週間を経過した日まで、監査役会の監査報告はその受領から1週間を経過した日までに通知することとされており（会社計算規則130条、132条）、合意で日程を定めることもできます。
上場会社は電子提供措置を総会の3週間前の日までに開始する必要があるので（会社法325条の3）、その分さらに前倒しになります。

実務のポイント

  • 総会日は、会場の確保、役員の都合、他社の集中日、前年の開催日との関係（著しく離れると理由の記載が必要：会社法施行規則63条1号）から決める。
  • 監査の日程は、会計監査人・監査役会と「合意により定めた日」（会社計算規則130条1項1号ハ、132条1項1号ロ）を年初に取り決めておく。
  • 決算取締役会では、計算書類・事業報告の承認（会社法436条3項）と総会の招集決定（会社法298条）を同じ回で行うことが多い。
  • 印刷会社・株主名簿管理人・郵便の締切りは、法定期限よりも早い。社内の締切りは外部業者の日程から決める。
  • 総会後の手続（決議通知、臨時報告書、変更登記は2週間以内）まで、ひとつの日程表にまとめる。

進め方

  1. 前年の実績と会場の空きから総会日（例：6月26日）を仮決めする。
  2. 招集通知の発送期限（総会日の2週間前まで）と、上場会社は電子提供措置の開始日（3週間前の日まで）を計算する。
  3. 招集通知の印刷・封入・発送の日程を、印刷会社・株主名簿管理人と決める。
  4. 決算取締役会の日を、監査報告の受領後かつ印刷入稿前に置く。
  5. 会計監査人・監査役会と監査報告の通知日を合意し、計算書類・事業報告の提出日を決める。
  6. 総会後の決議通知・臨時報告書・登記・配当支払いの日程も記入し、取締役会に報告する。

注1招集通知の発送期限と備置きの開始日 重要
  1. 条文
    会社法 299条1項 （株主総会の招集の通知）

    第1項　株主総会を招集するには、取締役は、株主総会の日の二週間（前条第一項第三号又は第四号に掲げる事項を定めたときを除き、公開会社でない株式会社にあっては、一週間（当該株式会社が取締役会設置会社以外の株式会社である場合において、これを下回る期間を定款で定めた場合にあっては、その期間））前までに、株主に対してその通知を発しなければならない。

  2. 条文
    会社法 442条1項 一号 （計算書類等の備置き及び閲覧等）

    第1項　株式会社は、次の各号に掲げるもの（以下この条において「計算書類等」という。）を、当該各号に定める期間、その本店に備え置かなければならない。

    • 一　各事業年度に係る計算書類及び事業報告並びにこれらの附属明細書（第四百三十六条第一項又は第二項の規定の適用がある場合にあっては、監査報告又は会計監査報告を含む。）　定時株主総会の日の一週間（取締役会設置会社にあっては、二週間）前の日（第三百十九条第一項の場合にあっては、同項の提案があった日）から五年間
  3. やさしく言うと

    公開会社では、総会の日の2週間前までに招集通知を発送します。計算書類・事業報告・監査報告は、総会の2週間前の日から本店に備え置き、株主が見られるようにします。

  4. この事例では

    6月26日の総会なら、発送日と総会日の間に14日を空ける必要があるので、6月11日までに発送します。備置きは6月12日（26日の2週間前の日）から始めます。日数の数え方は招集通知の節でも説明しています。

  5. 落とし穴

    「発送」は郵便局に差し出した日です。印刷会社からの出荷日ではないので、郵便局への差出日を記録に残してください。

注1定款にない基準日には公告が必要 重要
  1. 条文
    会社法 124条3項 （基準日）

    第3項　株式会社は、基準日を定めたときは、当該基準日の二週間前までに、当該基準日及び前項の規定により定めた事項を公告しなければならない。ただし、定款に当該基準日及び当該事項について定めがあるときは、この限りでない。

  2. やさしく言うと

    基準日を新しく定めたら、基準日の2週間前までに、基準日と、その日の株主が何の権利を使えるか（例：臨時総会の議決権）を公告しなければなりません。

  3. なぜこのルールか

    株式を買った人が、基準日までに株主名簿の書換え（名義書換え）をすれば権利を使える、ということを知る機会を与えるためです。公告がないと、株主は名義書換えの必要に気づけません。

  4. この事例では

    公告を欠いた基準日で議決権者を確定すると、株主が名義書換えの機会を奪われたとして、総会の決議の効力が争われるおそれがあります。基準日を延ばして公告し直すのが安全です。

  5. 落とし穴

    「公告の日」と「基準日」の間は2週間必要です。官報は申込みから掲載まで日数がかかり、電子公告は調査機関への依頼も必要なので、掲載日から逆算してください。

注1基準日の権利は3か月以内 重要
  1. 条文
    会社法 124条2項 （基準日）

    第2項　基準日を定める場合には、株式会社は、基準日株主が行使することができる権利（基準日から三箇月以内に行使するものに限る。）の内容を定めなければならない。

  2. 条文
    会社法 124条3項 （基準日）

    第3項　株式会社は、基準日を定めたときは、当該基準日の二週間前までに、当該基準日及び前項の規定により定めた事項を公告しなければならない。ただし、定款に当該基準日及び当該事項について定めがあるときは、この限りでない。

  3. やさしく言うと

    基準日の株主が使える権利は、基準日から3か月以内に使うものに限られます。3か月を過ぎて総会を開くなら、新しい基準日を定め、その2週間前までに公告します。

  4. この事例では

    3月31日が基準日なら、6月30日を過ぎると、3月末の株主名簿で議決権を行使させることはできません。延期方式を選ぶなら、取締役会で新しい基準日を決め、公告の日程を確保します。

  5. 落とし穴

    新しい基準日の株主名簿で議決権者が決まるので、3月末の株主とは顔ぶれが変わります。招集通知の送付先も新しい基準日の株主になります。

注2役員の任期はどうなるか
  1. 条文
    会社法 332条1項 （取締役の任期）

    第1項　取締役の任期は、選任後二年以内に終了する事業年度のうち最終のものに関する定時株主総会の終結の時までとする。ただし、定款又は株主総会の決議によって、その任期を短縮することを妨げない。

  2. 条文
    会社法 346条1項 （役員等に欠員を生じた場合の措置）

    第1項　役員（監査等委員会設置会社にあっては、監査等委員である取締役若しくはそれ以外の取締役又は会計参与。以下この条において同じ。）が欠けた場合又はこの法律若しくは定款で定めた役員の員数が欠けた場合には、任期の満了又は辞任により退任した役員は、新たに選任された役員（次項の一時役員の職務を行うべき者を含む。）が就任するまで、なお役員としての権利義務を有する。

  3. やさしく言うと

    役員の任期は「定時総会の終結の時」に終わります。定時総会が開かれないまま本来開くべき時期を過ぎた場合は、その時期の経過によって任期が満了すると一般に解されています。人数を欠く場合は、任期満了の役員が後任の就任まで権利義務を持ち続けます。

  4. この事例では

    延期方式では、6月末（定款で定めた時期の末）で任期満了となる役員が権利義務役員として残る扱いになることが考えられます。登記の扱い（退任日など）を含め、司法書士と事前に確認してください。継続会方式なら、6月の総会で役員選任ができるので、この問題を避けられます。

  5. 落とし穴

    任期の扱いには、定款の定め（「毎年6月に招集する」など）との関係も含めて解釈の幅があります。方針は弁護士・司法書士の意見を得たうえで取締役会で決めてください。

注3上場会社は有価証券報告書の提出期限にも注意

注1続行の決議があれば招集手続は不要 重要
  1. 条文
    会社法 317条 （延期又は続行の決議）

    株主総会においてその延期又は続行について決議があった場合には、第二百九十八条及び第二百九十九条の規定は、適用しない。

  2. やさしく言うと

    総会で「延期する」（議事に入らず後日に回す）や「続行する」（議事の途中で後日に続ける）と決議したときは、後日の会について、取締役会の招集決定（会社法298条）も招集通知（会社法299条）も要りません。

  3. なぜこのルールか

    後日の会は、当初の総会と同じ総会の続きと考えられるからです。株主は当初の総会で後日の会のことを知る機会があったので、改めて招集手続をする必要はない、という考え方です。

  4. この事例では

    監査が間に合わないときは、6月の総会で決議事項を処理し、報告事項を継続会に回す続行の決議をします。継続会の日時・場所は総会で決めるのが原則ですが、決められなければ議長への一任を決議しておきます。

  5. 用語

    延会と継続会：延会は議事に入らずに後日に延ばした会、継続会は議事に入った後、続きを後日に行う会。どちらも会社法317条の決議による。

注2継続会の時期と議決権を行使できる株主

    会社法 124条2項 （基準日）

    第2項　基準日を定める場合には、株式会社は、基準日株主が行使することができる権利（基準日から三箇月以内に行使するものに限る。）の内容を定めなければならない。

  2. やさしく言うと

    基準日の株主が使える権利は、基準日から3か月以内に使うものに限られます。

  3. なぜこのルールか

    継続会は当初の総会と同じ総会なので、当初の基準日の株主が議決権を行使すると一般に解されています。しかし、継続会が当初の総会から大きく離れ、基準日から3か月を大幅に超えると、実質的に別の総会ではないか、古い株主名簿で決めてよいのかという疑問が生じます。

  5. 落とし穴

注3計算書類の報告と承認
  1. 条文
    会社法 439条 （会計監査人設置会社の特則）

    会計監査人設置会社については、第四百三十六条第三項の承認を受けた計算書類が法令及び定款に従い株式会社の財産及び損益の状況を正しく表示しているものとして法務省令で定める要件に該当する場合には、前条第二項の規定は、適用しない。この場合においては、取締役は、当該計算書類の内容を定時株主総会に報告しなければならない。

  2. 条文
    会社法 438条3項 （計算書類等の定時株主総会への提出等）

    第3項　取締役は、第一項の規定により提出され、又は提供された事業報告の内容を定時株主総会に報告しなければならない。

  3. やさしく言うと

    会計監査人のいる会社では、監査の結果に問題がなければ、計算書類は総会の「承認」ではなく「報告」で足ります。事業報告も報告事項です。

  4. この事例では

  5. 実務のコツ

    継続会の前に、計算書類・事業報告・監査報告を株主に提供し、本店に備え置きます。法律上の招集通知ではなくても、当初の総会と同じ水準の情報提供を心がけると、株主の理解を得やすくなります。

デメリット

注1基準日後の株主にも議決権を与えられる 重要
  1. 条文
    会社法 124条4項 （基準日）

    第4項　基準日株主が行使することができる権利が株主総会又は種類株主総会における議決権である場合には、株式会社は、当該基準日後に株式を取得した者の全部又は一部を当該権利を行使することができる者と定めることができる。ただし、当該株式の基準日株主の権利を害することができない。

  2. やさしく言うと

    総会の議決権については、会社は、基準日の後に株式を手に入れた人にも議決権を使わせると決めることができます。ただし、その株式の基準日の株主の権利を奪うことはできません。

  3. なぜこのルールか

    基準日後に新株を発行したり、合併で新しい株主が加わったりした場合、その人たちを総会から締め出すと実態に合わないことがあります。一方、同じ株式について、基準日株主と譲受人の両方が議決権を持つことはできないので、基準日株主を優先しています。

    4月に発行した新株は基準日にはなかった株式なので、基準日株主の議決権を奪いません。取締役会で新株主に議決権を与える旨を決議できます。

  5. 落とし穴

    基準日後に既存の株式を買った人に議決権を与えることは、その株式の基準日株主（売主）の権利を害するので、できないと解されています。

実務取締役会決議あり取締役会設置会社公開会社#
A
総会の開催前であれば、取締役会の決議で招集を撤回し、新しい日時で改めて招集することができると一般に解されています。この場合、新しい総会について改めて招集通知を発送し、法定の期間（公開会社は2週間）を確保します。
撤回は、総会の日までに、招集通知と同じ程度の方法で株主に知らせる必要があります（郵送、ウェブサイト、上場会社は適時開示など）。
日程に余裕がない場合や撤回が株主に十分伝わらないおそれがある場合は、予定日に最小限の規模で総会を開き、延期・続行の決議（会社法317条）をする方法もあります。延期後の日が基準日から3か月を超えるなら、新たな基準日の設定が必要です。

根拠が明らかでない点（推測を含みます）

  • 招集の撤回を取締役会の決議で行うこと、撤回を招集通知と同じ程度の方法で知らせる必要があることは、一般的な解釈で、条文に明記されたものではありません。
  • 撤回が一部の株主に伝わらなかった場合の決議の効力を直接判断した判例は確認できていません。

実務のポイント

  • まず「同じ日・別会場」「同じ日・時刻変更」で対応できないかを検討する。会場変更なら撤回・再招集までは不要なことが多い（変更の周知は必要）。
  • 招集の撤回は取締役会決議で行う。代表取締役の判断だけで撤回しない。
  • 撤回・延期を知らずに来場する株主に備え、予定会場に案内係を置くか掲示をする。
  • 既に提出された議決権行使書面は、撤回した総会のものとして効力を失う。新しい総会では改めて行使してもらう。
  • 予定日に開いて延期・続行の決議をする場合、議長・役員の最小限の出席と会場（代替会場）の確保が必要。

総会を延期する方法の比較

推奨A案　開催前に取締役会で招集を撤回し、新しい日で改めて招集する

メリット
  • 当日、会場に誰も集まらずに済み、株主の安全を確保できる。
デメリット
  • 撤回を全株主に確実に伝える必要があり、伝わらなかった株主が来場するおそれがある。
  • 新しい招集通知の発送と法定の期間が必要。

B案　予定日に最小限の規模で開会し、延期・続行を決議する（会社法317条）

メリット
  • 改めて招集通知を出さなくてよい。
  • 撤回が伝わらなかった株主との問題が生じない。
デメリット
  • 当日、会場（代替会場）と最小限の人員が必要で、安全面で問題が残る。
  • 延期後の日が基準日から3か月を超えるなら別途の手続が必要。

推奨：株主の安全を最優先し、撤回を周知できる時間がある（数日以上ある）ならA案を推奨します。前日・当日の判断で周知が間に合わない場合はB案を検討します。

進め方

  1. 気象情報・交通機関・会場の状況を確認し、選択肢（会場変更、撤回・再招集、開会して延期）を比較する。
  2. 取締役会（招集の省略や書面決議を活用）で方針を決議する。
  3. 株主に撤回・変更を通知する（郵送・ウェブサイト・適時開示）。
  4. 株主名簿管理人・印刷会社と再招集の日程を決める（基準日の要否を確認）。
  5. 新しい総会について取締役会で招集を決定し、招集通知を発送する。
  6. 予定日には会場に案内を掲示し、来場者に対応する。

取締役会の決議を経ずに、代表取締役の判断で招集の撤回（延期）を株主に通知してしまった場合

  1. 撤回の通知を出した日と方法、株主への到達状況を確認する。
  2. 速やかに取締役会を開き（急ぐ場合は書面決議）、撤回の追認と、新しい日時での招集を決議する。
  3. 新しい招集通知を、法定の期間を守って発送する。延期後の日が基準日から3か月を超えるなら、新たな基準日を定めて公告する。
  4. 予定日に会場に来た株主がいれば、その対応の記録を残す。
  5. 緊急時の撤回の手順（取締役会の開き方、代表取締役への一任の範囲）を規程に定めておく。

法律上の注意点 注釈3件・クリックで開く

注1開催前の撤回は取締役会で 重要
  1. 条文
    会社法 298条4項 （株主総会の招集の決定）

    第4項　取締役会設置会社においては、前条第四項の規定により株主が株主総会を招集するときを除き、第一項各号に掲げる事項の決定は、取締役会の決議によらなければならない。

  2. やさしく言うと

    取締役会のある会社では、総会の日時・場所・議題などは取締役会で決めます。いったん決めた総会をやめたり日時を変えたりすることも、取締役会で決めるべきだと考えられています。

  3. なぜこのルールか

    総会を開くかどうかは株主の権利行使の機会に直結するので、代表取締役1人ではなく取締役会の判断にゆだねています。

  4. この事例では

    台風のように急を要する場合でも、取締役会を開いて撤回を決議します。全員の同意による招集手続の省略（会社法368条2項）やWEB会議を使えば、短時間で開催できます。定款に書面決議の定めがあれば、それを使うこともできます。

  5. 落とし穴

    総会の撤回・日程変更については会社法に明文の規定がなく、その方法や効力については解釈によっています。重要な総会では弁護士と相談しながら進めてください。

注2新しい総会には新しい招集通知が必要
  1. 条文
    会社法 299条1項 （株主総会の招集の通知）

    第1項　株主総会を招集するには、取締役は、株主総会の日の二週間（前条第一項第三号又は第四号に掲げる事項を定めたときを除き、公開会社でない株式会社にあっては、一週間（当該株式会社が取締役会設置会社以外の株式会社である場合において、これを下回る期間を定款で定めた場合にあっては、その期間））前までに、株主に対してその通知を発しなければならない。

  2. やさしく言うと

    撤回した後に開く総会は新しい総会なので、改めて招集の決定をし、総会の2週間前まで（公開会社の場合）に招集通知を発送します。

  3. この事例では

    再招集の日程は、印刷・発送の期間と法定の期間から逆算して決めます。延期後の総会日が基準日から3か月を超えるときは、新しい基準日を定めて公告する必要があるので、さらに日程が延びます（基準日の問いを参照）。

注3開会して延期を決議する方法
  1. 条文
    会社法 317条 （延期又は続行の決議）

    株主総会においてその延期又は続行について決議があった場合には、第二百九十八条及び第二百九十九条の規定は、適用しない。

  2. やさしく言うと

    予定どおり総会を開き、その場で「延期する」と決議すれば、後日の会（延会）について、改めて招集の決定や招集通知をする必要はありません。

  3. この事例では

    撤回の通知が間に合わない場合や、来場する株主がいる可能性が高い場合は、予定日に少人数で開会して延期を決議する方法が考えられます。延会でも当初の基準日の株主が議決権を行使するので、基準日から3か月以内に延会を開ける日程にします。

  4. 落とし穴

    開会するには、議長と議事録作成に必要な役員、延期の決議を可決できるだけの議決権（延期の決議は普通決議）が要ります。出席株主がほとんどいない場合も想定し、事前に大株主の出席や委任状の確保を検討してください。

応用取締役会決議あり取締役会設置会社非公開会社親子会社・グループ金融機関取引建設業#
A
事業年度は定款で定めているのが通常なので、株主総会の特別決議で定款を変更します。3月決算を12月決算に変えると、変更後の最初の事業年度は4月1日から12月31日までの9か月になります（事業年度の末日を変更する場合の最初の事業年度は1年6か月以内であればよい、会社計算規則59条2項）。
定款の定時総会の基準日（3月31日）と開催時期（毎年6月）も、12月31日・翌年3月に合わせて同時に変更します。役員の任期は「選任後○年以内に終了する事業年度のうち最終のものに関する定時総会の終結の時まで」なので、事業年度が短くなると任期の満了が早まることがあります。
借入契約には決算期の変更を銀行に通知する、又は財務制限条項の判定時期を変える定めがあることが多く、建設業の許可を持つ会社は事業年度終了後4か月以内の書類提出（建設業法11条2項）の時期も変わります。税務署への届出（法人税法15条）も必要です。

根拠が明らかでない点（推測を含みます）

  • 事業年度の変更によって役員の任期が短縮されるという扱いは、会社法332条1項の文言からの解釈です。直接判断した判例は確認できていません。
  • 借入契約に決算期の変更の通知・承諾条項があること、財務制限条項の判定時期が変わることは、一般的な契約の例として述べたもので、実際の契約の条項を確認してください。
  • 経営事項審査の審査基準日の扱いや、建設業法11条2項の書類の提出の具体的な運用（9か月の事業年度の扱い）は、許可行政庁の運用によるので、当サイトでは確認していません。
  • グループ通算制度など税務上の決算期の統一の要否は、本問では扱っていません。

実務のポイント

  • 変更する定款の条項は、事業年度・定時総会の招集時期・基準日の3つをセットで確認する。附則で「変更後の最初の事業年度は令和○年4月1日から同年12月31日まで」と明記する。
  • 定款変更は、変更後の最初の事業年度の末日（例：12月31日）より前に効力を生じさせる。6月の定時総会で決議するのが一般的。
  • 取締役・監査役ごとに、変更後の任期の満了時期を計算し直し、任期管理表を更新する（短縮される役員の改選が、変更後の最初の定時総会で必要になることがある）。
  • 借入契約・シンジケートローン契約の「決算期の変更」に関する条項（事前通知・承諾、財務制限条項の判定時期）を確認し、定款変更の前に銀行と協議する。
  • 建設業・宅建業などの許認可がある場合は、決算の届出の時期や経営事項審査の審査基準日がずれることを、許可担当部署と確認する。

進め方

  1. 親会社の経理部門と、変更の時期（どの年の12月から合わせるか）を決める。
  2. 定款の該当条項と附則の案、役員の任期の再計算表、借入契約の条項の一覧を作る。
  3. 取引銀行に決算期変更の予定を説明し、必要なら承諾を得る。
  4. 取締役会で、定款変更議案を定時総会（又は書面決議）に付議することを決議する。
  5. 株主総会の特別決議（100％子会社なら書面決議）で定款を変更する。
  6. 税務署・都道府県・市町村に事業年度変更の届出をし、許認可官庁への届出の時期を確認する。
  7. 変更後の最初の事業年度の決算・定時総会（翌年3月）の日程を組む。任期が満了する役員の改選議案を準備する。

法律上の注意点 注釈4件・クリックで開く

注1変更後の最初の事業年度は1年6か月まで 重要
  1. 条文
    会社計算規則 59条2項 （各事業年度に係る計算書類）

    第2項　各事業年度に係る計算書類及びその附属明細書の作成に係る期間は、当該事業年度の前事業年度の末日の翌日（当該事業年度の前事業年度がない場合にあっては、成立の日）から当該事業年度の末日までの期間とする。この場合において、当該期間は、一年（事業年度の末日を変更する場合における変更後の最初の事業年度については、一年六箇月）を超えることができない。

  2. やさしく言うと

    事業年度は原則1年以内です。ただし、決算日を変える年の最初の事業年度に限り、1年6か月まで延ばせます。

  3. なぜこのルールか

    決算日を変えると、どうしても半端な期間が生じます。その期間を短くするか長くするかを会社が選べるようにしつつ、長すぎる期間で計算書類が作られないよう上限を置いています。

  4. この事例では

    3月決算を12月決算にする場合、最初の事業年度を4月から12月までの9か月に短くするのが通常です。翌年12月まで延ばすと21か月になり、1年6か月を超えるので認められません。

  5. 実務のコツ

    附則に「第○期は令和○年4月1日から同年12月31日まで」と書き、計算書類・事業報告の表紙にも期間を明記します。前期との比較が9か月対12か月になるので、事業報告で説明を加えると親切です。

注2役員の任期が短くなることがある 重要
  1. 条文
    会社法 332条1項 （取締役の任期）

    第1項　取締役の任期は、選任後二年以内に終了する事業年度のうち最終のものに関する定時株主総会の終結の時までとする。ただし、定款又は株主総会の決議によって、その任期を短縮することを妨げない。

  2. やさしく言うと

    取締役の任期は、「選ばれてから2年以内に終わる事業年度のうち、最後のものについての定時総会が終わる時まで」です。年数そのものではなく、事業年度の区切りで決まります。

  3. この事例では

    例えば令和7年6月の定時総会で選任された任期2年の取締役は、本来は令和9年6月の定時総会で任期満了です。令和7年中に事業年度を12月末に変えると、選任後2年以内に終わる最後の事業年度は令和8年12月期になり、その定時総会（令和9年3月）で任期が満了します。

  4. 落とし穴

    任期の再計算を忘れると、改選の議案を出し忘れ、任期切れのまま放置することになります。監査役（会社法336条1項、4年）や、定款で任期を伸ばしている非公開会社の役員も、全員分を計算し直してください。

  5. 推測を含む点

    事業年度の変更で任期が短縮される扱いは、条文の文言からの解釈で、登記実務でも一般にそう扱われていると考えられますが、個別の事案では司法書士に満了時期を確認してください。

注3基準日と定時総会の時期も合わせて変える
  1. 条文
    会社法 124条2項 （基準日）

    第2項　基準日を定める場合には、株式会社は、基準日株主が行使することができる権利（基準日から三箇月以内に行使するものに限る。）の内容を定めなければならない。

  2. 条文
    会社法 296条1項 （株主総会の招集）

    第1項　定時株主総会は、毎事業年度の終了後一定の時期に招集しなければならない。

  3. やさしく言うと

    定時総会は事業年度が終わった後の一定の時期に開きます。基準日の株主が行使できる権利は基準日から3か月以内のものに限られます。

  4. この事例では

    事業年度を12月末にしたら、定款の基準日も12月31日に変え、定時総会は翌年3月までに開くようにします。基準日を3月31日のままにすると、12月期の定時総会（3月）では基準日がまだ来ていないことになり、使えません。

  5. 実務のコツ

    定款に基準日を定めておけば、毎年の基準日の公告は不要です（会社法124条3項ただし書）。

注4許認可・税務の届出と銀行との関係
  1. 条文
    建設業法 11条2項 （変更等の届出）

    第2項　許可に係る建設業者は、毎事業年度終了の時における第六条第一項第一号及び第二号に掲げる書類その他国土交通省令で定める書類を、毎事業年度経過後四月以内に、国土交通大臣又は都道府県知事に提出しなければならない。

  2. 条文
    法人税法 15条 （事業年度を変更した場合等の届出）

    法人がその定款等に定める会計期間を変更し、又はその定款等において新たに会計期間を定めた場合には、遅滞なく、その変更前の会計期間及び変更後の会計期間又はその定めた会計期間を納税地の所轄税務署長に届け出なければならない。

  3. やさしく言うと

    建設業の許可を持つ会社は、事業年度が終わるたびに4か月以内に決算の書類を許可行政庁に出します。会計期間を変えたときは、税務署に遅滞なく届け出ます。

  4. この事例では

    9か月の事業年度についても、終了後4か月以内に建設業の決算の書類の提出が必要になります。経営事項審査を受けている会社は、審査基準日（決算日）が変わるので、公共工事の入札の予定と合わせて許可担当部署と確認してください。

  5. 落とし穴

    借入契約の財務制限条項は「各決算期末」で判定するのが一般的です。決算期を変えると判定の時期や対象となる期間（9か月の利益をどう扱うか）が変わるので、銀行と事前に協議し、必要なら変更契約を結びます。通知・承諾の条項に違反すると、期限の利益の喪失事由になるおそれがあります。
