Q343

取締役会議事録は、どこに、いつまで保管しておけばよいか。書面決議の同意書や電子データの議事録はどう扱うか。

基本取締役会設置会社#
A
取締役会の日から10年間、本店に備え置かなければなりません（会社法371条1項）。株主総会議事録と違い、支店に写しを置く義務はありません。
書面決議（決議の省略、会社法370条）をした場合は、取締役の同意の意思表示を記載した書面（同意書）や電磁的記録も、決議があったとみなされた日から10年間、同じく本店に備え置きます。報告の省略をした場合も、それを記録した議事録を備え置きます。
電子データの議事録は、本店のパソコン等でいつでも画面表示・印刷できる状態で保存しておけば、本店に備え置いていると扱えます。閲覧の請求があったときは、紙面又は画面に表示して閲覧させます。

根拠が明らかでない点（推測を含みます）

  • 電子データの議事録を本店のパソコン等で表示・印刷できる状態にしておけば本店に備え置いたと扱える、という点は、会社法371条2項2号・施行規則226条の閲覧方法から導かれる一般的な理解で、備置きの具体的な方法を定めた規定は本サイトで確認できていません。
  • 「10年経過後も長期保存する会社が多い」は実務の一般的な傾向として書いたもので、統計などの裏付けはありません。

実務のポイント

  • 起算日は「取締役会の日」。書面決議は「決議があったものとみなされた日」。
  • 備置き場所は本店。本店移転の際は議事録も移す（電子なら本店で表示できる状態を確保する）。
  • 同意書・提案書は議事録とひとまとめにして保管する（閲覧請求の対象になる）。
  • 10年経過後も、訴訟・登記・税務の必要から長期保存する会社が多い。社内の文書管理規程で永久保存とすることも検討する。
  • 議事録の添付資料（上程書・配布資料）は法律上の備置き対象ではないが、議事録が「別紙」を引用しているときは一体として保管する。

すでに手続を欠いてしまった場合（事後の是正）

議事録や書面決議の同意書を本店に備え置いていなかった場合（担当役員の手元や外部倉庫にしかない、電子データが特定の個人のパソコンにしかない等）

  1. 過去10年分の議事録・同意書の所在を一覧にし、欠けている回がないかを確認する。
  2. 本店以外に保管していたものは本店に戻す。電子データは、本店で表示・印刷できる共有の保存場所に移す。
  3. 欠けている回があれば、別問（議事録の紛失）の手順で写しの回収や追認を行う。
  4. 備置きを怠ると過料の対象になり得る（会社法976条8号）ことを担当者に周知し、保管場所と責任者を社内規程で定める。
  5. 取締役会に、点検の結果と是正の内容を報告する。

実務取締役会設置会社監査役設置会社#
A
監査役設置会社（監査等委員会設置会社・指名委員会等設置会社も同じ）では、株主が議事録を閲覧・謄写するには裁判所の許可が必要です（会社法371条3項）。株主が裁判所の許可を得ずに直接請求してきた場合、会社は法律上応じる義務はなく、「裁判所の許可を得たうえで請求してください」と回答すれば足ります。
これに対し、監査役を置かない取締役会設置会社（会計限定の監査役しかいない会社を含む）では、株主は権利の行使に必要があれば、営業時間内いつでも裁判所の許可なしに請求できます（同条2項）。この場合、会社は正当な理由なく拒めません。
いずれの場合も、任意に閲覧させることは禁止されていませんが、取締役会議事録には営業秘密が含まれることが多いので、任意の開示は慎重に判断してください。

根拠が明らかでない点（推測を含みます）

  • 任意の開示を判断する機関（取締役会か代表取締役か）について法令の定めはなく、社内規程と案件の重要度によって決めるのが実務上の対応です。

実務のポイント

  • まず自社が「監査役設置会社」かを確認する。会計限定の監査役しかいない会社は、ここでいう監査役設置会社に当たらない（会社法2条9号）。
  • 請求者が株主であることを株主名簿（上場会社は個別株主通知）で確認する。
  • 監査役設置会社では、裁判所の許可書の提示がない限り応じる義務はない。回答は書面で丁寧に行う。
  • 許可が不要な会社では、請求の理由（権利行使に必要か）を確認し、正当な理由なく拒むと過料の対象になり得る（会社法976条4号）。
  • 任意に開示する場合は、範囲（議案・期間）を限定し、営業秘密部分の取扱いを検討する。

進め方

  3. 監査役設置会社等なら、裁判所の許可が必要である旨の回答書を送る。
  4. 許可不要の会社なら、請求の目的・対象を確認し、閲覧の日時・場所・方法を指定して閲覧させる。
  5. 任意に開示するかどうかは、法務部・弁護士と協議して決める。
  6. 対応の経過を記録し、取締役会（又は監査役）に報告する。

注1裁判所は会社の言い分を聴いてから判断する 重要
  1. 条文
    会社法 870条2項 一号 （陳述の聴取）

    第2項　裁判所は、次の各号に掲げる裁判をする場合には、審問の期日を開いて、申立人及び当該各号に定める者の陳述を聴かなければならない。ただし、不適法又は理由がないことが明らかであるとして申立てを却下する裁判をするときは、この限りでない。

    • 一　この法律の規定により株式会社が作成し、又は備え置いた書面又は電磁的記録についての閲覧等の許可の申立てについての裁判　当該株式会社
  2. 条文
    会社法 869条 （疎明）

    この法律の規定による許可の申立てをする場合には、その原因となる事実を疎明しなければならない。

  3. やさしく言うと

    閲覧許可の申立てがあると、裁判所は審問の日を開き、申立人と会社の両方の言い分を聴いてから判断します。申立人は、許可を求める理由となる事実を「疎明」（一応確からしいと裁判官に思わせる程度の証明）しなければなりません。

  4. この事例では

    会社は、審問で意見を述べる機会を必ず活用します。申立人の疎明が不十分であれば、その点を指摘します。申立ての範囲が広すぎる場合（「過去10年分すべて」など）は、権利行使に必要な範囲に限定されるべきだと主張します。

  5. 用語

    非訟事件：裁判所が後見的な立場で判断する手続。通常の訴訟のように公開の法廷で対立する形をとらず、決定で判断します。議事録の閲覧許可はこの手続で行われます。

    「秘密が含まれる」と言うだけでは足りません。どの議案のどの部分に、どのような情報があり、開示されると何が起きるか（例：競合会社の役員である申立人に価格戦略が知られる）を具体的に説明し、資料を出します。申立人が競合会社の関係者かどうかも重要な事情です。

推奨A案　写しを回収し、紛失の経緯書を付けて備え置く

登記所・提出先・社内データから写しが見つかる回。

メリット
  • 当時の議事録の内容をそのまま示せる。
  • 事実を偽らずに済む。
デメリット
  • 写しの回収に時間がかかる。
  • 写しであって原本ではないことの説明が必要。

B案　現在の取締役会で当時の決議の内容を確認し、追認する

写しが見つからず、決議の存在を示す必要がある重要な事項。

メリット
  • 事実を創作せずに、決議の内容を記録として残せる。
デメリット
  • 決議の内容を他の資料から確認する手間がかかる。
  • 当時の決議の証明としての力は、当時の議事録に劣る。

C案　当時の出席者に署名し直してもらい、議事録を作り直す

（推奨しない）

メリット
  • 見た目は原本に近い書類ができる。
デメリット
  • 当時の議事録を装うと虚偽の記載の問題になり、発覚すれば会社と役員の信用を大きく損なう。
  • 当時と現在で出席者が異なると、そもそも署名を集められない。

推奨：まずA案で写しを集め、写しが見つからない回の重要事項はB案で確認・追認します。C案は採るべきではありません。

進め方

  1. 失われた議事録・同意書の範囲を、開催記録と照合して確定する。
  2. 監査役に報告する。
  3. 写しの回収先に照会し、写しを集める（登記所の附属書類の閲覧、提出先への照会、社内データの検索）。
  4. 回収した写しに、紛失の経緯書と写しの出所を付けて本店に備え置く。
  5. 写しが見つからない回のうち重要な事項は、取締役会で確認・追認の決議をし、その議事録を備え置く。
  6. 取締役会で、紛失の経緯、回収の結果、再発防止策を報告する。

すでに手続を欠いてしまった場合（事後の是正）

本問そのものが、議事録の備置き義務に違反した後の是正です。基本の順序は次のとおりです。

  1. 失われた議事録の範囲を確定し、監査役に報告する。
  2. 登記所の附属書類、提出先、社内データから写しを回収し、出所を記録する。
  3. 回収した写しに紛失の経緯書を付け、本店に備え置く。
  4. 写しが見つからない回の重要事項は、現在の取締役会で確認・追認の決議をする。
  5. 取締役会で経緯と再発防止策を報告し、議事録に残す。
  6. 原本の電子化・二重保管と、保存期間内の書類の廃棄禁止・廃棄の承認手順を社内規程で定める。

注1議事録は10年間、本店に備え置く義務がある 重要
  1. 条文
    会社法 371条1項 （議事録等）

    第1項　取締役会設置会社は、取締役会の日（前条の規定により取締役会の決議があったものとみなされた日を含む。）から十年間、第三百六十九条第三項の議事録又は前条の意思表示を記載し、若しくは記録した書面若しくは電磁的記録（以下この条において「議事録等」という。）をその本店に備え置かなければならない。

  2. やさしく言うと

    取締役会議事録と書面決議の同意書は、取締役会の日（書面決議なら決議があったとみなされた日）から10年間、本店に置いておかなければなりません。

  3. なぜこのルールか

    株主や債権者が、裁判所の許可などを得て議事録を見られるようにするためです。会社自身にとっても、決議があったことを証明する大切な証拠です。

  4. この事例では

    7年前から5年前の議事録はまだ10年以内なので、廃棄したことはこの義務に違反しています。残りの保存期間の間、できる限り写しを集めて備え置く必要があります。

注3登記所に残っている写しを使う
  1. 条文
    商業登記法 11条の2 （附属書類の閲覧）

    登記簿の附属書類の閲覧について利害関係を有する者は、手数料を納付して、その閲覧を請求することができる。この場合において、第十七条第三項に規定する電磁的記録又は第十九条の二に規定する電磁的記録に記録された情報の閲覧は、その情報の内容を法務省令で定める方法により表示したものを閲覧する方法により行う。

  2. やさしく言うと

    登記の申請に添付した書類（附属書類）は登記所で保存され、利害関係のある人は手数料を払って閲覧を請求できます。

  3. この事例では

    役員の選定や本店移転など、登記に使った回の取締役会議事録は、登記所に添付書面として残っている可能性があります。会社自身は利害関係人として閲覧を請求できると考えられるので、管轄の登記所に問い合わせます。

  4. 推測を含む点

    附属書類の保存期間には限りがあると考えられ、古い申請の書類は既に廃棄されていることがあります。保存の有無と閲覧・写しの取得の方法は、登記所に確認してください。

注4写しも見つからない回はどうするか
  1. 条文
    会社法 369条3項 （取締役会の決議）

    第3項　取締役会の議事については、法務省令で定めるところにより、議事録を作成し、議事録が書面をもって作成されているときは、出席した取締役及び監査役は、これに署名し、又は記名押印しなければならない。

  2. やさしく言うと

    議事録は、取締役会の議事について作るものです。現在の取締役会で決議したことは、現在の取締役会の議事録に記録します。

  3. この事例では

    写しが見つからない回で、決議の存在を示す必要がある重要な事項は、招集通知・配付資料・その後の業務の記録から決議の内容を確認し、現在の取締役会で「当時の決議の内容を確認し、追認する」決議をします。その議事録を、紛失の経緯書とともに備え置きます。

  4. 推測を含む点

    現在の取締役会の確認・追認の決議が、当時の決議の存在の証明としてどこまで通用するかは、事案によると考えられ、これを判断した判例は確認できていません。決議の根拠とした資料の一覧を残しておくことが大切です。
