Q295

取締役会議事録は、どこに、いつまで保管しておけばよいか。書面決議の同意書や電子データの議事録はどう扱うか。

基本取締役会設置会社#
A
取締役会の日から10年間、本店に備え置かなければなりません（会社法371条1項）。株主総会議事録と違い、支店に写しを置く義務はありません。
書面決議（決議の省略、会社法370条）をした場合は、取締役の同意の意思表示を記載した書面（同意書）や電磁的記録も、決議があったとみなされた日から10年間、同じく本店に備え置きます。報告の省略をした場合も、それを記録した議事録を備え置きます。
電子データの議事録は、本店のパソコン等でいつでも画面表示・印刷できる状態で保存しておけば、本店に備え置いていると扱えます。閲覧の請求があったときは、紙面又は画面に表示して閲覧させます。

実務のポイント

  • 起算日は「取締役会の日」。書面決議は「決議があったものとみなされた日」。
  • 備置き場所は本店。本店移転の際は議事録も移す（電子なら本店で表示できる状態を確保する）。
  • 同意書・提案書は議事録とひとまとめにして保管する（閲覧請求の対象になる）。
  • 10年経過後も、訴訟・登記・税務の必要から長期保存する会社が多い。社内の文書管理規程で永久保存とすることも検討する。
  • 議事録の添付資料（上程書・配布資料）は法律上の備置き対象ではないが、議事録が「別紙」を引用しているときは一体として保管する。

注110年間・本店に備え置く 重要
  1. 条文
    会社法 371条1項 （議事録等）

    第1項　取締役会設置会社は、取締役会の日（前条の規定により取締役会の決議があったものとみなされた日を含む。）から十年間、第三百六十九条第三項の議事録又は前条の意思表示を記載し、若しくは記録した書面若しくは電磁的記録（以下この条において「議事録等」という。）をその本店に備え置かなければならない。

  2. やさしく言うと

    取締役会議事録と、書面決議の同意書などは、取締役会の日（書面決議なら決議があったとみなされた日）から10年間、本店に置いておかなければなりません。

  3. なぜこのルールか

    株主や債権者が閲覧を求めたときにすぐ応じられるようにするためです。取締役の責任を追及するための証拠になるので、一定期間の保存が義務付けられています。

  4. この事例では

    倉庫や外部の保管業者に預けていると、閲覧請求があってもすぐに出せません。直近10年分は本店（電子なら本店で表示できる状態）に置き、それより古いものを外部保管にする運用が考えられます。

  5. 落とし穴

    議事録を備え置かなかった場合は、取締役等が過料の対象になり得ます（会社法976条8号）。

注2株主総会議事録との違い

    会社法 318条3項 （議事録）

    第3項　株式会社は、株主総会の日から五年間、第一項の議事録の写しをその支店に備え置かなければならない。ただし、当該議事録が電磁的記録をもって作成されている場合であって、支店における次項第二号に掲げる請求に応じることを可能とするための措置として法務省令で定めるものをとっているときは、この限りでない。

    株主総会議事録は、本店に10年間置くほか、写しを支店にも5年間置く必要があります。取締役会議事録には、支店に写しを置く義務はありません。

  3. この事例では

    支店で取締役会議事録の閲覧を求められても、法律上は本店で対応すれば足ります。ただし、閲覧の可否の判断は本店の事務局で一元的に行うと決めておきましょう。

Q296

株主から取締役会議事録を閲覧させてほしいと請求された。監査役設置会社の場合、応じなければならないか。

実務取締役会設置会社監査役設置会社#
A
監査役設置会社（監査等委員会設置会社・指名委員会等設置会社も同じ）では、株主が議事録を閲覧・謄写するには裁判所の許可が必要です（会社法371条3項）。株主が裁判所の許可を得ずに直接請求してきた場合、会社は法律上応じる義務はなく、「裁判所の許可を得たうえで請求してください」と回答すれば足ります。
これに対し、監査役を置かない取締役会設置会社（会計限定の監査役しかいない会社を含む）では、株主は権利の行使に必要があれば、営業時間内いつでも裁判所の許可なしに請求できます（同条2項）。この場合、会社は正当な理由なく拒めません。
いずれの場合も、任意に閲覧させることは禁止されていませんが、取締役会議事録には営業秘密が含まれることが多いので、任意の開示は慎重に判断してください。

実務のポイント

  • まず自社が「監査役設置会社」かを確認する。会計限定の監査役しかいない会社は、ここでいう監査役設置会社に当たらない（会社法2条9号）。
  • 請求者が株主であることを株主名簿（上場会社は個別株主通知）で確認する。
  • 監査役設置会社では、裁判所の許可書の提示がない限り応じる義務はない。回答は書面で丁寧に行う。
  • 許可が不要な会社では、請求の理由（権利行使に必要か）を確認し、正当な理由なく拒むと過料の対象になり得る（会社法976条4号）。
  • 任意に開示する場合は、範囲（議案・期間）を限定し、営業秘密部分の取扱いを検討する。

進め方

  1. 請求書の受領日を記録し、請求者が株主であるか確認する。
  2. 自社が監査役設置会社等かを確認する。
  3. 監査役設置会社等なら、裁判所の許可が必要である旨の回答書を送る。
  4. 許可不要の会社なら、請求の目的・対象を確認し、閲覧の日時・場所・方法を指定して閲覧させる。
  5. 任意に開示するかどうかは、法務部・弁護士と協議して決める。
  6. 対応の経過を記録し、取締役会（又は監査役）に報告する。

注1株主の閲覧請求の原則 重要
  1. 条文
    会社法 371条2項 （議事録等）

    第2項　株主は、その権利を行使するため必要があるときは、株式会社の営業時間内は、いつでも、次に掲げる請求をすることができる。

    • 一　前項の議事録等が書面をもって作成されているときは、当該書面の閲覧又は謄写の請求
    • 二　前項の議事録等が電磁的記録をもって作成されているときは、当該電磁的記録に記録された事項を法務省令で定める方法により表示したものの閲覧又は謄写の請求
  2. やさしく言うと

    株主は、自分の権利（取締役の責任追及、総会での議決権行使など）を行使するために必要なときは、会社の営業時間内いつでも、取締役会議事録の閲覧や謄写（コピー）を請求できます。

  3. なぜこのルールか

    株主が取締役の業務執行をチェックするための手段です。取締役会で何が決められたかを知らなければ、責任追及や議決権の行使を適切に行えないからです。

  4. この事例では

    監査役を置かない取締役会設置会社では、この原則どおり、株主は直接会社に請求できます。会社は、権利行使に必要な範囲かを確認したうえで、閲覧の日時・場所を指定して応じます。

注2監査役設置会社では裁判所の許可が必要 重要
  1. 条文
    会社法 371条3項 （議事録等）

    第3項　監査役設置会社、監査等委員会設置会社又は指名委員会等設置会社における前項の規定の適用については、同項中「株式会社の営業時間内は、いつでも」とあるのは、「裁判所の許可を得て」とする。

  2. 条文
    会社法 2条 九号 （定義）

    この法律において、次の各号に掲げる用語の意義は、当該各号に定めるところによる。

    • 九　監査役設置会社　監査役を置く株式会社（その監査役の監査の範囲を会計に関するものに限定する旨の定款の定めがあるものを除く。）又はこの法律の規定により監査役を置かなければならない株式会社をいう。
  3. やさしく言うと

    監査役（業務監査権限のあるもの）を置く会社、監査等委員会設置会社、指名委員会等設置会社では、株主は裁判所の許可を得なければ取締役会議事録を閲覧できません。会計限定の監査役しかいない会社は、ここでいう監査役設置会社には含まれません。

  4. なぜこのルールか

    これらの会社では、監査役や委員会が取締役の業務執行をチェックしているので、株主が直接見る必要性は相対的に小さいと考えられています。一方、議事録には営業秘密が多く含まれるので、裁判所が必要性を判断する仕組みにしています。

  5. この事例では

    許可を得ていない株主からの請求には、法律上応じる義務はありません。回答書では、裁判所の許可が必要であることと、許可を得た場合の対応を案内します。登記事項証明書で監査役の登記（会計限定の旨の登記の有無を含む）を確認しておくと判断を誤りません。

  6. 落とし穴

    会計限定の監査役しかいない会社が「監査役がいるから許可が必要」と誤解して拒むと、正当な理由のない拒絶として過料の対象になり得ます（会社法976条4号）。

実務取締役会設置会社#
A
債権者は、役員（又は執行役）の責任を追及するため必要があるときに限り、しかも裁判所の許可を得た場合にだけ、取締役会議事録の閲覧・謄写を請求できます（会社法371条4項）。これは監査役の有無にかかわらず同じです。
したがって、裁判所の許可を得ていない債権者からの請求には、法律上応じる義務はありません。株主総会議事録は債権者も営業時間内いつでも閲覧を請求できる（会社法318条4項）のと異なる点に注意してください。
回答では、裁判所の許可が必要であることを伝えます。取引関係の悪化を避けるため、窓口を一本化し、事実関係の説明が必要な場合は議事録ではなく別の方法で説明することを検討します。

実務のポイント

  • 債権者の請求は「役員等の責任追及のため」という目的に限られる。単なる取引上の関心や情報収集目的では許可されない。
  • 監査役の有無に関係なく、債権者には常に裁判所の許可が必要。
  • 株主総会議事録（債権者も直接請求できる）と取り違えない。
  • 許可の申立てがされた場合、裁判所は会社の陳述を聴く手続をとる（会社法870条2項1号）。会社として意見を述べる準備をする。
  • 親会社の株主（親会社社員）が子会社の議事録を求める場合も、裁判所の許可が必要（会社法371条5項）。

進め方

  1. 請求者が債権者であることと、請求の目的を確認する。
  2. 法務部・弁護士に相談し、背後にある紛争（未払い、損害賠償請求）の有無を把握する。
  3. 裁判所の許可が必要である旨を書面で回答する。
  4. 裁判所への申立てがあれば、陳述の準備（著しい損害のおそれの有無など）をする。
  5. 許可が出れば、許可の範囲で閲覧・謄写に応じる。

A
裁判所は、閲覧許可の裁判をする前に、審問の期日を開いて会社の陳述を聴かなければなりません（会社法870条2項1号）。会社は、①申立人の権利行使に必要な範囲を超えていないか、②閲覧により会社や親会社・子会社に著しい損害を及ぼすおそれがないか（会社法371条6項）を中心に、具体的な事実と資料で意見を述べます。
許可が出た場合は、許可決定に示された範囲（対象期間・議案）で閲覧・謄写に応じなければならず、正当な理由なく拒めば過料の対象になり得ます（会社法976条4号）。許可の範囲外の部分まで見せる必要はありません。範囲内であっても会社が独自に黒塗りすることは、許可決定の内容によっては問題になり得るので、黒塗りが必要と考える部分は審問の段階で主張しておくことが重要です。

実務のポイント

  • 申立人が株主であること、権利行使の必要性（何の権利のためか）が具体的に疎明されているかを検討する。
  • 「著しい損害のおそれ」は抽象的に主張しても通りにくい。営業秘密・交渉中の案件・個人情報など、具体的な内容と損害を示す。
  • 対象議事録の範囲を限定する（期間・議案の特定）よう求めることも有効な主張。
  • 許可決定を受けたら、範囲を正確に読み、閲覧日時・場所・謄写方法を申立人と調整する。
  • 上場会社では、未公表の重要事実が含まれる部分の取扱いを、開示担当と事前に協議する。

進め方

  1. 申立書・呼出状を受け取ったら、弁護士に委任し、対象となる議事録を特定する。
  2. 対象議事録を精査し、営業秘密・未公表事実・個人情報などの箇所と、開示した場合の損害を整理する。
  3. 審問期日で、必要性の範囲と著しい損害のおそれについて陳述し、資料を提出する。
  4. 許可決定（又は却下決定）の内容を確認する。不服があれば即時抗告の要否を弁護士と検討する。
  5. 許可の範囲で閲覧・謄写を実施し、実施記録を残す。
  6. 取締役会・監査役に経過を報告する。

    • 四　この法律の規定に違反して、正当な理由がないのに、書類若しくは電磁的記録に記録された事項を法務省令で定める方法により表示したものの閲覧若しくは謄写又は書類の謄本若しくは抄本の交付、電磁的記録に記録された事項を電磁的方法により提供すること若しくはその事項を記載した書面の交付を拒んだとき。
  2. やさしく言うと

    法律に基づく閲覧・謄写の請求を、正当な理由なく拒むと、取締役等が100万円以下の過料に処せられることがあります。

  3. この事例では

    許可決定が出たら、許可された範囲で速やかに閲覧・謄写の日程を調整します。許可の範囲を会社独自に狭く解釈して拒むことは避け、範囲に疑問があれば弁護士と相談して申立人と協議します。

  4. 実務のコツ

    閲覧当日は、事務局と法務担当が立ち会い、閲覧・謄写した範囲と時間を記録しておくと、後で争いになったときの資料になります。
