Q277

利益相反取引や競業取引をした取締役が、取引後に取締役会へ報告しなければならないのはどんな場合か。事前に承認を受けていても報告は必要か。

基本取締役会設置会社#
A
取締役会設置会社では、競業取引・利益相反取引（直接取引・間接取引）をした取締役は、事前の承認の有無にかかわらず、取引の後、遅滞なく、その取引の重要な事実を取締役会に報告しなければなりません（会社法365条2項）。承認を受けていても報告は必要です。
報告するのは取引をした取締役本人です。内容は、取引の相手方、目的物、数量・金額、条件、承認の範囲内で行われたか、会社に損害が生じていないか、などの重要な事実です。
報告があったときは、その内容の概要を取締役会議事録に記載します。報告を怠ったり虚偽の報告をしたりすると、過料の対象になります。

根拠が明らかでない点（推測を含みます）

  • 報告すべき「重要な事実」の具体的な項目（相手方、目的物、数量・金額、条件、承認の範囲内か、損害の有無）は、一般的な例で、条文や省令に列挙されたものではありません。

実務のポイント

  • 報告義務者は「取引をした取締役」。代表取締役が代わりに報告するのではなく、本人に報告させる（本人の発言として議事録に残す）。
  • 承認時に開示した内容と比べ、実際の取引で変わった点（金額、条件、時期）を中心に報告させる。
  • 報告は承認とは別の手続。承認決議の議事録とは別に、報告事項として記載する。
  • 取締役会のない会社には、この報告義務の規定はない（取締役会設置会社の制度）。
  • 指名委員会等設置会社の執行役にも準用されている。

進め方

  1. 承認を受けた取引・承認済みの包括取引の一覧を事務局で管理し、取引の実行状況を担当部署から把握する。
  2. 取引が実行されたら、次回の取締役会の報告事項に入れ、当該取締役に報告書の作成を依頼する。
  3. 取締役会で、当該取締役本人から報告させ、質疑を行う。
  4. 報告の内容の概要を議事録に記載し、報告書を議事録の別紙として保存する。
  5. 承認の範囲を超えていた等の問題が判明したら、追認や是正の議案を検討する。

すでに手続を欠いてしまった場合（事後の是正）

競業取引・利益相反取引をした取締役が、取引後の報告をしていなかったことが分かった場合

  1. 報告がされていない取引を、承認の記録（議事録）と取引の記録を照合して洗い出す。
  2. 次回の取締役会で、当該取締役に重要な事実を報告させ、遅れた理由もあわせて説明させる。
  3. 報告の内容の概要を議事録に記載する（会社法施行規則101条3項6号イ）。
  4. 承認の範囲外の取引が見つかったら、追認などの手続を別に進める。
  5. 承認済み取引の管理台帳を作り、報告の時期を事務局が管理する。

注1取引後の報告義務の内容 重要
  1. 条文
    会社法 365条2項 （競業及び取締役会設置会社との取引等の制限）

    第2項　取締役会設置会社においては、第三百五十六条第一項各号の取引をした取締役は、当該取引後、遅滞なく、当該取引についての重要な事実を取締役会に報告しなければならない。

  2. やさしく言うと

    取締役会がある会社では、競業取引・利益相反取引をした取締役は、取引の後に遅れずに、その取引の重要な事実を取締役会に報告しなければなりません。

  3. なぜこのルールか

    事前の承認は、取引の予定に基づいて行われます。実際に取引した結果が承認のとおりだったか、会社に損害が出ていないかを、取締役会が事後に確認して監督できるようにするためです。

  4. この事例では

    承認を受けた取引でも、実行後に必ず報告させてください。事務局は承認済み取引の一覧を作り、実行されたものを次回の取締役会の報告事項に入れる運用にすると漏れを防げます。

  5. 落とし穴

    「承認を受けたから報告は不要」という誤解がよくあります。条文は「承認を受けた取締役」ではなく「取引をした取締役」に報告を求めています。承認を受けていない取引であっても報告義務はあります。

実務取締役会設置会社#
A
継続的な取引で包括承認を受けている場合は、一定期間ごとにまとめて報告する運用が実務で広く行われており、一般に許されると考えられています。法律は「取引後、遅滞なく」と定めるだけで、1件ごとの報告を求めているわけではないからです。
ただし、「遅滞なく」の要請はあるので、まとめる期間は長すぎないようにします。四半期ごと（3か月に1回）が実務の目安で、包括承認の決議の中で報告の時期と方法を決めておくのが一般的です。
承認の範囲を超えそうな取引、通常と異なる条件の取引、会社に損害が出るおそれのある取引は、まとめずにその都度速やかに報告させてください。

根拠が明らかでない点（推測を含みます）

  • まとめて報告する運用が「遅滞なく」（会社法365条2項）を満たすという点は、一般的な解釈と実務の運用によるもので、これを判断した判例は確認できていません。
  • 「四半期ごと（3か月に1回）」は実務上の目安で、法令の根拠はありません。

実務のポイント

  • 包括承認の決議に「四半期ごとに実績を報告する」と入れておく。報告の時期について取締役会があらかじめ決めておくと、「遅滞なく」の判断がぶれにくい。
  • 報告の項目をそろえる：期間、件数、取引総額、承認の上限との比較、条件の変更の有無、未回収の債権。
  • 例外的な取引（上限超過の見込み、異例の条件、トラブル）はまとめずに随時報告させる。
  • 年1回の包括承認の更新時に、1年分の実績をまとめて確認する。
  • 報告する取締役が複数の子会社を兼任しているときは、子会社ごとに分けて報告させる。

  2. 経理部が四半期末に取引実績を集計し、当該取締役に報告書の案を渡す。
  3. 当該取締役が内容を確認し、四半期末後の最初の定例取締役会で報告する。
  4. 議事録に報告の概要を記載し、報告書を別紙とする。
  5. 上限に近づいているときは、追加の承認の上程を検討する。

すでに手続を欠いてしまった場合（事後の是正）

まとめて報告すると決めた時期（例：四半期ごと）を過ぎても、報告がされていなかった場合

  2. 次回の取締役会で当該取締役に実績を報告させ、遅れた理由を説明させて議事録に記載する。
  3. 上限の超過など承認の範囲外の取引があれば、追認と上限の変更の手続を進める。
  4. 報告の時期を取締役会の年間スケジュールに組み込み、事務局から事前に資料の提出を求める。

注1「遅滞なく」とはどのくらいか 重要
  1. 条文
    会社法 365条2項 （競業及び取締役会設置会社との取引等の制限）

    第2項　取締役会設置会社においては、第三百五十六条第一項各号の取引をした取締役は、当該取引後、遅滞なく、当該取引についての重要な事実を取締役会に報告しなければならない。

  2. やさしく言うと

    「遅滞なく」は、正当な理由のない遅れは許されないが、「直ちに」ほどの即時性は求めない、という意味で使われる言葉です。

  3. なぜこのルールか

    報告の目的は、取締役会が取引の結果を確認して監督することです。継続的な取引を1件ずつ報告しても、かえって全体像が見えにくくなります。合理的な期間でまとめて報告するほうが、監督の目的に適う場合もあります。

  4. この事例では

    包括承認を受けた継続取引なら、四半期ごとのまとめ報告が実務の目安です。半年や1年に1回では「遅滞なく」と言いにくくなるので、少なくとも四半期ごとにすることをお勧めします。

  5. 落とし穴

    まとめ報告を認めるのは、通常の範囲内の取引に限るべきです。上限を超えた取引や、会社に不利な取引を「次の四半期報告で」と先送りすると、報告義務違反と評価されるおそれがあります。

    報告は情報を伝えることが目的なので、全員に確実に伝わるなら、わざわざ会議を開く必要はありません。一方、職務執行状況の報告は、取締役会が実際に開かれ、取締役同士が議論する機会を確保する意味があるため、省略できないことになっています。

  5. この事例では

    取引後の報告（会社法365条2項）は、省略できない報告として挙げられていないので、全員への通知で取締役会での報告に代えることができます。急ぎの報告や、次回の取締役会まで間がある場合に使うと便利です。

  6. 落とし穴

    監査役設置会社では、監査役全員にも通知が必要です。取締役だけに送って監査役を漏らすと、省略の効果が生じません。

承認した条件と違う取引は、違う部分については承認の範囲外の取引、つまり承認のない取引と同じ扱いになると考えるのが安全です。報告を受けた取締役会は、報告を「聞きおく」だけで終わらせず、①違いの内容と理由を確認し、②会社に不利でなければ実際の条件で追認し、③不利なら追認せずに是正を求める、という処理を決める必要があります。
相手方が承認した会社とは別の会社（例：その子会社）に変わっている場合は、その会社との取引そのものが承認を受けていないことになります。兼任取締役がその別会社を代表しているか、利害がどう重なるかを確認し、改めて承認（追認）を検討します。
報告の場で違いが見つかった場合は、その場で追認まで決議せず、条件の検証をしてから次の取締役会で決議するのが通常です。

根拠が明らかでない点（推測を含みます）

  • 承認と違う条件の部分を承認のない取引と同じ扱いにする点は、承認が開示された重要な事実を前提にすることからの解釈で、これを直接判断した判例は登録簿にはありません。
  • どの程度の違いから承認の範囲外になるかの基準は、条文・判例で確認できていません（推測を含みます）。
  • 追認が契約の時にさかのぼって効力を生じる点は、民法116条にならった一般的な解釈です。

実務のポイント

  • 報告書と承認時の上程書・議事録を並べて照合する。価格・数量・相手方・期間・支払条件のどこが違うかを特定する。
  • 違いが会社に有利（承認より安く買えた等）なら、実務上は問題が小さいが、相手方の変更は有利・不利に関係なく承認の範囲外になる。
  • 承認の範囲外の部分は、追認するか是正するかを取締役会で決める。報告を受けただけでは承認したことにならない。
  • 取引をした取締役は、追認の決議に加われない。
  • 違いが生じた原因（交渉での変更、担当者の誤解）を確認し、承認後に条件が変わるときは事前に再承認を求める手順を作る。

進め方

  1. 報告の内容を、承認時の上程書・議事録と照合し、違いを一覧にする。
  2. 取締役会の議事録に、報告の内容と、承認した条件との違いが判明したことを記載する。
  3. 違いの理由を当該取締役と担当部署から聴き、条件の公正さを検証する。監査役に報告する。
  4. 次の取締役会に、実際の条件での追認（又は是正の方針）を上程する（当該取締役は議決に加わらない）。
  5. 是正するなら、相手方に差額の返還や条件の変更を書面で求める。
  6. 承認後に条件が変わる場合の事前再承認の手順を取締役会規程等に定める。

本問そのものが、承認と違う条件で行われた取引の事後処理です。進め方の要点は次のとおりです。

  1. 報告書と承認時の上程書・議事録を照合し、違いを一覧にする。
  2. 違いが判明したことを議事録に記載し、監査役に報告する。
  3. 条件の公正さを検証し、次の取締役会で追認又は是正の方針を決議する（当該取締役は議決に加わらない）。
  4. 是正するなら、相手方に書面で差額の返還や条件の変更を求める。
  5. 承認後に条件を変更するときは事前に再承認を求める手順を定める。

法律上の注意点 注釈4件・クリックで開く

注1承認と違う条件の取引は、承認を受けたことになるのか 重要
  1. 条文
    会社法 356条1項 二号 （競業及び利益相反取引の制限）

    第1項　取締役は、次に掲げる場合には、株主総会において、当該取引につき重要な事実を開示し、その承認を受けなければならない。

    • 二　取締役が自己又は第三者のために株式会社と取引をしようとするとき。
  2. やさしく言うと

    利益相反取引の承認は、取締役が開示した重要な事実（相手方、価格、数量など）を前提にした「その取引」についての承認です。前提の条件と違う取引をすれば、違う部分は承認を受けていないことになります。

  3. なぜこのルールか

    取締役会は、開示された条件を見て会社に不利でないかを判断しています。条件が変われば、その判断は及ばないからです。

  4. この事例では

    価格が承認より高い、相手方が別の会社に変わっている、といった違いは、承認の範囲外として扱い、追認するか是正するかを取締役会で決めます。

  5. 推測を含む点

    条件のわずかな違い（例：引渡日が数日ずれた）まで承認の範囲外になるかは、条文・判例で基準を確認できていません。会社の判断に影響し得る違いかどうかで判断し、迷うときは追認しておくのが安全と考えます。

注2報告を受けただけでは、承認にならない
  1. 条文
    会社法 365条2項 （競業及び取締役会設置会社との取引等の制限）

    第2項　取締役会設置会社においては、第三百五十六条第一項各号の取引をした取締役は、当該取引後、遅滞なく、当該取引についての重要な事実を取締役会に報告しなければならない。

  2. やさしく言うと

    取引後の報告は、取締役会が事後にチェックするための手続です。報告を受けたことと、取引を承認することは別のものです。

  3. この事例では

    報告の場で違いが見つかったら、議事録に「承認した条件と異なることが判明した」と書き、追認するかどうかは別の議案として次の取締役会で決めます。報告の議事録に「了承した」とだけ書くと、後で何を承認したのかが分からなくなります。

  4. 実務のコツ

    報告書の様式に「承認した条件との違いの有無」の欄を設けると、違いが見落とされにくくなります。

注3追認の決議と特別利害関係
  1. 条文
    会社法 369条2項 （取締役会の決議）

    第2項　前項の決議について特別の利害関係を有する取締役は、議決に加わることができない。

  2. 条文
    民法 116条 （無権代理行為の追認）

    追認は、別段の意思表示がないときは、契約の時にさかのぼってその効力を生ずる。ただし、第三者の権利を害することはできない。

  3. やさしく言うと

    取引の相手方を代表する取締役は、追認の決議に加われません。追認をすれば、取引は契約の時にさかのぼって有効になると一般に解されています。

  4. この事例では

    上程書では、承認した条件と実際の条件を対照表で示し、実際の条件で追認することを明記します。当該取締役には説明だけをさせ、採決の前に退席させます。

注4不利な違いがあれば、責任の問題になる
  1. 条文
    会社法 423条3項 一・二号 （役員等の株式会社に対する損害賠償責任）

    第3項　第三百五十六条第一項第二号又は第三号（これらの規定を第四百十九条第二項において準用する場合を含む。）の取引によって株式会社に損害が生じたときは、次に掲げる取締役又は執行役は、その任務を怠ったものと推定する。

    • 一　第三百五十六条第一項（第四百十九条第二項において準用する場合を含む。）の取締役又は執行役
    • 二　株式会社が当該取引をすることを決定した取締役又は執行役
  2. やさしく言うと

    利益相反取引で会社に損害が出たときは、取引をした取締役や、会社として取引を決めた取締役は、任務を怠ったと推定されます。

  3. この事例では

    承認より高く買っていたなど会社に不利な違いがあれば、追認せずに差額の返還や条件の是正を求め、損害が残れば責任を検討します。条件変更に合意した担当の取締役も、推定の対象になり得ます。
