Q243

定時株主総会で取締役全員が再任された。社長も引き続き代表取締役を務めるが、総会後の取締役会で改めて選定する必要があるか。手続と登記はどうするか。

基本取締役会決議あり取締役会設置会社監査役設置会社#
A
必要です。代表取締役は取締役であることが前提なので、取締役の任期が満了すると、代表取締役の地位も失います。再任された取締役が引き続き代表取締役になるには、総会後の取締役会で改めて代表取締役に選定しなければなりません（会社法362条2項3号・3項）。
実務では、総会の直後に取締役会を開き、代表取締役と役付取締役を選定します。全員が会場にいれば、取締役と監査役全員の同意で招集手続を省略できます（会社法368条2項）。
選定後は、2週間以内に代表取締役の重任の登記をします（会社法915条1項）。議事録の押印について、出席した取締役・監査役の印鑑証明書が必要になる場合と、代表取締役が登記所に届け出た印鑑を押すことで不要になる場合があるので、押印の仕方を事前に決めておきます。

実務のポイント

  • 取締役の任期満了と同時に代表取締役の地位もなくなる。選定の取締役会を総会当日に開き、代表者の空白期間を作らない。
  • 総会前に、招集手続省略の同意（取締役・監査役全員）と、議事録への押印の方法（届出印を押すか、各人の実印と印鑑証明書か）を決めておく。
  • 代表取締役の選定議事録は登記の添付書面になる。誰が出席し、誰が選定されたか、本人が就任を承諾したかを明確に書く。
  • 代表取締役が交代する場合は、新任者の印鑑の届出や、銀行・取引先への届出の準備も同時に進める。
  • 役付取締役（会長・社長・専務等）の選定、業務執行取締役の選定もあわせて決議することが多い。

進め方

  1. 総会の招集を決める取締役会の段階で、総会後の取締役会の日時・場所・議案（代表取締役の選定等）を決めておく。
  2. 取締役・監査役全員に、総会後の取締役会の招集手続省略について同意を得る（当日でもよい）。
  3. 総会終了後、控室等で取締役会を開き、議長を選び、代表取締役を選定する。
  4. 被選定者がその場で就任を承諾し、その旨を議事録に記載する。
  5. 議事録を作成し、出席取締役・監査役が押印する（登記に必要な印鑑を確認）。
  6. 2週間以内に、代表取締役の重任の登記を申請する（取締役の重任の登記とあわせて行う）。

法律上の注意点 注釈3件・クリックで開く

注1代表取締役は、取締役会が選定する 重要
  1. 条文
    会社法 362条2項 三号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 三　代表取締役の選定及び解職
  2. 条文
    会社法 362条3項 （取締役会の権限等）

    第3項　取締役会は、取締役の中から代表取締役を選定しなければならない。

  3. やさしく言うと

    取締役会のある会社では、取締役会が取締役の中から代表取締役を選びます（選定）。代表取締役を辞めさせる（解職）のも取締役会です。

  4. なぜこのルールか

    代表取締役は会社の顔として対外的な取引をすべて行う重要な役職なので、取締役全員で構成する取締役会が選び、監督することにしています。

  5. この事例では

    取締役が全員再任された場合でも、「取締役の中から」選ぶという前提がいったん切れるので、総会後に改めて選定決議が必要です。代表取締役の任期は独立に決まっているわけではなく、取締役の任期が終われば代表取締役の地位も終わると考えてください。

  6. 用語

    重任：任期満了で退任した者が、同時に再び選任・選定されて就任すること。登記では「重任」と記載する。

注2総会の後すぐに開くときは、招集手続を省略する
  1. 条文
    会社法 368条2項 （招集手続）

    第2項　前項の規定にかかわらず、取締役会は、取締役（監査役設置会社にあっては、取締役及び監査役）の全員の同意があるときは、招集の手続を経ることなく開催することができる。

  2. やさしく言うと

    取締役会は通常、1週間前（定款で短縮可）までに招集通知を出しますが、取締役と監査役全員が同意すれば、通知なしで開催できます。

  3. この事例では

    総会の終了後に控室で取締役会を開くのが一般的です。新任取締役も含めて全員の同意を取り、議事録の冒頭に「全員の同意により招集の手続を経ずに開催した」と書いておきます。欠席者がいる場合は、事前に通常の招集手続（招集通知の発送）をしておく必要があります。

  4. 落とし穴

    新任の取締役は、総会で選任され就任を承諾した時点で取締役になります。招集通知や同意の対象から新任者を漏らさないように注意してください。

注32週間以内の登記と、印鑑証明書の扱い
  1. 条文
    会社法 915条1項 （変更の登記）

    第1項　会社において第九百十一条第三項各号又は前三条各号に掲げる事項に変更が生じたときは、二週間以内に、その本店の所在地において、変更の登記をしなければならない。

  2. 条文
    商業登記規則 61条6項 三号 （添付書面）

    第6項　代表取締役又は代表執行役の就任による変更の登記の申請書には、次の各号に掲げる場合の区分に応じ、それぞれ当該各号に定める印鑑につき市町村長の作成した証明書を添付しなければならない。ただし、当該印鑑と変更前の代表取締役又は代表執行役（取締役を兼ねる者に限る。）が登記所に提出している印鑑とが同一であるときは、この限りでない。

    • 三　取締役会の決議によつて代表取締役又は代表執行役を選定した場合　出席した取締役及び監査役が取締役会の議事録に押印した印鑑
  3. やさしく言うと

    代表取締役の氏名と住所は登記事項なので、変更（重任を含む）があれば2週間以内に登記します。取締役会で代表取締役を選んだときは、原則として、議事録に押印した出席取締役と監査役の印鑑証明書を添付します。

  4. なぜこのルールか

    代表取締役の選定は会社の代表者を決める重要な行為なので、議事録が偽造されていないことを印鑑証明書で確かめる仕組みになっています。

  5. この事例では

    ただし、変更前の代表取締役が登記所に提出している印鑑を議事録に押していれば、印鑑証明書の添付は不要です（商業登記規則61条6項ただし書）。再任の場合はこの方法が使えることが多いので、議事録の署名欄に届出印を押す段取りをしておきます。

  6. 実務のコツ

    登記の期限を過ぎると、代表者が過料の制裁を受けることがあります。総会のスケジュールを作る段階で、登記の申請日まで決めておきましょう。

Q244

取締役会で代表取締役社長を解職する議案を出すことになった。社長本人は議決に加われるか。社長が議長の場合はどうするか。

実務取締役会決議あり取締役会設置会社#
A
加われません。判例は、代表取締役の解職の決議について、解職される代表取締役は特別利害関係人に当たるとしています（会社法369条2項）。定足数・過半数も、本人を除いた取締役の数で計算します。
社長が議長を務める定めになっていても、特別利害関係人が自分の解職議案の議事を主宰するのは適切でないと一般に解されています。この議案については、取締役会規程の定める順序で他の取締役が議長を務めるか、出席取締役の互選で議長を選びます。
解職されても、取締役の地位は残ります（取締役を辞めさせるには株主総会の解任決議が必要です）。解職と同時に後任の代表取締役を選定し、2週間以内に登記してください。

実務のポイント

  • 解職される代表取締役は議決に加われず、定足数の分母からも外れる。例：取締役5名なら、残り4名の過半数（3名）の出席と、出席者の過半数の賛成が必要。
  • 本人には弁明の機会を与えるのが望ましい。弁明を聞いた後、議決の前に退席を求める。
  • 議長は、取締役会規程の順序（「社長に事故あるときは、あらかじめ定めた順序で他の取締役」等）に従って交代させる。定めがなければ互選する。
  • 後任の代表取締役の選定では、選定される候補者本人は一般に特別利害関係人に当たらないと解されており、議決に加わるのが通例。
  • 解職と後任選定を同じ取締役会で決議し、代表者の空白を作らない。会社の実印・銀行印・通帳の管理者も同時に決めておく。

進め方

  1. 解職を求める取締役が、理由と根拠資料を整理し、他の取締役・監査役と事前に相談する。
  2. 招集権者に議題を示して取締役会を招集してもらう（招集権者が社長本人で応じない場合は、招集請求の手続をとる）。
  3. 当日、議長を交代させる（社長が議長の定めの場合）。

注1解職される代表取締役は、特別利害関係人 重要
  1. 条文
    会社法 369条1項 （取締役会の決議）

    第1項　取締役会の決議は、議決に加わることができる取締役の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）が出席し、その過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行う。

  2. 条文
    会社法 369条2項 （取締役会の決議）

    第2項　前項の決議について特別の利害関係を有する取締役は、議決に加わることができない。

  3. やさしく言うと

    決議について特別の利害関係を持つ取締役は、議決に加われません。取締役会の定足数と賛成数は、議決に加われる取締役を基準に数えます。

  4. なぜこのルールか

    取締役は会社のために忠実に職務を行う義務を負います。自分の地位がかかった決議では、会社のためではなく自分のために投票してしまうおそれがあるため、議決から外します。

  5. 判例
    代表取締役解任決議と特別利害関係
    最高裁判所第二小法廷 昭和44年3月28日 判決（民集23巻3号645頁）

    代表取締役の解任に関する取締役会の決議については、その代表取締役は特別利害関係人に当たるとした判決。

    代表取締役の解任（解職）に関する取締役会の決議について、その代表取締役は特別利害関係人に当たるとしました。

  6. この事例では

    社長は解職議案の議決に加われません。取締役が6名なら、社長を除く5名が基準となり、3名以上の出席と、出席者の過半数の賛成で可決します。社長本人を数に入れて定足数を数えると、決議の効力が争われる原因になります。

注2後任の選定では、候補者本人は議決に加われるか
  1. 条文
    会社法 362条2項 三号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 三　代表取締役の選定及び解職
  2. やさしく言うと

    代表取締役の選定も取締役会の決議で行います。

  3. なぜこのルールか

    選定される取締役は、代表取締役になるという点で利害がありますが、会社の業務執行者を誰にするかは取締役全員が経営の判断として関わるべき事項です。そのため、選定される本人は一般に特別利害関係人に当たらないと解されています。

  4. この事例では

    後任の候補者本人も、選定の議決に加わるのが通例です。一方、解職の議案と選定の議案は、議決に加われる者が違うので、議案を分けて別々に採決し、議事録にもそれぞれの結果を書きます。

  5. 落とし穴

    解職の議案と後任の選定を1つの議案にまとめて採決すると、解職される社長を外すべきかどうかで混乱します。必ず分けてください。

注3解職されても、取締役のまま残る
  1. 条文
    会社法 339条1項 （解任）

    第1項　役員及び会計監査人は、いつでも、株主総会の決議によって解任することができる。

  2. やさしく言うと

    取締役を辞めさせる（解任）のは株主総会です。取締役会ができるのは、代表取締役の地位を外す（解職）ことまでです。

  3. この事例では

    解職された元社長は、取締役として取締役会に出席し、議決に加わる権利を持ち続けます。取締役からも外れてもらう必要があるなら、辞任を求めるか、臨時株主総会を招集して解任を諮ることになります。

  4. 実務のコツ

    解職された元社長の報酬は、代表取締役としての職務がなくなったことを踏まえて見直すことがありますが、一方的な減額は争いになりやすいので、報酬の決め方の定めや本人の同意を確認して慎重に進めてください。

他の取締役は、招集権者である代表取締役に対し、議題を示して取締役会の招集を請求できます。請求から5日以内に、請求の日から2週間以内の日を会日とする招集通知が出されなければ、請求した取締役が自ら招集できます（会社法366条2項・3項）。監査役も、同じ仕組みで招集を請求・招集できます（会社法383条2項・3項）。

実務のポイント

  • まず定款・取締役会規程で招集権者と、招集権者に事故があるときの順序を確認する。
  • 招集請求は書面（電子メール可）で、議題（代表取締役解職の件・代表取締役選定の件）を明示し、日付の分かる方法で送る。
  • 5日以内に招集通知が出なければ、請求した取締役が招集する。招集期間（1週間、定款で短縮可）を守り、全員に通知する。
  • 監査役には、不正の事実を直ちに報告する（会社法357条1項）。監査役自身も差止めや招集請求の権限を持つ。
  • 解職と同時に、会社代表印・銀行印・通帳・印鑑カード・システムの権限を確保する段取りを決めておく。

進め方

  1. 不正の事実と証拠を確保し、弁護士に相談する。監査役に報告する。
  2. 取締役（または監査役）が、招集権者である代表取締役に、議題を示して招集を請求する。
  3. 請求から5日以内に、2週間以内の日を会日とする招集通知が出されるかを待つ。
  4. 出されなければ、請求した取締役が自ら招集通知を全取締役・全監査役に発する（定款の招集期間を守る）。
  5. 取締役会で議長を選び、代表取締役本人を議決から外して解職を決議し、後任を選定する。
  6. 2週間以内に変更登記をし、金融機関・取引先に通知する。印鑑・通帳等の引継ぎを受ける。
  7. 不正について調査委員会の設置、損害の回復、責任追及の要否を検討する。

注1招集権者が応じないときは、招集を請求し、自ら招集する 重要
  1. 条文
    会社法 366条2項 （招集権者）

    第2項　前項ただし書に規定する場合には、同項ただし書の規定により定められた取締役（以下この章において「招集権者」という。）以外の取締役は、招集権者に対し、取締役会の目的である事項を示して、取締役会の招集を請求することができる。

  2. 条文
    会社法 366条3項 （招集権者）

    第3項　前項の規定による請求があった日から五日以内に、その請求があった日から二週間以内の日を取締役会の日とする取締役会の招集の通知が発せられない場合には、その請求をした取締役は、取締役会を招集することができる。

  3. やさしく言うと

    定款や取締役会で招集権者を決めていても、他の取締役は、議題を示して招集を求められます。5日たっても、2週間以内の日に開く取締役会の招集通知が出なければ、請求した取締役が自分で招集できます。

  4. なぜこのルールか

    招集権者が自分に不利な議題を避けて取締役会を開かないと、取締役会による監督が働かなくなります。そのため、他の取締役にも取締役会を開く手段を与えています。

  5. この事例では

    請求の日をはっきりさせるため、書面や電子メールで請求します。5日を過ぎたら、請求した取締役が招集通知を全員に発します。会日は、招集通知から1週間（定款で短縮していればその期間）以上後にする必要があります。

  6. 実務のコツ

    監査役も、取締役の不正や法令違反のおそれがあるときは、同じように取締役会の招集を請求し、応じられなければ自ら招集できます（会社法383条2項・3項）。取締役と監査役のどちらが動くのが早いかを、弁護士と相談して決めましょう。

会長と社長の2人を代表取締役にしたい。それぞれ単独で会社を代表できるか。会長は対外的な儀礼だけ、社長が業務全般、と権限を分けることはできるか。

実務取締役会決議あり取締役会設置会社#
A
代表取締役を複数置くことはでき、それぞれが単独で会社を代表します。代表取締役は、会社の業務に関する一切の行為をする権限を持つからです（会社法349条4項）。
社内で「会長は儀礼的な行事、社長は業務全般」と分担を決めることはできます。しかし、その制限は、事情を知らない取引先などの第三者には主張できません（会社法349条5項）。会長が分担外の契約を結んでも、相手方が制限を知らなければ、会社は契約の効力を否定できません。
複数の代表取締役を置くときは、取締役会で選定し、2週間以内に登記します。分担は職務権限規程などで明確にし、会社代表印の管理方法も決めてください。

実務のポイント

  • 代表取締役の員数を定款で定めている場合は、その範囲内か確認する（「代表取締役1名」と定めていれば定款変更が必要）。
  • 権限の分担は職務権限規程・取締役会決議で明確にする。社内の決裁ルール（稟議）に反した行為は、社内では任務懈怠の問題になる。
  • 外部への効果：分担の制限は善意の第三者に対抗できない。重要な取引先には、誰が窓口かを伝えておく。
  • 会社代表印（登記所への届出印）を誰が管理するか、もう1人の代表取締役が印鑑を届け出るかを決める。
  • 登記簿には代表取締役2名の氏名・住所が載る。共同でなければ代表できない、という定めを登記する制度はない。

進め方

  1. 定款の代表取締役の員数・役付取締役の定めを確認する。
  2. 職務の分担（会長・社長それぞれの所管）と決裁権限を整理し、職務権限規程の改定案を作る。
  3. 取締役会で代表取締役の選定（追加）と職務分担を決議する。被選定者が就任を承諾する。
  4. 2週間以内に代表取締役の就任の登記をする（印鑑証明書等の添付書面を司法書士と確認）。
  5. 必要に応じて新任の代表取締役の印鑑を登記所に届け出る。金融機関・取引先に通知する。

注1代表取締役は、一人ひとりが会社を代表する 重要
  1. 条文
    会社法 349条4項 （株式会社の代表）

    第4項　代表取締役は、株式会社の業務に関する一切の裁判上又は裁判外の行為をする権限を有する。

  2. やさしく言うと

    代表取締役は、会社の業務に関するあらゆる行為（契約、裁判など）を会社の代表として行う権限を持っています。代表取締役が2人いれば、それぞれが単独でこの権限を持ちます。

  3. なぜこのルールか

    取引の相手方が、契約のたびに「この人に代表権があるか」を細かく調べなくて済むよう、代表取締役の権限は包括的なものとされています。

  4. この事例では

    会長と社長を両方代表取締役にすると、どちらも単独で契約を結べます。2人の署名がそろわなければ契約できない、という形（共同代表）を外部に示す登記の制度は今の会社法にはありません。

注2社内の分担は、事情を知らない第三者に主張できない
  1. 条文
    会社法 349条5項 （株式会社の代表）

    第5項　前項の権限に加えた制限は、善意の第三者に対抗することができない。

  2. やさしく言うと

    代表取締役の権限を社内で制限しても（例：会長は儀礼のみ）、その制限を知らない相手方には「権限外だから無効だ」と主張できません。

  3. この事例では

    会長が分担外の契約を結んだ場合、相手方が分担を知らなければ、会社はその契約に拘束されます。社内では、職務権限規程に反した行為として会長の責任を問題にできるにとどまります。重要な取引先には窓口となる代表取締役を伝え、会社代表印の管理を一元化するなど、実務上の工夫で対応します。

  4. 落とし穴

    相手方が制限を知っていた（悪意）ことを会社が証明できれば、制限を主張できる余地があります。しかし証明は難しいことが多いので、頼らないほうが安全です。

実務取締役会決議あり取締役会設置会社監査役設置会社#
A
できるだけ早く取締役会を開き、新しい代表取締役を選定してください。代表取締役が任期満了や辞任で退任したときは、後任が決まるまで元の代表取締役が権利義務を持ち続けますが（会社法351条1項）、死亡の場合はこの仕組みが使えないため、会社を代表する人がいない状態になります。
取締役会は、定款・取締役会規程に「社長に事故があるときは他の取締役が招集する」旨の定めがあればその順序に従い、なければ各取締役が招集できると一般に解されています。取締役と監査役全員が同意すれば、招集手続を省略してすぐに開けます（会社法368条2項）。
死亡により取締役の員数が法律・定款の下限を下回った場合は、株主総会で取締役を選任するか、裁判所に一時取締役の選任を申し立てます（会社法346条2項）。代表取締役の死亡と後任の就任は、2週間以内に登記します。

実務のポイント

  • まず定款・取締役会規程で、招集権者に事故があるときの順序と、残った取締役の数を確認する。
  • 残った取締役が3名以上（取締役会設置会社の下限）か、定款の員数を満たすかを確認する。下回れば総会の招集か一時取締役の申立てを検討する。
  • 死亡した代表取締役は取締役でもなくなる。定足数は残った取締役の数を基準に考える。
  • 会社代表印・銀行届出印・通帳・印鑑カードの所在を確認し、遺族側の手元にないかも確認する。
  • 金融機関・取引先・従業員への連絡、代表者変更の手続（登記、各種届出）を一覧にして進める。

進め方

  1. 取締役・監査役に死亡の事実を連絡し、取締役会の開催日時を調整する。
  2. 定款・規程で招集権者の順序を確認し、全員の同意を得て招集手続を省略するか、招集通知を発する。
  3. 取締役会で議長を選び、後任の代表取締役を選定する。
  4. 取締役の員数が不足する場合は、臨時株主総会の招集（取締役の選任）を決議するか、一時取締役の選任を申し立てる。
  5. 2週間以内に、死亡による代表取締役・取締役の退任と、後任の代表取締役の就任の登記を申請する。
  6. 金融機関・主要取引先に代表者変更を通知し、届出印・通帳等の管理を引き継ぐ。

注1死亡では、前任者の「権利義務」は残らない 重要
  1. 条文
    会社法 351条1項 （代表取締役に欠員を生じた場合の措置）

    第1項　代表取締役が欠けた場合又は定款で定めた代表取締役の員数が欠けた場合には、任期の満了又は辞任により退任した代表取締役は、新たに選定された代表取締役（次項の一時代表取締役の職務を行うべき者を含む。）が就任するまで、なお代表取締役としての権利義務を有する。

  2. やさしく言うと

    代表取締役がいなくなったとき、任期満了や辞任で退任した人は、後任が就任するまで代表取締役としての権利と義務を持ち続けます。

  3. なぜこのルールか

    会社に代表者がいない空白の期間を作らないための仕組みです。ただし、本人が亡くなった場合や解職された場合は、この仕組みは働きません。

  4. この事例では

    唯一の代表取締役が死亡すると、その時点で会社を代表できる人がいなくなります。契約の締結や銀行取引が止まるおそれがあるので、数日内に取締役会を開いて後任を選定してください。

  5. 用語

    権利義務取締役（権利義務代表取締役）：任期満了や辞任で退任した後も、後任が就任するまで役員としての権利義務を持ち続ける人のこと。

注2招集権者がいないとき、誰が取締役会を招集するか
  1. 条文
    会社法 366条1項 （招集権者）

    第1項　取締役会は、各取締役が招集する。ただし、取締役会を招集する取締役を定款又は取締役会で定めたときは、その取締役が招集する。

  2. 条文
    会社法 368条2項 （招集手続）

    第2項　前項の規定にかかわらず、取締役会は、取締役（監査役設置会社にあっては、取締役及び監査役）の全員の同意があるときは、招集の手続を経ることなく開催することができる。

  3. やさしく言うと

    取締役会は、本来は各取締役が招集できます。定款などで招集権者を決めた場合は、その人が招集します。取締役と監査役全員の同意があれば、招集手続なしで開けます。

  4. この事例では

    多くの会社の定款には「社長に事故があるときは、あらかじめ取締役会で定めた順序により他の取締役が招集する」という定めがあるので、その順序に従います。定めがなく招集権者が死亡した場合は、原則に戻って各取締役が招集できると一般に解されています。全員の同意を得て招集手続を省略するのが最も早い方法です。

  5. 実務のコツ

    定款の「事故があるとき」の順序（副社長→専務→…）を、取締役会で毎年確認しておくと、緊急時に迷いません。

    会社法 331条5項 （取締役の資格等）

    第5項　取締役会設置会社においては、取締役は、三人以上でなければならない。

  2. 条文
    会社法 346条1項 （役員等に欠員を生じた場合の措置）

    第1項　役員（監査等委員会設置会社にあっては、監査等委員である取締役若しくはそれ以外の取締役又は会計参与。以下この条において同じ。）が欠けた場合又はこの法律若しくは定款で定めた役員の員数が欠けた場合には、任期の満了又は辞任により退任した役員は、新たに選任された役員（次項の一時役員の職務を行うべき者を含む。）が就任するまで、なお役員としての権利義務を有する。

  3. 条文
    会社法 346条2項 （役員等に欠員を生じた場合の措置）

    第2項　前項に規定する場合において、裁判所は、必要があると認めるときは、利害関係人の申立てにより、一時役員の職務を行うべき者を選任することができる。

  4. やさしく言うと

    取締役会のある会社では、取締役は3人以上必要です。死亡で退任した取締役には権利義務が残らないので、人数が足りなくなったら、株主総会で新しい取締役を選ぶか、裁判所に一時的な取締役（一時取締役）を選んでもらいます。

  5. この事例では

    取締役が3名の会社で1名が死亡すると、残りは2名で法律上の下限を下回ります。この場合でも、取締役会を開いて代表取締役を選び、臨時株主総会を招集する対応が考えられますが、決議の有効性に疑問が生じ得る場面なので、弁護士と相談のうえ、必要なら一時取締役の選任を申し立ててください。株主が少数の会社なら、株主全員の同意を得て早急に総会を開く方法もあります。

  6. 落とし穴

    定款で「取締役5名以上」などと定めている場合は、その員数を下回っても欠員になります。定款の員数も確認してください。

実務取締役会決議あり取締役会設置会社#
A
代表取締役の地位だけを辞任することができます。会社と役員の関係は委任なので、いつでも辞任でき（会社法330条、民法651条1項）、辞任の意思表示が会社に届いた時に効力が生じます（民法97条1項）。辞任に取締役会の承認は必要ありません。
ただし、辞任で代表取締役が1人もいなくなる場合は、後任が就任するまで、辞任した人が代表取締役としての権利義務を持ち続けます（会社法351条1項）。そのため、辞任届を受け取ったら、取締役会で後任の代表取締役を選定してください。
辞任届には「代表取締役を辞任する（取締役は辞任しない）」と明記してもらいます。登記には辞任届を添付し、押印した印鑑によっては印鑑証明書も必要になります（商業登記規則61条8項）。

実務のポイント

  • 辞任届の文言を確認する：「代表取締役を辞任します。取締役の地位にはとどまります。」と明確に。曖昧だと取締役の辞任と誤解される。
  • 辞任の効力発生日：届いた日か、届に書いた日（例：後任選定の取締役会の日）。後任の就任日と合わせると空白がない。
  • 登記所に印鑑を提出している代表取締役の辞任届は、届出印を押すか、実印を押して印鑑証明書を付ける。
  • 後任の選定と、退任者の役職（会長・相談役など）や報酬の見直しを同じ取締役会で決めることが多い。
  • 2週間以内に代表取締役の辞任と後任の就任の登記をする。

進め方

  1. 本人から辞任の意向を聞き、辞任の日と後任の候補を相談する。
  2. 辞任届を受け取る（届出印を押してもらう）。
  3. 取締役会で、辞任の報告を受け、後任の代表取締役を選定する。必要に応じて役付取締役の変更も決議する。
  4. 被選定者が就任を承諾する。
  5. 2週間以内に変更登記を申請する（辞任届、取締役会議事録、必要な印鑑証明書）。
  6. 金融機関・取引先に代表者変更を通知する。

注1代表取締役の地位だけを辞任できる 重要
  1. 条文
    会社法 330条 （株式会社と役員等との関係）

    株式会社と役員及び会計監査人との関係は、委任に関する規定に従う。

  2. 条文
    民法 651条1項 （委任の解除）

    第1項　委任は、各当事者がいつでもその解除をすることができる。

  3. やさしく言うと

    会社と取締役の関係は「委任」という契約の関係で、委任はいつでもやめることができます。代表取締役の地位も、取締役の地位とは別に辞任できると一般に解されています。

  4. なぜこのルールか

    取締役は株主総会で選ばれ、代表取締役は取締役会で選ばれます。2つの地位は選ばれ方が違うので、代表取締役だけを辞めることも認められています。

  5. この事例では

    辞任届に「代表取締役を辞任する」「取締役の地位にはとどまる」と明記してもらいます。辞任に取締役会の承認は不要で、取締役会では「報告事項」として扱います。

  6. 落とし穴

    会社に不利な時期の辞任は、やむを得ない事由がない限り、会社に損害を賠償する責任が生じ得ます（民法651条2項）。引継ぎの期間を考えて辞任日を決めてもらいましょう。

登記の前か後かで結論が変わります。代表取締役の解職は登記事項であり、登記の前は、解職を知らない相手方（善意の第三者）に対して「もう代表者ではない」と主張できません（会社法908条1項前段）。登記の後は、原則として主張できますが、相手方に正当な理由があって登記を知らなかった場合は別です（同項後段）。

実務のポイント

  • 登記の申請は決議当日か翌日に行うのが理想。2週間の期限は「最長」と考える。
  • 金融機関には、決議の当日に議事録の写しを示して代表者変更と届出印の変更を届け出る。払戻しの停止を依頼する。
  • 主要取引先には書面（配達記録の残る方法）で通知する。通知した記録が、相手方の悪意を証明する証拠になる。
  • 元代表取締役の肩書（名刺、ウェブサイト、メール署名）を直ちに変更させる。「会長」等の肩書を残すと表見代表の問題が生じ得る。
  • 元代表取締役が無断で結んだ契約は、相手方が解職を知っていたかどうかを確認し、弁護士と対応を検討する。

進め方

  1. 解職決議の直後に、会社代表印・銀行印・通帳・印鑑カード・ネットバンキングの権限を確保する。
  2. 金融機関に代表者変更を届け出て、元代表取締役による取引の停止を依頼する。
  3. 変更登記を申請する（できれば決議の翌営業日まで）。
  4. 主要取引先に、代表者変更の通知書を送る。
  5. 名刺・ウェブサイト・社内システム上の肩書と権限を変更する。
  6. 元代表取締役が既に行った契約・払戻しを調べ、相手方の善意・悪意を確認して対応を決める。

注1登記の前は、知らない相手に「もう代表者ではない」と言えない 重要
  1. 条文
    会社法 908条1項 （登記の効力）

    第1項　この法律の規定により登記すべき事項は、登記の後でなければ、これをもって善意の第三者に対抗することができない。登記の後であっても、第三者が正当な事由によってその登記があることを知らなかったときは、同様とする。

  2. やさしく言うと

    登記すべき事項は、登記をするまでは、それを知らない第三者に主張できません。登記をした後でも、相手方に正当な理由があって登記を知らなかったときは、主張できません。

  3. なぜこのルールか

    取引の相手方は、登記簿を見て代表者を確かめます。会社が登記を怠っていたせいで、登記を信じた相手方が損をするのは不公平だからです。

  4. この事例では

    解職の登記をする前に、元代表取締役が解職を知らない取引先と契約すると、会社はその契約の効力を否定できないおそれがあります。登記をできるだけ早く申請し、それまでの間は、主要な取引先と金融機関に個別に通知して「知っている」状態にしておくことが重要です。

  5. 用語

    善意・悪意：法律では、ある事実を知らないことを「善意」、知っていることを「悪意」という。道徳的な善悪の意味ではない。

注2代表者らしい肩書を残すと、会社が責任を負うことがある
  1. 条文
    会社法 354条 （表見代表取締役）

    株式会社は、代表取締役以外の取締役に社長、副社長その他株式会社を代表する権限を有するものと認められる名称を付した場合には、当該取締役がした行為について、善意の第三者に対してその責任を負う。

  2. やさしく言うと

    代表取締役でない取締役に「社長」「副社長」など会社の代表者と思われる肩書を付けると、その取締役がした行為について、事情を知らない第三者に対し会社が責任を負います。

  3. 判例
    表見代表取締役（代表取締役代行者）と持ち回り決議
    最高裁判所第一小法廷 昭和44年11月27日 判決（民集23巻11号2301頁）

    「代表取締役代行者」という名称は、旧商法262条にいう会社を代表する権限を有するものと認むべき名称に当たるとした。また、持ち回りの方式によった決議は有効な取締役会の決議とは認められないとされた事例であり、代表者選任が無効な場合に旧商法262条の類推適用により会社が善意の第三者に責任を負うとされた事例でもある。

    「代表取締役代行者」という名称も、会社を代表する権限があると認められる名称に当たるとしました。肩書の名称が広く判断されることを示しています。

  4. この事例では

    解職された元代表取締役が取締役として残る場合、「会長」「代表」などの肩書を使わせ続けると、表見代表取締役として会社が責任を負うおそれがあります。肩書を変更し、名刺の回収と社外への周知を徹底してください。

  5. 落とし穴

    会社がその肩書の使用を認めていた（付けていた、黙認していた）ことが前提です。解職後に肩書を外し、その事実を記録に残しておくことが会社を守ります。

注3代表権のない者の行為の扱い
  1. 条文
    民法 113条1項 （無権代理）

    第1項　代理権を有しない者が他人の代理人としてした契約は、本人がその追認をしなければ、本人に対してその効力を生じない。

  2. やさしく言うと

    代理権のない人が本人の名前で結んだ契約は、本人が認めない限り、本人に効力が生じません。代表権を失った人が会社名義で結んだ契約も、原則として同じ扱いです。

  3. この事例では

    登記後で、相手方も解職を知り得た場合は、元代表取締役の契約は会社に効力が及ばないのが原則です。ただし、会社にとって有利な契約であれば、取締役会（または新しい代表取締役）が追認して有効にすることもできます。どちらにするかは、契約の内容を確認して判断してください。

  4. 実務のコツ

    元代表取締役が会社に損害を与えた場合は、取締役としての任務懈怠の責任（会社法423条1項）や、不法行為の責任を検討します。
