Q075

株主総会の議長は誰が務めるのか。定款で「社長が議長となる」と定めている会社で、社長が当日出席できないときはどうするか。

A
誰が議長になるかは会社法に定めがなく、通常は定款で「取締役社長が議長となる。社長に事故があるときは、取締役会があらかじめ定めた順序により他の取締役が議長となる」と定めています。社長が病気・出張などで出席できないときは、この「事故があるとき」に当たり、取締役会で定めた順序の1番目の取締役が議長を務めます。
代行の順序は、総会の招集を決める取締役会で、あわせて決議しておくのが実務の基本です。順序が決まっておらず、代わりになる取締役もいないときは、総会の場で出席株主の決議により議長を選びます。
なお、株主が裁判所の許可を得て自ら招集した総会では、定款の議長の定めは当然には適用されず、総会で議長を選ぶのが一般的な扱いです。

実務のポイント

  • まず定款の株主総会の章（「招集権者及び議長」の条）を確認する。社長・会長のどちらが議長か、代行の順序を誰が決めるかが書かれている。
  • 代行順位は「第1順位　取締役副社長【氏名】、第2順位　専務取締役【氏名】」のように氏名で特定し、2人以上決めておく。
  • 「事故があるとき」には、病気・不在のほか、議長不信任動議が可決された場合なども含むと一般に解されている。
  • 代行議長になる取締役には、シナリオ一式を事前に渡し、リハーサルにも参加してもらう。
  • 議長が誰であったかは株主総会議事録の記載事項（会社法施行規則72条3項5号）。交代があれば両名を書く。

進め方

  1. 総会の約2か月前：定款の議長の定めと前年の代行順位の決議を確認する。
  2. 招集決定の取締役会の上程書に「議長の代行順位」の議案を入れる（招集決定と同じ議事録にまとめてよい）。
  3. 取締役会で代行順位を決議し、議事録を作成する。
  4. 代行候補の取締役にシナリオを渡し、リハーサルで実際に読み上げてもらう。
  5. 当日朝、社長の体調・到着を確認する。欠席が確定したら、代行議長が冒頭で「定款第【○】条により私が議長を務めます」と述べる。
  6. 総会議事録に実際に議長を務めた者の氏名と、代行した根拠を記載する。

注1議長について会社法は何を定めているか 重要
  1. 条文
    会社法 315条 （議長の権限）

    第1項　株主総会の議長は、当該株主総会の秩序を維持し、議事を整理する。

    第2項　株主総会の議長は、その命令に従わない者その他当該株主総会の秩序を乱す者を退場させることができる。

  2. やさしく言うと

    会社法は、議長に「会場の秩序を守る」「議事を整理して進める」という権限を与えています。しかし、誰が議長になるかは書いていません。

  3. なぜこのルールか

    議長の選び方は会社ごとの事情（社長が務めるのか会長が務めるのか）に合わせればよいので、定款に任せています。定款に定めがなければ、総会そのものが議長を選びます。

  4. 条文
    会社法 29条

    第二十七条各号及び前条各号に掲げる事項のほか、株式会社の定款には、この法律の規定により定款の定めがなければその効力を生じない事項及びその他の事項でこの法律の規定に違反しないものを記載し、又は記録することができる。

  5. やさしく言うと

    定款には、法律に反しない限り、会社の運営に関する事柄を自由に書くことができます。議長の定めもその一つです。

  6. この事例では

    自社の定款の議長条項を読み、①議長は誰か、②代わりの者を誰がどう決めるか、③全員に事故があるときどうするか、を確認します。③の定めがなくても、総会で議長を選べば足ります。

注2代行の順序を取締役会で決める理由
  1. 条文
    会社法 362条2項 一号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 一　取締役会設置会社の業務執行の決定
  2. やさしく言うと

    取締役会は、会社の仕事の進め方を決める機関です。定款が「取締役会があらかじめ定めた順序」と書いていれば、その順序は取締役会が決議で決めます。

  3. なぜこのルールか

    総会の当日になってから誰が議長をするか迷うと、開会が遅れたり、議長の資格をめぐって株主と争いになったりします。事前に決議しておけば、代行議長は「定款と取締役会決議に基づいて議長を務める」と明確に説明できます。

  4. この事例では

    招集を決める取締役会の議案に「議長の代行順位」を加え、順序を氏名で決議します。継続会・延会も含むと書いておくと、当日続行になった場合も同じ順序が使えます。

  5. 実務のコツ

    取締役が交代する定時総会では、退任予定の取締役も総会終了までは取締役です。代行順位に含めてかまいませんが、新任の取締役は総会で選任されるまで取締役ではないので含めません。

注3定款に定めがない、または全員に事故があるとき
  1. 条文
    会社法 309条1項 （株主総会の決議）

    第1項　株主総会の決議は、定款に別段の定めがある場合を除き、議決権を行使することができる株主の議決権の過半数を有する株主が出席し、出席した当該株主の議決権の過半数をもって行う。

  2. やさしく言うと

    議長を総会で選ぶときは、普通の決議の方法、つまり出席した株主の議決権の過半数で決めると一般に解されています。

  3. この事例では

    開会前に事務局（または出席している取締役）が仮に進行役となり、「議長の選任をお諮りします」と述べて議長候補を提案し、拍手などで賛否を確認します。選ばれた議長の氏名と選任の経過は総会議事録に書きます。

  4. 落とし穴

    仮の進行役が、選任前に議案の審議を始めてはいけません。議長が決まるまでは、議長選任以外のことは進めないでください。

  5. 実務のコツ

    株主が裁判所の許可を得て招集した総会（会社法297条4項）でも、総会で議長を選ぶのが一般的です。会社側の取締役が当然に議長になるわけではない点に注意してください。

    会社法施行規則 72条3項 五号 （議事録）

    第3項　株主総会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 五　株主総会の議長が存するときは、議長の氏名
  2. やさしく言うと

    総会に議長がいたときは、その氏名を議事録に必ず書きます。

  3. この事例では

    代行議長が務めた場合は「定款第【○】条第2項及び取締役会の定めた順序により、取締役副社長【氏名】が議長となった」と、代行の根拠とあわせて記載します。登記の添付書類にする場合にも、誰が議長だったかが確認されます。

実務取締役会設置会社上場会社#
A
いったん休憩を宣言して状況を確認し、続行できないと判断したら、定款と取締役会が定めた代行順位に従って次の取締役が議長を引き継ぎ、それまでの議事の続きから再開します。
議長が「事故」で職務を行えなくなったときは、定款の代行規定がそのまま働くので、交代について総会の決議は要りません。交代前に済んだ報告・質疑・採決は有効で、やり直す必要はありません。
新しい議長は、再開の冒頭で交代の事実と根拠、どこから再開するかを株主に説明します。議事録には、両名が議長を務めたことと交代の時刻・経過を記載します。

実務のポイント

  • 議長本人が「続けられる」と言っても、受け答えが不安定なら事務局と副議長役の取締役が交代を促す。無理に続けると議事の進め方に疑義が生じる。
  • 交代は「休憩→再開」の形で行うと、株主に経過を説明しやすい。休憩中も会場を閉じず、株主の退出・再入場を妨げない。
  • 再開時は、交代前の到達点（例：第2号議案の質疑の途中）を明確に告げる。採決済みの議案は再度採決しない。
  • 代行議長の手元に、全議案のシナリオと想定問答を常に置いておく（途中から引き継げるよう、ページ番号を付けておく）。
  • 体調不良者が出た場合の救護（看護師・AED・救急車の要請）の手順を事前に決めておく。

進め方

  1. 議長の異変に気付いたら、事務局がメモで副議長役の取締役に知らせ、議長に休憩を宣言してもらう（宣言できなければ代行順位1位の取締役が宣言する）。
  2. 休憩中に、議長本人・医療担当と相談して続行の可否を判断する。
  3. 続行不能なら、代行順位1位の取締役が議長席に着く。その取締役も事故があれば次の順位の者、全員不在なら総会で議長を選任する。
  4. 再開を宣言し、交代の事実・根拠と再開する箇所を説明する。
  5. 残りの議事を進める。交代前に済んだ採決は繰り返さない。
  6. 総会後、議事録に交代の時刻と経過、両議長の氏名を記載する。上場会社は取引所への連絡や開示の要否も確認する。

注1議長が職務を続けられなくなったら、誰が交代を決めるか 重要
  1. 条文
    会社法 315条1項 （議長の権限）

    第1項　株主総会の議長は、当該株主総会の秩序を維持し、議事を整理する。

  2. やさしく言うと

    議長の役目は、総会の議事を整理して進めることです。議長が病気などでこの役目を果たせなくなれば、別の人が議長を務める必要があります。

  3. なぜこのルールか

    総会の途中で議長が不在のままだと、誰も発言の許可や採決の宣言をできず、議事が止まってしまいます。そこで多くの会社は、定款で「社長に事故があるときは、取締役会が定めた順序で他の取締役が議長となる」と決めています。

  4. 用語

    事故があるとき：病気、急用、不在などで、その人が職務を行えない状態をいいます。総会の途中で起きた場合も含まれます。

  5. この事例では

    総会の途中で社長が体調を崩したときも「事故があるとき」に当たるので、定款と取締役会決議の順序どおりに交代します。交代について総会の決議は不要です。順位の者が全員務められないときは、総会で議長を選任します。

実務取締役会設置会社上場会社#
A
一括審議方式は、議長の議事整理の権限（会社法315条1項）の範囲内の進め方として、一般に認められており、上場会社の定時総会で広く使われています。報告事項と全議案の説明を先に済ませ、質疑をまとめて受けた後、各議案を順に採決します。
この方式でも、議案ごとに採決すること、株主が各議案について質問・動議を出す機会があることは変わりません。冒頭で進め方を説明し、議場に賛同を求めておくと、後で「質問の機会が奪われた」と争われにくくなります。
株主提案がある、議案の賛否が拮抗している、修正動議が予想される、といった総会では、議案ごとに上程・審議・採決する個別審議方式のほうが分かりやすく、争いも生じにくいと考えられます。

実務のポイント

  • 一括審議を選ぶ目安：会社提案のみで議案が定型的、株主の関心が業績全般に集中する、質問者が多く時間配分が必要、などの場合。
  • 個別審議を選ぶ目安：株主提案がある、委任状勧誘が行われている、特定の議案（買収防衛策、役員報酬など）に反対が予想される場合。
  • 一括審議でも、修正動議・手続的動議は審議の時間内に受け付けると冒頭で明言する。
  • 採決は議案ごとに分けて行い、議事録にも議案ごとの結果を書く。
  • 質問が報告事項・決議事項のどれに関するものか区別して答えると、説明義務を果たしたことが記録に残りやすい。

進め方

  1. 総会の約1か月前に、株主提案の有無・議決権行使の見込みを踏まえて方式を決め、シナリオを作る。
  2. 開会後、報告事項の報告と全議案の説明（上程）を行う。
  3. 議長が「質疑は報告事項・議案を一括して受けます。動議もこの時間にお受けします」と方式を説明し、議場の賛同を拍手で確認する。
  4. 質疑応答を行う。議長は質問が出尽くしたか、または相当な時間が経過したかを見て、質疑の終了を諮る。
  5. 各議案を順に採決し、議案ごとに結果を宣言する。
  6. 議事録に、方式、質疑の概要、議案ごとの結果を記載する。

注1議事の進め方を決めるのは誰か 重要
  1. 条文
    会社法 315条1項 （議長の権限）

    第1項　株主総会の議長は、当該株主総会の秩序を維持し、議事を整理する。

  2. やさしく言うと

    議長には、議事をどの順番で、どのように進めるかを決める権限があります。

  3. なぜこのルールか

    会社法は総会の細かな進め方を定めていません。会場の状況や株主の関心に応じて、議長が合理的に進め方を選べるようにしているのです。

  4. この事例では

    報告事項と全議案をまとめて説明し、質疑をまとめて受ける一括審議方式も、議長の議事整理の権限の範囲内と一般に解されています。冒頭で方式を説明し拍手で賛同を得ておけば、進め方への異論にも答えやすくなります。

  5. 落とし穴

    「質疑はまとめて受ける」とした以上、質疑の時間に動議の提出も受け付けてください。採決に入ってから動議を受け付けないと扱うと、株主が動議を出す機会を奪ったと争われるおそれがあります。

注2一括審議でも説明義務は議案ごとに果たす
  1. 条文
    会社法 314条 （取締役等の説明義務）

    取締役、会計参与、監査役及び執行役は、株主総会において、株主から特定の事項について説明を求められた場合には、当該事項について必要な説明をしなければならない。ただし、当該事項が株主総会の目的である事項に関しないものである場合、その説明をすることにより株主の共同の利益を著しく害する場合その他正当な理由がある場合として法務省令で定める場合は、この限りでない。

  2. やさしく言うと

    取締役・監査役は、株主から総会の目的事項（報告事項・議案）について質問されたら、必要な説明をしなければなりません。

  3. なぜこのルールか

    説明は、株主が議案に賛成するか反対するかを判断するためのものです。質問をまとめて受けても、各議案の判断に必要な説明がされたかどうかで、説明義務を果たしたかが判断されます。

  4. この事例では

    回答者は「第2号議案の候補者に関するご質問にお答えします」のように、どの議案に関する回答かを明示します。議事録にも、主な質問と回答の概要を議案と結び付けて記載すると、後で説明義務違反を主張されたときの資料になります。

注3採決は議案ごとに行う

    会社法 309条1項 （株主総会の決議）

    第1項　株主総会の決議は、定款に別段の定めがある場合を除き、議決権を行使することができる株主の議決権の過半数を有する株主が出席し、出席した当該株主の議決権の過半数をもって行う。

    総会の決議は議案ごとに行い、議案ごとに賛成が過半数（特別決議なら3分の2以上など）かを判定します。

    時間短縮のため複数議案を一度に拍手で採決する方法は、株主が議案ごとに異なる意思を示せなくなるので避けてください。

実務取締役会設置会社上場会社#
A
採決の方法は会社法に定めがなく、定款や規程に定めがなければ、議長が拍手・挙手・起立・投票などから選べると一般に解されています。大事なのは、賛成が必要な数（普通決議なら出席株主の議決権の過半数）に達したかどうかが明らかになることです。
書面・電磁的方法による事前行使は出席した株主の議決権に数えられます（会社法311条2項・312条3項）。事前行使分と、会社提案に賛成することが確認できている大株主の分だけで賛成が必要数を超えていれば、会場で拍手により採決し、「事前行使分を含め過半数の賛成」と宣言する方法で足りるとされています。
反対に、事前行使の段階で賛否が拮抗しているときは、拍手では会場の株主の賛否を数えられないため、投票などで正確に集計する必要があります。

実務のポイント

  • 前日（行使期限の経過後）に事前行使の最終集計を取り、議案ごとに「事前行使＋確実な賛成株主だけで可決ラインを超えるか」を判定しておく。
  • 判定には、会場出席の株主（事前行使をしていない者）が全員反対した場合でも可決となるかを確認する（保守的な計算）。
  • 当日出席した株主が事前行使をしていた場合、当日の行使を優先するのが一般的な扱い。集計上、事前行使分から差し引くかどうかの処理ルールを決めておく。
  • 特別決議（3分の2以上）の議案は、普通決議より余裕が小さくなるので別に判定する。
  • 議事録には「議決権行使書等による事前行使分を含め、出席株主の議決権の過半数（3分の2以上）の賛成」と書く。拍手の大きさだけを根拠にしない。

進め方

  1. 議決権行使の期限経過後、株主名簿管理人から事前行使の集計を受け取る。
  2. 議案ごとに、事前行使の賛成数・反対数・棄権数と、会場出席が見込まれる議決権数を表にする。
  3. 「会場出席の全議決権が反対でも可決か」を判定し、拍手採決でよい議案と投票が必要な議案に分ける。
  4. 当日、受付の出席株主数・議決権数を開会直前に確定し、定足数を確認する。
  5. 議長が議案ごとに拍手で賛否を諮り、「事前行使分を含め過半数の賛成」と宣言する。
  6. 総会後、最終の賛否の数（上場会社は臨時報告書の作成に必要）を確定し、議事録を作成する。

注1採決の方法は決まっているか 重要
  1. 条文
    会社法 309条1項 （株主総会の決議）

    第1項　株主総会の決議は、定款に別段の定めがある場合を除き、議決権を行使することができる株主の議決権の過半数を有する株主が出席し、出席した当該株主の議決権の過半数をもって行う。

  2. やさしく言うと

    普通決議は、①議決権の過半数を持つ株主が出席し（定足数）、②出席した株主の議決権の過半数が賛成すれば成立します。どうやって賛否を確かめるかは、条文に書かれていません。

  3. なぜこのルールか

    賛否の確かめ方は、総会の規模や議案の性質によって適した方法が違います。そのため、賛成数が必要な数に達したことが明らかになる方法であれば、議長が選べると一般に解されています。

  4. この事例では

    事前行使で可決が確実な議案は拍手で足ります。賛否が拮抗する議案は、拍手では賛成数が分からないので投票にします。

  5. 落とし穴

    定款を「出席株主の議決権の過半数」から変更している会社（定足数の排除など）は、定款の要件で判定してください。定款を確認せずにシナリオの決まり文句を使うのは危険です。

注2事前行使は「出席」に数える 重要
  1. 条文
    会社法 311条2項 （書面による議決権の行使）

    第2項　前項の規定により書面によって行使した議決権の数は、出席した株主の議決権の数に算入する。

  2. 条文
    会社法 312条3項 （電磁的方法による議決権の行使）

    第3項　第一項の規定により電磁的方法によって行使した議決権の数は、出席した株主の議決権の数に算入する。

  3. やさしく言うと

    議決権行使書やインターネットで事前に賛否を示した株主の議決権は、会場に来ていなくても、出席した議決権として数えます。

  4. なぜこのルールか

    書面などで議決権を行使できる制度は、会場に来られない株主にも意思を反映させるためのものです。そこで、定足数の計算にも賛否の計算にも含めることにしています。

  5. この事例では

    前日までの事前行使の集計で、賛成だけで可決ラインを超えているかを確認します。超えていれば、会場の拍手の大きさにかかわらず可決なので、議長は「事前行使分を含め」と根拠を示して宣言します。

  6. 実務のコツ

    事前行使した株主が当日来場した場合は、当日の議決権行使を優先し、事前行使は撤回されたものとして扱うのが一般的です。来場株主の分を事前行使から差し引く処理を株主名簿管理人と決めておきます。

注3役員選任の定足数
  1. 条文
    会社法 341条 （役員の選任及び解任の株主総会の決議）

    第三百九条第一項の規定にかかわらず、役員を選任し、又は解任する株主総会の決議は、議決権を行使することができる株主の議決権の過半数（三分の一以上の割合を定款で定めた場合にあっては、その割合以上）を有する株主が出席し、出席した当該株主の議決権の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行わなければならない。

  2. やさしく言うと

    役員の選任・解任では、定款で定足数を軽くしても、議決権の3分の1を下回ることはできません。

  3. この事例では

    定款で普通決議の定足数を排除している会社でも、役員選任議案だけは「議決権の3分の1以上の出席」を確認してから採決します。シナリオの定足数の報告に、役員選任の要件も満たしている旨を入れておくと安全です。

  4. 落とし穴

    役員選任の決議要件（出席株主の議決権の過半数）は、定款で引き上げることはできても、引き下げることはできません。

A
賛否が拮抗する議案は、拍手や挙手では賛成の議決権数が分からないため、投票（議決権数を記載した投票用紙による採決）で行います。採決方法の選択は議長の議事整理の権限に含まれると一般に解されていますが、投票の手順は事前に決め、冒頭で株主に説明しておくことが重要です。
集計では、①事前行使（書面・電磁的方法）、②会場で投票した株主本人、③委任状を持つ代理人の分を、重複なく合計します。事前行使をした株主が会場で投票したときは当日の投票を優先する、白票や記載の不備は無効か棄権か、などの処理ルールは、事前に決めて一貫して適用してください。
争いになるおそれが強いときは、総会検査役の選任申立て（会社法306条）や、弁護士・株主名簿管理人の立会いを検討します。

実務のポイント

  • 投票用紙は受付で出席票と一緒に渡し、株主番号・議決権数をあらかじめ印字（バーコード化）しておく。手書きの議決権数は集計ミスの原因になる。
  • 代理人の資格（定款で株主に限るなど）と委任状の有効性は受付で確認し、判断に迷う委任状は理由を記録して保留扱いにする。
  • 処理ルールを文書化する：当日の投票と事前行使の優先関係、白票・判読不能・二重投票の扱い、委任状と本人来場の重複。
  • 集計には時間がかかるので、休憩を宣言して集計し、再開後に結果を宣言する。集計に要する時間を事前に試算しておく。
  • 投票用紙・委任状・議決権行使書面は総会後3か月間本店に備え置く（会社法310条6項・311条3項）。閲覧謄写請求に備えて整理して保管する。

進め方

  1. 総会の1か月前までに、投票採決の要否を判断し、株主名簿管理人と投票用紙・集計システム・要員を手配する。
  2. 処理ルール（優先関係・無効票の扱い）を文書にし、弁護士の確認を受ける。必要なら総会検査役の選任申立てを検討する。
  3. 受付で本人確認・代理権の確認をし、投票用紙を渡す。来場した事前行使株主を記録する。
  4. 議長が冒頭で投票による採決の方法を説明し、採決時に投票を実施する（投票箱の回収・締切りの宣言）。
  5. 休憩を宣言して集計する。事前行使分と当日投票分を合計し、重複を除く。
  6. 再開後、議長が賛成・反対の議決権数と結果を宣言する。
  7. 総会議事録に投票による採決の経過と賛否の数を記載し、投票用紙等を保管する。上場会社は臨時報告書（金融商品取引法24条の5第4項の制度）に賛否の数を記載する。

A
短時間の休憩は、議長の議事整理の権限（会社法315条1項）により、議長の判断で宣言できると一般に解されています。総会の決議は必要ありません。
休憩を宣言するときは、理由と再開予定時刻を告げ、会場から出た株主にも再開が分かるよう案内します。再開後は、休憩前にどこまで進んだかを確認してから続けます。
休憩が数時間に及ぶ、当日中に再開できない、といった場合は、休憩ではなく、総会の決議により続行（継続会）や延期を決める必要があります（会社法317条）。

実務のポイント

  • 休憩の理由の例：投票の集計、マイク・映像・ネット配信の不具合、体調不良者の救護、議場の混乱の鎮静、想定外の質問への回答準備。
  • 再開予定時刻を具体的に告げる。予定より延びるときは、その都度アナウンスで知らせる。
  • 休憩中も会場は開けておき、株主の出入りを妨げない。受付は継続し、休憩中に来場した株主の出席も記録する。
  • 再開時に出席株主数が大きく変わったときは、必要に応じて定足数を再確認する。
  • 休憩・再開の時刻と理由は議事録に記載する。

進め方

  1. 事務局が休憩の必要を判断し、議長にメモで伝える（例：集計に約20分）。
  2. 議長が理由と再開予定時刻を告げて休憩を宣言する。
  3. 休憩中に原因を解消する（集計、機器の交換、回答の準備）。延びる場合は会場アナウンスで知らせる。
  4. 再開時刻の数分前に再開を予告するアナウンスを行う。
  5. 議長が再開を宣言し、休憩前の到達点を確認してから議事を続ける。
  6. 議事録に休憩と再開の時刻・理由を記録する。

注1休憩は議長の判断でできるか 重要
  1. 条文
    会社法 315条1項 （議長の権限）

    第1項　株主総会の議長は、当該株主総会の秩序を維持し、議事を整理する。

  2. やさしく言うと

    議長は、会場の秩序を守り、議事を整理する権限を持っています。

  3. なぜこのルールか

    集計や機器の復旧のために少し議事を止めることは、議事をきちんと進めるための措置です。いちいち総会の決議にかけていては、かえって進行が滞ります。そのため、短時間の休憩は議長の判断で宣言できると一般に解されています。

  4. この事例では

    集計待ちや機器トラブルでは、議長が理由と再開予定時刻を告げて休憩を宣言すれば足ります。休憩について拍手で賛同を求める必要はありませんが、求めても差し支えありません。

  5. 落とし穴

    休憩を繰り返して質疑の時間を実質的に削ったり、特定の株主が会場を離れている間に再開したりすると、議事の進め方が著しく不公正だと争われるおそれがあります。

注2長時間・翌日以降に及ぶときは続行の決議

    会社法 317条 （延期又は続行の決議）

  2. やさしく言うと

    総会を後日に延期したり、続きを後日に行ったりするには、総会の決議が必要です。決議があれば、新たな招集の決定や招集通知は要りません。

  3. なぜこのルールか

    休憩は同じ総会の中で一時止めるだけですが、別の日に続けるとなると、株主が出席の予定を立て直す必要があり、影響が大きいからです。

  4. この事例では

    復旧の見込みが立たず当日中の再開が難しいときは、休憩を延ばし続けるのではなく、議場で続行（継続会）の決議をとります（下の「当日審議が終わらない場合」のQ&Aを参照）。

実務取締役会設置会社上場会社#
A
総会の議場で「続行」の決議（普通決議）をすれば、後日、同じ総会の続きとして継続会を開けます（会社法317条）。この場合、取締役会の招集決定や新たな招集通知は不要です。
決議では、継続会の日時と場所を決めるのが基本です。日時・場所を議長に一任する決議も実務上見られますが、出席しなかった株主にも分かるよう、決まり次第ウェブサイト等で知らせてください。
継続会は、もとの総会と同じ株主（基準日の株主）が議決権を行使するため、基準日から3か月以内に開く必要があります（会社法124条2項）。継続会では、続行を決めた時点の議事の続きから審議します。

実務のポイント

  • まず本当に続行が必要か検討する。質疑が十分に尽くされていれば、質疑を打ち切って採決に進む方が適切な場合もある。
  • 続行の決議は、議長が提案して議場に諮る（株主の動議として出ることもある）。賛否は普通決議で判定する。
  • 継続会の日時・場所は、会場の空き状況を事務局が休憩中に確認してから提案する。
  • 継続会の日は、基準日から3か月以内に収める。定時総会の場合は、計算書類の承認や役員の任期にも影響するので注意。
  • 継続会で審議する事項は、もとの総会の議題の範囲内に限られる。新しい議題は追加できない。

進め方

  1. 審議の残り時間と残る議事を事務局が見積もり、続行の要否を議長と協議する（必要なら休憩をとる）。
  2. 会場の予約・継続会の候補日時を確認する（基準日から3か月以内か確認）。
  3. 議長が議場に続行を提案し、日時・場所を示して賛否を諮る。
  4. 可決後、議長が継続会の日時・場所を告げ、当日の閉会（散会）を宣言する。
  5. 欠席株主のため、ウェブサイト等で継続会の日時・場所を案内する（法律上の招集通知は不要）。
  6. 当日の総会議事録を作成する。継続会の議事録は、継続会の終了後に別に作成する。

  1. 条文
    会社法 317条 （延期又は続行の決議）

    株主総会においてその延期又は続行について決議があった場合には、第二百九十八条及び第二百九十九条の規定は、適用しない。

  2. やさしく言うと

    総会で「延期」や「続行」を決議すれば、後日の会合のために、招集の決定（298条）や招集通知（299条）をやり直す必要はありません。

  3. 用語

    延期と続行：延期は、総会は成立したが議事に入らずに後日に送ること（後日の会を「延会」という）。続行は、議事に入った後、その続きを後日に行うこと（後日の会を「継続会」という）。

  4. なぜこのルールか

    後日の会合は新しい総会ではなく、もとの総会の一部と扱われます。もとの総会に出席した株主の前で日時・場所が決められているので、改めて通知しなくても株主の権利は守られると考えられているのです。

  5. この事例では

    審議が終わらないときは、議長が続行を提案し、普通決議で可決させます。日時・場所を決議に含めると、後で争われにくくなります。

注2継続会の日はいつまでか
  1. 条文
    会社法 124条2項 （基準日）

    第2項　基準日を定める場合には、株式会社は、基準日株主が行使することができる権利（基準日から三箇月以内に行使するものに限る。）の内容を定めなければならない。

  2. やさしく言うと

    基準日の株主が行使できる権利は、基準日から3か月以内に行使するものに限られます。

  3. なぜこのルールか

    継続会でも、議決権を行使するのはもとの総会と同じ基準日の株主です。基準日から3か月を過ぎると、その基準日に基づく議決権の行使ができなくなると考えられています。

  4. この事例では

    3月31日が基準日の会社で6月下旬に総会を開いた場合、継続会は6月30日までに開く必要があります。残りの日数が少ないので、当日の段階で会場の確保ができる日を選んで決議してください。

  5. 落とし穴

    基準日から3か月を過ぎてしまうと、継続会として開けず、新たに基準日を定めて改めて総会を招集することになります。

注3続行の決議は総会の権限の範囲内か
  1. 条文
    会社法 309条5項 （株主総会の決議）

    第5項　取締役会設置会社においては、株主総会は、第二百九十八条第一項第二号に掲げる事項以外の事項については、決議をすることができない。ただし、第三百十六条第一項若しくは第二項に規定する者の選任又は第三百九十八条第二項の会計監査人の出席を求めることについては、この限りでない。

  2. やさしく言うと

    取締役会がある会社の総会は、原則として、招集通知で示した議題以外の事項を決議できません。

  3. なぜこのルールか

    一方で、延期・続行は議題そのものではなく、その議題をどう審議するかという手続の問題なので、招集通知に記載がなくても議場で決議できるとされています。会社法317条がその前提で定められています。

  4. この事例では

    続行の決議は議場で提案して差し支えありません。ただし、継続会で新しい議題を追加することはできないので、残る議事が招集通知の議題の範囲内かを確認してください。

注4議事録の作り方
  1. 条文
    会社法施行規則 72条3項 一・二号 （議事録）

    第3項　株主総会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 一　株主総会が開催された日時及び場所（当該場所に存しない取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役。第四号において同じ。）、執行役、会計参与、監査役、会計監査人又は株主が株主総会に出席をした場合における当該出席の方法を含む。）
    • 二　株主総会の議事の経過の要領及びその結果
  2. やさしく言うと

    議事録には、総会を開いた日時・場所と、議事の経過・結果を書きます。

  3. この事例では

    当日の議事録には続行を決議した経過と継続会の日時・場所を書きます。継続会の議事録は継続会の日時・場所で別に作成し、もとの総会の継続会であることを明記します。登記に使う場合は、両方の議事録が必要になることがあります。

  4. 実務のコツ

    継続会でも、出席株主数・議決権数を受付で改めて確定し、継続会の議事録に記載します。

Q082

議長が「可決」と宣言した議案について、総会後に集計し直したところ、実は賛成が必要な数に足りていなかったことが分かった。どう対応すべきか。

応用取締役会設置会社上場会社#
A
すぐに弁護士に相談し、集計の誤りの内容を確定させたうえで、議事録への記載、登記・開示、再決議の要否を判断します。賛成が必要な数に達していない議案について、可決したものとして手続を進めるのは避けるべきです。
議長が誤って可決を宣言した決議の効力については、実際の賛否の数によって成否が決まるとする考え方と、議長の宣言により決議が成立したうえで、決議の方法の法令違反として取消しの対象になる（会社法831条1項1号）とする考え方があり、見解が分かれています。いずれの立場でも、そのままにしておくと後で効力を争われるおそれが大きい点は変わりません。
総会の場で誤りに気付いたときは、閉会前に議長が訂正し、正しい結果を宣言し直すのが最も確実です。

実務のポイント

  • 誤りの原因を特定する：事前行使の集計漏れ、来場株主との重複、委任状の扱い、特別決議の要件の取り違えなど。
  • 正しい賛否の数を、株主名簿管理人の記録・投票用紙・委任状で再確認し、確認の過程を記録に残す。
  • 議事録には事実と異なる結果を書かない。作成済みなら、どう記載・訂正するかを弁護士と協議する。
  • 役員選任・定款変更など登記を伴う議案は、登記申請を止めて判断する。上場会社は、臨時報告書・適時開示の訂正の要否も確認する。
  • 再決議が必要なときは、臨時総会の招集（取締役会決議）を検討する。決議取消しの訴えの提訴期間は決議の日から3か月。

進め方

  1. 誤りが判明したら、事務局長が法務担当・代表取締役に報告し、登記・開示などの後続手続を一時停止する。
  2. 株主名簿管理人と共に集計をやり直し、正しい賛否の数と誤りの原因を確定する。
  3. 弁護士に相談し、決議の効力、議事録の記載、開示・登記の扱いを決める。
  4. 取締役会に経過を報告し、必要なら臨時総会を招集して改めて決議する（招集の決定は取締役会決議）。
  5. 上場会社は、開示済みの議決権行使結果の訂正（臨時報告書の訂正等）の要否を確認し、必要な手続をとる。
  6. 再発防止策（集計の二重チェック、判定表の作成、前日のリハーサル）を定める。

注1決議の成否は何で決まるか 重要
  1. 条文
    会社法 309条1項 （株主総会の決議）

    第1項　株主総会の決議は、定款に別段の定めがある場合を除き、議決権を行使することができる株主の議決権の過半数を有する株主が出席し、出席した当該株主の議決権の過半数をもって行う。

  2. やさしく言うと

    決議が成立する条件は、賛成した議決権の数で決まります。普通決議なら出席した議決権の過半数、特別決議なら3分の2以上です。

  3. なぜこのルールか

    議長の宣言は、決議の結果を議場に示すものです。議長が数を誤って宣言した場合、決議があったと言えるのかどうかについては、実際の賛否の数を重視する考え方と、宣言で決議が成立し、手続の誤りとして取消しの問題になるという考え方があり、見解が分かれています。

  4. この事例では

    どちらの考え方でも、正しい数では賛成が足りない議案を可決扱いのまま進めると、後で効力を否定されるおそれがあります。弁護士と協議し、議事録・登記・開示を正しい数に基づいて扱う方針を決めてください。

注2決議の取消しの訴えとの関係
  1. 条文
    会社法 831条1項 一号 （株主総会等の決議の取消しの訴え）

    第1項　次の各号に掲げる場合には、株主等（当該各号の株主総会等が創立総会又は種類創立総会である場合にあっては、株主等、設立時株主、設立時取締役又は設立時監査役）は、株主総会等の決議の日から三箇月以内に、訴えをもって当該決議の取消しを請求することができる。当該決議の取消しにより株主（当該決議が創立総会の決議である場合にあっては、設立時株主）又は取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役。以下この項において同じ。）、監査役若しくは清算人（当該決議が株主総会又は種類株主総会の決議である場合にあっては第三百四十六条第一項（第四百七十九条第四項において準用する場合を含む。）の規定により取締役、監査役又は清算人としての権利義務を有する者を含み、当該決議が創立総会又は種類創立総会の決議である場合にあっては設立時取締役（設立しようとする株式会社が監査等委員会設置会社である場合にあっては、設立時監査等委員である設立時取締役又はそれ以外の設立時取締役）又は設立時監査役を含む。）となる者も、同様とする。

    • 一　株主総会等の招集の手続又は決議の方法が法令若しくは定款に違反し、又は著しく不公正なとき。
  2. やさしく言うと

    決議の方法が法令や定款に違反するとき、株主などは決議の日から3か月以内に、決議の取消しを裁判所に求めることができます。

  3. 条文
    会社法 831条2項 （株主総会等の決議の取消しの訴え）

    第2項　前項の訴えの提起があった場合において、株主総会等の招集の手続又は決議の方法が法令又は定款に違反するときであっても、裁判所は、その違反する事実が重大でなく、かつ、決議に影響を及ぼさないものであると認めるときは、同項の規定による請求を棄却することができる。

  4. やさしく言うと

    手続の違反が重大でなく、決議の結果に影響しないときは、裁判所は取消しの請求を退けることがあります（裁量棄却）。

  5. この事例では

    可決と否決が入れ替わる集計の誤りは、まさに「決議に影響を及ぼす」誤りなので、裁量棄却は期待できません。決議の不存在の確認を求められる可能性もあります（会社法830条1項）。誤りを放置せず、正しい扱いに改めることが必要です。

注3議事録に何を書くか
  1. 条文
    会社法施行規則 72条3項 二号 （議事録）

    第3項　株主総会の議事録は、次に掲げる事項を内容とするものでなければならない。

    • 二　株主総会の議事の経過の要領及びその結果
  2. やさしく言うと

    議事録には、議事の経過と結果を書きます。

  3. なぜこのルールか

    議事録は、総会で何が起きたかを記録する文書です。事実と違う結果を書くと、登記や株主の閲覧を通じて誤りが広がります。

  4. この事例では

    総会の場で訂正した場合は、誤った宣言と訂正の経過を両方書きます。総会後に判明した場合は、議長が可決と宣言した事実と、再集計の結果をどう記載するかを弁護士と協議して決めます。登記の添付書面として使う前に必ず確認してください。

  5. 落とし穴

    集計の誤りに気付きながら、宣言どおりの結果で登記を申請すると、登記の真実性の問題を生じます。

注4再決議で是正する
  1. 条文
    会社法 298条4項 （株主総会の招集の決定）

    第4項　取締役会設置会社においては、前条第四項の規定により株主が株主総会を招集するときを除き、第一項各号に掲げる事項の決定は、取締役会の決議によらなければならない。

  2. やさしく言うと

    取締役会がある会社では、総会の招集の決定は取締役会で決議します。

  3. この事例では

    決議の効力に疑いが残る場合は、臨時総会を招集して改めて決議する方法が確実です。取締役会で招集の決定（日時・場所・議題など）を決議し、招集通知に経緯を簡潔に説明します。招集の上程書・議事録の書き方は、招集の決定の節を参照してください。

  4. 落とし穴

    再決議の招集通知で、誤りの経緯を説明せずに同じ議案を出し直すと、株主の判断材料が不足します。経緯と再決議の理由を簡潔に記載してください。
