Q116

普通決議・特別決議・特殊決議は何が違うのか。招集の準備で、各議案にどの決議が必要かをどう確認すればよいか。

基本取締役会設置会社取締役会非設置会社#
A
違いは「定足数（何人分の議決権が出席すればよいか）」と「賛成の割合」です。普通決議は、議決権の過半数を持つ株主が出席し、出席議決権の過半数の賛成で成立します（会社法309条1項）。特別決議は、議決権の過半数が出席し、出席議決権の3分の2以上の賛成が必要です（同条2項）。特殊決議は、株主の「頭数」の要件が加わる最も重い決議で、全株式に譲渡制限を付ける定款変更などに使います（同条3項・4項）。
普通決議と特別決議の定足数は定款で変えられますが、役員の選任・解任や特別決議には下げられる限度（3分の1）があります。
準備の段階では、議案ごとに根拠条文を確認し、「決議要件」「定足数の定款の定め」「議決権を行使できない株主の有無」を一覧表にしておくと、シナリオ・議事録・集計の誤りを防げます。

根拠が明らかでない点（推測を含みます）

  • 「多くの上場会社の定款は普通決議の定足数を排除している」「特別決議の定足数を3分の1以上と定める会社が多い」は実務の傾向として述べたもので、統計による確認はしていません。自社の定款で必ず確認してください。

実務のポイント

  • 特別決議が必要なものは309条2項各号に列挙されている。定款変更・事業譲渡・合併等の組織再編・募集株式の有利発行・監査役の解任・資本金の額の減少（一部例外あり）などが代表例。
  • 役員の選任・解任は普通決議だが、定足数は定款でも3分の1未満に下げられない（341条）。監査役・監査等委員である取締役の解任や累積投票で選任された取締役の解任は特別決議。
  • 特殊決議の頭数要件（「株主の半数以上」等）は、議決権の数ではなく株主の人数で数える。
  • 自社の定款の「株主総会の決議方法」の条文（定足数の排除・緩和）を必ず確認し、議案ごとの要件表に反映する。
  • 議長シナリオの採決の台詞と議事録の記載（「3分の2以上の賛成」等）を、要件表と一致させる。

進め方

  1. 目的事項（議題）が固まったら、議案ごとに根拠条文と決議の種類を特定する。
  2. 定款の決議方法の規定を確認し、議案ごとの定足数と可決要件を一覧表にする。
  3. 議決権を行使できない株式（自己株式、相互保有株式、議決権制限株式）を確認し、分母となる議決権総数を計算する。
  4. 事前行使の集計で、各議案が要件を満たす見込みかを確認する（特別決議は特に注意）。
  5. 議長シナリオ・議事録案に、議案ごとの決議要件を正しく書き込む。

注1普通決議の要件と定款による変更 重要
  1. 条文
    会社法 309条1項 （株主総会の決議）

    第1項　株主総会の決議は、定款に別段の定めがある場合を除き、議決権を行使することができる株主の議決権の過半数を有する株主が出席し、出席した当該株主の議決権の過半数をもって行う。

  2. やさしく言うと

    普通決議は、①議決権の過半数を持つ株主が出席し（定足数）、②出席した株主の議決権の過半数が賛成すれば成立します。「定款に別段の定めがある場合を除き」とあるので、定足数は定款で緩和したり、なくしたりできます。

  3. なぜこのルールか

    上場会社などでは株主が分散していて、過半数の出席を集めるのが難しいことがあります。そのため、普通決議の定足数は会社が定款で調整できるようにしています。

  4. この事例では

    多くの上場会社の定款は「法令又は定款に別段の定めがある場合を除き、出席した株主の議決権の過半数をもって行う」として、普通決議の定足数を排除しています。この場合でも、役員選任など法律が別に下限を定めている議案には、その下限が適用されます。

  5. 用語

    定足数：決議をするために最低限出席していなければならない議決権の量。事前行使された議決権も出席に含める。

    定款変更や合併など、会社の基礎を変える重要な事項は、より多くの株主の賛成を必要とすることで、少数の株主だけで決まらないようにしています。

    招集の準備段階で、特別決議の議案については事前行使の集計を早めに確認し、3分の2に届かないおそれがあれば、主要株主への説明や議案の見直しを検討します。定款で定足数を「3分の1以上」と定めている会社が多いので、自社の定款を確認してください。

  5. 落とし穴

    特別決議の定足数を定款で「排除」することはできません。3分の1が下限です。

  2. 条文
    会社法 309条4項 （株主総会の決議）

    第4項　前三項の規定にかかわらず、第百九条第二項の規定による定款の定めについての定款の変更（当該定款の定めを廃止するものを除く。）を行う株主総会の決議は、総株主の半数以上（これを上回る割合を定款で定めた場合にあっては、その割合以上）であって、総株主の議決権の四分の三（これを上回る割合を定款で定めた場合にあっては、その割合）以上に当たる多数をもって行わなければならない。

  3. やさしく言うと

    全株式に譲渡制限を付ける定款変更などは、議決権を行使できる株主の「人数の半数以上」で、かつその議決権の3分の2以上の賛成が必要です。非公開会社が株主ごとに異なる扱い（属人的な定め）を定款に設けるときは、さらに重く、総株主の人数の半数以上で、総株主の議決権の4分の3以上の賛成が必要です。

  4. なぜこのルールか

    株式を自由に売れなくなる、株主ごとに権利が変わるなど、株主の地位に大きな影響を与えるので、大株主だけで決められないよう人数の要件を加えています。

  5. この事例では

    特殊決議の議案では、議決権の数とは別に、賛成した株主の人数を集計する欄を集計表に設けます。309条3項は「議決権を行使することができる株主」が基準なので、欠席した株主も分母に含まれる点に注意してください。

注4役員の選任・解任の定足数には下限がある
  1. 条文
    会社法 341条 （役員の選任及び解任の株主総会の決議）

    第三百九条第一項の規定にかかわらず、役員を選任し、又は解任する株主総会の決議は、議決権を行使することができる株主の議決権の過半数（三分の一以上の割合を定款で定めた場合にあっては、その割合以上）を有する株主が出席し、出席した当該株主の議決権の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行わなければならない。

  2. やさしく言うと

    役員（取締役・会計参与・監査役）を選任・解任する決議は、普通決議の一種ですが、定足数を定款で下げる場合も3分の1が限度です。

  3. この事例では

    定款で普通決議の定足数を排除していても、役員選任には適用されません。多くの会社は、定款に「取締役の選任決議は、議決権を行使することができる株主の議決権の3分の1以上を有する株主が出席し」という条文を別に置いています。自社の定款にこの条文があるか確認してください。

  4. 実務のコツ

    監査役の解任は、この条文ではなく特別決議（309条2項7号）によります（343条4項で341条の適用が外されています）。

総会の日までに、事前行使の勧誘（大株主への依頼、議決権行使の督促状の送付）や当日出席の呼びかけで、出席議決権を3分の1以上に積み上げる必要があります。それでも届かない場合は、取締役選任議案は決議できず、任期満了の取締役は後任が選ばれるまで取締役の権利義務を引き続き負うことになります（346条1項）。
定足数を満たさないまま「可決」と扱うと、決議の方法の法令違反として取消しの対象になります。

根拠が明らかでない点（推測を含みます）

  • 定足数を欠いたまま可決と扱った決議の効力について、取消事由にとどまるか不存在とみる余地があるかは、本文で明示していません。一般には決議の方法の法令違反として取消事由と解されていますが、瑕疵の程度によっては見解が分かれます。
  • 役員の選任手続を怠ったことによる過料（会社法976条22号）は「員数を欠くこととなった場合」の規定で、権利義務取締役が職務を続けている場合にどの時点から適用されるかは、本文では断定していません。

実務のポイント

  • 定款の決議方法の条文を、普通決議・役員選任・特別決議ごとに確認する。役員選任の定足数を「3分の1以上」とする条文がなければ、原則どおり過半数の出席が必要。
  • 定足数は「議決権を行使できる株主の議決権」を分母に計算する。自己株式・相互保有株式などは分母から除く。
  • 事前行使の集計は総会の数日前から日次で確認し、不足の見込みがあれば早めに督促する。
  • 当日、会場出席者の議決権を受付で集計し、開会時に議長が定足数を確認できるようにする（定足数の確認は議案ごとに必要）。
  • 定足数不足で決議できなかった場合の議長シナリオ（流会・延会）も用意しておく。

注1役員選任の定足数は3分の1が下限 重要
  1. 条文
    会社法 341条 （役員の選任及び解任の株主総会の決議）

    第三百九条第一項の規定にかかわらず、役員を選任し、又は解任する株主総会の決議は、議決権を行使することができる株主の議決権の過半数（三分の一以上の割合を定款で定めた場合にあっては、その割合以上）を有する株主が出席し、出席した当該株主の議決権の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行わなければならない。

  2. やさしく言うと

    役員の選任・解任の決議は、普通決議の規定（309条1項）にかかわらず、議決権の過半数（定款で定めても3分の1以上）を持つ株主が出席しなければなりません。

  3. なぜこのルールか

    役員は会社の経営を任される重要な立場なので、ごく一部の株主だけで選ばれることがないよう、最低限の出席を確保しています。

  4. この事例では

    出席が30％では、定款で3分の1まで下げていても足りません。総会の日までに少なくとも3分の1を超える出席（事前行使を含む）を集める必要があります。計算は端数を切り上げ、分母の確定を誤らないようにしてください。

    「普通決議の定足数を排除しているから役員選任も定足数不要」と誤解している例があります。定款の文言が「法令に別段の定めがある場合を除き」となっているのは、この341条のような規定を想定しているためです。

自己株式と、当社が実質的に支配できる会社（議決権の4分の1以上を当社グループが持つ会社など）が持つ当社株式には、議決権がありません（会社法308条1項・2項）。これらは定足数の分母（議決権の総数）にも出席議決権にも入れません。子会社が持つ当社株式も、相互保有として議決権がないのが通常です。

棄権の扱いは「出席したが賛成しなかった」として分母に入り、結果として反対と同じ効果になる点に注意してください。

根拠が明らかでない点（推測を含みます）

  • 白紙の扱いを招集の際に定めていない場合に「出席には数えるが賛否にはどちらにも入れない」とする扱いは、一般的な解釈として述べたもので、直接の条文はありません。
  • 途中退席した株主の議決権を「退席後の議案では出席から除く扱いが多い」とする点は実務の傾向で、統計の確認はしていません。

実務のポイント

  • 分母は「議決権を行使することができる株主の議決権」。基準日現在の株主名簿から、自己株式・相互保有株式・単元未満株式を除いて計算する。
  • 相互保有の判定（4分の1以上）は、原則として基準日で行う（会社法施行規則67条3項）。基準日後に持株比率が変わった場合の扱いも条文で確認する。
  • 白紙の扱いを招集の際に定めていない場合、白紙の行使書は出席には数えるが、賛否にはどちらにも入れない（結果として可決に必要な賛成に数えられない）。
  • 棄権欄を設けた場合、棄権は出席議決権（分母）に含まれる。
  • 議案ごとに議決権を行使できない株主がいる場合（特別利害関係などで制限がある場合）は、議案ごとに分母を確認する。

  2. 当社グループが議決権の4分の1以上を持つ会社が当社株式を持っていないかを調べ、相互保有株式を特定する。
  3. 議決権の総数（分母）を確定し、招集通知・シナリオに記載する。
  4. 事前行使を、賛成・反対・棄権・白紙（取扱いの定めに従った処理）に分けて集計する。
  5. 当日出席分を合算し、議案ごとに定足数と賛成割合を計算する。
  6. 集計表を総会後も保管し、議事録・臨時報告書（上場会社）と数字を一致させる。

注1議決権がない株式 重要
  1. 条文
    会社法 308条1項 （議決権の数）

    第1項　株主（株式会社がその総株主の議決権の四分の一以上を有することその他の事由を通じて株式会社がその経営を実質的に支配することが可能な関係にあるものとして法務省令で定める株主を除く。）は、株主総会において、その有する株式一株につき一個の議決権を有する。ただし、単元株式数を定款で定めている場合には、一単元の株式につき一個の議決権を有する。

  2. 条文
    会社法 308条2項 （議決権の数）

    第2項　前項の規定にかかわらず、株式会社は、自己株式については、議決権を有しない。

  3. やさしく言うと

    株主は原則として1株（単元株制度があれば1単元）につき1個の議決権を持ちます。ただし、会社自身が持つ自己株式と、会社が経営を実質的に支配できる株主（相互保有株主）が持つ株式には議決権がありません。

  4. なぜこのルールか

    会社が自分の株式や支配下の会社を通じて議決権を行使すると、経営者が自分を選ぶような形になり、株主による監督が働かなくなるからです。

  5. この事例では

    分母（議決権の総数）からこれらの株式を除いて計算します。単元未満株式にも議決権がないので除きます。

注3白紙の議決権行使書の扱い
  1. 条文
    会社法施行規則 66条1項 二号 （議決権行使書面）

    第1項　法第三百一条第一項の規定により交付すべき議決権行使書面に記載すべき事項又は法第三百二条第三項若しくは第四項の規定により電磁的方法により提供すべき議決権行使書面に記載すべき事項は、次に掲げる事項とする。

    • 二　第六十三条第三号ニに掲げる事項についての定めがあるときは、第一号の欄に記載がない議決権行使書面が株式会社に提出された場合における各議案についての賛成、反対又は棄権のいずれかの意思の表示があったものとする取扱いの内容
  2. やさしく言うと

    招集の際に白紙の扱いを決めていれば、議決権行使書面に、賛否の欄が空白の場合に「賛成」「反対」「棄権」のどれとして扱うかを記載します。

  3. なぜこのルールか

    白紙の扱いを事前に示しておけば、株主は自分の行使がどう扱われるかを分かったうえで提出でき、会社が後から都合よく扱うことも防げます。

  4. この事例では

    実務では「会社提案は賛成、株主提案は反対として扱う」と定める会社が多く見られます。定めがない場合は、白紙の行使書は出席には数えますが、賛成にも反対にも数えません。結果として賛成率を下げる方向に働くので、定めを置いておくのが一般的です。

  5. 落とし穴

    取扱いの定めは招集の際に決めておく必要があります（会社法施行規則63条3号ニ）。総会の直前になって白紙を賛成に数えることにはできません。

注4棄権は反対と同じ効果になる
  1. 条文
    会社法 309条1項 （株主総会の決議）

    第1項　株主総会の決議は、定款に別段の定めがある場合を除き、議決権を行使することができる株主の議決権の過半数を有する株主が出席し、出席した当該株主の議決権の過半数をもって行う。

  2. やさしく言うと

    可決に必要なのは、出席した株主の議決権の過半数の賛成です。分母は「出席した議決権」なので、出席して棄権した議決権も分母に入ります。

  3. この事例では

    棄権が多い議案では、賛成が反対より多くても、出席議決権の過半数に届かず否決になることがあります。集計表では棄権を分母に入れて計算し、議長に正確な数字を渡してください。

  4. 実務のコツ

    会場で途中退席した株主の議決権を、その後の議案の出席に数えるかは、受付・退出の管理方法とあわせて事前に方針を決めておきます。一般には退席後の議案では出席から除く扱いが多いようです。

A
会社法は採決の方法を定めていないので、議長の議事整理の権限で、拍手・挙手・起立・投票などから適切な方法を選べます。拍手でも、事前行使と当日出席の大株主の賛否で、可決・否決が明らかであれば足りると一般に解されています。
しかし、賛否が拮抗し、会場の株主の賛否で結果が変わり得る場合には、拍手では正確な議決権数が分からないため、投票（票決）によるべきです。この場合、投票用紙・集計の手順・集計中の休憩をあらかじめ準備しておきます。
議長は、判定の根拠（事前行使分と当日の賛否の合計）を確認して結果を宣言し、議事録には賛成の割合などを記載します。

根拠が明らかでない点（推測を含みます）

  • 拍手による採決でも、可決・否決が明らかであれば適法とする点は一般的な解釈です。注釈の判例欄に掲げたものは下級審の判断で、上級審がこの点を判断したものは確認できていません。
  • 臨時報告書で会場の賛否を集計しなかった旨を記載する実務は、開示府令の規定（未確認）ではなく実務の一般論として述べています。

実務のポイント

  • 事前行使の集計で「会場の全員が反対しても可決」「会場の全員が賛成しても否決」のどちらかに当たるかを、総会前に確認する。どちらでもなければ投票の準備をする。
  • 投票による場合は、投票用紙に株主番号と議決権数を印字する、受付で配布する、集計の担当と時間を決める。
  • 株主提案と会社提案が両立しない場合の採決の順序（会社提案を先に採決し、可決されれば株主提案は否決とする等）を議場に説明する。
  • 大株主（法人株主の代理人等）が会場で行使する場合は、その賛否を個別に確認して集計に入れる。
  • 議事録には、判定方法と結果（賛成の議決権数・割合）を記載する。

採決の方法の比較

A案　拍手（挙手）で採決する

事前行使と大株主の賛否で結果が明らかな場合。

メリット
  • 短時間で終わり、運営が簡単。
デメリット
  • 議決権の数が分からないため、結果が拮抗すると可決・否決を証明できない。

推奨B案　投票で採決する

賛否が拮抗し、会場の賛否で結果が変わり得る場合。

メリット
  • 議決権数で正確に判定でき、後日の訴訟にも耐える記録が残る。
デメリット
  • 投票用紙の準備・集計の人員・集計時間（休憩）が必要。

C案　大株主の賛否を個別に確認し、残りは拍手とする

会場に大株主の代理人がいて、その賛否で結果が確定する場合。

メリット
  • 投票より簡単で、議決権数の根拠も残せる。
デメリット
  • 大株主の賛否だけでは結果が確定しない場合には使えない。

推奨：本問のように株主提案と会社提案が拮抗するなら、B案（投票）を推奨します。総会前の集計で結果が確定していればA案、大株主の賛否で確定するならC案で足ります。どの方法をとるか、総会前に議長と事務局で決めておきます。

進め方

  1. 総会の1週間前から事前行使の集計を毎日確認し、拮抗の見込みかを判断する。
  2. 拮抗の見込みなら、投票方式の採用、投票用紙・集計システム、会場レイアウト、シナリオを準備する。
  3. 受付で議決権数を確認し、投票用紙を配る。
  4. 議長が採決方法（投票による旨）と採決の順序を説明し、投票を実施する。
  5. 休憩中に事前行使分と投票分を合算し、検算する。
  6. 議長が結果を宣言する。議事録と臨時報告書（上場会社）に結果を記載する。

注1採決の方法は議長が決められる 重要
  1. 条文
    会社法 315条1項 （議長の権限）

    第1項　株主総会の議長は、当該株主総会の秩序を維持し、議事を整理する。

  2. やさしく言うと

    議長は総会の秩序を守り、議事を整理する権限を持ちます。会社法は採決の方法を具体的に定めていないので、拍手・挙手・投票などのどれで採決するかは、議長がこの権限に基づいて決めます。

  3. なぜこのルールか

    総会の規模や議案の性質に応じて、効率よく、かつ正確に株主の意思を確認できる方法を選べるようにするためです。

  4. 判例
    非株主の議決権行使・拍手による強引な議事進行と決議方法の瑕疵（下級審）
    大阪高等裁判所 昭和42年9月26日 判決（高民集20巻4号411頁）

    退職役員に対する慰労金は在職中の職務執行の対価としての性質を有し報酬規定の対象となり株主総会決議を要するとした。株主でない者が議決権を行使したことは決議方法の法令違反に当たり、騒然とした中で強引に議事を進め賛否を拍手で決めたことは決議方法が著しく不公正であるとされた事例（出訴期間経過後の取消事由の追加を認めた点を含む）。

    騒然とした中で強引に議事を進め拍手で賛否を決した点などが問題とされた下級審の裁判例です。拍手による採決は、賛否が明らかな場面に限るべきことを示しています。

  5. この事例では

    一般に、決議に必要な賛成が明らかになる方法であれば、拍手でも適法と解されています。今回のように拮抗する場合は、拍手では議決権数が分からないので、投票によるのが適切です。投票の実施は、議長が会場に宣言すれば足ります。

  6. 落とし穴

    拮抗しているのに拍手で「可決」と宣言すると、後で賛成が過半数に達していたかを証明できず、決議の方法の違反として取消しを争われるおそれがあります。

注2可決の判定の基準

Q121

公開会社である当社（非上場）が、全株式に譲渡制限を付ける定款変更をしたい。普通の特別決議とは何が違い、どのような手続が必要か。

応用取締役会決議あり取締役会設置会社公開会社#
A
全株式に譲渡制限を付ける定款変更は「特殊決議」が必要です。議決権を行使できる株主の半数以上（人数）であって、その株主の議決権の3分の2以上の賛成が必要で、特別決議よりも重い要件です（会社法309条3項1号）。欠席した株主も人数の分母に入るので、株主数が多い会社では人数要件が最大の壁になります。
あわせて、①反対株主の株式買取請求の手続（効力発生日の20日前までの通知・公告）、②株券発行会社であれば株券提供公告（効力発生日の1か月前まで）、③変更登記、が必要です。定款変更の効力発生により非公開会社となるので、役員の任期や機関設計への影響も確認します。
上場会社は、上場を維持したまま全株式に譲渡制限を付けることは想定されていないので、この手続は非上場会社を前提とします。

根拠が明らかでない点（推測を含みます）

  • 効力発生日を後から変更して通知・公告の期間を確保できるかは、定款変更の効力発生日を総会決議でどう定めたか（取締役会に委ねる形か）によります。決議で確定日を定めた場合は、総会で変更の決議が必要になる可能性があり、推測を含みます。
  • 上場会社が上場を維持したまま全株式に譲渡制限を付けることは「想定されていない」としたのは、取引所の上場廃止基準によるもので、取引所規則の条文は確認していません。

実務のポイント

  • 人数要件の確認：株主名簿で「議決権を行使できる株主の人数」を数え、その半数以上の賛成が見込めるか、事前に主要株主・従業員株主等に説明する。
  • 買取請求への備え：反対株主は「公正な価格」での買取りを請求できる。資金と、価格協議が整わない場合の裁判所の価格決定手続を想定しておく。
  • 効力発生日を議案で明確にし、そこから逆算して通知・公告の期限を管理する。
  • 株券発行会社かどうかを定款と登記で確認する。株券を発行していれば株券提供公告が必要。
  • 非公開会社になった後の定款（取締役の任期の伸長、株主総会の招集期間、譲渡承認機関）を同時に整備するか検討する。

進め方

  1. 株主構成を分析し、人数要件・議決権要件の見込みを試算する。
  2. 取締役会で、臨時株主総会の招集と定款変更議案（効力発生日を含む）を決議する。
  3. 招集通知（公開会社なので総会の2週間前まで）を発送する。株券発行会社は株券提供公告も行う。
  4. 効力発生日の20日前までに、株主に定款変更の通知（または公告）をする。
  5. 総会で特殊決議により承認する。反対株主の買取請求を受け付ける（効力発生日の20日前から前日まで）。
  6. 効力発生日に定款変更が効力を生じる。2週間以内に変更登記をする。
  7. 買取請求をした株主と価格を協議し、効力発生日から60日以内に支払う（協議不調なら価格決定の申立てに対応）。

すでに手続を欠いてしまった場合（事後の是正）

特殊決議の人数要件を確認せず特別決議の要件だけで「可決」と扱った場合、又は反対株主への通知・公告、株券提供公告を期限までにしなかった場合

  1. 決議の集計を見直し、議決権を行使できる株主の人数の半数以上の賛成があったかを確認する。足りなければ、要件を欠く可決として、改めて臨時総会で特殊決議をやり直すことを検討する。
  2. 反対株主への通知・公告（効力発生日の20日前まで）が遅れた場合は、効力発生日を変更して（取締役会で決定し、変更後の日を公告・通知する）、買取請求の期間を確保する。
  3. 株券提供公告が間に合わない場合も、効力発生日を延ばして公告期間（1か月）を確保する。
  4. 効力発生日を過ぎて登記まで済ませていた場合は、登記の扱いを司法書士と、決議の効力を弁護士と確認する。
  5. 株主に経過を説明し、買取請求をする機会を改めて確保する。

応用取締役会決議あり取締役会設置会社非公開会社親子会社・グループ#
A
親会社は議決権を行使できます。取締役会と違い、株主総会では、議案に特別の利害関係を持つ株主も議決権を行使できるのが原則です。
ただし、特別の利害関係を持つ株主が議決権を行使したことで「著しく不当な決議」がされたときは、株主は決議の取消しを求めることができます（会社法831条1項3号）。譲渡価格が不当に安いなど、子会社と少数株主に不利な条件で親会社の賛成によって可決すると、取り消されるおそれがあります。
親会社の持株は90％未満なので略式の手続（会社法468条1項）は使えず、特別決議による承認が必要です（会社法467条1項2号・309条2項11号）。反対株主には株式買取請求権があり（会社法469条）、効力発生日の20日前までに株主に通知（又は公告）しなければなりません。
したがって、①譲渡価格の公正さを第三者の評価で裏付け、②子会社の取締役会でその検討の経過を残し、③参考書類で少数株主に十分に説明することが最も重要です。

根拠が明らかでない点（推測を含みます）

  • どの程度の不利な条件であれば「著しく不当な決議」（会社法831条1項3号）に当たるかの基準を示した判例は、サイトの判例登録簿にありません。本文の「第三者評価の範囲内の価格なら争われにくい」は推測を含みます。
  • 親会社の取締役を兼ねる子会社の取締役が、親会社との取引の取締役会決議で特別利害関係取締役に当たるかは、見解が分かれます。本文の「議決に加わらない扱いが安全」は安全策で、法律上の義務とは断定できません。
  • B案の「少数株主の過半数の賛成を条件とする」方法は、会社法に定めのない任意の工夫で、その法的効果（取消しを防げるか）を判断した判例は確認できていません。

実務のポイント

  • 親会社の持株割合を確認する：90％以上（特別支配会社）なら総会の承認は不要。本問は70％なので特別決議が必要。
  • 譲渡価格は、親会社から独立した第三者（会計士・評価機関）の評価を取得し、取締役会でその評価の前提を検討する。
  • 親会社の役員を兼ねる取締役は、取締役会での事業譲渡契約の承認決議に加わるか慎重に判断する（加わらない扱いが安全）。
  • 参考書類には、譲渡の理由、対価とその算定根拠、少数株主の利益への配慮を具体的に書く。
  • 反対株主の買取請求に備え、効力発生日の20日前までの通知（非公開会社でも総会決議を経た場合は公告で代えられる）と買取資金を準備する。

親会社との事業譲渡を承認する総会の進め方の比較

推奨A案　第三者評価で価格の公正さを裏付けたうえで、親会社も議決権を行使して特別決議で承認する

メリット
  • 法律上の要件どおりで、確実に可決できる。
  • 価格の公正さを示す資料があれば、「著しく不当」と争われにくい。
デメリット
  • 少数株主の反対が強いと、買取請求や取消しの訴えが起こる可能性は残る。

B案　A案に加え、少数株主の過半数の賛成を得ることを会社が任意に条件とする

メリット
  • 少数株主の意思を尊重したことを示せ、取消しの訴えのリスクが一段と小さくなる。
デメリット
  • 法律上の要件ではないため、少数株主の賛成が得られないと譲渡ができなくなる。
  • 条件の付け方（議案の内容か、契約の条件か）を工夫する必要がある。

推奨：通常はA案で足ります。少数株主の中に強く反対する大口の株主がいる、又は価格の評価に幅があって争いになりやすい場合は、B案も検討してください。

進め方

  1. 親会社と譲渡の範囲・条件を協議し、独立した第三者に事業の価値の評価を依頼する。
  2. 取締役会で、評価結果と条件の公正さを検討し、事業譲渡契約の承認と臨時株主総会の招集を決議する（親会社の役員を兼ねる取締役の扱いを決める）。
  3. 招集通知と参考書類を株主に送る（非公開会社は1週間前まで）。少数株主には個別に説明の機会を設ける。
  4. 臨時株主総会で特別決議により事業譲渡契約を承認する。質疑では価格の算定根拠を丁寧に説明する。
  5. 効力発生日の20日前までに、事業譲渡をする旨を株主に通知する（又は公告する）。
  6. 買取請求があれば価格を協議し、まとまらなければ裁判所の価格決定手続に備える。
  7. 効力発生日に事業を引き渡し、取締役会に完了を報告する。

すでに手続を欠いてしまった場合（事後の是正）

親会社の賛成で可決した事業譲渡の承認決議について、少数株主から「著しく不当な決議」として取消しを求められた場合、又は反対株主への通知を効力発生日の20日前までにしていなかった場合

  1. 弁護士に相談し、譲渡価格と評価の資料、取締役会の検討経過を整理する（取消しの訴えは決議の日から3か月以内）。
  2. 価格が不当に低かった疑いがあれば、親会社と対価の見直し（追加の支払い）を協議し、子会社の取締役会で決議する。
  3. 見直し後の条件で改めて臨時株主総会の承認決議（再決議）をすることを検討する。
  4. 通知が遅れていた場合は、効力発生日を延ばして20日前の通知と買取請求の期間（効力発生日の20日前の日から前日まで）を確保する。既に効力発生日を過ぎていれば、弁護士と対応を検討する。
  5. 少数株主に経過を説明し、買取請求の機会を改めて確保する。
  6. 取締役会で経過と再発防止策（親会社との取引の検証手順）を報告する。

注1利害関係のある株主も議決権を行使できるが、著しく不当な決議は取り消され得る 重要
  1. 条文
    会社法 831条1項 三号 （株主総会等の決議の取消しの訴え）

    第1項　次の各号に掲げる場合には、株主等（当該各号の株主総会等が創立総会又は種類創立総会である場合にあっては、株主等、設立時株主、設立時取締役又は設立時監査役）は、株主総会等の決議の日から三箇月以内に、訴えをもって当該決議の取消しを請求することができる。当該決議の取消しにより株主（当該決議が創立総会の決議である場合にあっては、設立時株主）又は取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役。以下この項において同じ。）、監査役若しくは清算人（当該決議が株主総会又は種類株主総会の決議である場合にあっては第三百四十六条第一項（第四百七十九条第四項において準用する場合を含む。）の規定により取締役、監査役又は清算人としての権利義務を有する者を含み、当該決議が創立総会又は種類創立総会の決議である場合にあっては設立時取締役（設立しようとする株式会社が監査等委員会設置会社である場合にあっては、設立時監査等委員である設立時取締役又はそれ以外の設立時取締役）又は設立時監査役を含む。）となる者も、同様とする。

    • 三　株主総会等の決議について特別の利害関係を有する者が議決権を行使したことによって、著しく不当な決議がされたとき。
  2. やさしく言うと

    議案に特別の利害関係を持つ株主が議決権を行使し、その結果、著しく不当な決議がされたときは、他の株主などが決議の取消しを裁判所に求めることができます。

  3. なぜこのルールか

    株主は自分の利益のために議決権を行使してよいのが原則なので、利害関係があるだけで議決権を奪うことはしていません。そのかわり、多数派が自分に都合のよい決議を押し通した場合に、事後に取り消せるようにしています。

  4. この事例では

    親会社は、事業の譲受人として特別の利害関係を持つ株主に当たると考えられますが、議決権の行使自体は禁止されていません。問題は「著しく不当」かどうかで、譲渡価格が適正な価値より大きく低い場合などが典型です。独立した第三者評価の範囲内の価格にし、その経過を記録しておくことが、取消しを防ぐ最大の手立てです。

  5. 用語

    特別の利害関係：議案の成立によって、株主としての立場を離れた個人的な利益や不利益を受ける関係。取引の相手方である株主が典型例。

  6. 落とし穴

    取締役会では特別利害関係取締役は議決に加われませんが（会社法369条2項）、株主総会では議決権を行使できます。両者のルールを混同しないでください。

注2どの決議が必要か（略式手続が使えるか）
  1. 条文
    会社法 467条1項 二号 （事業譲渡等の承認等）

    第1項　株式会社は、次に掲げる行為をする場合には、当該行為がその効力を生ずる日（以下この章において「効力発生日」という。）の前日までに、株主総会の決議によって、当該行為に係る契約の承認を受けなければならない。

    • 二　事業の重要な一部の譲渡（当該譲渡により譲り渡す資産の帳簿価額が当該株式会社の総資産額として法務省令で定める方法により算定される額の五分の一（これを下回る割合を定款で定めた場合にあっては、その割合）を超えないものを除く。）
  2. 条文
    会社法 468条1項 （事業譲渡等の承認を要しない場合）

    第1項　前条の規定は、同条第一項第一号から第四号までに掲げる行為（以下この章において「事業譲渡等」という。）に係る契約の相手方が当該事業譲渡等をする株式会社の特別支配会社（ある株式会社の総株主の議決権の十分の九（これを上回る割合を当該株式会社の定款で定めた場合にあっては、その割合）以上を他の会社及び当該他の会社が発行済株式の全部を有する株式会社その他これに準ずるものとして法務省令で定める法人が有している場合における当該他の会社をいう。以下同じ。）である場合には、適用しない。

  3. 条文
    会社法 309条2項 十一号 （株主総会の決議）

    第2項　前項の規定にかかわらず、次に掲げる株主総会の決議は、当該株主総会において議決権を行使することができる株主の議決権の過半数（三分の一以上の割合を定款で定めた場合にあっては、その割合以上）を有する株主が出席し、出席した当該株主の議決権の三分の二（これを上回る割合を定款で定めた場合にあっては、その割合）以上に当たる多数をもって行わなければならない。この場合においては、当該決議の要件に加えて、一定の数以上の株主の賛成を要する旨その他の要件を定款で定めることを妨げない。

    • 十一　第六章から第八章までの規定により株主総会の決議を要する場合における当該株主総会
  4. やさしく言うと

    事業の重要な一部（譲り渡す資産の帳簿価額が総資産額の5分の1を超えるもの）を譲渡するには、株主総会の特別決議で契約の承認を受けます。ただし、相手方が議決権の10分の9以上を持つ親会社（特別支配会社）なら、総会の承認は要りません。

  5. この事例では

    親会社の持株は70％なので特別支配会社に当たらず、特別決議が必要です。親会社の70％だけで3分の2以上の賛成は満たすので可決はできますが、だからこそ少数株主から「著しく不当」と争われないよう配慮が必要になります。

注3反対株主の株式買取請求と通知
  1. 条文
    会社法 469条1項 （反対株主の株式買取請求）

    第1項　事業譲渡等をする場合（次に掲げる場合を除く。）には、反対株主は、事業譲渡等をする株式会社に対し、自己の有する株式を公正な価格で買い取ることを請求することができる。

    • 一　第四百六十七条第一項第一号に掲げる行為をする場合において、同項の株主総会の決議と同時に第四百七十一条第三号の株主総会の決議がされたとき。
    • 二　前条第二項に規定する場合（同条第三項に規定する場合を除く。）
  2. 条文
    会社法 469条3項 （反対株主の株式買取請求）

    第3項　事業譲渡等をしようとする株式会社は、効力発生日の二十日前までに、その株主（前条第一項に規定する場合における当該特別支配会社を除く。）に対し、事業譲渡等をする旨（第四百六十七条第二項に規定する場合にあっては、同条第一項第三号に掲げる行為をする旨及び同条第二項の株式に関する事項）を通知しなければならない。

  3. やさしく言うと

    事業譲渡に反対する株主は、会社に自分の株式を公正な価格で買い取るよう請求できます。会社は、効力発生日の20日前までに株主に事業譲渡をする旨を通知しなければなりません。総会の決議で承認を受けた場合は、公告で代えることもできます（同条4項）。

  4. なぜこのルールか

    多数決で会社の事業の重要な部分が変わることに反対する株主に、会社から出ていく機会を保障するためです。

  5. この事例では

    取引先など少数株主が反対しているなら、買取請求がされることを前提に資金を準備し、効力発生日から逆算して通知の期限を管理します。反対株主になるには総会の前に反対を通知し、総会で反対する必要がある（同条2項1号イ）ので、その旨も案内しておくと丁寧です。

注4子会社の取締役会での決議の仕方
  1. 条文
    会社法 369条2項 （取締役会の決議）

    第2項　前項の決議について特別の利害関係を有する取締役は、議決に加わることができない。

  2. やさしく言うと

    取締役会の決議では、議案に特別の利害関係を持つ取締役は議決に加われません。

  3. この事例では

    親会社の取締役を兼ねる子会社の取締役が、親会社との事業譲渡の議案で特別利害関係取締役に当たるかは、兼ねている地位（代表取締役か等）によって見解が分かれます。判断が難しいときは、議決に加わらない扱いにし、残りの取締役で定足数と過半数を満たすかを確認するのが安全です。

  4. 推測を含む点

    親会社の代表取締役を兼ねる取締役は、親会社を代表して契約する立場になるので、特別利害関係を認める方向で考えられやすいと思われます。代表権のない兼任取締役については、明確な基準は確認できていません。

  5. 実務のコツ

    利益相反取引（会社法356条1項2号）としての承認が必要かも、兼任の状況によって検討してください。
