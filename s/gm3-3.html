Q057

定款で「代理人は当会社の議決権を有する株主1名に限る」と定めている。株主から委任を受けた弁護士（株主ではない）が総会会場に来た。入場を断ってよいか。

実務取締役会設置会社公開会社非公開会社#
A
原則として断って構いません。判例は、代理人の資格を株主に限る定款の定めについて、総会が株主以外の第三者によって攪乱されることを防ぎ、会社の利益を守る趣旨の合理的な制限として有効と解しています。この定款の定めがある以上、株主でない弁護士は、代理人として議決権を行使するために入場することはできないのが原則です。
もっとも、定款の定めがあっても、株主以外の代理人を一律に排除できるわけではないと解されています。法人株主がその従業員を出席させる場合など、総会が攪乱されるおそれがなく、拒むと株主の議決権行使の機会を実質的に奪う場合には、代理人として認めるべきだとする判例・裁判例があります。
入場を断る場合は、受付で定款の規定を示して丁寧に説明し、株主本人が事前に書面・電子で議決権を行使できることを案内してください。

実務のポイント

  • 代理人資格の制限は定款で定める。定款になければ、株主以外の代理人も認めなければならない。
  • 制限の趣旨は「総会の攪乱防止」。攪乱のおそれがない者（法人株主の従業員、病気の株主の親族など）まで機械的に排除するのは慎重に。
  • 例外を認める基準（どのような場合に株主以外の代理人を入場させるか）を事前に決め、全員に同じ基準を適用する。
  • 代理人の人数を1名に限ることもできる（会社法310条5項）。
  • 断った経過（日時、相手、説明内容）を記録しておく。

進め方

  1. 招集通知に、代理人資格の制限と委任状の提出方法を記載しておく。
  2. 受付で、代理人であること・委任状・株主本人の議決権行使書面を確認する。
  3. 代理人が株主かを株主名簿で確認する。
  4. 株主でない場合、例外の基準（法人株主の従業員など）に当たるかを判断する。
  5. 当たらなければ入場を断り、定款の規定と事前行使の方法を説明する。
  6. 経過を記録し、総会の事務局責任者に報告する。

注1代理人による議決権の行使 重要
  1. 条文
    会社法 310条1項 （議決権の代理行使）

    第1項　株主は、代理人によってその議決権を行使することができる。この場合においては、当該株主又は代理人は、代理権を証明する書面を株式会社に提出しなければならない。

  2. 条文
    会社法 310条2項 （議決権の代理行使）

    第2項　前項の代理権の授与は、株主総会ごとにしなければならない。

  3. やさしく言うと

    株主は、代理人に議決権を行使させることができます。代理人は委任状などを会社に提出しなければならず、委任は総会ごとにする必要があります。

  4. なぜこのルールか

    株主が出席できなくても議決権を行使できるようにする一方、代理権の存在を確認し、包括的な委任で会社の支配が固定されることを防ぐためです。

  5. この事例では

    今回の弁護士は委任状を持っているので、代理人であること自体は確認できます。問題は、定款の代理人資格の制限との関係です。

注2代理人を株主に限る定款は有効か
  1. 条文
    会社法 310条5項 （議決権の代理行使）

    第5項　株式会社は、株主総会に出席することができる代理人の数を制限することができる。

  2. やさしく言うと

    会社法は、代理人の人数を制限できると定めていますが、代理人の資格（株主に限ること）については明文がありません。

  3. なぜこのルールか

    判例は、代理人を株主に限る定款の定めは、株主以外の第三者が総会に入り込んで議事を攪乱することを防ぎ、会社の利益を守るための合理的な範囲の制限として有効と解しています。

  4. 判例
    議決権行使の代理人を株主に限る定款規定の効力
    最高裁判所第二小法廷 昭和43年11月1日 判決（民集22巻12号2402頁）

    議決権行使の代理人の資格を株主に限る旨の定款の規定は有効であるとした判決。

    議決権行使の代理人の資格を株主に限る定款の規定は有効であるとした判決です。今回、株主でない弁護士の入場を断る根拠になります。

  5. この事例では

    定款に株主限定の規定があるので、株主でない弁護士の入場は原則として断れます。弁護士だから攪乱のおそれがないとして入場を認めるべきかについては、裁判例の判断が分かれており、一律の答えはありません。会社の方針を事前に決めておきます。

  6. 落とし穴

    定款の規定を理由に断る場合でも、受付での強い口調や実力での排除は避け、事務局責任者が冷静に説明してください。

A
認めるのが一般的です。法人株主は自ら総会に出席できないので、代表者本人が来るか、誰かに代理させるしかありません。判例は、株式会社である株主がその従業員を代理人として出席させた事案で、従業員は法人の指示に従って議決権を行使する者であり総会が攪乱されるおそれはないとして、代理人を株主に限る定款の定めがあっても入場を拒むことは許されないと解しています。
確認するのは、①法人株主の代表者が作成した委任状（又は職務代行の通知書）、②株主の議決権行使書面、③来場者がその法人の役員・従業員であることを示すもの（社員証・名刺など）です。
法人の代表者本人が来場した場合は、代理ではなく法人自身の出席なので、代表者であることを登記事項証明書や名刺などで確認できれば足ります。

実務のポイント

  • 代表者の来場は「本人の出席」、従業員の来場は「代理」。どちらかを受付で区別する。
  • 代理の場合、法人の代表者名義の委任状を求める。社印・代表者印の押印があると確認しやすい。
  • 来場者が法人の従業員であることを、社員証などで確認する（委任状に役職を記載してもらう）。
  • 招集通知に、法人株主の代理人の確認方法を案内しておく。
  • 法人株主が外国法人の場合は、署名者の権限の確認方法を事前に決めておく。

進め方

  1. 招集通知で、法人株主の代理人の来場時に必要な書類を案内する。
  2. 受付で議決権行使書面と委任状を確認する。
  3. 来場者の身分（役員・従業員）を確認する。
  4. 確認できたら入場を認め、出席者として集計する。
  5. 書類が足りない場合は、法人に電話で確認するなどして判断し、経過を記録する。

注1法人株主は誰が出席するか 重要
  1. 条文
    会社法 349条4項 （株式会社の代表）

    第4項　代表取締役は、株式会社の業務に関する一切の裁判上又は裁判外の行為をする権限を有する。

  2. やさしく言うと

    株式会社の代表取締役は、会社の業務に関する一切の行為をする権限を持ちます。法人株主の総会への出席・議決権行使も、代表者が会社を代表してすることになります。

  3. この事例では

    法人株主の代表取締役本人が来場すれば、法人自身の出席です。代表者でない役員・従業員が来るなら、代表者からの委任による代理となり、委任状が必要です（会社法310条1項）。

注2代理人を株主に限る定款との関係
  1. 条文
    会社法 310条1項 （議決権の代理行使）

    第1項　株主は、代理人によってその議決権を行使することができる。この場合においては、当該株主又は代理人は、代理権を証明する書面を株式会社に提出しなければならない。

  2. やさしく言うと

    代理人を株主に限る定款の定めは、総会の攪乱を防ぐための制限として有効とされていますが、その趣旨を超えて適用することはできないと考えられています。

  3. なぜこのルールか

    判例は、法人株主の従業員は法人の組織の中で上司の命令に従う立場にあり、個人的な意図で総会を攪乱するおそれはないから、その出席を拒むと法人株主の議決権行使の機会を実質的に奪うことになる、と考えています。

  4. 判例
    株主でない法人職員・従業員による議決権代理行使と提訴期間後の取消事由追加

    定款で議決権行使の代理人を株主に限っていても、株主である地方公共団体や会社が、上司の命令に服する義務を負い議決権の代理行使に当たって法人代表者の意図に反することができない職員・従業員に代理行使させることは、定款の規定に反しないとした。株主総会決議取消しの訴えにおいて、旧商法248条1項所定の期間経過後に新たな取消事由を追加主張することは許されないとした判決。

    定款で代理人を株主に限っていても、株主である会社等が、上司の命令に服し法人代表者の意図に反することができない従業員等に代理行使させることは、定款の規定に反しないとした判決です。法人株主の従業員の入場を認める根拠になります。

  5. この事例では

    法人株主の総務部の従業員が、代表者の委任状を持って来場したなら、株主でなくても入場を認めます。受付の判断基準（チェックリスト）にこの例外を明記しておきます。

  6. 落とし穴

実務のポイント

  • 名簿の閲覧を拒めるのは、権利の確保・行使に関する調査以外の目的、業務妨害・共同の利益を害する目的、情報の売却目的などの法定事由がある場合に限られる。
  • 委任状の確認基準は会社側・株主側で同じにする。基準を事前に株主側に示すと当日の紛争を減らせる。
  • 同じ株主の会社側への委任状と株主側への委任状が重複した場合の扱い（作成日の新しい方を有効など）を事前に決める。
  • 委任状の受付・集計に時間がかかるので、総会の開始時刻・受付時間・集計担当者を十分に確保する。
  • 検査役の選任（総会の手続の調査）を会社・株主の側から申し立てることも検討対象になる。

  3. 受け入れる場合は、議決権行使書面・当日の行使で賛否ごとの議決権数を特定してもらう。

A
共有の株式の議決権は、共有者が権利を行使する者1人を定め、その氏名を会社に通知しなければ行使できません（会社法106条本文）。相続人の1人が来場しても、権利行使者として通知されていなければ、原則として議決権の行使を認めないのが基本です。
権利行使者の決定は、共有物の管理に関する事項として、共有者の持分の価格の過半数で決めると解されています（民法264条・252条1項）。3名の相続人の法定相続分が均等なら、2名以上の賛成で権利行使者を決められます。
会社が同意すれば、通知がなくても共有者の1人の権利行使を認めることができます（会社法106条ただし書）。ただし、判例は、会社の同意があっても、その権利行使が民法の共有に関する規定に従ったものでなければ適法にならないと解しています。他の相続人の意向を確認できないまま、来場した1人の行使を会社の判断で認めるのは避けてください。

実務のポイント

  • まず株主名簿の名義（被相続人のまま）と、相続人・持分を確認する。
  • 権利行使者の通知を受ける書式を用意し、共有者の過半数で決定したことが分かるようにしてもらう。
  • 会社の同意（106条ただし書）は、共有者間の決定が民法に従っていることを確認できる場合に限るのが安全。
  • 通知・催告の受領者の指定（会社法126条3項）もあわせて求める。
  • 同族会社で相続人間に争いがある場合、議決権の扱いが総会の結果を左右し得るので、弁護士に相談する。

進め方

  1. 相続の発生を把握したら、相続人と法定相続分を確認する（戸籍、遺言の有無）。
  2. 相続人に、権利行使者の指定と通知（及び通知の受領者の指定）を依頼する。
  3. 総会の前に、権利行使者の通知書を受け取り、共有者の過半数で決めたことを確認する。
  4. 当日は、通知された権利行使者の出席・委任状だけを受け付ける。
  5. 通知がない場合は、その株式の議決権は行使できないものとして扱い、扱いを議事の記録に残す。
