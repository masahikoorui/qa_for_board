Q093

株主総会で株主から質問されたら、役員はどこまで答えなければならないか。答えなくてよいのはどんな場合か。

基本取締役会設置会社監査役設置会社上場会社#
A
取締役・監査役などは、株主から総会で特定の事項について説明を求められたら、株主が議題について合理的に判断するのに必要な範囲で説明しなければなりません（会社法314条）。
一方、①総会の目的である事項（報告事項・決議事項）に関係しない質問、②説明すると株主全体の利益を著しく害する質問、③会社法施行規則71条が定める場合（調査が必要な事項、他人の権利を侵害する事項、同じ質問の繰返し、その他正当な理由がある場合）は、説明を断ることができます。
義務が生じるのは「総会の場で」質問されたときです。事前に届いた質問状だけでは、まだ説明義務は生じないと一般に解されています。
説明が不十分なまま採決すると、決議の方法の法令違反として決議取消しの理由になり得ます。断るときも「なぜ答えられないか」を一言添え、答えられる範囲は答えるのが実務の基本です。

根拠が明らかでない点（推測を含みます）

  • 「必要な説明」の水準を「平均的な株主が議題について合理的に判断できる程度」とする点は一般的な解釈で、本サイトの判例登録簿にこれを示した最高裁判例はありません（説明義務を扱った下級審の裁判例はあるとされますが、原文は確認できていません）。
  • 事前に届いた質問状だけでは説明義務が生じないという点は、会社法314条が「株主総会において」説明を求められた場合と定めていることからの解釈です。

実務のポイント

  • 「必要な説明」の水準は、平均的な株主が議題について賛否を判断できる程度と一般に解されている。細部まで全部答える義務はないが、議題に関係する質問を門前払いにしない。
  • 拒絶事由は、①目的事項に関しない、②株主共同の利益を著しく害する、③施行規則71条1号〜4号の4類型。事務局はこの類型ごとに想定問答を分けておく。
  • 報告事項（事業報告など）についての質問も説明義務の対象になる。決議事項だけが対象ではない。
  • 断るときは理由を述べる（「個別の取引先との契約条件は、相手方との守秘の約束があるため差し控えます」など）。理由のない拒絶は過料の対象にもなる（会社法976条）。
  • 回答者は議長の指名で決める。取締役への質問は担当取締役、監査に関する質問は監査役が答える。

進め方

  1. 総会の4〜6週間前までに、議案・事業報告ごとに想定問答を作り、各問に「回答する／一部回答／拒絶（理由の類型）」を付ける。
  2. リハーサルで、拒絶する問の言い回しを議長・回答役員と確認する。
  3. 当日、質問を受けたら、議長が質問の趣旨を確認し、回答者を指名する。
  4. 事務局（ブレーン席）が、拒絶事由に当たるかを即座に判断し、議長にメモで伝える。
  5. 拒絶する場合も、理由と、答えられる範囲の情報（公表済みの数字など）を述べる。
  6. 議事録に、質問の要旨と回答の要旨（拒絶した場合はその旨と理由）を残す。

注1役員はどんな場合に説明しなければならないか 重要
  1. 条文
    会社法 314条 （取締役等の説明義務）

    取締役、会計参与、監査役及び執行役は、株主総会において、株主から特定の事項について説明を求められた場合には、当該事項について必要な説明をしなければならない。ただし、当該事項が株主総会の目的である事項に関しないものである場合、その説明をすることにより株主の共同の利益を著しく害する場合その他正当な理由がある場合として法務省令で定める場合は、この限りでない。

  2. やさしく言うと

    株主から総会の場で「この点を説明してほしい」と言われたら、取締役・監査役などは必要な説明をしなければなりません。ただし、総会で扱うテーマに関係ない質問や、答えると株主みんなが損をするような質問、法務省令が決める場合は、断ってかまいません。

  3. なぜこのルールか

    株主は、総会で議案に賛成するか反対するかを決めます。そのための情報を得る機会を保障するのが説明義務です。逆に、議題と関係のない質問にまで全部答えさせると、総会が終わらず、ほかの株主の時間を奪ってしまうので、範囲を限っています。

  4. 用語

    株主総会の目的である事項：招集通知に書かれた報告事項と決議事項（議題）のこと。

  5. この事例では

    想定問答は、報告事項（事業報告・計算書類）と各決議事項ごとに作ります。事業報告に書いてある事項（業績、対処すべき課題、役員の報酬総額など）は目的事項に関係するので、原則として答える前提で準備してください。

  6. 落とし穴

    「必要な説明」は株主の判断に必要な程度と一般に解されていますが、具体的な線引きは事案ごとです。重要な議案（役員選任、組織再編など）では、説明不足が決議取消しの理由として争われやすいので、厚めに準備します。

注2説明を断れる場合（法務省令の4類型） 重要
  1. 条文
    会社法施行規則 71条1項 一・二・三・四号 （取締役等の説明義務）

    法第三百十四条に規定する法務省令で定める場合は、次に掲げる場合とする。

    • 一　株主が説明を求めた事項について説明をするために調査をすることが必要である場合（次に掲げる場合を除く。）
      イ　当該株主が株主総会の日より相当の期間前に当該事項を株式会社に対して通知した場合
      ロ　当該事項について説明をするために必要な調査が著しく容易である場合
    • 二　株主が説明を求めた事項について説明をすることにより株式会社その他の者（当該株主を除く。）の権利を侵害することとなる場合
    • 三　株主が当該株主総会において実質的に同一の事項について繰り返して説明を求める場合
    • 四　前三号に掲げる場合のほか、株主が説明を求めた事項について説明をしないことにつき正当な理由がある場合
  2. やさしく言うと

    説明を断れるのは、①調べないと答えられない場合（ただし、株主が前もって相当の期間前に知らせていた場合や、調べるのがとても簡単な場合は断れない）、②答えると会社や他人の権利を侵害する場合、③同じ株主が同じことを繰り返し聞く場合、④その他正当な理由がある場合です。

  3. なぜこのルールか

    その場で答えられない事項や、答えると第三者に迷惑がかかる事項まで説明を強いるのは無理があります。一方、前もって質問を知らされていた場合は準備できるので、「調査が必要」を理由には断れません。

  4. この事例では

    ブレーン席では、拒絶する理由がどの類型かを決めてから議長にメモを渡します。①の「調査が必要」を使うときは、事前質問状に書かれていなかったかを必ず確認してください（書かれていたら、この理由は使えません）。

  5. 実務のコツ

    断る場合でも「後日、会社のウェブサイトで」「個別にご説明します」と言う約束は慎重に。約束すれば守る必要があり、特定の株主だけに情報を出すと公平性の問題も生じます。

注1事前に質問を知らせていた場合、「調査が必要」では断れない 重要
  1. 条文
    会社法施行規則 71条1項 一号 （取締役等の説明義務）

    法第三百十四条に規定する法務省令で定める場合は、次に掲げる場合とする。

    • 一　株主が説明を求めた事項について説明をするために調査をすることが必要である場合（次に掲げる場合を除く。）
      イ　当該株主が株主総会の日より相当の期間前に当該事項を株式会社に対して通知した場合
      ロ　当該事項について説明をするために必要な調査が著しく容易である場合
  2. やさしく言うと

    「調べないと答えられないので説明しません」と断れるのが原則ですが、株主が総会の相当前にその質問を会社に知らせていた場合は、この理由では断れません。調べる時間があったからです。

    会社に準備の時間を与えた株主の質問まで「その場では分からない」で済ませると、事前に質問を知らせる意味がなくなります。事前通知を促し、充実した説明につなげる趣旨です。

  4. 用語

    相当の期間：法律に日数の定めはありません。その質問を調べるのに通常必要な時間があったかで判断されると考えられています。

  5. この事例では

    1週間前に届いた20項目は、多くが社内資料で答えられる事項なら「相当の期間前」の通知に当たる可能性が高いと考えて、回答を準備してください。大がかりな調査が必要な項目（過去10年分の個別取引の集計など）だけは、当日、調査が必要である旨を説明して断る余地があります。

注1財務制限条項の質問は説明義務の対象になるか 重要
  1. 条文
    会社法 314条 （取締役等の説明義務）

    取締役、会計参与、監査役及び執行役は、株主総会において、株主から特定の事項について説明を求められた場合には、当該事項について必要な説明をしなければならない。ただし、当該事項が株主総会の目的である事項に関しないものである場合、その説明をすることにより株主の共同の利益を著しく害する場合その他正当な理由がある場合として法務省令で定める場合は、この限りでない。

  2. やさしく言うと

    役員は、総会で株主から説明を求められたら、総会の目的である事項（報告事項・決議事項）に関係する限り、必要な説明をしなければなりません。

  3. なぜこのルールか

    株主が事業報告を理解し、配当などの議案に賛成するか反対するかを判断できるようにするためです。

  4. 用語

    財務制限条項（コベナンツ）：借入契約で、借り手が一定の財務指標（純資産、利益、借入れの倍率など）を維持することを約束する条項。守れないと、期限の利益の喪失や金利の引上げなどの事由になることが多い。

  5. この事例では

    財務制限条項は、資金繰りや配当の余地に影響するので、事業報告の報告や剰余金の配当の議案に関係する事項と考えられます。「議題に関係しない」として門前払いにするのは難しいでしょう。

    第1項　前条第一号に規定する「株式会社の現況に関する事項」とは、次に掲げる事項（当該株式会社の事業が二以上の部門に分かれている場合にあっては、部門別に区別することが困難である場合を除き、その部門別に区別された事項）とする。

    • 五　当該事業年度における次に掲げる事項についての状況（重要なものに限る。）

      ロ　設備投資

    公開会社の事業報告には、主要な借入先と借入額、重要な資金調達の状況、会社が対処すべき課題などを書かなければなりません。

  3. この事例では

    株主の質問は、事業報告に書かれた借入れや課題についての質問として受け止め、事業報告の記載を出発点に説明します。業績の悪化で借入条件に影響が出るおそれがあるなら、それが「対処すべき課題」として事業報告に書かれているかも確認しておきます。

注3守秘義務を理由に差し控えられる範囲 重要
  1. 条文
    会社法施行規則 71条1項 二・四号 （取締役等の説明義務）

    法第三百十四条に規定する法務省令で定める場合は、次に掲げる場合とする。

    • 二　株主が説明を求めた事項について説明をすることにより株式会社その他の者（当該株主を除く。）の権利を侵害することとなる場合
    • 四　前三号に掲げる場合のほか、株主が説明を求めた事項について説明をしないことにつき正当な理由がある場合
  2. やさしく言うと

    説明すると会社や他の人の権利を侵害することになる場合や、説明しないことに正当な理由がある場合は、説明を断ることができます。

  3. この事例では

    銀行との契約で守秘義務を負っている具体的な数値基準や契約条件は、説明すると銀行の契約上の権利を害するおそれがあるとして、差し控える余地があります。ただし、条項の存在や抵触の有無といった株主の判断に必要な部分まで一律に差し控えると、必要な説明をしていないと評価されるおそれがあります。差し控える部分を最小限にし、理由を述べてください。

  4. 推測を含む点

    契約上の守秘義務が施行規則71条2号の「権利を侵害することとなる場合」に当たるかを直接判断した判例は確認できていません。守秘義務条項の文言（法令に基づく開示を例外としているかなど）によって判断が変わる可能性があり、本文の線引きは推測を含みます。

  5. 落とし穴

    守秘義務を理由に断った事項を、後日、IR説明会などで別の形で開示すると、総会での拒絶の理由が疑われます。開示の方針を社内で統一してください。

    • 一　株主総会等の招集の手続又は決議の方法が法令若しくは定款に違反し、又は著しく不公正なとき。
  2. やさしく言うと

    説明義務に違反したまま採決すると、決議の方法の法令違反として、決議の取消しを求められるおそれがあります。

  3. この事例では

    剰余金の配当の議案の審議中に、配当の余地に関わる財務制限条項について必要な説明をしなかった場合、その配当決議が争われる材料になり得ます。答えられる範囲を答えた経過を議事録に残しておくことが備えになります。
