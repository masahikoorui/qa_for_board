Q001

取締役会を廃止する（または新たに置く）予定である。株主総会で決められる事項はどう変わるか。

基本取締役会設置会社取締役会非設置会社#
A
取締役会がない会社の株主総会は、会社に関する一切の事項を決議できる「万能の機関」です。取締役会がある会社の株主総会は、会社法に定められた事項と定款で定めた事項に限って決議できます。
取締役会設置会社では、日常の業務執行の決定は取締役会に任され、総会は役員の選任・解任、定款変更、合併などの基本的な事項に集中します。また、取締役会設置会社の総会は、招集通知に書いた議題（会議の目的である事項）以外は決議できません。
どちらの会社でも、会社法が「株主総会の決議によって」と定めている事項を、定款で取締役や取締役会に決めさせることはできません。

実務のポイント

  • 機関変更の前に、現在の定款・取締役会規程で「総会で決める」とされている事項（例：代表取締役の選定方法、重要な取引の承認）を一覧にし、変更後に誰が決めるかを整理する。
  • 取締役会を廃止すると、招集通知の書面要件・議題の制限（会社法309条5項）がなくなる一方、総会がどんな事項でも決議できるので、株主から業務執行に関する提案が出る可能性も考えておく。
  • 取締役会を置くと、総会は会社法と定款に定めた事項しか決議できなくなる。総会で決め続けたい事項があれば、定款に明記しておく（会社法295条2項）。
  • 法定の総会決議事項（役員の選任、定款変更など）は、どちらの機関設計でも取締役会などに委ねられない（会社法295条3項）。
  • 機関設計の変更は定款変更（特別決議）と登記を伴う。取締役会の廃止・設置は登記事項なので、効力発生日から2週間以内に変更登記をする。

進め方

  1. 現在の定款・社内規程から、総会の決議事項と取締役会の決議事項を一覧にする。
  2. 機関変更後の権限の分担（総会・取締役（会）・代表取締役）を表に整理し、定款・規程の改正案を作る。
  3. 定款変更議案（取締役会の設置又は廃止）を株主総会に付議する。
  4. 総会で特別決議により定款を変更する。
  5. 変更登記を申請し、社内規程（取締役会規程、決裁権限規程）を改正する。

注1取締役会のない会社の総会は何でも決められる 重要
  1. 条文
    会社法 295条1項 （株主総会の権限）

    第1項　株主総会は、この法律に規定する事項及び株式会社の組織、運営、管理その他株式会社に関する一切の事項について決議をすることができる。

  2. 条文
    会社法 295条2項 （株主総会の権限）

    第2項　前項の規定にかかわらず、取締役会設置会社においては、株主総会は、この法律に規定する事項及び定款で定めた事項に限り、決議をすることができる。

  3. やさしく言うと

    取締役会のない会社では、株主総会は会社のことなら何でも決められます。これに対し、取締役会のある会社では、株主総会が決められるのは「会社法に書いてあること」と「定款に書いたこと」だけです。

  4. なぜこのルールか

    取締役会のない会社は、株主と経営者がほぼ同じ小さな会社を想定しているので、株主が直接何でも決められる方が実態に合います。取締役会のある会社は、株主が多く経営を専門家に任せることを想定しているので、日々の経営判断は取締役会に任せ、株主総会は基本的な事項に集中させています。

  5. この事例では

    取締役会を廃止すると、株主総会は例えば「この取引をするかどうか」といった業務執行の事項も決議できるようになります。逆に取締役会を置くと、そうした事項を総会で決めるには定款に定めておく必要があります。機関変更の前に、権限の分担表を作ってください。

  6. 用語

    取締役会設置会社：取締役会を置く会社（定款で置いた会社と、公開会社など法律上置かなければならない会社）のこと。

注2総会の権限を他の機関に委ねることはできない 重要
  1. 条文
    会社法 295条3項 （株主総会の権限）

    第3項　この法律の規定により株主総会の決議を必要とする事項について、取締役、執行役、取締役会その他の株主総会以外の機関が決定することができることを内容とする定款の定めは、その効力を有しない。

  2. やさしく言うと

    会社法が「株主総会で決める」と定めている事項を、定款で「取締役会で決められる」などと定めても、その定めは無効です。

  3. なぜこのルールか

    役員の選任や定款変更などは、会社の持ち主である株主の利益に直結します。これを経営者側が自分たちだけで決められるようにすると、株主が会社をコントロールできなくなるからです。

  4. この事例では

    取締役会を置いても廃止しても、取締役の選任・解任、定款変更、合併などは必ず株主総会で決めます。中小企業でよく見られる「後任の取締役を取締役会で決めておいた」という処理は無効なので注意してください。

  5. 落とし穴

    会社法自身が取締役会での決定を認めている事項（例：一定の要件の下での剰余金の配当）は、法律の定めに従えば取締役会で決めることができます。これは定款で勝手に委ねるのとは別の話です。

注3取締役会設置会社の総会は、通知した議題しか決議できない
  1. 条文
    会社法 309条5項 （株主総会の決議）

    第5項　取締役会設置会社においては、株主総会は、第二百九十八条第一項第二号に掲げる事項以外の事項については、決議をすることができない。ただし、第三百十六条第一項若しくは第二項に規定する者の選任又は第三百九十八条第二項の会計監査人の出席を求めることについては、この限りでない。

  2. 条文
    会社法 299条2項 二号 （株主総会の招集の通知）

    第2項　次に掲げる場合には、前項の通知は、書面でしなければならない。

    • 二　株式会社が取締役会設置会社である場合
  3. やさしく言うと

    取締役会のある会社では、株主総会は、招集を決めるときに定めた「会議の目的である事項（議題）」以外は決議できません。また、招集通知は書面（株主の承諾があればメール等）で出さなければなりません。

  4. なぜこのルールか

    株主が多い会社では、株主は招集通知を見て出席するかどうかを決めます。通知にない事項をいきなり決議すると、欠席した株主が不意打ちを受けるからです。

  5. この事例では

    取締役会を置くと、総会当日に株主から出された新しい議題（例：社長の解任）は決議できなくなります。取締役会を廃止した場合は、この制限はなくなりますが、欠席した株主との紛争を避けるため、決議予定の事項は事前に知らせておくのが無難です。

注4代表取締役の決め方も変わる
  1. 条文
    会社法 349条3項 （株式会社の代表）

    第3項　株式会社（取締役会設置会社を除く。）は、定款、定款の定めに基づく取締役の互選又は株主総会の決議によって、取締役の中から代表取締役を定めることができる。

  2. 条文
    会社法 362条3項 （取締役会の権限等）

    第3項　取締役会は、取締役の中から代表取締役を選定しなければならない。

  3. やさしく言うと

    取締役会のない会社では、代表取締役は、定款、取締役どうしの互選、株主総会の決議のいずれかで決めます（決めなければ取締役全員が会社を代表します）。取締役会のある会社では、取締役会が代表取締役を選びます。

  4. この事例では

    取締役会を廃止するときは、代表取締役をどの方法で決めるかを定款変更とあわせて決め、登記の添付書類（総会議事録や互選書）を準備します。取締役会を置くときは、新しい取締役会で代表取締役を選定し直す必要があるかを、司法書士と確認してください。

Q002

定時株主総会と臨時株主総会は何が違うか。定時総会で決める予定だった議案を、後日の臨時総会で決議してもよいか。

基本取締役会設置会社取締役会非設置会社#
A
定時株主総会は毎事業年度の終了後一定の時期に必ず開く総会で、臨時株主総会は必要があるときにいつでも開ける総会です。決議の要件や効力には違いがありません。
取締役の選任や定款変更のような議案は、臨時総会でも決議できます。ただし、計算書類の承認（会計監査人設置会社で一定の要件を満たす場合は報告）と事業報告の報告は、定時総会で行うものとされています。
また、役員の任期は「定時株主総会の終結の時」を基準に終わるので、臨時総会で選任しても任期の終わり方は変わりません。

実務のポイント

  • 定時総会でしかできない事項（計算書類の承認・報告、事業報告の報告）を確認する（会社法438条、439条）。
  • 臨時総会を開くには、議決権を行使する株主を確定するため、別に基準日を定めて公告するか、総会当日の株主名簿によるかを決める（定款の基準日は通常、定時総会用）。
  • 役員の任期は選任の時期にかかわらず、「選任後○年以内に終了する事業年度のうち最終のものに関する定時株主総会の終結の時」に満了する。臨時総会で選んだ役員も同じ。
  • 定時総会と同じ日に、続けて臨時総会を開くこともできるが、議決権を持つ株主の範囲が違う場合（基準日が異なる場合）は、別々の総会として受付・議事録を分ける。
  • 臨時総会を開く典型例：役員の欠員補充、定款変更、組織再編、第三者割当（有利発行）、株式併合。

注1定時総会と臨時総会の区別 重要
  1. 条文
    会社法 296条 （株主総会の招集）

    第1項　定時株主総会は、毎事業年度の終了後一定の時期に招集しなければならない。

    第2項　株主総会は、必要がある場合には、いつでも、招集することができる。

    第3項　株主総会は、次条第四項の規定により招集する場合を除き、取締役が招集する。

  2. やさしく言うと

    定時総会は、毎年決まった時期に必ず開く総会です。臨時総会は、それ以外で必要になったときに開く総会です。名前は違っても、招集の手続や決議のルールは同じです。

  3. なぜこのルールか

    会社は毎年、1年間の成績（計算書類）を株主に示し、承認を受ける必要があります。その場として毎年の定時総会が義務づけられています。一方、急な役員の補充や組織再編は、次の定時総会まで待てないことがあるので、いつでも臨時総会を開けるようにしています。

  4. この事例では

    定時総会で予定していた取締役選任や定款変更の議案を、準備の都合で臨時総会に回すことは可能です。ただし、計算書類と事業報告は定時総会で扱う事項なので、これを臨時総会に回すことはできません。

  5. 落とし穴

    定款の「毎年6月に定時総会を開く」といった定めに反して定時総会を開かないと、定款違反・法令違反となり、取締役の過料の対象にもなり得ます（会社法976条18号）。

注2計算書類の承認と事業報告は定時総会で
  1. 条文
    会社法 438条2項 （計算書類等の定時株主総会への提出等）

    第2項　前項の規定により提出され、又は提供された計算書類は、定時株主総会の承認を受けなければならない。

  2. 条文
    会社法 438条3項 （計算書類等の定時株主総会への提出等）

    第3項　取締役は、第一項の規定により提出され、又は提供された事業報告の内容を定時株主総会に報告しなければならない。

  3. やさしく言うと

    計算書類（貸借対照表・損益計算書など）は定時総会の承認を受け、事業報告は定時総会で報告します。会計監査人を置く会社で一定の要件を満たすときは、計算書類も「承認」ではなく「報告」で足ります（会社法439条）。

  4. この事例では

    定時総会で計算書類の承認を受けられなかった場合（否決・決議漏れなど）の扱いは、別の問題になります（計算書類の承認の節を参照）。日程を組むときは、計算書類の承認・報告を必ず定時総会の議題に入れてください。

注3臨時総会で選任しても任期の終わり方は同じ
  1. 条文
    会社法 332条1項 （取締役の任期）

    第1項　取締役の任期は、選任後二年以内に終了する事業年度のうち最終のものに関する定時株主総会の終結の時までとする。ただし、定款又は株主総会の決議によって、その任期を短縮することを妨げない。

  2. やさしく言うと

    取締役の任期は「選ばれてから2年以内に終わる最後の事業年度について開く定時総会が終わる時まで」です。期間を日数で数えるのではなく、定時総会を基準に終わります。

  3. この事例では

    例えば3月決算の会社で、令和7年9月の臨時総会で選任された取締役は、2年以内に終わる最後の事業年度（令和9年3月期）の定時総会（令和9年6月）の終結の時に任期満了となります。臨時総会で選任するときは、任期満了の時期を候補者に説明し、管理台帳に記録しておきましょう。

  4. 実務のコツ

    補欠や増員で選任した取締役の任期を他の取締役とそろえたいときは、定款に「補欠又は増員により選任された取締役の任期は、他の在任取締役の任期の満了する時までとする」といった定めを置くのが一般的です（任期の短縮は定款で可能です）。

注4臨時総会では議決権を行使できる株主の確定が必要
  1. 条文
    会社法 124条3項 （基準日）

    第3項　株式会社は、基準日を定めたときは、当該基準日の二週間前までに、当該基準日及び前項の規定により定めた事項を公告しなければならない。ただし、定款に当該基準日及び当該事項について定めがあるときは、この限りでない。

  2. やさしく言うと

    総会で議決権を使える株主を決めるため「基準日」を定めるときは、定款に定めがある場合を除き、基準日の2週間前までに公告します。

  3. この事例では

    定款の基準日（例：毎年3月31日）は定時総会のためのものなので、臨時総会では、取締役会で新たに基準日を定めて公告するのが一般的です。株主が少なく株式の移動もない非公開会社では、基準日を定めず、総会当日の株主名簿上の株主に議決権を行使させる方法もあります。

  4. 落とし穴

    基準日の公告を忘れると、予定の日程で総会を開けなくなります。臨時総会の日程は、公告の手配（官報・電子公告）から逆算して決めてください。

実務取締役会設置会社#
A
応じる必要はなく、応じてはいけません。取締役会設置会社の株主総会は、招集通知に記載した議題以外の事項を決議できないからです（会社法309条5項）。
議長は、その求めが法律上決議できない事項であることを説明し、議題として取り上げない旨を宣言して議事を進めます。仮に採決してしまうと、その決議は招集手続・決議方法の法令違反として取消しの対象になります。
例外として、総会に提出された資料を調査する者の選任、総会の延期・続行、会計監査人の出席を求めることは、通知になくても決議できます。株主が議題を追加したいときは、株主提案権（会社法303条）や招集請求（会社法297条）の手続によることになります。

実務のポイント

  • 「議題の追加」と「議案の修正」を区別する。通知した議題の範囲内で議案の内容を変える修正動議は、一定の範囲で当日も出せる（修正動議は当日の運営の節を参照）。
  • 議長は、株主の発言を頭ごなしに封じず、①法律上この総会で決議できないこと、②株主提案権・招集請求という手続があることを簡潔に説明する。
  • 通知にない議題でも決議できる例外（会社法309条5項ただし書・317条）を、議長と事務局が事前に確認しておく。
  • 解任の要求の背景に不祥事などがある場合は、説明義務の範囲で質問として受け止め、必要な説明をする。
  • 議事録には、株主の求めと議長の対応の要旨を簡潔に記録しておく。

進め方

  1. 株主から議題追加の求めがあったら、議長は発言の趣旨を確認する（議題の追加か、議案の修正か、質問か）。
  2. 議題の追加であれば、議長は事務局・顧問弁護士と短く確認し、法律上決議できない旨を説明する。
  3. 議題として取り上げない旨を宣言し、当初の議事に戻る。
  4. 株主が引き続き求める場合は、株主提案権・招集請求の手続があることを説明する（詳細は後日、事務局で対応すると伝える）。
  5. 総会終了後、議事録に経過を記載し、株主から正式な提案・請求があれば期限・要件を確認して対応する。

注1通知した議題以外は決議できない 重要
  1. 条文
    会社法 309条5項 （株主総会の決議）

    第5項　取締役会設置会社においては、株主総会は、第二百九十八条第一項第二号に掲げる事項以外の事項については、決議をすることができない。ただし、第三百十六条第一項若しくは第二項に規定する者の選任又は第三百九十八条第二項の会計監査人の出席を求めることについては、この限りでない。

  2. 条文
    会社法 298条1項 二号 （株主総会の招集の決定）

    第1項　取締役（前条第四項の規定により株主が株主総会を招集する場合にあっては、当該株主。次項本文及び次条から第三百二条までにおいて同じ。）は、株主総会を招集する場合には、次に掲げる事項を定めなければならない。

    • 二　株主総会の目的である事項があるときは、当該事項
  3. やさしく言うと

    取締役会のある会社の総会では、招集のときに決めて通知した「会議の目的である事項（議題）」しか決議できません。例外は、総会に出された資料を調べる人の選任と、会計監査人に出席を求めることだけです。

  4. なぜこのルールか

    株主は招集通知を見て、出席するか、委任状や議決権行使書面で済ませるかを決めます。当日に新しい議題を決議すると、欠席した株主は意見を言う機会もなく、不意打ちになるからです。

  5. この事例では

    「社長の解任」は招集通知に書かれていない新しい議題なので、この総会では決議できません。議長は採決せず、取り上げない旨を宣言します。

  6. 用語

    議題と議案：議題は「何について決めるか」（例：取締役3名選任の件）、議案は「どう決めるか」の具体的な案（例：Aさん、Bさん、Cさんを選任する）。

注2総会の延期・続行は通知になくても決議できる
  1. 条文
    会社法 317条 （延期又は続行の決議）

    株主総会においてその延期又は続行について決議があった場合には、第二百九十八条及び第二百九十九条の規定は、適用しない。

  2. やさしく言うと

    総会で「延期する」「続きは後日行う（続行）」と決議した場合、改めて招集の決定や招集通知をしなくても、後日の会（延会・継続会）を開けます。この延期・続行の決議は、議事の進め方に関する決議なので、通知にない議題に当たらないと考えられています。

  3. この事例では

    解任を求める株主が「総会を延期せよ」と動議を出した場合は、手続的な動議として扱い、議長の判断で採決するか否かを決めます（動議への対応は当日の運営の節を参照）。

手続は、取締役会で定款変更議案を付議することを決定し、株主総会の特別決議で定款を変更します。総会で代表取締役を選定したときは、その総会議事録を添付して代表取締役の変更登記を申請します。

実務のポイント

  • 定款の文言は「取締役会の決議によるほか、株主総会の決議によっても」とし、取締役会の選定権限を残す形にする（取締役会の権限を奪う形にすると、有効性に疑問が生じ得る）。
  • 総会と取締役会で異なる者を代表取締役に選んだ場合など、権限が衝突したときの扱いを、社内で整理しておく。
  • 解職（代表取締役から外すこと）も総会でできるようにするのか、文言で明確にしておく。
  • 定款変更は特別決議（議決権の過半数の出席、出席議決権の3分の2以上の賛成）が必要。
  • 総会で代表取締役を選定した場合、登記の添付書類は株主総会議事録（と株主リスト）になる。

進め方

  1. オーナー株主・取締役と、目的（例：事業承継の過程で株主が代表者を決められるようにしたい）と定款の文言を協議する。
  2. 司法書士・弁護士に定款案と登記の扱いを確認する。
  3. 取締役会で、株主総会の招集と定款変更議案の付議を決議する。
  4. 招集通知（非公開会社は原則1週間前まで）に定款変更議案の概要を記載して発送する。
  5. 株主総会で特別決議により定款を変更する。
  6. 以後、総会で代表取締役を選定・解職したときは、総会議事録を作成し、2週間以内に登記を申請する。

注1定款で定めれば総会の権限を広げられる 重要
  1. 条文
    会社法 295条2項 （株主総会の権限）

    第2項　前項の規定にかかわらず、取締役会設置会社においては、株主総会は、この法律に規定する事項及び定款で定めた事項に限り、決議をすることができる。

  2. やさしく言うと

    取締役会のある会社の総会は、会社法に書いてある事項に加え、定款に書いた事項も決議できます。つまり、定款を変えれば、総会で決められる事項を増やせます。

  3. なぜこのルールか

    総会の権限を限っているのは経営の専門家である取締役会に任せる趣旨ですが、株主自身が「この事項は自分たちで決めたい」と定款で決めるなら、それを認めても株主の利益を害しないからです。

  4. この事例では

    代表取締役の選定を総会でもできるようにするには、定款に明記します。定款を変更するまでは、総会で代表取締役を選んでも、その決議には効力がありません。

    会社法 362条2項 三号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 三　代表取締役の選定及び解職

    会社法 362条3項 （取締役会の権限等）

    第3項　取締役会は、取締役の中から代表取締役を選定しなければならない。

  3. やさしく言うと

    取締役会のある会社では、代表取締役を選ぶことと外すことは取締役会の仕事とされ、取締役会は必ず代表取締役を選ばなければなりません。

  4. なぜこのルールか

    代表取締役を取締役会が選び・外せることは、取締役会が代表取締役を監督するための重要な手段です。最高裁判所の判断も、取締役会の権限を残したまま総会でも選定できるとする定款を、この監督の仕組みを損なわないものとして有効としたものと理解されています。

    定款の文言は「取締役会の決議によるほか、株主総会の決議によっても」とし、取締役会の権限を奪わない形にします。取締役会の権限を完全に奪い、総会だけが選べるとする定めの有効性は、この最高裁判所の判断の射程外であり、慎重に考えるべきです。

    総会と取締役会がそれぞれ別の人を選ぶと混乱します。どちらかが選定したら他方で追加選定するかどうかなど、運用ルールを決めておきましょう。

Q001 取締役会を廃止する（または新たに置く）予定である。株主総会で決められる事項はどう変わるか。
Q005

取締役が辞任したため、取締役会の決議で後任の取締役を選任してしまった。登記の準備中に、取締役の選任は株主総会の決議事項だと指摘された。どう処理すればよいか。

実務取締役会決議あり取締役会設置会社非公開会社#
A
取締役会で行った後任取締役の選任は無効です。取締役の選任は株主総会の決議事項で（会社法329条1項）、これを取締役会に委ねることはできないからです（会社法295条3項）。
すぐに株主総会を開いて改めて取締役を選任し、その総会議事録を添付して登記を申請します。員数を欠いている間は、辞任した取締役が新しい取締役の就任まで取締役としての権利義務を持ち続けるので（会社法346条1項）、その人を含めて取締役会を運営します。
あわせて、無効な選任を受けた人が加わって行った取締役会の決議に問題がないかを点検し、必要なら有効な構成の取締役会で決議し直します。

実務のポイント

  • まず、辞任によって法律・定款の員数を欠いたかを確認する（取締役会設置会社は3人以上。会社法331条5項）。員数を欠いていれば辞任者が権利義務取締役として残る。
  • 取締役会で「選任」された人は取締役ではない。その人が議決に加わった取締役会決議は、その人を除いても定足数・過半数を満たすかを確認する。
  • 株主が少ない非公開会社なら、株主全員の同意による招集手続の省略や、書面決議（みなし決議）で早く選任できる（別の節を参照）。
  • 辞任による退任と新任の就任の登記は、原則としてそれぞれ2週間以内。辞任者が権利義務取締役として残る場合、辞任の登記は後任の就任まで受理されない扱いになるので、まとめて申請する。
  • 再発防止として、総会決議事項の一覧を取締役会規程の付録にし、議題の事前チェックをする。

進め方

  1. 辞任の日、員数、取締役会で行った決議の内容と、その後に開いた取締役会の議事を整理する。
  2. 司法書士・弁護士に、登記と無効な選任の影響を相談する。
  3. 取締役会（辞任した権利義務取締役を含む適法な構成）で、臨時株主総会の招集を決議する。前の誤った選任決議は効力がないことを確認する。
  4. 臨時株主総会で後任の取締役を選任する（就任承諾を得る）。
  5. 総会議事録・就任承諾書・株主リストなどを添付して、辞任と就任の変更登記を申請する。
  6. 無効な選任を受けた人が加わった取締役会の決議を点検し、必要なものは再決議する。

注1取締役の選任は株主総会の権限 重要
  1. 条文
    会社法 329条1項 （選任）

    第1項　役員（取締役、会計参与及び監査役をいう。以下この節、第三百七十一条第四項及び第三百九十四条第三項において同じ。）及び会計監査人は、株主総会の決議によって選任する。

  2. 条文
    会社法 295条3項 （株主総会の権限）

    第3項　この法律の規定により株主総会の決議を必要とする事項について、取締役、執行役、取締役会その他の株主総会以外の機関が決定することができることを内容とする定款の定めは、その効力を有しない。

  3. やさしく言うと

    取締役・監査役などの役員は、株主総会で選びます。定款で「取締役会で選べる」と定めても無効なので、取締役会での選任は当然に無効です。

  4. なぜこのルールか

    取締役を選ぶことは、株主が会社の経営者を決め、経営をコントロールするための最も基本的な権利だからです。取締役が自分たちの仲間を選べるようにすると、株主のチェックが働かなくなります。

  5. この事例では

    取締役会での選任決議は効力がないので、改めて株主総会で選任します。選任の効力は総会の決議と本人の就任承諾によって生じるので、登記の就任日は総会の日（承諾がそれより後ならその日）になります。

注2辞任した取締役が残る「権利義務取締役」 重要
  1. 条文
    会社法 346条1項 （役員等に欠員を生じた場合の措置）

    第1項　役員（監査等委員会設置会社にあっては、監査等委員である取締役若しくはそれ以外の取締役又は会計参与。以下この条において同じ。）が欠けた場合又はこの法律若しくは定款で定めた役員の員数が欠けた場合には、任期の満了又は辞任により退任した役員は、新たに選任された役員（次項の一時役員の職務を行うべき者を含む。）が就任するまで、なお役員としての権利義務を有する。

  2. やさしく言うと

    取締役の辞任や任期満了によって、法律や定款で決めた人数を下回ったときは、辞めた人も、後任が就任するまでは取締役としての権利と義務を持ち続けます。

  3. なぜこのルールか

    人数が足りないと取締役会が開けず、会社の運営が止まってしまうので、後任が来るまでのつなぎとして辞めた人に残ってもらう仕組みです。

  4. この事例では

    辞任した取締役は、後任が総会で選任されるまで取締役会に出席し、議決に加われます。総会招集を決める取締役会にも、その人に招集通知を出してください。無効な選任を受けた人ではなく、この人が正しい構成員です。

  5. 落とし穴

    辞任者が権利義務取締役として残っている間は、辞任による退任の登記は受理されないのが登記実務の扱いです。後任の就任登記と同時に申請します。

  6. 用語

    一時役員（仮取締役）：辞任者が死亡した場合など、権利義務取締役に頼れないときに、利害関係人の申立てで裁判所が選ぶ一時的な取締役（会社法346条2項）。

注3登記の期限と添付書類
  1. 条文
    会社法 915条1項 （変更の登記）

    第1項　会社において第九百十一条第三項各号又は前三条各号に掲げる事項に変更が生じたときは、二週間以内に、その本店の所在地において、変更の登記をしなければならない。

  2. 条文
    商業登記法 46条2項 （添付書面の通則）

    第2項　登記すべき事項につき株主総会若しくは種類株主総会、取締役会又は清算人会の決議を要するときは、申請書にその議事録を添付しなければならない。

  3. やさしく言うと

    取締役が変わったら2週間以内に変更の登記をします。総会の決議が必要な事項の登記には、その総会の議事録を添付します。

  4. この事例では

    取締役会議事録で取締役の就任登記を申請しても受理されません。今回の誤りは登記の段階で気づくことが多いので、気づいた時点で総会を開き、総会議事録（と株主リスト）を添付して申請し直します。

  5. 落とし穴

    登記を怠ると、代表取締役等は100万円以下の過料に処されることがあります（会社法976条1号）。手続のやり直しで期限を過ぎそうな場合も、できるだけ速やかに申請してください。

注4無効な選任を受けた人が加わった取締役会の決議
  1. 条文
    会社法 369条1項 （取締役会の決議）

    第1項　取締役会の決議は、議決に加わることができる取締役の過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）が出席し、その過半数（これを上回る割合を定款で定めた場合にあっては、その割合以上）をもって行う。

  2. やさしく言うと

    取締役会の決議は、取締役の過半数が出席し、出席者の過半数が賛成すれば成立します。取締役でない人が加わっても、その人を除いて数えて要件を満たしていれば、決議の成立には影響しないと考えられます。

  3. この事例では

    無効な選任を受けた人が出席した取締役会ごとに、その人を除いた出席者数・賛成者数で要件を満たすかを点検します。満たさない決議や、その人の意見が結論に大きく影響した決議は、正しい構成の取締役会で改めて決議します。

  4. 実務のコツ

    点検の結果は、表にして上程書に添付し、取締役会議事録にも報告として残すと、後日の説明に役立ちます。

Q006

非公開の中小会社で、ここ数年、定時株主総会を開いていなかったことが分かった。役員の任期も過ぎている。どう立て直せばよいか。

応用取締役会決議あり取締役会設置会社非公開会社#
A
速やかに株主総会を開いて、役員を選任し、計算書類を承認（事業報告を報告）し、役員変更の登記をするのが基本です。
定時総会を開かないことは会社法296条1項違反で、取締役は過料の対象になり得ます。役員の任期は、本来定時総会を開くべきだった時期の経過によって満了したと扱われるのが一般的で、員数を欠く場合は退任した役員が権利義務を持ち続けます（会社法346条1項）。
長期間登記をしていないと、登記の懈怠による過料のほか、最後の登記から12年を経過すると休眠会社として解散したものとみなされるおそれがあります（会社法472条）。

実務のポイント

  • 役員の任期が満了した時期（どの年の定時総会の時期か）を、定款の任期・選任日から正確に計算する。登記上の退任日にかかわるので司法書士と確認する。
  • 未承認の事業年度の計算書類をどう扱うかは、専門家と相談のうえ決める（直近の事業年度だけでなく、過去分の承認もあわせて行う例が多い）。
  • 任期満了で退任した取締役は、員数を欠く限り権利義務取締役として取締役会を構成できるので、その取締役会で総会の招集を決議する。
  • 最後の登記から12年が近い（または過ぎた）場合は、法務大臣の公告・登記所の通知に注意し、届出や登記で解散を回避する。
  • 再発防止として、毎年の総会日程・任期満了表を作り、顧問税理士・司法書士と共有する。

進め方

  1. 定款、登記事項証明書、過去の議事録、決算書を集め、最後に開いた総会と役員の任期を確認する。
  2. 任期満了日・権利義務の状態・登記の要否を司法書士と整理する。
  3. 取締役会（権利義務取締役を含む）で、株主総会の招集を決議する。
  4. 株主総会で、計算書類の承認（事業報告の報告）と役員の選任を行う。
  5. 役員変更登記（任期満了による退任と就任・重任）を申請する。
  6. 翌年以降の総会・任期・登記の管理表を作り、毎年の運用に組み込む。

注1定時総会は毎年必ず開く 重要
  1. 条文
    会社法 296条1項 （株主総会の招集）

    第1項　定時株主総会は、毎事業年度の終了後一定の時期に招集しなければならない。

  2. 条文
    会社法 976条1項 十八号 （過料に処すべき行為）

    発起人、設立時取締役、設立時監査役、設立時執行役、取締役、会計参与若しくはその職務を行うべき社員、監査役、執行役、会計監査人若しくはその職務を行うべき社員、清算人、清算人代理、持分会社の業務を執行する社員、民事保全法第五十六条に規定する仮処分命令により選任された取締役、監査役、執行役、清算人若しくは持分会社の業務を執行する社員の職務を代行する者、第九百六十条第一項第五号に規定する一時取締役、会計参与、監査役、代表取締役、委員、執行役若しくは代表執行役の職務を行うべき者、同条第二項第三号に規定する一時清算人若しくは代表清算人の職務を行うべき者、第九百六十七条第一項第三号に規定する一時会計監査人の職務を行うべき者、検査役、監督委員、調査委員、株主名簿管理人、社債原簿管理人、社債管理者、事務を承継する社債管理者、社債管理補助者、事務を承継する社債管理補助者、代表社債権者、決議執行者、外国会社の日本における代表者又は支配人は、次のいずれかに該当する場合には、百万円以下の過料に処する。ただし、その行為について刑を科すべきときは、この限りでない。

    • 十八　第二百九十六条第一項の規定又は第三百七条第一項第一号（第三百二十五条において準用する場合を含む。）若しくは第三百五十九条第一項第一号の規定による裁判所の命令に違反して、株主総会を招集しなかったとき。
  3. やさしく言うと

    定時株主総会は毎年、決算期の後の決まった時期に開かなければなりません。開かないと、取締役などは100万円以下の過料に処されることがあります。

  4. なぜこのルールか

    定時総会は、株主が1年間の成績を確認し、役員を選び直す場です。開かないと、株主のチェックが働かないまま経営が続いてしまいます。

  5. この事例では

    家族経営の会社などで総会が形だけになり、議事録も作っていないケースがあります。気づいた時点で、取締役会で総会の招集を決め、正規の手続で開催してください。過去に実際には開いていない総会の議事録を後から作ることは、事実と異なる書類の作成になるので、してはいけません。

注2任期が過ぎた役員はどうなっているか 重要
  1. 条文
    会社法 332条2項 （取締役の任期）

    第2項　前項の規定は、公開会社でない株式会社（監査等委員会設置会社及び指名委員会等設置会社を除く。）において、定款によって、同項の任期を選任後十年以内に終了する事業年度のうち最終のものに関する定時株主総会の終結の時まで伸長することを妨げない。

  2. 条文
    会社法 346条1項 （役員等に欠員を生じた場合の措置）

    第1項　役員（監査等委員会設置会社にあっては、監査等委員である取締役若しくはそれ以外の取締役又は会計参与。以下この条において同じ。）が欠けた場合又はこの法律若しくは定款で定めた役員の員数が欠けた場合には、任期の満了又は辞任により退任した役員は、新たに選任された役員（次項の一時役員の職務を行うべき者を含む。）が就任するまで、なお役員としての権利義務を有する。

  3. やさしく言うと

    非公開会社では、定款で取締役・監査役の任期を最長10年まで延ばせます。任期は「定時総会の終結の時」に満了しますが、定時総会が開かれないまま、本来開くべき時期が過ぎた場合は、その時期が過ぎた時に任期が満了すると一般に解されています。人数を欠く場合は、退任した役員が後任の就任まで権利義務を持ち続けます。

  4. この事例では

    まず定款で任期（2年か、10年まで延ばしているか）を確認し、それぞれの役員について任期が満了した時期を特定します。員数を欠いていれば、現在の役員は権利義務役員として取締役会を開き、総会を招集できます。

  5. 落とし穴

    任期満了の時期によっては、登記上の退任日が何年も前になり、その間の登記懈怠が明らかになります。過料の可能性も含め、司法書士とよく相談してください。

注3登記を放置すると「みなし解散」のおそれ
  1. 条文
    会社法 472条1項 （休眠会社のみなし解散）

    第1項　休眠会社（株式会社であって、当該株式会社に関する登記が最後にあった日から十二年を経過したものをいう。以下この条において同じ。）は、法務大臣が休眠会社に対し二箇月以内に法務省令で定めるところによりその本店の所在地を管轄する登記所に事業を廃止していない旨の届出をすべき旨を官報に公告した場合において、その届出をしないときは、その二箇月の期間の満了の時に、解散したものとみなす。ただし、当該期間内に当該休眠会社に関する登記がされたときは、この限りでない。

  2. やさしく言うと

    最後の登記から12年たった株式会社は「休眠会社」とされ、法務大臣の官報公告から2か月以内に「事業を廃止していない」旨の届出（または登記）をしないと、解散したものとみなされます。

  3. なぜこのルールか

    実際には活動していない会社の登記が残り続けると、登記の信頼性が下がり、悪用のおそれもあるからです。

  4. この事例では

    役員の任期は最長でも10年なので、きちんと改選の登記をしていれば12年登記がないことは通常起きません。総会を開いていない会社は登記も止まっていることが多いので、最後の登記の日を確認し、登記所からの通知が届いていないかも確認してください。

  5. 実務のコツ

    みなし解散の登記がされてしまっても、一定期間内であれば株主総会の特別決議で会社を継続できる制度がありますが、手続が増えます。早めの是正が何より大切です。

注4計算書類の承認と事業報告
  1. 条文
    会社法 438条2項 （計算書類等の定時株主総会への提出等）

    第2項　前項の規定により提出され、又は提供された計算書類は、定時株主総会の承認を受けなければならない。

  2. やさしく言うと

    計算書類は定時総会の承認を受けるのが原則です。総会を開いていなかった期間は、この承認が欠けていることになります。

  3. この事例では

    是正の総会では、少なくとも直近の事業年度の計算書類を承認し、事業報告を報告します。過去の未承認期をあわせて承認するかどうかは、剰余金の配当や税務申告との関係があるため、税理士・弁護士と相談して決めてください。

  4. 落とし穴

    総会を開いていなくても、税務申告は決算書に基づいて行っていることが多いです。総会で承認した計算書類と、申告に使った決算書が一致しているかを確認しましょう。

監査役1名の会社で、その監査役が期中に辞任した。臨時株主総会を開いて後任を選ぶべきか、次の定時総会まで待ってよいか。

実務取締役会決議あり取締役会設置会社監査役設置会社#
A
法律上は、員数を欠いたときは遅滞なく後任を選任する手続をとる必要があります。選任の手続を怠ると、取締役は過料の対象になり得ます（会社法976条22号）。
辞任した監査役は、後任が就任するまで監査役としての権利義務を持ち続けるので（会社法346条1項）、監査の空白は直ちには生じません。しかし、これは「待ってよい」という意味ではないため、次の定時総会がすぐの場合を除き、臨時総会（株主が少なければ書面決議など）で選任するのが基本です。
補欠監査役をあらかじめ選任していれば、その人が就任するだけで足ります（会社法329条3項）。

実務のポイント

  • 辞任か死亡かで扱いが違う。死亡などで権利義務者がいないときは、利害関係人の申立てによる一時監査役（仮監査役）の選任も検討する（会社法346条2項）。
  • 「次の定時総会まで待つ」のは、定時総会が近く、臨時総会を開くより合理的な場合に限るのが実務の目安。その場合も、待つ理由を取締役会で確認し議事録に残す。
  • 監査役選任議案の提出には、監査役（権利義務監査役を含む）の同意が必要（会社法343条1項）。
  • 後任監査役の任期は原則4年。定款に補欠の任期の定め（前任者の残任期間）があれば、それによる（会社法336条3項）。
  • 補欠監査役の予選の有効期間（通常は次の定時総会の開始の時まで）を確認する。

進め方

  1. 辞任届を受領し、辞任日、員数、権利義務の状態、補欠監査役の有無を確認する。
  2. 後任候補者を選び、就任の内諾を得る。
  3. 辞任した監査役（権利義務監査役）から、選任議案提出の同意を書面で得る。
  4. 取締役会で臨時株主総会の招集（又は書面決議の提案）を決議する。
  5. 株主総会で後任監査役を選任し、就任承諾書を受領する。
  6. 辞任と就任の変更登記を申請する（就任日から2週間以内）。

注1辞任しても後任が来るまでは監査役 重要
  1. 条文
    会社法 346条1項 （役員等に欠員を生じた場合の措置）

    第1項　役員（監査等委員会設置会社にあっては、監査等委員である取締役若しくはそれ以外の取締役又は会計参与。以下この条において同じ。）が欠けた場合又はこの法律若しくは定款で定めた役員の員数が欠けた場合には、任期の満了又は辞任により退任した役員は、新たに選任された役員（次項の一時役員の職務を行うべき者を含む。）が就任するまで、なお役員としての権利義務を有する。

  2. 条文
    会社法 346条2項 （役員等に欠員を生じた場合の措置）

    第2項　前項に規定する場合において、裁判所は、必要があると認めるときは、利害関係人の申立てにより、一時役員の職務を行うべき者を選任することができる。

  3. やさしく言うと

    辞任で監査役がいなくなる場合、辞任した人が後任の就任まで監査役の権利義務を持ち続けます。辞任者が亡くなった場合などで頼れないときは、裁判所に一時的な監査役を選んでもらうこともできます。

  4. この事例では

    今回は辞任なので、辞任した監査役が引き続き取締役会に出席し、監査を行います。ただし本人は辞めたいと考えているので、早く後任を選ぶ必要があります。

注2選任の手続を怠ると過料 重要
  1. 条文
    会社法 976条1項 二十二号 （過料に処すべき行為）

    発起人、設立時取締役、設立時監査役、設立時執行役、取締役、会計参与若しくはその職務を行うべき社員、監査役、執行役、会計監査人若しくはその職務を行うべき社員、清算人、清算人代理、持分会社の業務を執行する社員、民事保全法第五十六条に規定する仮処分命令により選任された取締役、監査役、執行役、清算人若しくは持分会社の業務を執行する社員の職務を代行する者、第九百六十条第一項第五号に規定する一時取締役、会計参与、監査役、代表取締役、委員、執行役若しくは代表執行役の職務を行うべき者、同条第二項第三号に規定する一時清算人若しくは代表清算人の職務を行うべき者、第九百六十七条第一項第三号に規定する一時会計監査人の職務を行うべき者、検査役、監督委員、調査委員、株主名簿管理人、社債原簿管理人、社債管理者、事務を承継する社債管理者、社債管理補助者、事務を承継する社債管理補助者、代表社債権者、決議執行者、外国会社の日本における代表者又は支配人は、次のいずれかに該当する場合には、百万円以下の過料に処する。ただし、その行為について刑を科すべきときは、この限りでない。

    • 二十二　取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役）、会計参与、監査役、執行役又は会計監査人がこの法律又は定款で定めたその員数を欠くこととなった場合において、その選任（一時会計監査人の職務を行うべき者の選任を含む。）の手続をすることを怠ったとき。
  2. やさしく言うと

    役員の人数が足りなくなったのに、後任を選ぶ手続をしないと、取締役などは100万円以下の過料に処されることがあります。

  3. なぜこのルールか

    権利義務役員の制度はあくまでつなぎです。会社が後任選びを放置すると、辞めたい人を縛り続け、監査の質も下がるからです。

  4. この事例では

    「次の定時総会まで待つ」かどうかは、定時総会までの期間、臨時総会の費用と手間、株主の数などを考えて判断します。定時総会の招集が目前（例えば1～2か月以内）であれば待つ判断もあり得ますが、半年以上先なら臨時総会を開くのが基本です。いずれの場合も、検討の経過を取締役会議事録に残してください。

  5. 実務のコツ

    株主が少ない会社では、株主全員の同意による書面決議（会社法319条）で選任すれば、総会を開かずに済みます（書面決議の節を参照）。

注3監査役選任議案には監査役の同意が必要
  1. 条文
    会社法 343条1項 （監査役の選任に関する監査役の同意等）

    第1項　取締役は、監査役がある場合において、監査役の選任に関する議案を株主総会に提出するには、監査役（監査役が二人以上ある場合にあっては、その過半数）の同意を得なければならない。

  2. やさしく言うと

    取締役が監査役を選ぶ議案を総会に出すときは、監査役の同意を得なければなりません。

  3. なぜこのルールか

    監査役は取締役を監査する立場なので、取締役が自分たちに都合のよい監査役を選ばないよう、現在の監査役にチェックさせる仕組みです。

  4. この事例では

    権利義務を有する辞任監査役から同意を得ます。同意は口頭でも法律上は足りるとされますが、後日の証明のため同意書をもらっておきましょう。

注4補欠監査役を選んでおくと欠員に強い
  1. 条文
    会社法 329条3項 （選任）

    第3項　第一項の決議をする場合には、法務省令で定めるところにより、役員（監査等委員会設置会社にあっては、監査等委員である取締役若しくはそれ以外の取締役又は会計参与。以下この項において同じ。）が欠けた場合又はこの法律若しくは定款で定めた役員の員数を欠くこととなるときに備えて補欠の役員を選任することができる。

  2. 条文
    会社法 336条3項 （監査役の任期）

    第3項　第一項の規定は、定款によって、任期の満了前に退任した監査役の補欠として選任された監査役の任期を退任した監査役の任期の満了する時までとすることを妨げない。

  3. やさしく言うと

    株主総会では、役員が欠けたときに備えて、あらかじめ補欠の役員を選んでおけます。また、定款で定めれば、補欠として選ばれた監査役の任期を、前任者の残りの任期に合わせられます。

  4. この事例では

    監査役が1名だけの会社は、欠員が起きると直ちに員数を欠くので、定時総会で補欠監査役を選んでおくと、今回のような場合に臨時総会が不要になります。補欠の選任の有効期間は、通常、次の定時総会の開始の時までとされるので、毎年選び直します（補欠選任の詳細は役員選任の節を参照）。
