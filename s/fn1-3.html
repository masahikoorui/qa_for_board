対象会社であれば、コミットメントフィー（融資枠の手数料）には、利息制限法のみなし利息の規定（3条・6条）が適用されません（特定融資枠契約法3条）。対象外の会社では、この特例が使えないため、手数料が「利息とみなされ」、実際に借りた額に対する利息と合わせて利息制限法の上限を超える部分が無効になるおそれがあると考えられています。そのため、対象外の会社には、手数料を取らない当座貸越などで代わりに対応するのが一般的です。
いずれにしても、契約の締結は極度額で「多額の借財」かを判定し、該当すれば取締役会で決議します。

  • 対象外の会社に手数料付きの融資枠が提案された場合は、手数料と利息の合計が利息制限法の上限内に収まるか、銀行と法的な整理を確認する。
  • 契約後に資本金を減らしても、対象かどうかは締結時で判定される（更新時に改めて判定されるかは契約の構成による）。

注2手数料は利息とみなされることがある
  1. 条文
    利息制限法 3条 （みなし利息）

    前二条の規定の適用については、金銭を目的とする消費貸借に関し債権者の受ける元本以外の金銭は、礼金、割引金、手数料、調査料その他いかなる名義をもってするかを問わず、利息とみなす。ただし、契約の締結及び債務の弁済の費用は、この限りでない。

  2. やさしく言うと

    お金の貸し借りに関して貸主が受け取るお金は、「手数料」などの名前でも、原則として利息とみなされます。

  3. なぜこのルールか

    名目を変えれば利息の上限を逃れられる、ということを防ぐための規定です。

  4. この事例では

    コミットメントフィーは、まだ借りていない枠に対して払う手数料なので、利息とみなされると、実際の借入額が小さい場合に利率の上限（元本100万円以上は年1割5分。利息制限法1条）を超えるおそれがあります。対象外の会社では、この点を銀行と確認します。

  5. 推測を含む点

    対象外の会社のコミットメントフィーが実際にみなし利息として無効とされるかは、手数料の性質や借入れの状況によるもので、これを判断した判例は確認できていません。特例法がわざわざ設けられたことから、そのおそれがあると一般に考えられている、という整理です。

注3特例の内容
  1. 条文
    特定融資枠契約法 3条 （利息制限法等の適用除外）

    利息制限法第三条及び第六条並びに出資の受入れ、預り金及び金利等の取締りに関する法律第五条の四第四項の規定は、特定融資枠契約に係る前条第一項の手数料については、適用しない。

  2. やさしく言うと

    対象になる契約の手数料には、利息制限法のみなし利息の規定などが適用されません。

  3. この事例では

    対象会社であれば、コミットメントフィーを手数料として支払っても、利息制限法の問題は生じません。決議の判断材料には、年間の手数料の見込み額を入れておきます。

  4. 実務のコツ

    特例が適用されるのは「手数料」の部分です。実際に借りた分の利息は、通常どおり利息制限法の上限の範囲内である必要があります。

A
締結時の決議で「個々の引出しの決定を代表取締役に委任する」とし、引出しの金額や使途に限定がなければ、全額の引出しも委任の範囲内なので、改めて決議する必要はないと考えられます。ただし、締結時の決議で資金使途（例：運転資金）や1回の引出しの上限を定めている場合、手元資金として置いておく目的の引出しがその範囲に入るかを確認し、入らなければ付議します。

  • 上場会社の適時開示・臨時報告書の要否は取引所規則・金融商品取引法の基準によるもので、本文では具体的な基準を確認していません。

A
借入れの効力が生じるのは最終の契約書に調印したときなので、「多額の借財」としての決議は、調印までに必要です。他方、マンデートレターは、アレンジャーに組成を依頼し、主要な条件（総額・期間・金利の水準・手数料など）を示す書面で、手数料の支払や秘密保持などの義務を負うことがあります。会社が実質的に借入れの方針を決める段階なので、重要な案件では、この段階で取締役会に「組成の方針と主要な条件の範囲」を決議しておき、最終の条件が決まったら、その範囲内での調印を代表取締役に任せる2段階の方法が実務的です。
2段階にすると、組成の途中で条件が範囲を外れたとき（参加行が集まらず総額が減る、金利が上がる等）だけ再付議すればよく、調印日に間に合わないという事態を避けられます。1回で済ませるなら、最終条件がほぼ固まった調印前に決議します。

根拠が明らかでない点（推測を含みます）

  • マンデートレターの差入れの段階で取締役会決議が法律上必要かは明確でなく、本文は重要な業務執行として決議しておく実務上の考え方です。
  • マンデートレターに一般にどのような義務の条項が置かれるかは、JSLAの参考例の内容を本文では確認していないため、一般的な説明にとどめています。
  • 基準金利の名称（TORF・TIBORなど）は例示です。
  • 議事録写し・決議証明書がエージェントを通じて参加行に配布されるという点は一般的な実務の説明で、契約ごとに確認が必要です。

実務のポイント

  • マンデートレターで負う義務（アレンジメントフィーの支払、他の銀行と並行して交渉しない約束、秘密保持、費用負担）を確認する。
  • 組成段階の決議では、総額・期間・金利の上限・手数料の上限・資金使途・担保・財務制限条項の方針を「範囲」で決める。
  • アレンジャー・エージェントの選定理由（条件比較、従来の取引）を判断材料に入れる。
  • 参加行の中に当社役員の兼任先がないかを確認する（利益相反）。
  • 調印時には、銀行が取締役会議事録の写しや決議の証明書を求めることが多いので、調印日より前に決議を終える。

  5. 範囲内なら代表取締役が契約書に調印する。範囲外なら再付議する。

注1借入れの決議は調印までに 重要
  1. 条文
    会社法 362条4項 二号 （取締役会の権限等）

    第4項　取締役会は、次に掲げる事項その他の重要な業務執行の決定を取締役に委任することができない。

    • 二　多額の借財
  2. やさしく言うと

    多額の借入れは取締役会が決めます。シンジケートローンの借入れの契約が成立するのは、最終の契約書に調印したときです。

  3. 用語

    アレンジャー：借主から依頼を受け、条件を調整し、参加する銀行を集めてシンジケートローンを組成する銀行。

  4. 用語

    エージェント：契約後、借主と参加行の間の連絡、元利金の受渡し、通知などの事務を、参加行のために行う銀行。

  5. この事例では

    調印前に、総額・期間・金利・手数料・財務制限条項などの範囲を取締役会で決めておきます。範囲を決めて委任すれば、最終条件の確定は代表取締役に任せられます。

注2マンデートレターの段階で決めておく理由
  1. 条文
    会社法 362条2項 一号 （取締役会の権限等）

    第2項　取締役会は、次に掲げる職務を行う。

    • 一　取締役会設置会社の業務執行の決定
  2. やさしく言うと

    取締役会は、会社の重要な業務執行を決めます。

  3. この事例では

    マンデートレターを出すと、会社はそのアレンジャーと組成を進めることを約束し、手数料や費用の負担、他行と並行して交渉しない約束などを負うことがあります。重要な資金調達の方針はこの時点で事実上決まるので、取締役会で方針と条件の範囲を決めておくのが適切です。

  4. 推測を含む点

    マンデートレターの差入れ自体が「多額の借財」に当たるとまでは言いにくいと考えられます。この段階で決議するのは、重要な業務執行の決定として、また調印時の手続を円滑にするための実務上の工夫です。

  5. 実務のコツ

    JSLAは、マンデートレター・秘密保持誓約書・参加意向表明書の参考例を公表しています（参考リンク）。銀行から示された書面の条項を確認する際の参考になります。

注3調印後の報告で監督を果たす
  1. 条文
    会社法 363条2項 （取締役会設置会社の取締役の権限）

    第2項　前項各号に掲げる取締役は、三箇月に一回以上、自己の職務の執行の状況を取締役会に報告しなければならない。

  2. やさしく言うと

    代表取締役は、3か月に1回以上、取締役会に職務の状況を報告します。

  3. この事例では

    調印後は、最終の総額・金利・手数料・財務制限条項・参加行の一覧を報告させ、決議の範囲内だったことを議事録に残します。銀行に提出する議事録写しと、最終の契約書の内容が食い違わないかも事務局が確認します。

  4. 実務のコツ

    シンジケートローンでは、議事録写しや決議の証明書はエージェントを通じて参加行に配布されるのが通常です。提出先と提出日を記録しておくと、後で決議の範囲を説明しやすくなります。

A
財務制限条項は、抵触すると期限の利益を失う（全額の返済を求められる）おそれがある重い条項なので、取締役会は「どの条項を、どの水準で受け入れるか」を決議します。上程書・議事録には、各条項の内容（指標の定義、基準値、判定の時期、抵触したときの効果）を具体的に書き、受け入れる上限（例：純資産は前期末の75％以上の維持まで）を定めます。
判断材料としては、①現在の指標と基準値との余裕、②業績が悪化した場合の試算（どの程度の減益で抵触するか）、③他の借入契約の財務制限条項との関係（クロスデフォルト条項で連鎖しないか）、④抵触したときの手続（銀行への報告、権利放棄（ウェイバー）の取得）を確認します。
契約締結後は、判定日ごとに遵守状況を取締役会に報告させます。抵触したとき・しそうなときの対応は、別の節（財務制限条項・期限の利益）で扱います。

根拠が明らかでない点（推測を含みます）

  • 財務制限条項の内容まで決議しないと委任として不十分と評価されるかを判断した判例は確認できていません。本文は実務上の考え方です。
  • 条項の例（純資産75％、2期連続の経常損失、レバレッジ比率）は説明のための例で、実際の水準は契約ごとに異なります。
  • 上場会社の財務制限条項に関する開示の要否は、開示府令・取引所規則の要件によるので個別の確認が必要です。

実務のポイント

  • 指標の定義（単体か連結か、経常利益か営業利益か、純有利子負債の計算方法）を契約書で正確に確認し、上程書に書く。
  • 判定の時期（本決算のみか、中間期も含むか）と判定の書類（計算書類、遵守状況の報告書）を確認する。
  • 業績の悪化シナリオで、どの程度の減益・損失で抵触するかを試算する。
  • 他の借入れにクロスデフォルト条項（他の債務の不履行も期限の利益の喪失事由とする条項）があるか確認する。
  • 上場会社は、財務制限条項付きの契約について、金融商品取引法・取引所規則上の開示の要否を確認する。

財務制限条項の決議の仕方の比較

推奨A案　条項の内容と受け入れる上限を具体的に決議する

メリット
  • 取締役会が条項の重さを判断したことが明確。
  • 交渉で条項が厳しくなったときに再付議の基準になる。
デメリット
  • 上程書の作成に手間がかかる。

B案　「財務制限条項を含む」とだけ決議し、内容は代表取締役に委任する

メリット
  • 手続が簡単。
デメリット
  • 取締役会が重要な条件を判断していないことになり、委任として不十分と評価されるおそれがある。

C案　財務制限条項の受入れ方針（社内基準）を別に決議し、各契約はその範囲内で委任する

メリット
  • 複数の借入れで条項の水準をそろえられる。
デメリット
  • 方針の決議と各契約の照合という二重の管理が必要。

推奨：A案を推奨します。借入れごとに条項の内容と上限を決議するのが、取締役会の判断として最も確かです。財務制限条項付きの借入れが多い会社は、C案で社内の受入れ基準を決め、個々の契約は基準内かを確認する運用にすると効率的です。

進め方

  1. 財務部が契約書案から財務制限条項を抜き出し、指標の定義・基準値・判定時期・効果を表にする。
  2. 経理部が、現在の指標と悪化シナリオでの試算を作る。
  3. 法務部が、他の借入契約のクロスデフォルト条項との関係を確認する。
  4. 取締役会で、財務制限条項の受入れを含めて契約の締結を決議する。
  5. 判定日ごとに、遵守状況を取締役会に報告する。

すでに手続を欠いてしまった場合（事後の是正）

財務制限条項の内容を取締役会に示さないまま（又は決議した上限より厳しい条項で）契約を締結していた場合

  1. 契約書の財務制限条項と、取締役会の決議内容を照合する。
  2. 現在の指標と基準値との余裕を確認する（抵触のおそれがあれば最優先で対応）。
  3. 監査役に報告する。
  4. 次の取締役会で、条項の内容を報告し、契約の締結を追認する。
  5. 以後、判定日ごとの遵守状況の報告を決議する。
  6. 財務制限条項の社内の受入れ基準を定める。

注1財務制限条項は「多額の借財」の重要な条件 重要
  1. 条文
    会社法 362条4項 二号 （取締役会の権限等）

    第4項　取締役会は、次に掲げる事項その他の重要な業務執行の決定を取締役に委任することができない。

    • 二　多額の借財
  2. やさしく言うと

    多額の借入れを取締役会で決めるときは、金額だけでなく、会社に重い義務を課す条件も判断の対象です。

  3. 用語

    財務制限条項（コベナンツ）：借主に、純資産・利益・負債比率などの財務指標を一定の水準に保つことを約束させる契約条項。守れないと、銀行の請求により借入金を直ちに返さなければならなくなる（期限の利益の喪失）ことがある。

  4. この事例では

    上程書には、条項ごとに指標の定義・基準値・判定の時期・抵触時の効果を書き、「これより厳しい条項は受け入れない」という上限を決議します。

  5. 落とし穴

    「財務制限条項を含む契約を締結する」とだけ決議して中身を書かないと、取締役会が条項の重さを判断したことになりません。

注2期限の利益を失うということ
  1. 条文
    民法 136条 （期限の利益及びその放棄）

    第1項　期限は、債務者の利益のために定めたものと推定する。

    第2項　期限の利益は、放棄することができる。ただし、これによって相手方の利益を害することはできない。

  2. やさしく言うと

    返済の期限は、ふつう借主のためのものです。期限まで返さなくてよいという利益を「期限の利益」といいます。

  3. この事例では

    財務制限条項に抵触すると、この期限の利益を失い、銀行から全額の返済を求められることがあります。他の借入れにクロスデフォルト条項があれば、別の借入れでも期限の利益を失うおそれがあり、会社の資金繰りが一気に危うくなります。判断材料に、他の契約との関係を必ず入れます。

  4. 推測を含む点

    期限の利益の喪失が「当然」に生じるか「銀行の請求」によって生じるかは、条項ごとに契約で定められます。本文は一般的な説明で、具体的な効果は契約書で確認してください。

注1債権は原則として自由に譲渡できる 重要
  1. 条文
    民法 466条2項 （債権の譲渡性）

    第2項　当事者が債権の譲渡を禁止し、又は制限する旨の意思表示（以下「譲渡制限の意思表示」という。）をしたときであっても、債権の譲渡は、その効力を妨げられない。

  2. やさしく言うと

    債権は原則として他人に譲れます。譲渡を禁止・制限する約束があっても、譲渡そのものは有効です（ただし、その約束を知っていた譲受人には、借主は支払を拒めるなどの保護があります。民法466条3項）。

  3. なぜこのルールか

    債権をお金に換えやすくして、資金の流れを良くするためです。一方で、借主が「知らない人に払うことになる」不利益にも配慮しています。

  4. この事例では

    シンジケートローン契約には、貸付債権の譲渡についての条項（借主の承諾の要否、譲渡先の範囲など）が置かれているのが通常です。承諾を求められたら、まず契約の条項を確認し、承諾を拒める場合か、拒めない場合かを判断します。

    JSLAは貸付債権の売買にかかる契約書の参考例を公表していますが、シンジケートローン契約の譲渡条項の具体的な内容は本文では確認していません。個々の契約書で確認してください。

    第4項　取締役会は、次に掲げる事項その他の重要な業務執行の決定を取締役に委任することができない。

    • 二　多額の借財
  2. やさしく言うと

    取締役会が決めなければならないのは、会社が借りる（債務を負う）ことです。

  3. この事例では

    貸主が入れ替わっても、会社の債務の額・条件は変わらないので、承諾は代表取締役の権限で行えると考えられます。ただし、承諾の条件として金利や期間を変える場合は、条件の変更として付議します。

  2. やさしく言うと

    取締役が他の会社を代表して自分の会社と取引するときは、利益相反取引として承認が必要です（取締役会設置会社では取締役会の承認。会社法365条1項）。

  3. 判例
    利益相反取引の意義と承認を欠く取引の効力（相対的無効）
    最高裁判所大法廷 昭和43年12月25日 判決（民集22巻13号3511頁）

    旧商法265条の「取引」には、取締役と会社の間で直接成立する利益相反行為だけでなく、取締役個人の債務について取締役が会社を代表して債権者に対し債務引受をするような行為も含まれるとした。取締役会の承認を受けない取引について、会社は当該取締役に対しては無効を主張できるが、会社以外の第三者との間の取引については、その第三者が承認を受けていないことを知っていたことを主張・立証しなければ無効を主張できないとした判決。

    承認を受けない利益相反取引の効力について、会社と取締役の間では無効、第三者には悪意の立証が必要とした判決です。

  4. この事例では

    今回の譲渡自体は、参加行と信託銀行の間の取引で、会社と信託銀行の取引ではありません。しかし、今後、兼任取締役が信託銀行を代表して会社と条件変更などをする場面では、承認が必要になり得ます。承諾の段階で取締役会に報告し、扱いを決めておきます。

  5. 推測を含む点

    兼任取締役が譲受人を代表しない場合に、条件変更等の決議で特別利害関係人に当たるかは明確な判例が確認できていません。議決に加えない扱いは慎重な実務としての提案です。

融資枠25億円が付議基準・会社の規模に照らして「多額の借財」に当たるなら、締結は取締役会の決議を欠いた手続違反です。契約は直ちに無効にはなりませんが、銀行が決議のないことを知り又は知ることができたときは、会社は無効を主張できると解されています。本件では銀行が議事録の写しを求めた記録があり、提出がなかったなら銀行も決議の欠如を「知ることができた」と評価され得ます。会社にとっても、契約の効力が不安定なままでは困るので、契約を維持するなら速やかに追認します。

注1決議を欠く契約の効力 重要
  1. 条文
    会社法 349条4項 （株式会社の代表）

    第4項　代表取締役は、株式会社の業務に関する一切の裁判上又は裁判外の行為をする権限を有する。

  2. やさしく言うと

    代表取締役には会社を代表して契約する広い権限があるので、取締役会の決議を欠いた契約でも、直ちに無効にはなりません。

  3. 判例
    取締役会決議を経ない代表取締役の取引の効力
    最高裁判所第三小法廷 昭和40年9月22日 判決（民集19巻6号1656頁）

    代表取締役が、取締役会の決議を経てすることを要する対外的な個々的取引行為を決議を経ないでした場合でも、相手方が決議を経ていないことを知り又は知ることができたときでない限り、その取引行為は有効であるとした判決。

    決議を要する取引を決議なしにした場合、相手方が決議のないことを知り又は知ることができたときに限って無効とした判決です。

  4. この事例では

    銀行が議事録の写しを求めたのに提出がなかったなら、銀行は決議がないことを「知ることができた」と評価され得ます。その場合、会社も銀行も契約の効力に不安を抱えることになるので、契約を維持するなら追認で確定させます。

  5. 推測を含む点

    決議の欠如を理由とする無効は、会社の利益を守るためのものなので、主張できるのは原則として会社側だと一般に解されています。ただし、本問のような場面で銀行側から無効を主張できるかを判断した判例は確認できていません。

A
親会社では、①親会社自身の借主としての契約締結（融資枠の総額で多額の借財に当たるか判定）と、②子会社の引出しについての連帯保証の両方を取締役会で決議します。保証は「借財」に含まれると解されているので、保証する可能性のある額（子会社ごとの引出上限の合計）で判定します。
子会社では、取締役会設置会社であれば、子会社自身の借主としての契約締結（子会社ごとの引出上限で判定）を、それぞれの取締役会で決議します。子会社が特定融資枠契約法の対象かどうかは、親会社が大会社や有価証券報告書提出会社などに当たれば、その子会社として対象になります（同法2条1項5号）。
また、親会社と子会社の取締役を兼ねる者が、片方を代表して保証や契約をする場合は、利益相反取引の承認と特別利害関係の扱いを確認します。

根拠が明らかでない点（推測を含みます）

  • 保証の判定額を「子会社の引出上限の合計」とするのは実務上の考え方で、法令・判例の根拠は確認できていません。
  • 兼任取締役が子会社の債務の保証の決議で特別利害関係人に当たるかは見解が分かれ得る点で、本文は慎重な扱いを示しています。
  • マルチボロワー方式の契約の具体的な構成（融資枠の共有、引出上限、保証の方式）は契約ごとに異なり、銀行の書式の内容は確認していません。
  • 保証料の水準と税務上の扱いは、個別に税理士等の確認が必要です。

実務のポイント

  • 親会社の決議は「自社の借入れ」と「子会社の引出しの保証」の2本立て。保証の上限額（子会社ごとの引出上限）も決める。
  • 子会社ごとに引出上限があるか、融資枠を共有するか（誰かが使うと他が使えない）を契約書で確認する。
  • 子会社の財務状況が悪化した場合に、親会社の保証が履行される可能性を判断材料に入れる。保証料の要否も検討する。
  • 財務制限条項が親会社の連結数値で判定されるか、子会社の単体数値も対象かを確認する。
  • 子会社の取締役会で決議する前提として、親会社の子会社管理規程で承認・報告の流れを決めておく。

グループ会社の融資枠の確保方法の比較

推奨A案　マルチボロワー方式（子会社も借主、親会社が保証）

メリット
  • 子会社が直接、機動的に引き出せる。
  • 契約が1本で、銀行との交渉が一本化できる。
デメリット
  • 親会社の保証の決議、子会社ごとの決議、兼任者の扱いなど手続が多い。
  • 子会社の業績悪化が親会社の保証債務に直結する。

B案　親会社だけが借主となり、引き出した資金を子会社に転貸する

メリット
  • 契約の当事者が親会社だけで簡単。
デメリット
  • 転貸のたびに親子間の貸付けの手続が必要。
  • 親会社の借入金として計上される。

C案　子会社ごとに個別のコミットメントライン（又は当座貸越）を結ぶ

メリット
  • 子会社の自立的な資金調達になる。
デメリット
  • 契約が増え、手数料・管理の負担が大きい。
  • 子会社単独では条件が悪くなりやすい。

推奨：グループで資金需要の時期が子会社ごとに異なり、子会社が自ら機動的に引き出す必要がある場合はA案を推奨します。子会社の資金需要が小さい、又は親会社でグループの資金を一元管理したい場合は、B案やキャッシュ・マネジメント・システムが適しています。

進め方

  1. 親会社の財務部が、マルチボロワー方式の条件（総額、子会社ごとの上限、保証、財務制限条項）を整理する。
  2. 子会社が特定融資枠契約法の対象か確認する（親会社が同法2条1項1〜4号に当たるか）。
  3. 親子の役員の兼任状況を確認し、利益相反・特別利害関係を整理する。
  4. 各子会社の取締役会で、借主として契約に加わることを決議する。
  5. 親会社の取締役会で、自社の契約締結と子会社の引出しの保証を決議する。
  6. 契約を締結し、子会社の引出状況を親会社の取締役会に四半期ごとに報告する。

すでに手続を欠いてしまった場合（事後の是正）

マルチボロワー方式の契約について、親会社の保証や子会社の借入れの決議を欠いたまま締結していた場合

  1. 契約書で、借主、引出上限、保証の範囲、締結日を確認し、親会社・子会社それぞれの決議の有無を整理する。
  2. 親子それぞれの監査役に報告する。
  3. 決議を欠いていた会社の取締役会で、契約への参加（子会社）又は保証（親会社）を追認する。兼任取締役の扱いに注意する。
  4. エージェントに追認後の議事録写しを提出する。
  5. 親会社の子会社管理規程に、グループでの資金調達の承認・報告の手順を定める。

注1子会社も特例の対象になる 重要
  1. 条文
    特定融資枠契約法 2条1項 五号 （定義）

    第1項　この法律において「特定融資枠契約」とは、一定の期間及び融資の極度額の限度内において、当事者の一方の意思表示により当事者間において当事者の一方を借主として金銭を目的とする消費貸借を成立させることができる権利を相手方が当事者の一方に付与し、当事者の一方がこれに対して手数料を支払うことを約する契約であって、意思表示により借主となる当事者の一方が契約を締結する時に次に掲げる者であるものをいう。

    • 五　前各号に掲げる者の子会社（会社法第二条第三号に規定する子会社をいい、前各号に掲げる者を除く。）
  2. やさしく言うと

    大会社や有価証券報告書を出す会社などの子会社は、自らは小さな会社でも、コミットメントラインの特例の対象になる借主です。

  3. この事例では

    親会社が上場会社（有価証券報告書提出会社で監査証明を受ける会社）なら、その子会社（会社法2条3号の子会社）は対象になります。子会社の手数料にも利息制限法のみなし利息の規定は適用されません（特定融資枠契約法3条）。

  4. 落とし穴

    子会社かどうかは、議決権の過半数を持つかなど会社法の基準で判断します。持分法適用会社のように子会社に当たらない会社は、この号では対象になりません。

注2保証も「借財」として決める
  1. 条文
    会社法 362条4項 二号 （取締役会の権限等）

    第4項　取締役会は、次に掲げる事項その他の重要な業務執行の決定を取締役に委任することができない。

    • 二　多額の借財
  2. やさしく言うと

    多額の借財は取締役会が決めます。他人の債務の保証も、会社が将来支払う義務を負うので、借財に含まれると解されています。

  3. この事例では

    子会社の引出上限の合計（25億円）と利息等を保証の上限として決議します。子会社が引き出すたびに保証の決議をするのではなく、契約締結時に保証の範囲を決めておきます。

  4. 判例
    取締役会決議を要する重要な財産の処分
    最高裁判所第一小法廷 平成6年1月20日 判決（民集48巻1号1頁）

    重要な財産の処分に当たるかは、財産の価額、総資産に占める割合、保有目的、処分行為の態様、従来の取扱い等を総合考慮して判断するとし、総資産の約1.6％に当たる株式の譲渡について、重要な財産の処分に当たらないとはいえないとした判決。

    重要性を金額や総資産に占める割合などで総合判断するとした判決です。保証の額も、親会社の総資産等に照らして重要性を判断します。

  5. 実務のコツ

    保証料を取るかどうかは、子会社の少数株主の有無や税務も考えて決めます。完全子会社でも、保証料の考え方を上程書に書いておくと判断の過程が明確になります。

注3兼任取締役の扱い
  1. 条文
    会社法 369条2項 （取締役会の決議）

    第2項　前項の決議について特別の利害関係を有する取締役は、議決に加わることができない。

  2. やさしく言うと

    決議に特別な利害関係を持つ取締役は、議決に加われません。

  3. この事例では

    親会社が銀行に対して子会社の債務を保証するのは、親会社と銀行の取引であり、兼任取締役が子会社を代表して親会社と取引するわけではありません。ただし、保証料の契約は親子間の取引なので、兼任取締役が子会社を代表するなら利益相反取引の承認が必要です（会社法356条1項2号・365条1項）。

  4. 推測を含む点

    子会社の代表取締役を兼ねる親会社の取締役が、子会社の債務の保証の決議で特別利害関係人に当たるかを判断した判例は確認できていません。本文の文例では、慎重を期して議決に加えない扱いを示しています。
