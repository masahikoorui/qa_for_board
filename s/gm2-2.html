Q023

招集通知はいつまでに発送すればよいか。「2週間前まで」の日数はどう数えるのか。

基本取締役会設置会社取締役会非設置会社公開会社非公開会社#
A
公開会社は総会の日の2週間前までに、非公開会社は1週間前までに招集通知を発送します（会社法299条1項）。非公開会社でも書面投票・電子投票を採る場合は2週間前まで、取締役会非設置の非公開会社は定款で1週間より短くできます。
「2週間前まで」とは、発送日と総会日の間に丸14日（中14日）を空けるという意味だと一般に解されています。例えば6月26日（木）の総会なら、6月11日までに発送します。
期限は「発した」日で判断する発信主義なので、郵便局に差し出した日が基準です。株主に届いた日ではありません。

実務のポイント

  • 自社の区分（公開会社か、取締役会設置会社か、書面投票を採るか）で期限を確定する。
  • 数え方：総会日の前日から遡って14日を確保し、その前日が発送期限（総会日−15日）。
  • 発送日は、郵便局の差出票（受領証）など客観的な記録で残す。
  • 上場会社は電子提供措置の開始期限（総会の3週間前の日）が別にあり、こちらが先に来る。
  • 法定期限ぎりぎりではなく、社内目標日を数日前に置く。

進め方

  1. 総会日を確定する。
  2. 自社に適用される期間（2週間・1週間・定款で短縮）を確認する。
  3. 総会日から逆算して発送期限を算出し、日程表に記入する。
  4. 印刷会社・郵便局の差出日を確定する。
  5. 差出日の記録を保存する。

注1招集通知の発送期限 重要
  1. 条文
    会社法 299条1項 （株主総会の招集の通知）

    第1項　株主総会を招集するには、取締役は、株主総会の日の二週間（前条第一項第三号又は第四号に掲げる事項を定めたときを除き、公開会社でない株式会社にあっては、一週間（当該株式会社が取締役会設置会社以外の株式会社である場合において、これを下回る期間を定款で定めた場合にあっては、その期間））前までに、株主に対してその通知を発しなければならない。

  2. やさしく言うと

    公開会社は総会の2週間前までに、非公開会社は1週間前までに招集通知を出します。非公開会社でも書面や電子で議決権を行使させるときは2週間前です。取締役会がない非公開会社は、定款でさらに短くできます。

  3. なぜこのルールか

    株主が議案を検討し、出席の予定を立て、書面投票の準備をするための時間を確保するためです。株主が多く、会社と距離のある公開会社ほど長い期間が必要とされています。

  4. この事例では

    自社がどの区分かを定款（株式の譲渡制限の有無、取締役会の有無）と招集決定（書面投票の有無）で確認し、期限を決めます。

注2日数の数え方
  1. 条文
    民法 140条

    日、週、月又は年によって期間を定めたときは、期間の初日は、算入しない。ただし、その期間が午前零時から始まるときは、この限りでない。

  2. 条文
    民法 141条 （期間の満了）

    前条の場合には、期間は、その末日の終了をもって満了する。

  3. やさしく言うと

    民法の期間の数え方では、初日は数えず、最後の日が終わった時に期間が満了します。会社法の「総会の日の2週間前までに」は、この考え方を総会日から過去に向けて当てはめ、総会日を数えずに遡って14日を確保し、その前に発送する、と一般に解されています。

  4. この事例では

    6月26日の総会なら、25日から遡って12日までの14日間を空ける必要があるので、発送期限は6月11日です。「中14日」と覚えておくと間違えにくくなります。

  5. 落とし穴

    期限の日が土日祝日でも、前倒しにはなっても後ろにずれることはありません。郵便局の窓口の営業日を確認しておきましょう。

注3発信主義と到達の扱い
  1. 条文
    会社法 126条1項 （株主に対する通知等）

    第1項　株式会社が株主に対してする通知又は催告は、株主名簿に記載し、又は記録した当該株主の住所（当該株主が別に通知又は催告を受ける場所又は連絡先を当該株式会社に通知した場合にあっては、その場所又は連絡先）にあてて発すれば足りる。

  2. やさしく言うと

    会社から株主への通知は、株主名簿の住所（株主が別の連絡先を届けていればそこ）に宛てて出せば足ります。

  3. この事例では

    期限内に株主名簿の住所に宛てて発送していれば、郵便の遅れで株主への到着が遅れても、期限違反にはなりません。逆に、期限内に発送していなければ、早く届いても期限違反です。

実務取締役会決議あり取締役会設置会社公開会社#
A
そのまま開くと、招集手続の法令違反として決議取消しの原因になり、しかも裁量棄却（違反が軽微として取消しを退けること）は期待しにくいので、避けるべきです。判例は、法定期間に2日足りない招集通知について、瑕疵が重大で裁量棄却は許されないとしています。
原則的な対応は、取締役会で総会の日を変更（招集の撤回と再招集）し、新しい日から数えて法定期間を満たすよう改めて通知することです。新しい日が基準日から3か月を超えないかも確認します。
株主が少ない会社で書面投票を採っていなければ、株主全員の同意による招集手続の省略（会社法300条）や、全員出席総会で対応できる場合もあります。

実務のポイント

  • まず実際の差出日を確認し、何日不足しているかを正確に計算する（印刷会社の出荷日ではなく郵便局の差出日）。
  • 1日の不足でも「軽微」とは扱われないリスクが高い。法定期間は株主の検討期間を保障するもので、短縮は重大な瑕疵とされやすい。
  • 総会日を後ろにずらす場合、会場、役員の日程、基準日から3か月、配当の支払開始日、登記の期限を確認する。
  • 既に返送された議決権行使書面は、撤回した総会のものとして扱えないので、新しい総会で改めて行使を依頼する。
  • 印刷会社との契約上の責任（追加費用の負担）も整理する。

進め方

  1. 差出日と不足日数を確認し、弁護士に相談する。
  2. 変更後の総会日を決め、会場・役員・株主名簿管理人と調整する。
  3. 取締役会で、当初の総会の招集を撤回し、新しい日時で招集することを決議する。
  4. 株主に日程変更のお知らせと新しい招集通知を発送する（上場会社は適時開示・電子提供措置の修正）。
  5. 当初の予定日に来場する株主への案内を準備する。

    第1項　次の各号に掲げる場合には、株主等（当該各号の株主総会等が創立総会又は種類創立総会である場合にあっては、株主等、設立時株主、設立時取締役又は設立時監査役）は、株主総会等の決議の日から三箇月以内に、訴えをもって当該決議の取消しを請求することができる。当該決議の取消しにより株主（当該決議が創立総会の決議である場合にあっては、設立時株主）又は取締役（監査等委員会設置会社にあっては、監査等委員である取締役又はそれ以外の取締役。以下この項において同じ。）、監査役若しくは清算人（当該決議が株主総会又は種類株主総会の決議である場合にあっては第三百四十六条第一項（第四百七十九条第四項において準用する場合を含む。）の規定により取締役、監査役又は清算人としての権利義務を有する者を含み、当該決議が創立総会又は種類創立総会の決議である場合にあっては設立時取締役（設立しようとする株式会社が監査等委員会設置会社である場合にあっては、設立時監査等委員である設立時取締役又はそれ以外の設立時取締役）又は設立時監査役を含む。）となる者も、同様とする。

    • 一　株主総会等の招集の手続又は決議の方法が法令若しくは定款に違反し、又は著しく不公正なとき。
  3. やさしく言うと

    招集通知の期間を守らないと、招集手続が法律に違反していることになり、株主は決議から3か月以内に決議の取消しを求められます。

  4. この事例では

    1日の遅れでも法令違反であることに変わりはありません。不足が分かった時点で、開催日を変える方向で検討してください。

注2裁量棄却はあてにできない 重要
  1. 条文
    会社法 831条2項 （株主総会等の決議の取消しの訴え）

    第2項　前項の訴えの提起があった場合において、株主総会等の招集の手続又は決議の方法が法令又は定款に違反するときであっても、裁判所は、その違反する事実が重大でなく、かつ、決議に影響を及ぼさないものであると認めるときは、同項の規定による請求を棄却することができる。

  2. やさしく言うと

    違反が重大でなく、かつ決議の結果に影響しないときに限り、裁判所は取消しの請求を退けることができます。2つの条件の両方が必要です。

  3. 判例
    招集手続の瑕疵と裁量棄却の限界
    最高裁判所第一小法廷 昭和46年3月18日 判決（民集25巻2号183頁）

    株主総会の招集手続又は決議方法の瑕疵がその性質・程度から重大である場合には、決議の結果に影響がないときでも、裁判所は裁量により決議取消請求を棄却することはできないとした。取締役会の有効な決議なく招集され、かつ法定期間に2日足りない招集通知によって開催された総会について、瑕疵が重大であり裁量棄却は許されないとした判決。

    取締役会の有効な決議なく招集され、法定期間に2日足りない招集通知で開かれた総会について、瑕疵は重大で、決議に影響がなくても裁量棄却は許されないとされました。

  4. この事例では

    大株主の賛成で可決が確実でも、「影響がない」だけでは足りず、「重大でない」ことも必要です。期間の不足は株主の検討の機会を奪うもので重大と評価されやすいため、裁量棄却に期待して開催するのは危険です。

注3株主が少ない会社の別の選択肢
  1. 条文
    会社法 300条 （招集手続の省略）

    前条の規定にかかわらず、株主総会は、株主の全員の同意があるときは、招集の手続を経ることなく開催することができる。ただし、第二百九十八条第一項第三号又は第四号に掲げる事項を定めた場合は、この限りでない。

  2. やさしく言うと

    書面投票・電子投票を採っていなければ、株主全員が同意すれば招集手続を省略して総会を開けます。

  3. 判例
    全員出席総会の決議の効力
    最高裁判所第二小法廷 昭和60年12月20日 判決（民集39巻8号1869頁）

    招集権者による招集手続を欠く場合でも、株主全員がその開催に同意して出席したいわゆる全員出席総会でされた決議は有効に成立するとした。株主の代理人が出席した場合も、株主が会議の目的たる事項を了知して委任し、決議がその事項の範囲内のものであれば、決議は有効に成立するとした判決。

    招集手続を欠いても、株主全員が開催に同意して出席した全員出席総会の決議は有効とされました。

  4. この事例では

    株主が数名の会社なら、全員から招集手続の省略への同意書をもらえば、予定日に開催できます（招集手続の省略・全員出席総会の節を参照）。株主が多い会社や書面投票を採る会社では使えないので、日程変更で対応します。

実務取締役会設置会社公開会社非公開会社#
A
宛先不明で返送された通知は、株主名簿の住所に宛てて期限内に発送していれば、通常到達すべき時に到達したものとみなされるので（会社法126条1項・2項）、招集手続の瑕疵にはなりません。
一方、会社の事務ミスで送っていなかった株主がいる場合は、その株主に対する招集手続の法令違反です。判例は、自分には瑕疵がない株主でも、他の株主への招集手続の瑕疵を理由に決議取消しの訴えを起こせるとしています。
判明したら直ちに送付し、漏れた株主数・議決権数、法定期間を満たすかを確認します。期間を満たせないなら、総会日の変更や、漏れた株主の同意の取得などを弁護士と検討します。

実務のポイント

  • 漏れの原因（名簿の抽出条件、名義書換えの反映漏れ、共有株式の代表者）を特定し、他にも漏れがないか全件を照合する。
  • 返送分は、株主名簿の住所と一致しているかを確認する。株主から住所変更の届出を受けていたのに反映していなかったなら、会社の落ち度になる。
  • 5年以上継続して通知が到達しない株主には、通知を省略できる（会社法196条1項）。
  • 株式が共有されている場合、共有者が通知を受ける者を定めて届け出ていればその者に、なければ共有者の1人に送れば足りる（会社法126条3項・4項）。
  • 漏れた株主へのお詫びと送付の記録（日時・方法）を残す。

進め方

  1. 漏れた株主・返送された株主の一覧を作り、株主名簿と照合する。
  2. 漏れた株主に直ちに招集通知を送付する（速達・持参・メール承諾者なら電磁的方法）。
  3. 法定期間を満たすか、漏れの規模はどの程度かを弁護士と確認する。
  4. 必要なら、取締役会で総会日の変更を検討する。
  5. 返送分は封筒ごと保管し、名簿の住所と一致していることを記録する。
  6. 発送リストの作成手順を見直す。

注1名簿の住所に送れば到達したとみなされる 重要
  1. 条文
    会社法 126条1項 （株主に対する通知等）

    第1項　株式会社が株主に対してする通知又は催告は、株主名簿に記載し、又は記録した当該株主の住所（当該株主が別に通知又は催告を受ける場所又は連絡先を当該株式会社に通知した場合にあっては、その場所又は連絡先）にあてて発すれば足りる。

  2. 条文
    会社法 126条2項 （株主に対する通知等）

    第2項　前項の通知又は催告は、その通知又は催告が通常到達すべきであった時に、到達したものとみなす。

  3. やさしく言うと

    会社は、株主名簿の住所（株主が届け出た連絡先があればそこ）に宛てて通知を出せば足り、その通知は、普通なら届くはずの時に届いたものとみなされます。

  4. なぜこのルールか

    株主が多い会社では、株主が引っ越しても届け出ないことがあります。そのたびに会社が住所を調べなければならないとすると、総会の招集ができなくなるからです。

  5. この事例では

    宛先不明で返送された通知は、名簿の住所に宛てて期限内に出していれば適法な通知です。再送の義務はありませんが、株主から問い合わせがあれば丁寧に対応しましょう。

  6. 落とし穴

    株主から住所変更の届出を受けていたのに名簿に反映していなかった場合は、名簿の住所に送っても会社の落ち度とされるおそれがあります。

A

記載がない場合や、誤りが議案の判断に大きく影響する場合は、訂正文を郵送するなど、より確実な方法をとります。誤記の訂正にとどまるもの（生年月日、明らかな数値の誤り）は、内容を変える修正ではないので、取締役会の決議は通常不要です。
総会当日には、議長が訂正の内容を報告します。議案の内容そのものを変える必要がある誤りは、修正の周知では済まず、議案の撤回・修正や総会日程の見直しを検討します。

実務のポイント

  • 誤りの性質を分ける：①誤字・形式的誤り、②参考となる情報の誤り（略歴、数値）、③議案そのものの誤り（定款変更の条文、配当額）。③は弁護士と相談。
  • 招集通知に記載した周知方法（ウェブサイトのURL等）を確認し、そのとおりに掲載する。
  • 電子提供措置をとる会社は、電子提供措置事項の修正として、修正した旨と修正前の事項も掲載する（会社法325条の3第1項7号）。
  • 正誤表には、ページ・行、誤・正を明記する。
  • 監査済みの計算書類・事業報告の数値の誤りは、監査役・会計監査人に報告し、監査報告への影響を確認する。

進め方

  1. 誤りの箇所と正しい内容を確定し、原因を確認する。
  2. 誤りの性質（形式的か、議案の判断に影響するか）を判断する。必要なら弁護士・監査役に相談する。
  3. 招集通知に記載した方法で修正を周知する（ウェブ掲載、必要に応じ郵送）。
  4. 当日配布資料に正誤表を挟み、議長シナリオに訂正報告を入れる。
  5. 議事録に訂正の報告を記載する。

実務取締役会設置会社取締役会非設置会社監査役設置会社#
A
取締役会設置会社では、定時総会の招集通知に際して、取締役会の承認を受けた計算書類・事業報告（監査を受ける会社では監査報告・会計監査報告を含む）を株主に提供しなければなりません（会社法437条）。会計監査人設置会社で連結計算書類を作る場合は、連結計算書類も提供します（会社法444条6項）。
取締役会を置かない会社には、招集通知に添付する義務はありません。ただし、計算書類・事業報告（監査報告を含む）を総会の1週間前の日から本店に備え置き（会社法442条1項）、定時総会に提出して承認・報告を受けます（会社法438条）。
上場会社など電子提供措置をとる会社は、これらをウェブサイトに掲載することで提供します。

実務のポイント

  • 提供する範囲：計算書類（貸借対照表、損益計算書、株主資本等変動計算書、個別注記表）と事業報告。附属明細書は提供不要（備置きの対象）。
  • 監査役設置会社は監査報告を、会計監査人設置会社は会計監査報告も含める（会社法施行規則133条1項、会社計算規則133条1項）。
  • 監査を受けたものとみなされた場合（監査報告の期限徒過）は、その旨を記載した書面を提供する。
  • 取締役会の承認を受けた版と、招集通知に印刷した版が一致しているかを最終確認する。
  • 取締役会非設置会社でも、株主の理解のため任意に添付することは差し支えない。

進め方

  1. 計算書類・事業報告を作成し、監査役・会計監査人の監査を受ける。
  2. 取締役会（設置会社）で計算書類・事業報告を承認する。
  3. 招集通知に添付する書類の範囲を確認し、印刷・電子提供措置の原稿を作る。
  4. 招集通知とともに提供する（電子提供措置の会社はウェブ掲載）。
  5. 総会の2週間前の日（非設置会社は1週間前の日）から本店に備え置く。

実務取締役会設置会社非公開会社#
A
書面で招集通知を出すべき会社（取締役会設置会社、書面投票・電子投票を採る会社）でも、株主の承諾を得れば、書面に代えて電子メールなどの電磁的方法で通知を発することができます（会社法299条3項）。この場合、書面の通知を発したものとみなされます。
承諾は株主ごとに必要で、会社法施行令の定めに従い、あらかじめ用いる方法の種類・内容を示して書面又は電磁的方法で得ます。承諾しない株主には、従来どおり書面で送ります。
承諾した株主に参考書類や議決権行使書面を電磁的方法で提供することもできますが、株主から請求があれば書面を交付しなければなりません（会社法301条2項）。

実務のポイント

  • 承諾書には、送信方法（電子メール、添付ファイル形式）、送信先アドレス、承諾の撤回方法を記載する。
  • 承諾した株主から撤回の申出があれば、以後は書面で送る。
  • メールの送信日時が「発した」時になるので、送信記録を保存する。送信エラーは原因を確認する。
  • 株主名簿の住所に代わる「連絡先」として管理し、アドレス変更の届出の手順を決めておく。
  • 取締役会非設置会社で書面投票を採らない場合は、そもそも書面による通知が不要なので、承諾がなくてもメールで通知できる（記録は残す）。

進め方

  1. 承諾書の書式を作り、株主に送付する。
  2. 返送された承諾書を管理台帳に登録する（アドレス、承諾日）。
  3. 総会の招集時に、承諾株主にはメール、それ以外の株主には郵送で通知する。
  4. 送信記録・郵送記録を保存する。
  5. 撤回・アドレス変更の申出を台帳に反映する。

    承諾書を株主ごとにもらい、承諾した株主にはメールで、承諾していない株主には郵送で送ります。両方の方法が混在しても問題ありません。

注2参考書類・議決権行使書面の電磁的提供
  1. 条文
    会社法 301条2項 （株主総会参考書類及び議決権行使書面の交付等）

    第2項　取締役は、第二百九十九条第三項の承諾をした株主に対し同項の電磁的方法による通知を発するときは、前項の規定による株主総会参考書類及び議決権行使書面の交付に代えて、これらの書類に記載すべき事項を電磁的方法により提供することができる。ただし、株主の請求があったときは、これらの書類を当該株主に交付しなければならない。

  2. やさしく言うと

    メールでの通知を承諾した株主には、参考書類と議決権行使書面もメールなどで提供できます。ただし、株主から書面がほしいと言われたら、書面を渡さなければなりません。

  3. この事例では

    議決権行使書面をメールで送る場合、株主が賛否を記入して返送できる方法（PDFに記入して返信、専用サイト）を案内します。書面の交付請求に備え、印刷物も用意しておきましょう。

注3取締役会非設置会社では承諾がなくてもよい場合
  1. 条文
    会社法 299条2項 （株主総会の招集の通知）

    第2項　次に掲げる場合には、前項の通知は、書面でしなければならない。

    • 一　前条第一項第三号又は第四号に掲げる事項を定めた場合
    • 二　株式会社が取締役会設置会社である場合
  2. やさしく言うと

    書面での通知が必要なのは、取締役会設置会社と、書面投票・電子投票を採る会社だけです。

  3. この事例では

    取締役会がなく書面投票も採らない会社では、招集の方法に法律上の制限がないので、承諾がなくてもメールで通知できます。ただし、通知したことを証明できるよう送信記録を残しましょう（口頭・電話での招集の問いを参照）。

Q030

取締役会を置かない非公開の同族会社で、株主総会を電話や口頭で招集してもよいか。招集の期間や議題はどうなるか。

応用取締役会非設置会社非公開会社#
A
書面投票・電子投票を採らない限り、取締役会非設置会社の招集通知は書面である必要がなく、電話や口頭でも構いません（会社法299条2項の反対解釈）。
期間は総会の1週間前までが原則ですが、定款で1週間より短い期間（例：3日前まで）に短縮できます（会社法299条1項）。また、取締役会非設置会社では、通知していない事項も総会で決議できるとされています（会社法309条5項は取締役会設置会社のみに適用）。
もっとも、後日、「通知を受けていない」「その議題は聞いていない」と争われると、口頭では証明が困難です。メールやメッセージで日時・場所・議題を送り、記録を残すことを強く勧めます。株主全員の同意があれば招集手続自体を省略することもできます（会社法300条）。

実務のポイント

  • 招集の決定（日時・場所・議題等）は取締役が行う（取締役が複数なら過半数で決定するのが原則）。決定の記録を残す。
  • 定款に期間短縮の定めがあるかを確認する。定めがなければ1週間前まで。
  • 通知した事項以外を決議できるとしても、欠席した株主との紛争を避けるため、重要な議題は事前に知らせる。
  • 相続などで株主が増えたり、関係が悪化した株主がいる場合は、書面（内容証明郵便など）で通知し、証拠を残す。
  • 議事録には、招集の方法と日時を記載しておくと後日の証明に役立つ。

進め方

  1. 取締役が総会の日時・場所・議題を決定する（取締役の決定書を作る）。
  2. 定款の招集期間を確認し、期限までに全株主に通知する（メール・メッセージで記録を残す）。
  3. 株主全員の同意が得られるなら、招集手続の省略の同意書を取る方法も検討する。
  4. 総会を開き、議事録を作成する。

注1書面の通知が必要なのは限られた場合 重要
  1. 条文
    会社法 299条2項 一・二号 （株主総会の招集の通知）

    第2項　次に掲げる場合には、前項の通知は、書面でしなければならない。

    • 一　前条第一項第三号又は第四号に掲げる事項を定めた場合
    • 二　株式会社が取締役会設置会社である場合
  2. やさしく言うと

    招集通知を書面で出さなければならないのは、書面投票・電子投票を採る場合と、取締役会のある会社の場合です。それ以外の会社では、口頭や電話でも招集できます。

  3. なぜこのルールか

    取締役会のない会社は、株主が少なく顔見知りであることが多いので、形式的な書面を求めず、柔軟な招集を認めています。

  4. この事例では

    同族会社なら電話での招集も法律上は可能です。ただし、通知したことの証明が難しいので、メールやメッセージで日時・場所・議題を送り、記録を残してください。

注2招集期間は定款で短縮できる
  1. 条文
    会社法 299条1項 （株主総会の招集の通知）

    第1項　株主総会を招集するには、取締役は、株主総会の日の二週間（前条第一項第三号又は第四号に掲げる事項を定めたときを除き、公開会社でない株式会社にあっては、一週間（当該株式会社が取締役会設置会社以外の株式会社である場合において、これを下回る期間を定款で定めた場合にあっては、その期間））前までに、株主に対してその通知を発しなければならない。

  2. やさしく言うと

    非公開会社の招集期間は1週間ですが、取締役会のない会社では、定款で定めればさらに短くできます。

  3. この事例では

    定款に「会日の3日前までに」などの定めがあれば、その期間で足ります。定めがなければ1週間前までです。定款を確認せずに短い期間で招集すると、招集手続の違反になります。

注3通知していない議題も決議できるか
  1. 条文
    会社法 309条5項 （株主総会の決議）

    第5項　取締役会設置会社においては、株主総会は、第二百九十八条第一項第二号に掲げる事項以外の事項については、決議をすることができない。ただし、第三百十六条第一項若しくは第二項に規定する者の選任又は第三百九十八条第二項の会計監査人の出席を求めることについては、この限りでない。

  2. 条文
    会社法 295条1項 （株主総会の権限）

    第1項　株主総会は、この法律に規定する事項及び株式会社の組織、運営、管理その他株式会社に関する一切の事項について決議をすることができる。

  3. やさしく言うと

    通知した議題以外を決議できないという制限は、取締役会のある会社だけのルールです。取締役会のない会社の総会は、会社に関する一切の事項を決議できます。

  4. この事例では

    取締役会のない会社では、当日に出た議題も決議できると解されています。ただし、欠席した株主から不意打ちだと争われるおそれがあるので、重要な議題（役員の解任、定款変更など）は事前に通知しておくべきです。

  5. 落とし穴

    株主間に対立がある会社では、口頭の招集や当日の議題追加は紛争の火種になります。書面での通知と議題の明示を徹底してください。
